# gsc-auto-index

Автоматизация ручной отправки URL на индексацию в Google Search Console
(кнопка «Запросить индексирование» в инструменте проверки URL) сразу по **многим
отдельным Google-аккаунтам**, с соблюдением дневного лимита (по умолчанию 10 URL/аккаунт).

Работает **без Google API**: эмулирует ту же ручную кнопку через залогиненный браузер
(Playwright + постоянный профиль на каждый аккаунт). Логин в каждый аккаунт делается
руками **один раз**, дальше сессия переиспользуется.

## Как это устроено

- `src/login.mjs` — первичный вход. Открывает браузер с профилем аккаунта, ты сам
  логинишься (пароль, 2FA, капча). Сессия сохраняется в `profiles/<id>/`.
- `src/run.mjs` — прогон: по каждому аккаунту жмёт «Запросить индексирование» для
  списка URL, не больше дневного лимита, с рандомными задержками. Прогресс пишется в
  `state.json`, повторно за день один URL не отправляется.
- `config.json` — аккаунты, их свойства в GSC и списки URL.

## Установка

```bash
npm install          # ставит playwright и chromium
cp config.example.json config.json
# отредактируй config.json под свои аккаунты
```

### Формат `property` в config

- Domain property:    `"sc-domain:example.com"`
- URL-prefix property: `"https://www.example.com/"` (со слешем на конце, как в GSC)

## Использование

```bash
# 1) Один раз залогиниться в каждый аккаунт (откроется браузер):
npm run login            # по очереди все аккаунты
# или конкретный:
node src/login.mjs acc1

# 2) Прогон отправки на индексацию:
npm run run              # все аккаунты
node src/run.mjs acc1    # один аккаунт
```

## Расписание (раз в сутки)

Linux/macOS cron — каждый день в 10:00:
```
0 10 * * * cd /путь/к/проекту && /usr/bin/node src/run.mjs >> run.log 2>&1
```
Windows — Планировщик заданий, действие: `node src/run.mjs` в папке проекта.

> Для cron поставь `"headless": true` в config.json (без видимого окна).
> Но первый `login` всегда делай с видимым браузером (`headless:false`).

## Настройки (config.json)

| поле | смысл |
|------|-------|
| `dailyLimitPerAccount` | сколько URL слать на аккаунт в день (Google ~10) |
| `minDelayMs` / `maxDelayMs` | диапазон случайной паузы между действиями |
| `headless` | `false` — видимое окно (для отладки/логина), `true` — фоном |
| `accounts[].property` | свойство в Search Console |
| `accounts[].urls` | список URL для отправки |

## Важно / ограничения

- Это автоматизация интерфейса GSC, формально **против правил Google**. Используй на
  **своих** аккаунтах и не наглей с частотой — отсюда задержки и дневные лимиты.
- UI Search Console периодически меняется. Если кнопка перестала находиться —
  смотри скриншот в `screenshots/` и поправь регэкспы в `src/gsc.mjs`.
- `profiles/`, `state.json`, `config.json` не коммитятся (в `.gitignore`) — там
  сессии и данные аккаунтов.
- Если скрипт пишет «НЕ ЗАЛОГИНЕН» — сессия аккаунта истекла, перезапусти `login` для него.
