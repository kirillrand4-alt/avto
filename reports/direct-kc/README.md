# Отчёт «Директ КЦ» — сборка из выгрузок Roistat / Битрикс24

Готовый файл недели: `Отчет_Директ_КЦ_24.08-30.08.xlsx` (в корне репозитория).

## Исходные данные

Каталог задаётся переменной `SRC_DIR` (по умолчанию `src/`):

| Файл | Что берём |
|---|---|
| `project_294017_report_23_<период>.xlsx` | показы, визиты, расходы по уровням «ЯД сайт → Поиск/РСЯ → кампания» |
| `project_294017_report_default_<период>.xlsx` | сверка заявок и квал-лидов |
| `list_orders_294017_<период>.xlsx` | лиды и сделки: даты, статусы, стадии, суммы, мощность, оборудование, источник проверки |
| `Metriki-OM-KTs_2026.xlsx`, лист «Директ КЦ» | образец оформления (палитра, порядок строк, шапка недели) |

## Запуск

```bash
SRC_DIR=/путь/к/выгрузкам python3 build_report.py     # собрать книгу
python3 model.py                                       # диагностика модели
CALC_XLSX=recalc/<файл>.xlsx python3 verify.py         # 13 групп проверок
```

`verify.py` сверяет пересчитанную копию (её делает
`soffice --headless --convert-to xlsx`) с моделью: отсутствие формульных
ошибок, состав строк блоков, сходимость «аккаунт = сумма кампаний» и
«общий = сумма аккаунтов», совпадение текстовых выводов с числом Лид 3.

## Файлы

- `model.py` — загрузка выгрузок, фильтр источника проверки, Лид 1/2/3,
  привязка к РК, категории сделок, мощность, тип оборудования.
- `textgen.py` — текстовые выводы по сделкам с русской морфологией.
- `build_report.py` — сборка книги: «Директ КЦ», «Сделки», «Комментарий», «Методика».
- `verify.py` — проверки готового файла.

Правила расчёта продублированы на листе «Методика» готового отчёта.
