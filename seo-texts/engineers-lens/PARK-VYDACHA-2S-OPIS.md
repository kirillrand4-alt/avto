# 2-я сессия: выдача для влива в базу парка. Четыре файла, опись и честные границы

Собрано `park_vydacha_2s.py`. Все файлы лежат на дропе и в ветке
`claude/read-intro-section-hrstzj`, каталог `seo-texts/engineers-lens/`.

## Правило, соблюдённое без исключений

Требование владельца: «каждый контакт и факт должен доказываться ссылкой, которая ведёт на
доказательство; если ссылок несколько — должно быть несколько ссылок в базе».

* строк без ссылки в фактах, контактах и ОПО — **ноль**, они не пишутся вовсе;
* ссылка ведёт на КОНКРЕТНУЮ страницу (заключение ЭПБ, карточка, раздел), а не на список;
* рядом лежит ЦИТАТА — кусок текста, из которого взято утверждение;
* несколько источников = **несколько строк**, а не склейка через « | »: склейка теряет,
  какое поле откуда, и правило «перепроверить старое» перестаёт работать.

## 1. `PARK-VYDACHA-FAKTY-2S.csv` — 59 142 строки, 3 433 предприятия

Машина у предприятия, из реестра заключений ЭПБ Ростехнадзора (`monitor-pb.ru`).

```
inn ; predpriyatie ; tip ; marka_model ; zavodskoy_nomer ; sreda ; data ;
nomer_zaklucheniya ; srok_do ; status_sroka ; sila ; klass ; istochnik ; ssylka ; citata
```

```
с маркой ............ 29 421      с заводским номером ... 45 012
со сроком ЭПБ ....... 2 487       из них СРОК ИСТЁК ..... 1 351
без ссылки .......... 0
типы: ресивер 26 675 · компрессор 17 120 · воздуходувка 4 549 · компрессорная станция 3 109
      ВРУ 1 349 · осушитель 706 · генератор кислорода 586 · генератор азота · МКС · ПКС
```

**Что значит `tip` с приставкой «узел:»** — экспертиза на ДЕТАЛЬ при машине (холодильник
компрессора, ресивер компрессора). Машина у предприятия есть, но документ про узел.
Не выдавать как «у них стоит компрессор такой-то модели».

**`status_sroka = истёк`** — сильнейший повод: ресурс выработан, документ датирован.

## 2. `PARK-VYDACHA-KONTAKTY-2S.csv` — 23 543 строки, 2 805 предприятий

```
inn ; predpriyatie ; vid ; znachenie ; chelovek ; dolzhnost ; rol ; istochnik ; ssylka ; citata
```

```
по роли:  общий 20 842 · руководитель по ЕГРЮЛ 1 883 · не определена 380
          чужая 365 · закупки 40 · наша 33
с именем человека: 2 701
```

**Границы, которые прошу не стирать при вливе:**

* `общий` — телефон или почта ОРГАНИЗАЦИИ с карточки чеко. Это не ЛПР и не человек;
* `руководитель по ЕГРЮЛ` — имя и должность из DaData. Это первое лицо, а не технический
  ЛПР: покупает компрессор обычно не он;
* `чужая` — врач, кадры, бухгалтерия. **Строки НЕ удалены намеренно**: доказательство
  остаётся, а фильтр по роли обратим, удаление — нет;
* `наша` — 33 строки. Мало, и я это не прячу: технический ЛПР с личным мобильным по-прежнему
  самое узкое место.

## 3. `PARK-VYDACHA-PREDPRIYATIYA-2S.csv` — 2 978 карточек

```
inn ; predpriyatie ; nazvanie_egrul ; adres ; sayt ; rukovoditel ; dolzhnost_rukovoditelya ;
status_egrul ; vyruchka ; vyruchka_god ; okved_osnovnoy ; okvedov ; okved_kody ;
ssylka_checko ; ssylka_okved
```

* **выручка** — с карточки чеко, со ссылкой;
* **ОКВЭД — ВСЕ коды**, как просил владелец: `okved_kody` списком, `okvedov` числом.
  В среднем 33 кода на предприятие;
* **`status_egrul`** — из ЕГРЮЛ через DaData. **346 предприятий ликвидированы**: отсеются
  ДО обзвона, а не после;
* 17 карточек без ссылки на чеко — это те, где данные пришли только от DaData.

## Чего в выдаче НЕТ и почему — чтобы никто не искал

* **готовой витрины обзвона.** Роль проставлена только там, где источник её называет;
  «телефон организации» остаётся телефоном организации;
* **ОКВЭД у всех** — 924 предприятия из 2 978, сбор продолжается;
* **срока ЭПБ у всех** — 2 487 из 59 142: срок лежит в карточке заключения, каждая
  требует отдельного запроса, обход идёт;
* **садовых воздуходувок** — 3-я сессия нашла у себя 62 из 617, я померил у себя:
  **0 из 3 914**. Причина не везение: на садовую воздуходувку экспертизу промбезопасности
  не делают, класс до реестра ЭПБ не доходит.

## Ключ дедупа при вливе

```
факт:     inn + tip + marka_model + zavodskoy_nomer + data
контакт:  inn + znachenie (10 цифр для телефона)
```

Согласовано всеми тремя сессиями: заводской номер — единственное, что отличает машину от
такой же соседней, и без него два одинаковых компрессора схлопнутся в один факт.
