## tp_dogon.py
**Назначение.** Пересчитывает контактные телефоны в ранее скачанных карточках Tender.pro с помощью исправленного регулярного выражения. Используется для извлечения пропущенных номеров из комментариев без повторной загрузки данных из сети.
**Роль в системе.** Обогащение.
**Входы.** 
* `tp-kartochki.csv` (файла нет на диске)
**Выходы.** 
* `tp-kartochki.csv` (файла нет на диске)
**Провайдер.** не вызывает
**Раннер.** не вызывает
**Запуск.** `python3 tp_dogon.py [--suho]`
**По одному ИНН или списку.** Нет. В коде нет признаков работы по ИНН или списку ИНН, обработка идет по всему локальному файлу. Для работы по ИНН минимально требуется добавить аргумент командной строки для передачи ИНН и фильтрацию строк таблицы по этому полю.
**Зависимости.** Зависит от файла `tp-kartochki.csv`. От него зависит скрипт `tenderpro_lica.py`, который в дальнейшем подхватывает карточки с обновленными телефонами.
