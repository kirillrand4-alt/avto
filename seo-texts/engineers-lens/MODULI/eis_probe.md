## eis_probe.py

**Назначение.** Проверка гипотезы о наличии контактов технических специалистов в свободном тексте карточек закупок ЕИС (223-ФЗ). Скрипт скачивает карточки по реестровым номерам и извлекает содержимое блока дополнительной информации.

**Роль в системе.** Сбор из внешнего источника.

**Входы.** Файл со списком реестровых номеров закупок (передается через параметр `--ids`).

**Выходы.** `eis-probe.json` (файла нет на диске).

**Провайдер.** Не вызывает.

**Раннер.** `fetch_url`.

**Запуск.** `python3 eis_probe.py --ids <файл со списком регномеров> [--limit <число>] [--many] [--pachka <число>] [--threads <число>]`

**По одному ИНН или списку.** По списку реестровых номеров закупок - да. По ИНН - нет. Скрипт принимает реестровые номера закупок, а не ИНН организаций. Для запуска по ИНН необходимо добавить этап получения реестровых номеров закупок целевой компании.

**Зависимости.** В коде не видно.
