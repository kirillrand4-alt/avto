## nzl_razbor.py
**Назначение.** Модуль разбирает строки из отраслевых референс-листов НЗЛ с помощью языковой модели, извлекая структурированные данные о заказчиках, объектах и оборудовании. Это позволяет корректно обрабатывать сложную вёрстку, на которой ломаются обычные регулярные выражения.
**Роль в системе.** Обогащение.
**Входы.** Входной CSV-файл с референс-листом (`<nzl-otrasli.csv>`), число строк в коде не видно.
**Выходы.** Выходной CSV-файл с результатами разбора (`<out.csv>`), число строк в коде не видно.
**Провайдер.** Вызывает провайдера для извлечения сущностей из текста (конкретная модель в коде не видна). Модель запрашивает структурированный разбор строки референс-листа (заказчик, объект, год и другие поля) с условием возвращать «не знаю» при отсутствии данных.
**Раннер.** Не вызывает.
**Запуск.** `python3 nzl_razbor.py <nzl-otrasli.csv> <out.csv> [--batch 40] [--threads 15] [--ot 2005]`
**По одному ИНН или списку.** По списку (принимает на вход файл со строками референс-листа). Для запуска по конкретному ИНН потребуется добавить фильтрацию строк по ИНН на входе или возможность передавать ИНН отдельным аргументом CLI.
**Зависимости.** Зависимости от внешних файлов системы в коде не видны.
