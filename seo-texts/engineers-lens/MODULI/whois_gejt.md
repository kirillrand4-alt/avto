## whois_gejt.py
**Назначение.** Опрашивает сервис who.is для получения данных о владельцах доменов. Служит дополнительным источником WHOIS-информации на случай, если другие шлюзы отдают пустые поля по организации.
**Роль в системе.** Сбор из внешнего источника.
**Входы.** `/domeny.json` (файла нет на диске).
**Выходы.** `/whois4.json` (файла нет на диске).
**Провайдер.** не вызывает.
**Раннер.** не вызывает.
**Запуск.** `python whois_gejt.py --max-time`
**По одному ИНН или списку.** По списку доменов (есть признак работы по списку). Для прямого запуска по ИНН необходимо добавить предварительный модуль, который переводит ИНН компании в список её доменов.
**Зависимости.** Зависит от процесса, формирующего файл `/domeny.json`. От этого модуля зависят компоненты, обрабатывающие сохранённые WHOIS-данные из файла `/whois4.json`.
