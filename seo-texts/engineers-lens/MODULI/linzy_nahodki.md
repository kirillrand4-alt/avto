## linzy_nahodki.py

**Назначение.** Проверка собранных находок на предмет их опровержения. Скрипт считывает выдержки из указанных файлов и передает их провайдеру для оценки.

**Роль в системе.** Проверка.

**Входы.** Входной JSON-файл со списком находок (в докстроке указан пример `nahodki.json`; путей и количества строк в коде не видно).

**Выходы.** Выходной JSON-файл с вердиктами (в докстроке указан пример `verdikty.json`; путей и количества строк в коде не видно).

**Провайдер.** Вызывает провайдер для скептического разбора и оценки готовых выдержек из файлов. Наименование модели в коде не видно.

**Раннер.** Не вызывает.

**Запуск.** `python3 linzy_nahodki.py nahodki.json verdikty.json [--threads 8]`

**По одному ИНН или списку.** Да, модуль предназначен для работы со списком находок. Прямого параметра ИНН в аргументах нет. Чтобы запустить модуль по одному ИНН, требуется передать входной JSON-файл, содержащий находки только по этой компании.

**Зависимости.** В коде не видно.
