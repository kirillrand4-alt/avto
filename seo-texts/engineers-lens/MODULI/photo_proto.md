## photo_proto.py

**Назначение.** Интеграция проектных фотографий в готовый текстовый контент через API Fable. Служит прототипом для обработки фото-блока.

**Роль в системе.** Обогащение.

**Входы.** `gen/r2-fable-5/result-el-hansmann.json` (7 строк).

**Выходы.** `gen/r2-fable-5/result-el-hansmann-FOTO.json` (7 строк).

**Провайдер.** Вызывает провайдера для работы с API Fable. Конкретные модели в коде не видны.

**Раннер.** Не вызывает.

**Запуск.** Команда запуска без ключей (аргументы командной строки в коде не видны).

**По одному ИНН или списку.** Нет. В коде отсутствует признак работы по списку или передачи ИНН. Для реализации такой функциональности необходимо добавить прием параметров командной строки (ИНН или путь к списку) и сделать пути к файлам динамическими.

**Зависимости.** Зависит от этапа, создающего исходный файл `gen/r2-fable-5/result-el-hansmann.json`. Кто зависит от результата работы этого модуля, в коде не видно.
