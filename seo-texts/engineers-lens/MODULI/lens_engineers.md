## lens_engineers.py
**Назначение.** Генерация идей и аналитических гипотез для поиска инженеров РФ и их текущих работодателей через API провайдера. Запускает параллельную обработку задач разными методами (линзами) с последующим синтезом результатов.
**Роль в системе.** Обогащение.
**Входы.** Входные файлы с данными конкретных предприятий в коде не видны. Из связанных файлов на диске присутствуют SUMMARY.md (201 строк) и run-stats.json (97 строк).
**Выходы.** Из найденных файлов на диске: SUMMARY.md (201 строк), run-stats.json (97 строк). В докстроке также упоминается сохранение результатов в директорию engineers-lens/.
**Провайдер.** Вызывает провайдерский API (функции `ask`, `synthesize`). Конкретные названия моделей в коде не видны.
**Раннер.** Не вызывает.
**Запуск.**
`python3 lens_engineers.py [--only <линзы>] [--no-synth] [--synth-only] [--workers <количество>]`
**По одному ИНН или списку.** Да, признак работы по списку есть. Для запуска по конкретному ИНН в ключах командной строки нет явного аргумента, необходимо добавить передачу параметра ИНН в CLI.
**Зависимости.** Связан с файлами SUMMARY.md и run-stats.json. Другие зависимости по путям в коде не видны.
