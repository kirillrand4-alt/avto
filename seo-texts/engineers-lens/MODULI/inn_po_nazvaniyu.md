## inn_po_nazvaniyu.py

**Назначение.** Поиск ИНН организации по ее названию в локальной базе данных с фильтрацией родовых слов и контролем точности. Использование модуля позволяет сопоставлять текстовые названия компаний из сторонних источников с конкретными ИНН.

**Роль в системе.** Обогащение.

**Входы.** 
* `520847fd-7699-5483-869b-cf6d49851f67/scratchpad/master-base.sqlite` (файла нет на диске)
* `engineers-lens/centro/epb-centro-vse.csv` (7751 строк)
* `engineers-lens/centro/epb-vozdushnye.csv` (2308 строк)
* Входной файл со списком названий (указывается как аргумент командной строки, например `names.txt`)

**Выходы.** 
* Выходной файл с результатами сопоставления (указывается как аргумент командной строки, например `out.csv`)

**Провайдер.** не вызывает.

**Раннер.** не вызывает.

**Запуск.** 
* Замер точности: `python3 inn_po_nazvaniyu.py zamer`
* Обработка списка: `python3 inn_po_nazvaniyu.py razresh <names.txt> <out.csv>`

**По одному ИНН или списку.** Модуль работает по списку компаний (принимает текстовый файл на вход). Прямого запуска для проверки одного названия или ИНН через аргументы CLI не предусмотрено. Чтобы добавить поддержку работы по одному названию/ИНН, минимально требуется добавить обработку нового аргумента командной строки для передачи единичного значения и вывод найденных данных в консоль.

**Зависимости.** 
* Зависит от: базы `scratchpad/master-base.sqlite`, а также файлов `epb-centro-vse.csv` и `epb-vozdushnye.csv`.
* Кто зависит от него: в коде не видно.
