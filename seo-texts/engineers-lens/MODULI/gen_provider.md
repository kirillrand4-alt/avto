## gen_provider.py

**Назначение.** Модуль генерирует SEO-тексты через эндпоинт провайдера с автоматической доводкой по проверке качества (QA).
**Роль в системе.** Обогащение.
**Входы.** 
* `gen/STYLE-GUIDE-PODGOTOVKA.md` (190 строк)
* `gen/STYLE-GUIDE.md` (180 строк)
* `projects-index.json` (15260 строк)
**Выходы.** Путь к файлу результата передается через аргумент командной строки `--out` (в коде фиксированные пути выходов не видны).
**Провайдер.** Вызывает провайдера. В докстроке упоминается Opus 4.8, присутствует аргумент `--model` (список `modeli` во входных данных пуст).
**Раннер.** не вызывает.
**Запуск.** `python3 gen_provider.py <slug> [--payload FILE --out FILE --min-price N --no-price]` (поддерживаемые аргументы: `--etalon`, `--guide`, `--min-price`, `--model`, `--no-price`, `--out`, `--payload`).
**По одному ИНН или списку.** Да. Присутствует признак работы по списку, а также запуск по отдельному объекту (`<slug>`).
**Зависимости.** Зависит от файлов `gen/STYLE-GUIDE-PODGOTOVKA.md`, `gen/STYLE-GUIDE.md` и `projects-index.json`. Кто зависит от модуля: в коде не видно.
