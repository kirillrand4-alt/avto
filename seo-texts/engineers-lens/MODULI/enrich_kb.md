## enrich_kb.py
**Назначение.** Параллельное извлечение фактов из листов прайс-листов коммерческих центров через внешнее Fable API для пополнения базы знаний.
**Роль в системе.** Обогащение.
**Входы.** `katalogi/relevant-sheets.json` (файла нет на диске).
**Выходы.** `katalogi/kb-enrichment.json` (файла нет на диске).
**Провайдер.** Вызывает провайдер (Fable API), конкретные модели в коде не видно.
**Раннер.** Не вызывает.
**Запуск.** `python enrich_kb.py` (ключи командной строки в коде не видно).
**По одному ИНН или списку.** Нет. В коде отсутствует признак работы по ИНН или по списку компаний. Для поддержки этой функции требуется добавить аргументы командной строки (прием ИНН) и логику фильтрации обрабатываемых листов по переданным организациям в функции `worker`.
**Зависимости.** Зависит от входного файла `katalogi/relevant-sheets.json`. Кто зависит от выходных данных этого модуля, в коде не видно.
