## patenty_harvest.py
**Назначение.** Скрипт собирает данные о патентах организаций через API Google Patents, связывая ФИО изобретателей с юридическими лицами. Это используется для выявления и проверки аффилированных физических лиц предприятий.
**Роль в системе.** Сбор из внешнего источника.
**Входы.** Входной CSV файл с колонками `inn_zakazchika` и `zakazchik` (точный путь и количество строк в коде не видно).
**Выходы.** Выходной CSV файл (точный путь и количество строк в коде не видно).
**Провайдер.** Не вызывает.
**Раннер.** Не вызывает.
**Запуск.** `python3 patenty_harvest.py <predpriyatiya.csv> <out.csv> [--limit 40] [--pauza 4]`
**По одному ИНН или списку.** По списку. Прямой запуск по одиночному ИНН не поддерживается, так как скрипт требует на вход CSV файл. Для работы с единичным ИНН необходимо добавить обработку соответствующего флага командной строки или формировать CSV файл из одной строки.
**Зависимости.** В коде не видно.
