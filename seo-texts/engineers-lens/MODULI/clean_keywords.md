## clean_keywords.py
**Назначение.** Очистка и фильтрация вебмастерских поисковых фраз через Fable API с отбором релевантных запросов для поиска по сайту компрессорного магазина.
**Роль в системе.** Обогащение.
**Входы.** В коде не видно.
**Выходы.** inventory/keywords-clean.json (файла нет на диске).
**Провайдер.** Вызывает провайдера (в докстроке указан Fable API), конкретные модели в коде не видны.
**Раннер.** Не вызывает.
**Запуск.** `python clean_keywords.py` (аргументы командной строки в коде не видны, в коде объявлена функция main).
**По одному ИНН или списку.** Нет, признаков работы по ИНН или списку организаций нет. Чтобы добавить запуск по ИНН, минимально требуется ввести аргументы командной строки для приема ИНН или файла со списком и передавать их в функцию main для привязки ключевых слов к конкретной компании.
**Зависимости.** В коде не видно.
