## mpb_harvest.py
**Назначение.** Выгрузка реестра заключений экспертизы промышленной безопасности с сайта monitor-pb.ru в CSV-файл. Модуль ищет оборудование с истекающим сроком эксплуатации по поисковым запросам и извлекает ИНН заказчиков для выявления потребностей в замене техники.
**Роль в системе.** Сбор из внешнего источника.
**Входы.** В коде не видно (входные файлы не используются, данные собираются с внешнего сайта).
**Выходы.** В коде не видно (путь к выходному CSV-файлу передается через аргументы командной строки).
**Провайдер.** Не вызывает.
**Раннер.** Не вызывает.
**Запуск.** `python3 mpb_harvest.py "<поисковый запрос>" expiring <out.csv> [--max-pages <число>]`
**По одному ИНН или списку.** Да, есть признак работы по списку. При этом исходный поиск на сайте выполняется по названиям оборудования. Чтобы запускать модуль точечно по одному ИНН, необходимо добавить передачу ИНН в поисковый запрос или реализовать фильтрацию получаемых результатов по ИНН.
**Зависимости.** В коде не видно.
