## svesti_nazvaniya.py

**Назначение.** Сопоставляет исторические и советские названия предприятий с их современными наименованиями с помощью языковой модели. Это нужно для связывания архивных референс-листов с актуальными юридическими лицами.

**Роль в системе.** Обогащение.

**Входы.** В коде явные пути не зафиксированы. Входной файл со списком заказчиков передается через аргумент командной строки `<zakazchiki.json>`.

**Выходы.** В коде явные пути не зафиксированы. Результат сохраняется в файл, передаваемый через аргумент командной строки `<out.csv>`.

**Провайдер.** Вызывает провайдера (конкретные модели в коде не видны). Спрашивает современное название компании и страну по ее старому наименованию.

**Раннер.** Не вызывает.

**Запуск.** `python3 svesti_nazvaniya.py <zakazchiki.json> <out.csv> [--batch 25] [--threads 15]`

**По одному ИНН или списку.** По списку. Модуль работает с файлом наименований. Для запуска по одному объекту требуется либо сформировать входной файл из одной записи, либо добавить поддержку одиночного аргумента в командной строке. Поисковым идентификатором выступает название, а не ИНН.

**Зависимости.** В коде не видно.
