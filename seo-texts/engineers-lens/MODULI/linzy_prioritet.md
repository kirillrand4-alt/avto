## linzy_prioritet.py
**Назначение.** Модуль отправляет данные с рассчитанным приоритетом внешнему провайдеру для анализа формулы весов, поиска ошибок, определения недостающих переменных и проверки корректности ранжирования.
**Роль в системе.** Проверка.
**Входы.** 
- `SVODNAYA-centrobezhnye.csv`: 6582 строк.
**Выходы.** В коде не видно.
**Провайдер.** Вызывает провайдера (конкретная модель в коде не видна). Запрашивает разбор живых строк с приоритетами по четырем направлениям: ошибки и перекосы формулы, недостающие переменные, переоценка весов и проверка порядка элементов.
**Раннер.** не вызывает.
**Запуск.** `python3 linzy_prioritet.py [--threads <число>] [--only <группы>]`
**По одному ИНН или списку.** Нет. Признак работы по списку отсутствует, модуль обрабатывает фиксированный файл `SVODNAYA-centrobezhnye.csv`. Для реализации работы по ИНН необходимо добавить параметры командной строки для передачи ИНН и фильтрацию строк перед отправкой провайдеру.
**Зависимости.** Зависит от файла `SVODNAYA-centrobezhnye.csv`. Кто зависит от этого модуля: в коде не видно.
