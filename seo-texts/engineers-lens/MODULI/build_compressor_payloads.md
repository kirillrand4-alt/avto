## build_compressor_payloads.py

**Назначение.** Формирует структурированные данные (payloads) для страниц компрессорного оборудования, выполняя роутинг по подтипам, определение фасетов, макетов и привязку кейсов проектов.

**Роль в системе.** Сборка витрины.

**Входы.**
* `GUIDE.md` (файла нет на диске)
* `brand-facts-clean.json` (файла нет на диске)
* `gen/STYLE-GUIDE-ELEKTRO.md` (183 строк)
* `gen/STYLE-GUIDE.md` (180 строк)
* `projects-index.json` (15260 строк)
* `projects-photos.json` (56 строк)

**Выходы.** `gen/payload-<slug>.json` (динамические файлы по шаблону из докстроки, на диске не указаны).

**Провайдер.** Не вызывает.

**Раннер.** Не вызывает.

**Запуск.** `python build_compressor_payloads.py [--limit LIMIT]`

**По одному ИНН или списку.** Нет. Модуль предназначен для обработки продуктовых страниц компрессоров, а не компаний. Признак работы по списку страниц присутствует (поддерживается аргумент `--limit`). Чтобы запускать модуль по ИНН, необходимо добавить связь компрессорных данных с ИНН организаций и передачу ИНН через аргументы командной строки.

**Зависимости.**
* Зависит от: `gen/STYLE-GUIDE-ELEKTRO.md`, `gen/STYLE-GUIDE.md`, `projects-index.json`, `projects-photos.json` (а также ненайденных `GUIDE.md` и `brand-facts-clean.json`).
* Кто зависит от него: в коде не видно.
