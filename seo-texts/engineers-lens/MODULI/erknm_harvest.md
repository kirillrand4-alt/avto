## erknm_harvest.py
**Назначение.** Скачивает открытые данные ЕРКНМ и извлекает сведений о контрольных мероприятиях надзорных органов по заданным ИНН предприятий.
**Роль в системе.** Сбор из внешнего источника.
**Входы.** Файл со списком ИНН `<inn.txt>` (в коде путь не зафиксирован, файла нет на диске).
**Выходы.** CSV-файл с выгрузкой `<out.csv>` (в коде путь не зафиксирован, файла нет на диске).
**Провайдер.** Не вызывает.
**Раннер.** Не вызывает.
**Запуск.** `python3 erknm_harvest.py <inn.txt> <out.csv> [--god 2026] [--mesyacy 1,2,3]` (доступные аргументы: `--god`, `--mesyacy`).
**По одному ИНН или списку.** По списку (признак работы по списку равен true). Для запуска по одному ИНН требуется передать файл, содержащий одну строку с нужным ИНН.
**Зависимости.** В коде не видно.
