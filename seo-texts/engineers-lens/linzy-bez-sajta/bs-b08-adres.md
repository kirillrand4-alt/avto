Адрес — это метка для поиска, не прямой источник контактов. Польза есть, но она двухэтапная: сначала ФИО с должностью, потом телефон отдельно.

**Что работает:**

**1. ЕРКНМ (акты проверок)**
Выгрузка контрольных мероприятий есть. В актах проверок Роспотребнадзора, Ростехнадзора, экологических надзоров указывают присутствовавших: обычно директор + главный инженер или главный механик.

Опора: есть выгрузки ЕРКНМ в списке доступных источников.

Выход: 80-150 ФИО с должностями из 502 (15-30%). Телефонов там нет — придется звонить на общий номер (396 известны) и просить переключить на найденного человека.

Работа: парсинг актов по ИНН из выгрузки ЕРКНМ, извлечение ФИО через провайдерский API для чтения текста/сканов. Затем обзвон.

Цена: 1-2 дня на автоматизацию сбора ФИО, потом ручной обзвон по общим номерам.


**2. Локальные новости через поиск**
Водоканалы попадают в местные СМИ при авариях, ремонтах, запусках объектов. Цитируют технических людей: "главный инженер МУП Водоканал Иванов сообщил".

Опора: inn=7705013033 (ГУП Мосводосток) — крупное предприятие, точно есть в новостях. inn=6623034200 (Водоканал-НТ, Нижний Тагил, 2 млрд выручки) — тоже должны быть новости.

Запрос: "название из name_obzvon + регион + (авария OR ремонт OR очистные сооружения)".

Выход: 50-100 ФИО с должностями из 502 (10-20%). Телефонов в новостях нет.

Работа: автоматизация через обход сайтов с антидетект-браузером, извлечение ФИО из текста. Потом обзвон.

Цена: 2-3 дня на настройку поиска + обзвон.


**3. Социальные сети (ВКонтакте, Одноклассники)**
Люди указывают место работы. Поиск: "name_obzvon + region_iz_obzvona + должность (инженер OR механик OR энергетик)".

Опора: inn=7705013033 sajt_iz_obzvona=https://vk.com/mosvodostok, inn=6623034200 sajt_iz_obzvona=https://vk.com/vodokanal_nt — есть группы. Подписчики могут быть сотрудниками.

Выход: 20-50 профилей с указанием должности из 502 (4-10%). Телефон в профиле — редко (5-10% от найденных), но можно написать в личку.

Работа: автоматизация поиска через браузер, парсинг профилей. Если телефона нет — писать в личку или искать того же человека через общий номер.

Цена: 1-2 дня на автоматизацию, потом переписка или обзвон.


**Что не работает (иллюзии):**

**Карты (Яндекс, Google, 2ГИС):** Дают общие телефоны организации, которые уже есть (396 из 502). Технических людей там не указывают.

**Соседние юрлица:** Водоканалы стоят на территории очистных сооружений или в отдельных зданиях, не в бизнес-центрах. Смотрю строки: inn=7705013033 адрес "ул. Новокузнецкая, д. 26/8, стр. 1" (административное здание), inn=8904046652 "г. Новый Уренгой, ул. Юбилейная" (специализированный объект). Соседи не помогут.

**Филиалы:** В ЕГРЮЛ можно найти, но у водоканалов филиалов почти нет — один юрлиц на город. Смотрю строки: все 502 — это самостоятельные организации, не филиалы.


**Ранжирование по "людей с телефоном / труд":**

1. **ЕРКНМ + обзвон:** 80-150 ФИО за 1-2 дня автоматизации + обзвон. Лучшее соотношение.
2. **Социальные сети:** 20-50 профилей за 1-2 дня, но телефонов мало, нужна переписка.
3. **Новости + обзвон:** 50-100 ФИО за 2-3 дня + обзвон. Хуже ЕРКНМ по трудозатратам.

Адрес полезен как фильтр для сужения поиска (регион + название), но сам контакт он не даст. Все пути ведут к двухэтапной схеме: ФИО + должность из открытых источников, телефон через обзвон общих номеров с просьбой переключить.
