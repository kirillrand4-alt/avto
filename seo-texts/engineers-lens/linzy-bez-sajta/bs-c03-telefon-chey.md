## ЕРКНМ: акты проверок

**В актах проверок Роспотребнадзора, Росприроднадзора упоминают ответственных лиц с должностями.**

Действие: запросить выгрузку ЕРКНМ по 502 ИНН за 3-5 лет, прогнать PDF через провайдерский API для извлечения: ФИО + должность + телефон.

Оценка: 30-50% предприятий (150-250) имеют проверки. В 10-20% актов есть телефоны ответственных (15-50 техников). Работа: 1 день настройки + автопрогон = 15-50 телефонов.

## Мобильные vs городские

**Мобильные телефоны (9XX) чаще личные, городские (код региона) — общие:**
