**Порядок работ по 502 водоканалам без сайтов:**

## 1. Пересечение с базой Tender.pro
**Охват:** все 502  
**Выход:** 15-30 человек (оценка при ~5-10% пересечении с имеющимися 306 техническими людьми)  
**Труд:** 1 час (сопоставление ИНН)

База уже есть, нужно только проверить совпадения по ИНН. Моментально даёт готовых людей с телефонами.

## 2. Прямой обзвон по имеющимся телефонам
**Охват:** 396/502 (у кого есть telefony_iz_obzvona)  
**Выход:** 200-300 человек (при проходимости 50-75%)  
**Труд:** 40-60 часов звонков

Примеры телефонов из строк:
- inn=7705013033: +7 495 923-29-01
- inn=6445029380: +7 927 118-14-19
- inn=8904046652: +7 834 992-51-05

Секретарь переключает на главного инженера, записываете ФИО и прямой номер. Лучшее соотношение результат/труд для массового охвата.

## 3. Парсинг ЕРКНМ (акты проверок)
**Охват:** проверить сколько из 502 есть в выгрузке  
**Выход:** 30-80 человек (если в актах фигурируют должностные лица)  
**Труд:** 8-12 часов (настройка парсинга + обработка)

Выгрузка есть. В актах проверок Роспотребнадзора по водоканалам должны упоминаться ответственные: "главный инженер Иванов И.И. пояснил...". Нужно проверить наличие таких упоминаний в актах.

**Не проверено:** доля актов с упоминанием конкретных ФИО и должностей.

## 4. Парсинг планов закупок 223-ФЗ
**Охват:** проверить сколько из 502 размещают планы  
**Выход:** 20-50 человек (если указаны контактные лица)  
**Труд:** 6-10 часов (парсинг + фильтрация)

Выгрузка есть. В планах и извещениях может быть контактное лицо. Фильтр: закупки по ОКВЭД 37.00 или со словами "компрессор", "воздуходувка", "аэротенк".

**Не проверено:** указывают ли водоканалы в планах 223-ФЗ конкретных ответственных с должностями.

## 5. Email-рассылка с просьбой о контакте
**Охват:** 349/502 (у кого есть pochty_iz_obzvona)  
**Выход:** 10-25 человек (отклик 3-7%)  
**Труд:** 3 часа (подготовка письма + отправка)

Примеры почт из строк:
- inn=7705013033: secretar-cra@mosvodostok.ru
- inn=6445029380: blaqomup2024@mail.ru
- inn=8904046652: uqyk@mail.ru

Письмо: "Коллеги, по вопросу модернизации воздуходувок аэротенков. Подскажите контакт главного инженера/механика?" Низкий отклик, но минимальный труд.

**Итого порядок:**  
Tender.pro (1 час, 15-30 чел) → обзвон (50 часов, 200-300 чел) → ЕРКНМ (10 часов, 30-80 чел) → планы 223-ФЗ (8 часов, 20-50 чел) → рассылка (3 часа, 10-25 чел).

Первые два пункта дадут 215-330 человек за 51 час. Остальное — если нужно добить покрытие.
