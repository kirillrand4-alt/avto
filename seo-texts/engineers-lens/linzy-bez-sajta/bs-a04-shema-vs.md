## 1. ЕРКНМ — протоколы проверок водоканалов

**Механика**: В выгрузке ЕРКНМ есть протоколы Роспотребнадзора, Ростехнадзора. В каждом протоколе указываются должностные лица проверяемой организации — часто с ФИО и должностью. Главный инженер или начальник очистных могут присутствовать при проверке.

**Связка с ИНН**: Проверки привязаны к ИНН напрямую, ошибки быть не может.

**Что делать**:
- Отфильтровать из ЕРКНМ все проверки по 502 ИНН
- Для каждой проверки прочитать протокол (PDF/скан через API чтения)
- Извлечь ФИО и должности представителей организации
- Отобрать технические роли (главный инженер, главный механик, начальник цеха, начальник очистных)
- Телефоны не будут в протоколе, останется звонить на общий номер предприятия и спрашивать человека по ФИО

**Оценка**: 
- Нужен замер на 20-30 ИНН: сколько из них имеют проверки в ЕРКНМ за последние 3 года, в скольких протоколах указаны должностные лица, в скольких это технические роли
- Трудоемкость: 502 запроса к ЕРКНМ + чтение PDF (автоматизируется через API)
- Выход телефонов: 0 (но ФИО для целевого обзвона)

**Проверочный замер**: Взять 20 крупнейших ИНН из списка, проверить наличие проверок за 2022-2024.

## 2. Схемы водоснабжения и водоотведения на сайтах администраций

**Механика**: По 416-ФЗ схема утверждается администрацией, публикуется на её сайте. В схеме описывается оператор (организация), состояние систем, планы развития. В разделе про эксплуатацию может быть: контакты диспетчерской, аварийной службы, производственного отдела — иногда с ФИО и телефонами.

**Связка с ИНН**: 
- По адресу из ЕГРЮЛ определяется муниципалитет
- На сайте администрации ищется схема
- В схеме должно быть указано предприятие по имени (МУП/ГУП "Водоканал") или по ИНН
- Сопоставление вручную по имени, возможна ошибка при совпадении имён

**Что делать**:
- Для каждого из 502 извлечь муниципалитет из адреса ЕГРЮЛ
- Найти сайт администрации (через поиск или известные домены)
- На сайте найти схему водоснабжения (обычно в разделе ЖКХ, документы, градостроительство)
- Прочитать PDF/скан схемы
- Найти раздел про оператора/эксплуатацию
- Извлечь ФИО и контакты

**Оценка**:
- Покрытие: потенциально 502/502 (каждое поселение обязано иметь схему), но:
  - Не все публикуют
  - Часть публикует только титульный лист
  - Часть публикует скан низкого качества
- Выход людей с телефонами: неизвестно, нужен замер
- Трудоемкость: высокая
  - 502 поиска сайтов администраций
  - 502 поиска схем на сайтах
  - 502 чтения документов (PDF/скан, 50-200 страниц каждая)
  - 502 сопоставления оператора из схемы с ИНН предприятия

**Проверочный замер**: Взять 10 разных регионов и типов поселений (город, район, село), для каждого найти сайт администрации и схему, проверить:
- Сколько схем опубликовано
- Сколько схем содержат ФИО технических специалистов
- Сколько схем содержат телефоны этих специалистов

## 3. Контракты 44-ФЗ на ЕИС с участием водоканалов

**Механика**: Водоканалы как заказчики размещают контракты на ремонт, поставку оборудования, проектирование. В контракте указываются представители заказчика. Но это чаще снабженцы, юристы, а не технари. Однако для технических закупок (ремонт компрессоров, модернизация очистных) могут быть указаны главный инженер или главный механик.

**Связка с ИНН**: Поиск контрактов по ИНН заказчика на ЕИС.

**Что делать**:
- Для каждого из 502 ИНН найти контракты на ЕИС, где организация — заказчик
- Отфильтровать технические закупки (по ОКПД: оборудование, ремонт, эксплуатация очистных, компрессоры)
- Прочитать контракт (PDF)
- Извлечь ФИО представителей заказчика
- Отобрать технические роли по должности

**Оценка**:
- Покрытие: зависит от того, сколько водоканалов размещают закупки 44-ФЗ. МУПы обязаны, ООО — нет. Из строк: много МУП, ГУП, ГБУ — должны размещать.
- Выход людей с телефонами: телефоны в контрактах обычно есть (телефон представителя заказчика)
- Трудоемкость: средняя
  - 502 запроса к ЕИС
  - Фильтрация по предмету закупки
  - Чтение отфильтрованных контрактов (но не все 502 имеют технические закупки)

**Проблема**: ЕИС не индексирует текст вложений (из контекста). Значит, поиск по содержимому контракта невозможен. Можно искать только по реквизитам заказчика и названию/ОКПД закупки.

**Проверочный замер**: Взять 20 МУП/ГУП из списка, для каждого найти контракты за 2023-2024 с ОКПД по компрессорам/очистным, прочитать 3-5 контрактов, проверить наличие ФИО и телефонов технических специалистов в представителях заказчика.

## 4. Региональные порталы ЖКХ и новости муниципалитетов

**Механика**: 
- Некоторые регионы ведут публичные реестры организаций ЖКХ
- Новости администраций и местных СМИ упоминают специалистов водоканалов при авариях, ремонтах, запуске объектов
- Пресс-релизы, интервью

**Связка с ИНН**: По имени организации и региону, сопоставление вручную.

**Что делать**:
- Для каждого региона проверить наличие портала ЖКХ с реестрами
- Для каждого водоканала искать упоминания в новостях администрации (через поиск на сайте или через Яндекс/Google с фильтром по сайту)
- Извлекать ФИО из текстов

**Оценка**:
- Покрытие: низкое, не все регионы ведут реестры, не про все водоканалы пишут новости
- Выход людей с телефонами: телефонов в новостях обычно нет
- Трудоемкость: очень высокая (502 организации * поиск по каждой)

**Вывод**: Низкая эффективность, только как дополнение к основному методу.

## Рекомендация по приоритетам

1. **Сначала ЕРКНМ** — быстрый замер на 30 примерах, чтобы понять выход ФИО. Если 50%+ проверок дают технические роли — запускать полный обход 502.

2. **Параллельно контракты ЕИС** — замер на 20 МУП/ГУП с фильтром по техническим ОКПД. Если дают телефоны техническ специалистов — обход остальных МУП/ГУП из 502.

3. **Если первые два не дают нужного покрытия — схемы водоснабжения**, но с пониманием высокой трудоемкости. Сначала замер на 10 примерах разных типов поселений.

4. **Региональные источники** — точечно, по мере обхода, не как основной метод.

## Конкретный план первого шага

**Замер ЕРКНМ на примерах**:
- Взять 30 ИНН: 10 крупнейших (выручка >1 млрд), 10 средних (100-500 млн), 10 мелких (<100 млн)
- Для каждого проверить в ЕРКНМ наличие проверок за 2022-2024
- Для найденных проверок прочитать протоколы
- Посчитать: из 30 сколько имеют проверки, из них в скольких протоколах есть ФИО, из них сколько технических ролей

**Примеры для замера** (беру из строк выше):
1. 7705013033 (МОСВОДОСТОК, 27.6 млрд) — Москва
2. 6445029380 (БЛАГОУСТРОЙСТВО, 15 млрд) — Саратовская обл.
3. 8904046652 (УГВК, 2.3 млрд) — ЯНАО
4. 6623034200 (ВОДОКАНАЛ-НТ, 2 млрд) — Свердловская обл.
5. 4707028015 (КВК, 1.7 млрд) — Ленинградская обл.
...и так далее до 30.

- Сколько людей с ФИО можно получить из ЕРКНМ на 502 предприятия
- Трудоемкость в человеко-часах
- Людей с ФИО на единицу труда
