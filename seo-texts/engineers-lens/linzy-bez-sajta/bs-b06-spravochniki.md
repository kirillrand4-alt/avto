**РАВВ и региональные ассоциации водоканалов — не проверено, но маловероятно.**

Российская ассоциация водоснабжения и водоотведения (НП "РАВВ") существует, публикует список членов. Но в открытом доступе там обычно название организации + директор, технические специалисты не публикуются. Это не справочник кадров, а список юрлиц.

**Признак проверки за один заход:**  
Открыть сайт РАВВ (или регионального объединения), найти раздел «Члены» / «Реестр участников», посмотреть карточку любой организации. Если там только название + директор + общий телефон — бесполезно. Если есть поле «Главный инженер» или «Технический директор» с телефоном — работает.

Ожидаемый результат: **0–20 человек на 502 предприятия, 1–2 часа работы.**  
Причина: не все водоканалы — члены ассоциаций, и даже если есть — публикация технических контактов не стандартная практика.

**Что может дать больше — акты проверок из ЕРКНМ (у вас есть выгрузка).**

Росприроднадзор, Роспотребнадзор, Ростехнадзор проверяют водоканалы. В актах проверок часто пишут: «присутствовали: главный инженер Иванов И.И., начальник очистных сооружений Петров П.П.». Иногда с телефонами для связи.

**Признак проверки:** взять выгрузку ЕРКНМ, отфильтровать по 502 ИНН, найти акты за последние 2–3 года, извлечь из текста блоки вида «присутствовали» + парсинг ФИО + должностей. Если акты в PDF — через API провайдера (у вас есть).

**Ожидаемый результат:** 50–150 человек на 502 предприятия (покрытие зависит от частоты проверок по водоканалам), 4–8 часов работы (автоматизация извлечения из текстов).
