## Концессия: как определить оператора

**Признаки передачи:**
- "РВК", "Росводоканал" в названии (7730263559)
- ООО/АО вместо МУП при водоканальных ОКВЭДах (37.00 + 36.00)
- Юрадрес Москва/СПб при объекте в регионе
- Учредитель — крупный оператор (смотри ЕГРЮЛ → состав участников)

**Как найти настоящего держателя:**
Проверить учредителей через ЕГРЮЛ по ИНН. Если там АО "Росводоканал" (ИНН 7701983370) или ООО "РВК-Центр" — это оператор, решение у него. По 502 строкам: РВК-ТИХОРЕЦК (7730263559) — явный кандидат; МОСКОМСТРОЙ (7726445108) и МИЛЛЕНИУМ ГРУПП (9701020234) — подозрительные ОКВЭДы + московский адрес, проверить учредителей.

## Источники технических людей (по убыванию отдачи)

### 1. Прямой обзвон по общему телефону
**Действие:** Позвонить, попросить переключить на главного инженера / главного энергетика, получить ФИО и прямой номер.

**Охват:** 396 водоканалов (у кого есть telefony_iz_obzvona), ожидаемая конверсия 75-90% = **300-350 человек с телефоном**.

**Труд:** Ручной, 2 минуты на звонок × 396 = 13 часов чистого времени.

**Оценка отдачи:** 300÷13ч = **23 человека/час**. Самое быстрое.

---

### 2. ЕРКНМ: акты контрольных мероприятий
**Действие:** По каждому ИНН запросить акты проверок Роспотребнадзора/Ростехнадзора за 2021-2025. В актах указаны должностные лица водоканала, присутствовавшие при проверке (главный инженер, начальник очистных, энергетик). Извлечь ФИО + должность через OCR.

**Охват:** Проверяют не всех ежегодно, но за 4 года покрытие ~60-70% = **300-350 водоканалов**, 1-2 человека на акт.

**Труд:** Автомат (парсинг выгрузки + провайдерский API для чтения PDF). 502 запроса, обработка 350 актов.

**Оценка отдачи:** 350 человек / 2 дня работы программиста = **175 человек/день**. Второе по скорости после автоматизации.

---

### 3. Сайты муниципалитетов: раздел МУПов
**Действие:** У 502 водоканалов нет сайта, но есть муниципалитет. Найти сайт администрации района/города (address содержит муниципальное образование), пройти раннером владельца по разделу "Муниципальные предприятия" / "ЖКХ" / "Контакты". Там часто публикуют директора + телефон, иногда главного инженера.

**Охват:** На 40-50% муниципальных сайтов есть такие разделы = **200-250 водоканалов**.

**Труд:** Автомат через раннер. 502 муниципалитета × 5 минут на поиск сайта + обход = 2 дня серверного времени.

**Оценка отдачи:** 200 человек / 2 дня = **100 человек/день**.

---

### 4. ЕИС: извещения по ИНН водоканала
**Действие:** Не искать по всему ЕИС, а запросить извещения конкретного заказчика (ИНН водоканала). Открыть протоколы вскрытия + документацию. В техзадании часто указано контактное лицо для разъяснений (технический специалист). В протоколах — подписанты актов со стороны заказчика.

**Охват:** Крупные водоканалы (выручка >100 млн) точно закупают через ЕИС — это 79 из 502. Средние реже, но тоже бывают. Итого **150-200 водоканалов**.

**Труд:** Полуавтомат. API ЕИС для списка извещений (502 запроса), потом ручной просмотр протоколов (200 штук × 3 минуты = 10 часов).

**Оценка отдачи:** 150 человек / 10ч = **15 человек/час**. Ниже обзвона, но без голосовой нагрузки.

---

### 5. Социальные сети (ВКонтакте, Одноклассники)
**Действие:** Видно, что у МОСВОДОСТОК (7705013033) и ВОДОКАНАЛ-НТ (6623034200) есть группы ВК (sajt_iz_obzvona). Пройти раннером по этим группам, спарсить посты за год. Искать упоминания ФИО в новостях типа "Главный инженер Иванов И.И. провел совещание", фото с подписями. Расширить поиск: по названию водоканала найти группы через VK API.

**Охват:** У водоканалов без сайта соцсети редки. Оценка **50-80 водоканалов**.

**Труд:** Полуавтомат. Поиск групп (502 запроса VK API), парсинг постов (80 групп × 50 постов), ручной анализ упоминаний (5 часов).

**Оценка отдачи:** 50 человек / 5ч = **10 человек/час**. Низкая, но дает имена без звонков.

---

### 6. Протоколы 223-ФЗ и Tender.pro
**Действие:** Tender.pro уже дал 306 технических людей по промышленности. Отфильтровать водоканалы из 502: по ИНН запросить протоколы заключенных договоров. В протоколах — ФИО подписантов со стороны заказчика (обычно директор или главный инженер).

**Охват:** 223-ФЗ реже 44-ФЗ, но крупные МУПы используют. Оценка **100-150 водоканалов**.

**Труд:** Полуавтомат. 502 запроса по ИНН, парсинг 150 протоколов × 2 минуты = 5 часов.

**Оценка отдачи:** 100 человек / 5ч = **20 человек/час**. Средне.

---

### Не рекомендую (низкая отдача):

**Реестр лицензий Росприроднадзора:** Публичного API нет, ручной поиск по каждому водоканалу. Даже если найти, в лицензии часто директор, а не технический человек. Труд высокий, выход неясен.

**Программы ПКР СКИ:** Есть не у всех муниципалитетов, имена ответственных редки, поиск + чтение PDF займет недели.

## Итоговый план

1. **Прямой обзвон** (день 1): 396 звонков → 300-350 технических людей с телефоном. Ручная работа, но быстрая.

2. **ЕРКНМ** (день 2-3): Автомат, парсинг актов проверок → 300-350 человек. Требует программирования.

3. **Муниципальные сайты** (день 4-5): Раннер владельца по 502 администрациям → 200-250 человек.

4. **ЕИС по ИНН** (день 6): Полуавтомат, 150-200 человек. Дополняет основные треки.

5. **Соцсети** (день 7): 50-80 человек, низкий приоритет, но без звонков.

**Суммарно:** 1000-1200 технических контактов по 502 водоканалам за неделю работы (3 дня автоматизации + 4 дня выполнения). Прямой обзвон дает результат уже в первый день.
