## Как достать технических людей с телефонами

### Tier 1: высокий ROI, проверить первым делом

**1. Tender.pro — отфильтровать по 502 ИНН**
- Есть база 306 технических людей по промышленности.
- Отфильтровать по списку 502 ИНН водоканалов.
- **Труд:** 1 час (если есть доступ к базе).
- **Выход:** неизвестен без проверки, но если хотя бы 10% из 306 попадут в список 502, это ~30 контактов с должностями.
- **Телефоны:** зависит от полноты базы Tender.pro.

Опора: у вас написано "площадка Tender.pro (по ней уже собрано 306 технических людей по промышленности в целом)". Фильтр по ИНН — прямая операция.

**2. ЕРКНМ — парсинг актов проверок по 502 ИНН**
- Акты содержат ФИО сопровождающих лиц со стороны предприятия (обычно технические специалисты).
- Парсинг поля "представители проверяемого лица" из актов.
- **Труд:** 3-5 часов (автоматический парсинг через API или скрейпинг).
- **Выход:** 50-100 ФИО с должностями из ~200-300 актов (не все водоканалы проверялись недавно).
- **Телефонов нет**, но есть ФИО + должность → можно искать в VK/OK или звонить в водоканал с запросом "соедините с Ивановым А.И., главным механиком".

Опора: у вас есть "выгрузки ЕРКНМ (контрольные мероприятия)". Акты проверок публикуются на erknm.gov.ru с ФИО проверяемых лиц.

### Tier 2: средний ROI, если Tier 1 не дал 200+ контактов

**3. Поиск в региональных СМИ и пресс-релизах**
- Запросы вида: `"название водоканала" ("главный инженер" OR "главный механик" OR "главный энергетик")`.
- Парсинг статей, где цитируют технических специалистов.
- **Труд:** 10-15 часов (можно через Яндекс XML API или ручной обход топ-10 результатов по каждому из 502).
- **Выход:** 30-60 ФИО с должностями из ~150-200 водоканалов (не все попадают в новости).
- **Телефонов нет**, но есть ФИО + должность.

Опора: водоканалы регулярно дают комментарии в местные СМИ при авариях, ремонтах, сезонной подготовке. Примеры из строк показывают, что у крупных есть новостное поле (news_event, news_what), но оно пустое — значит, эти данные не собраны, но существуют в публичном доступе.

**4. VK/OK — поиск по месту работы**
- Поиск людей, указавших водоканал в поле "Место работы".
- Фильтр по должностям (инженер, механик, энергетик, начальник цеха).
- **Труд:** 5-10 часов (ручной обход по каждому водоканалу).
- **Выход:** 20-50 контактов с открытыми телефонами (10-15% из 502 водоканалов дадут хотя бы 1 профиль).
- **Телефоны:** у 30-50% профилей телефон в открытом доступе или можно написать в ЛС.

Опора: у части водоканалов в поле sajt_iz_obzvona указан vk.com (inn=7705013033, inn=6623034200). Значит, соцсети используются. Сотрудники могут указывать место работы.

### Tier 3: низкий ROI на единицу труда, но гарантированный результат

**5. Обход через общий телефон водоканала**
- У 396 из 502 есть телефон предприятия (поле telefony_iz_obzvona).
- Позвонить, спросить: "Соедините, пожалуйста, с главным инженером. Как его зовут?"
- Записать ФИО, попросить прямой телефон или мобильный.
- **Труд:** 40-60 часов (5-8 минут на звонок × 396 = ~33 часа чистого времени + повторные звонки).
- **Выход:** 250-350 контактов с прямыми телефонами (70-90% водоканалов дадут контакт).

Опора: поле telefony_iz_obzvona заполнено у 396 из 502 (примеры: inn=7705013033 имеет +7 495 923-29-01, inn=6445029380 имеет +7 927 118-14-19). Это не добыча из открытых источников, а прямой контакт.

## Что взять кроме людей: возраст очистных, мощность, ремонты

### Где это лежит

**1. Схемы водоснабжения и водоотведения**
- Муниципальные схемы ВиВ (утверждаются постановлениями администраций).
- Содержат: перечень объектов, мощность (м³/сут), год ввода в эксплуатацию, техническое состояние, планы ремонтов на 10 лет.
- **Где искать:** сайты администраций (раздел "ЖКХ" или "Водоснабжение"), поиск по запросу: `"схема водоснабжения и водоотведения" "название муниципалитета"`.
- **Труд:** 20-30 часов (502 муниципалитета, не все публикуют схемы).
- **Выход:** мощность и год ввода у 200-300 водоканалов из 502 (40-60%).

Опора: поле address содержит муниципалитет (пример: inn=7705013033 → г. Москва; inn=6445029380 → Краснопартизанский район Саратовской области). Схемы ВиВ обязательны по 416-ФЗ, но у 502 водоканалов без сайта схемы могут быть на сайте администрации.

**2. Контракты ЕИС — поиск по ключевым словам в названии закупки**
- Запросы вида: заказчик = ИНН водоканала, название содержит "ремонт очистных" OR "реконструкция аэротенка" OR "замена воздуходувки".
- **Труд:** 2-3 часа (автоматический запрос через API ЕИС по 502 ИНН).
- **Выход:** 50-100 контрактов на ремонт/реконструкцию (10-20% водоканалов дадут контракты).

Опора: у вас написано "ЕИС не индексирует текст вложений", но название закупки индексируется. Примеры из строк показывают, что поле stages содержит etp (inn=8904046652, inn=6623034200) — значит, закупки есть.

**3. 223-ФЗ планы закупок**
- Есть выгрузка.
- Фильтр по 502 ИНН, поиск позиций с ключевыми словами: "ремонт", "реконструкция", "воздуходувка", "компрессор".
- **Труд:** 1-2 часа (автоматический парсинг выгрузки).
- **Выход:** 30-60 планируемых закупок (6-12% водоканалов).

Опора: у вас написано "выгрузка планов закупок 223-ФЗ". Поле stages содержит etp у части строк.

### Как это меняет разговор

**Возраст очистных >25 лет:**
- Аргумент: "Оборудование выработало нормативный срок службы. Растут затраты на электроэнергию и внеплановые ремонты."
- Пример: если очистные 1985 года, им 39 лет — воздуходувка точно устарела.

**Плановый ремонт в ближайшие 6-12 месяцев:**
- Момент входа: "Вижу, у вас запланирован капремонт в Q2. Есть смысл заложить в смету замену воздуходувки на энергоэффективную."
- Если контракт уже подписан — холодный клиент, пропускаем.

**Идёт реконструкция (контракт заключён недавно):**
- Холодный клиент, только что купили оборудование. Звонить через 3-5 лет.

**Мощность (м³/сут):**
- Сегментация: >10 000 м³/сут — крупный клиент, бюджет есть; <5 000 м³/сут — малый, может не потянуть замену.
- Расчёт: воздуходувка работает ~8000 часов/год. При мощности 20 000 м³/сут экономия 20-30% электроэнергии даёт окупаемость за 3-4 года.

**Аварийность (из ЕРКНМ):**
- Если в актах проверок есть предписания по авариям на воздуходувках — аргумент: "Старое оборудование ненадёжно, простои стоят дорого."

## Ранжирование по ROI (люди с телефоном на единицу труда)

1. **Tender.pro:** 1 час → ~30 контактов = **30 контактов/час**.
2. **ЕРКНМ:** 5 часов → ~80 ФИО = **16 ФИО/час** (без телефонов, нужен второй этап).
3. **VK/OK:** 10 часов → ~40 контактов = **4 контакта/час**.
4. **Поиск в СМИ:** 15 часов → ~50 ФИО = **3 ФИО/час** (без телефонов).
5. **Обход через общий телефон:** 50 часов → ~300 контактов = **6 контактов/час** (гарантированный результат).

**Рекомендация:** начать с Tender.pro и ЕРКНМ (суммарно 6 часов, ~110 ФИО). Если нужны телефоны, добавить VK/OK (10 часов, +40 контактов). Если этого мало, запустить обход через общий телефон (50 часов, +300 контактов).
