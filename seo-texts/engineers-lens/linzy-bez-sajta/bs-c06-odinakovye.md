## Источники по КПД (людей с телефоном на единицу труда)

### 1. Tender.pro по 502 ИНН
**Выход**: 10-30 технических контактов  
**Работы**: 1-2 часа (фильтр готовой базы)  
**Опора**: указано, что Tender.pro дал 306 технических людей по промышленности, не сказано конкретно по водоканалам

Взять готовую базу 306 человек, отфильтровать по этим 502 ИНН. Если Tender.pro собирал контактные лица по закупкам, там должны быть технари.

### 2. ЕРКНМ (контрольные мероприятия) — имена без телефонов
**Выход**: 20-50 ФИО должностных лиц, 0-5 телефонов напрямую  
**Работы**: 4-6 часов (парсинг автоматический)  
**Опора**: ЕРКНМ указан как доступный источник

В протоколах проверок Роспотребнадзора/Ростехнадзора фиксируют, кто присутствовал: "в присутствии главного инженера Петрова И.И." Телефонов в протоколах нет, но имена + должности есть. Дальше имя можно искать в соцсетях по связке "ФИО + город предприятия" (из поля address). Парсинг выгрузки ЕРКНМ — API чтения текста уже есть.

### 3. Планы закупок 223-ФЗ + парсинг ТЗ — имена без телефонов
**Выход**: 50-100 ФИО разработчиков/согласующих, 0 телефонов напрямую  
**Работы**: 8-12 часов (парсинг PDF через API)  
**Опора**: выгрузка 223-ФЗ указана как доступная

Водоканалы закупают оборудование для очистных (воздуходувки, насосы, реагенты). В техзаданиях иногда указывают: "ТЗ разработано главным инженером Ивановым", "согласовано начальником цеха Сидоровым". PDF парсится через провайдерский API. Телефонов не будет, но связка "имя + должность + предприятие" позволяет искать дальше.

### 4. Соцсети VK по найденным именам (2-й шаг)
**Выход**: 10-30 телефонов  
**Работы**: 10-15 часов (ручной поиск или автопарсинг)  
**Опора**: в строках вижу VK у предприятий (inn=7705013033, inn=6623034200)

После получения имен из пп. 2-3 искать их в VK по "ФИО + город". Главные инженеры 45+ в соцсетях редко, но начальники участков 35-45 бывают. У части будут открыты телефоны в профиле или видны через взаимные контакты. Антидетект-браузер с прокси обходит блокировки парсинга VK.

### 5. Региональные новостные порталы — имена без телефонов
**Выход**: 30-60 упоминаний технических специалистов, 0 телефонов  
**Работы**: 20-30 часов (ручной поиск по 502 предприятиям)  
**Опора**: водоканалы попадают в новости (аварии, запуск объектов)

Поиск через Яндекс.Новости по фразе "название предприятия + главный инженер/главный механик". Пример: "Как рассказал главный инженер МУП Водоканал Алексей Смирнов...". Даст имя и должность, телефона не будет. КПД низкий из-за ручной работы.

## Ранжирование

1. **Tender.pro** (10-30 / 2 часа) — сразу делать  
2. **ЕРКНМ + парсинг** (20-50 имен / 6 часов) — имена для следующего шага  
3. **223-ФЗ + ТЗ** (50-100 имен / 12 часов) — массово, но без телефонов  
4. **VK по именам** (10-30 телефонов / 15 часов) — после пп. 2-3  
5. Новости (30-60 / 30 часов) — если всё остальное не сработает

**Итого реально**: 40-80 технических людей с телефонами за 35-40 часов работы по цепочке Tender.pro → ЕРКНМ → 223-ФЗ → VK.

## Линза (ошибки)

"ООО ВОДОКАНАЛ" повторяется (inn=2706027738 Хабаровский край, inn=4726003577 Ленинградская область, inn=2809000174 Амурская область). **Ключ — ИНН**, не название. При склейке баз использовать inn как первичный идентификатор. В противном случае "ООО ВОДОКАНАЛ" из Хабаровска получит телефон из Амурска.
