**Фильтр**: отсеять из 502 те, у кого статус = «Ликвидирована», «В стадии реорганизации», «Банкротство». Это 20 строк без статуса (502 − 482) + возможные нерабочие среди 482. Сократит холостые обзвоны.

**Риск**: не проверено, есть ли в выгрузке ЕРКНМ телефоны или только должности. Если только должности — даст имена без телефонов, польза снизится.

**Итого по рентабельности (люди с телефоном / час работы)**:

1. **ЕРКНМ**: 50-150 людей / 1-2 часа = 25-75 людей/час. Лучшее.
2. **Tender.pro**: 30-100 людей / 3-5 часов = 6-33 людей/час.
3. **VK**: 5-15 людей / 2-3 часа = 2-7 людей/час.
4. **Администрации**: 30-80 имён (без телефонов) / 20-40 часов = 1-4 имени/час.
5. **СМИ**: 20-50 имён (без телефонов) / 10-20 часов = 1-5 имён/час.

**Обзвон по 396 общим телефонам** (не парсинг, но эффективнее всего) — может дать 200-300 технических контактов, если продажник спросит секретаря: «Соедините с главным инженером». Это задача обзвона, не подготовки данных, но упомяну: по выручке и размеру хозяйства верхние 79 (>100 млн) стоит обзвонить в первую очередь.
