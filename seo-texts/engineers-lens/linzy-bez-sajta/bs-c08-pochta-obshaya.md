**1. Реестр контрактов 44-ФЗ (zakupki.gov.ru)**

В карточке контракта есть поле "контактное лицо заказчика". При закупке оборудования, ремонта, химреагентов часто указывают технического специалиста.

- Охват: все 502 (водоканалы закупают постоянно)
- Ожидаемый выход: 200-300 контактов с ФИО и должностью, из них 100-150 с телефоном
- Работа: автоматизированный сбор контрактов за 2-3 года по ИНН + парсинг поля контактов (40 часов настройки + прогон)

Опора: inn=7705013033 закупает по 223-ФЗ (поле `stages=etp`), значит и по 44-ФЗ тоже. Аналогично для inn=8904046652, inn=5256049340 и большинства крупных из выборки.

- Охват: 200-250 из 502 (не все размещают на Tender.pro)
- Ожидаемый выход: 50-80 человек, 30-50 с телефоном
- Работа: фильтрация имеющейся базы по ИНН из списка (2 часа)

**Ранжирование:**
1. Tender.pro: 15-25 телефонов/час труда
2. Реестр контрактов 44-ФЗ: 2-4 телефона/час труда

Общая почта даёт контакт технического человека в 2-3% случаев (7-10 контактов из 349 писем). Конверсия: 15-30% ответят, из них 10-20% дадут целевой контакт.

Опора: pochty_iz_obzvona для inn=7705013033 = `secretar-cra@mosvodostok.ru`, для inn=8904046652 = `uqyk@mail.ru` — это секретари, не технари.

**Смысл писать есть только на 106 компаний без телефона** (502 всего - 396 с телефоном). Для остальных 310 эффективнее прямой обзвон: секретарь переключит на главного инженера быстрее, чем ответит на письмо.

Правило "телефон важнее почты" означает: для холодных продаж звонок результативнее. Но для сбора контактов почта — это вход к телефону, если прямого номера нет.

**Итого по числам:**
- Tender.pro: 30-50 телефонов за 2 часа
- Реестр 44-ФЗ: 100-150 телефонов за 40 часов
- Общая почта: 7-10 телефонов за 2 часа (только для 106 без телефона)
