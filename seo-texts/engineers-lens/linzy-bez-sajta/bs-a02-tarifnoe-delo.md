Тарифное дело даст имена без телефонов. Телефонов там не публикуют по определению — это не контактная информация для населения, а служебная документация.

**Что там есть:**

Обосновывающие материалы к тарифам включают производственные программы, где водоканал подаёт сведения о состоянии объектов и планах. Эти документы подписывает директор (у 294 из 502 по строкам он уже известен из ЕГРЮЛ: inn=6658310073 Конин, inn=4230006156 Корчебный, inn=7731047695 Кириллов и т.д.). 

Технические люди (главный инженер, главный энергетик) встречаются как согласующие или ответственные исполнители в приложениях к программам — схемах водоснабжения, расчётах нагрузок. Но:
- Приложения публикуют не все регионы (примерно треть).
- В публикуемых приложениях имена стоят на 10-15% документов.
- Имя есть, телефона нет.

**В протоколах правления РЭК** имена только членов правления регулятора, а не водоканала.

**Цена:**

- Людей с именами: 25-50 из 502 (5-10%).
- Людей с телефонами: 0.
- Работа: обход 50+ региональных сайтов РЭК, поиск по каждому водоканалу отдельно (нет сводного реестра), чтение PDF-сканов вручную или через OCR. На водоканал 15-30 минут, на 502 — 125-250 часов.
- Соотношение: 25 имён / 125 часов = 0,2 имени в час, телефонов 0.

После получения имени всё равно придётся искать телефон другим способом (обзвон общего номера предприятия, который по строкам уже есть у 396 из 502). 

**Вывод:** источник даёт имена без телефонов, работы много, выход плохой. Если цель — технический человек с телефоном для обзвона, тарифное дело не решает задачу.
