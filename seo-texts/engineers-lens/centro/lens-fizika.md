## ТЕХНОЛОГИЧЕСКАЯ ФИЗИКА КАК ПРИЗНАК ПАРКА

Центробежные компрессоры неизбежны там, где совпадают три условия: **непрерывный режим**, **расход >50–100 тыс. м³/ч** и **давление >10 атм**. Это отсекает пищевую промышленность, ЖКХ, небольшие химпроизводства. Остаётся крупнотоннажная химия, металлургия и магистральный транспорт газа.

### 1. Реестр объектов I категории НВОС + производственная мощность

**Суть:** предприятия I категории — крупнейшие загрязнители, публичный реестр Росприроднадзора с ИНН и ОКВЭД. Массовый выброс CO₂ и NOₓ коррелирует с мощностью энергопотребления, а значит, с типом компрессорного парка. Крупнотоннажные переделы требуют центробежных машин по физике процесса.

**Конкретные ОКВЭД:**
- 20.14 (азотные соединения: аммиак >100 тыс. т/год → синтез-газовые и циркуляционные центробежные)
- 20.16.10 (пластмассы первичные: этилен >300 тыс. т/год → холодильные центробежные; ПЭВД — гиперкомпрессоры до 3000 атм, только центробежные)
- 24.10.1 (чугун: домна >2000 м³ → воздуходувки 150–300 тыс. м³/ч)
- 24.10.2 (сталь: конвертер >100 т/плавку → кислородные центробежные от РВУ)
- 19.20 (нефтепереработка: риформинг, крекинг >3 млн т/год сырья → циркуляционные компрессоры водорода и газов регенерации)

**Что даст:** ИНН, адрес площадки, ОКВЭД. Производственную мощность нужно добирать: корпоративные сайты (раздел «О компании»), отчёты по устойчивому развитию (ESG), Росстат (формы 1-предприятие, 11-ТЭР — частично открыты через hcbm.rostruda.ru, Единый портал госуслуг, публикации регионального Росстата).

**Алгоритм:**
1. Скачать реестр I категории (rpn.gov.ru, раздел «Государственный учёт»). Проверить структуру: есть ли ИНН, ОКВЭД, координаты. Если API закрыт — парсить HTML или запросить Excel через обращение.
2. Отфильтровать ОКВЭД 20.14, 20.16, 24.10, 19.20.
3. Для каждого ИНН найти мощность (начать с сайта, если пусто — отчёт ESG на раскрытии информации, если частная компания — пресс-релизы о пуске установок).
4. Если мощность выше порога (см. выше) — занести в выборку.
5. Кросс-чек с вашими 324: сколько пересечений. Если >30 % — метод валиден, остальные 70 % — новые.

**Риски пустоты:**
- Реестр может не содержать ИНН напрямую (только название и адрес). **Проверка (10 минут):** открыть реестр, посмотреть первые 5 записей. Если ИНН нет — придётся сопоставлять название + адрес с ЕГРЮЛ или СПАРК.
- Мощность может быть недоступна для частных компаний. **Проверка (1 час):** взять 10 случайных ИНН из ОКВЭД 20.14, попытаться найти мощность. Если найдено <3 — метод требует доработки (искать через тендеры на сырьё: объём закупки метана для аммиака пересчитывается в мощность).
- Мощность может быть суммарной по холдингу, а не по площадке. **Проверка:** для 3 известных многоплощадочных (СИБУР, Уралхим) сравнить цифру с сайта и сумму по отдельным заводам. Если расхождение — искать данные по площадкам в СМИ («запуск второй линии аммиака в Невинномысске»).

### 2. Справочники НДТ + декларации промышленной безопасности

**Суть:** информационно-технические справочники по наилучшим доступным технологиям описывают типовые технологические схемы с указанием оборудования. ИТС 18-2019 (органика), ИТС 26-2017 (металлургия), ИТС 19-2017 (нефтепереработка). Там есть таблицы: «процесс → обязательное оборудование → тип компрессора».

**Что даст:** понимание, в каких переделах центробежные неизбежны. Затем — список предприятий с этими переделами через декларации ПБ (должны быть в открытом доступе, ст. 14.1 ФЗ-116). Декларация содержит: описание технологии, перечень оборудования, часто с инвентарными номерами и моделями.

**Конкретная проверка:**
- ИТС 18-2019, раздел «Производство аммиака», найти блок-схему. Там будут центробежные компрессоры синтез-газа и циркуляционные. Зафиксировать: «производство аммиака мощностью >X требует центробежного».
- Запросить реестр деклараций ПБ через Ростехнадзор (gosnadzor.ru, раздел «Регистры»). Если закрыт — через запрос по 59-ФЗ (10 дней).
- Отфильтровать декларации по словам «аммиак», «этилен», «доменное дутьё».
- Парсить текст деклараций на упоминание «центробежный компрессор». Если есть — занести ИНН в выборку.

**Риски пустоты:**
- Реестр деклараций может быть закрыт или без полнотекстового поиска. **Проверка (15 минут):** зайти на сайт Ростехнадзора, найти раздел деклараций, попробовать поиск. Если закрыт — оценить, сколько стоит запрос через 59-ФЗ (бесплатно, но 10 дней + риск отказа).
- Декларации могут быть отсканированными PDF без OCR. **Проверка:** скачать 3 случайные декларации, проверить, распознаётся ли текст. Если нет — нужен OCR (Tesseract, ABBYY).
- В декларациях может не быть инвентарных номеров и моделей, только общие слова «компрессорное оборудование». **Проверка:** прочитать 2–3 декларации из разных отраслей. Если детализации нет — метод не даст признака «центробежный».

### 3. Магистральные газопроводы: схема ЕСГ → компрессорные станции

**Суть:** Газпром публикует схему Единой системы газоснабжения (annual-report.gazprom.ru, раздел «Транспортировка газа»). На каждой КС стоят ГПА (газоперекачивающие агрегаты) с центробежными нагнетателями. КС — это отдельные юрлица или филиалы «Газпром трансгаз X».

**Что даст:** список КС с географией. Затем — поиск ИНН через ЕГРЮЛ по названию («Компрессорная станция Починковская») или через структуру «Газпром трансгаз» (дочки публикуют списки филиалов).

**Конкретная проверка:**
1. Скачать интерактивную карту ЕСГ или годовой отчёт Газпрома (PDF, раздел «Активы»).
2. Выписать названия КС (их ~250 в РФ).
3. Для каждой найти ИНН: искать через СПАРК или ЕГРЮЛ по названию + «ООО» / «АО».
4. Кросс-чек с вашими 42: «Газпром трансгаз Уфа» уже есть (6 машин), но может быть не вся структура. Если в вашем списке 1 юрлицо «Газпром трансгаз», а КС у него 30 — метод даёт 29 новых точек (юрлица могут быть разными).

**Риски пустоты:**
- КС могут быть филиалами одного юрлица, тогда все 30 КС — один ИНН. **Проверка (30 минут):** взять 5 КС из разных регионов, найти их в ЕГРЮЛ. Если все — филиал одного «Газпром трансгаз», метод даёт 0 новых ИНН (но даёт адреса площадок для прямых контактов).
- Схема ЕСГ может не содержать названий КС, только линии. **Проверка (10 минут):** открыть карту, посмотреть легенду. Если названий нет — искать в годовом отчёте раздел «Дочерние общества».
- Газпром попадает под санкционное скрытие (ПП 301), значит, закупки не в ЕИС. Но это не мешает найти ИНН — просто не будет тендеров. Для вашего случая (поиск парка через ЭПБ) санкции не проблема: ЭПБ публикуется.

### 4. Производство серной кислоты и капролактама — узкие ниши с центробежными

**Суть:** серная кислота контактным методом (ОКВЭД 20.13.52) и капролактам (сырьё для найлона, ОКВЭД 20.14.23) требуют воздуходувок и компрессоров аммиака. Это узкие переделы: серной кислоты в РФ производят ~25 предприятий, капролактама — 3 (Кемерово, Дзержинск, возможно Менделеевск).

**Что даст:** список из ~30 ИНН, точность 100 % (если производят — компрессор есть). Источник: Росстат, форма статнаблюдения «Производство отдельных видов продукции» (публикуется на gks.ru, раздел «Промышленность», подраздел «Производство в натуральном выражении»). Там таблица: «Продукт (серная кислота в моногидрате, тыс. т) → Организация (название) → Объём».

**Конкретная проверка:**
1. Найти на gks.ru раздел «Производство серной кислоты» за 2025 год. Скачать Excel или скопировать таблицу.
2. Выписать названия организаций, убрать мелких (<50 тыс. т/год — там могут быть башенные методы без компрессоров).
3. Найти ИНН через СПАРК.
4. Кросс-чек с вашими 42 и 324.

**Риски пустоты:**
- Росстат может публиковать данные только по федеральным округам, без названий компаний (коммерческая тайна). **Проверка (20 минут):** открыть раздел, посмотреть детализацию. Если названий нет — метод не работает без платной подписки (СПАРК-Интерфакс даёт производственные мощности, но это 50–100 тыс. руб./год).
- Серная кислота может быть побочным продуктом (медеплавильные заводы), там компрессоры другого типа. **Проверка:** из списка убрать ОКВЭД 24.44 (медь), оставить только 20.13 (основная химия).

### 5. ТЭЦ и ПГУ с газотурбинными установками

**Суть:** парогазовые установки (ПГУ) содержат ГТУ (газовые турбины), перед ними стоит осевой или центробежный компрессор воздуха. Установленная мощность ГТУ >100 МВт требует центробежного. Источник: схема территориального планирования РФ в области энергетики (Минэнерго, публикуется на minenergo.gov.ru).

**Что даст:** список ТЭЦ и ГРЭС с ГТУ, далее — поиск ИНН через ЕГРЮЛ (большинство принадлежат «Интер РАО», «Газпром энергохолдинг», «Т Плюс», «Юнипро»).

**Риски пустоты:**
- ПГУ — это относительно новая технология (2000-е), старые ТЭЦ паротурбинные. Если в схеме ТП нет отметки «ПГУ», придётся искать в описании блоков. **Проверка:** открыть схему, посмотреть 3 крупных ТЭЦ (Москва, Санкт-Петербург, Екатеринбург), есть ли там столбец «Тип установки».
- Центробежные компрессоры ГТУ — часть турбины, замена редка (ресурс 100–200 тыс. часов, это 20–40 лет). ЭПБ на них может не делаться вообще. **Проверка:** зайти в ваш реестр ЭПБ, искать «газовая турбина» или «ГТУ». Если 0 результатов — метод не даст признака замены.

**Вывод по ТЭЦ:** высокий риск, что это не ваша ЦА (компрессоры ГТУ обслуживает производитель турбины — Siemens, GE, ОДК — замена не через дистрибьютора).

## ЧЕМ ИДЕИ МОГУТ ОКАЗАТЬСЯ ПУСТЫМИ

**Общий риск:** ОКВЭД может быть зарегистрирован на уровне холдинга (Москва, головной офис), а производство — в регионе. Тогда фильтр по ОКВЭД пропустит дочек без кода 20.14, хотя завод есть. **Проверка (1 час):** взять 5 компаний из ваших 42 (Казаньоргсинтез, НЛМК, Невинномысский Азот), проверить их ОКВЭД в ЕГРЮЛ. Если основной 20.14 есть — метод работает. Если ОКВЭД «Управление холдингом» (64.20) — нужно искать через дочерние общества (СПАРК → вкладка «Структура» → список дочек → их ОКВЭД).

**Быстрый тест всей логики (2 часа):**
1. Скачать реестр I категории НВОС (или парсить 50 первых записей).
2. Отфильтровать ОКВЭД 20.14.
3. Взять топ-10 по массе выбросов (прокси для размера).
4. Проверить есть ли они в ваших 42 или 324.
5. Если пересечение ≥3 — метод валиден, остальные 7 — новые.
6. Для 3 новых попытаться найти мощность производства на сайте.
7. Если найдено ≥2 — метод масштабируется.

Если тест провалился (пересечение 0, мощность не найдена) — проблема не в идее, а в источнике: либо реестр не содержит ИНН, либо ОКВЭД указан неверно. Тогда вернуться к вашему уроку про семь ошибок и проверить запрос заново.
