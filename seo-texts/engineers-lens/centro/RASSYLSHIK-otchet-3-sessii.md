# Рассыльщик: почему новости матчатся не с той компанией. Аудит 66 привязок

Третья сессия, задача 7 из VSEM-SESSIYAM. Проверены ВСЕ 66 пар «компания ↔ новостное событие»
из `news-campaign-master.csv`. Судили по НАСТОЯЩЕМУ тексту первоисточника: 31 VK-пост вытащен
через VK API (`wall.getById`, токен из ключницы), а не по извлечённому полю `what`. Каждую
подозрительную привязку адверсариально перепроверял отдельный агент (пытался ОПРАВДАТЬ).

## Итог

| | |
|---|---:|
| проверено пар | 66 |
| под подозрением | 24 |
| **подтверждённых мисматчей** | **16** |
| осталось сомнительными | 2 |
| оправдано перепроверкой (привязка верна) | 6 |

## Корневая причина — в коде `newsco_op.py`, не в данных

Функция `привязка()` присваивает уровень доказанности: `инн` (ИНН на странице) → `полное_имя`
→ **`ядро`** (совпало ядро имени по префиксам). В самом коде `ядро` помечено комментарием
«слабое (тёзки!)». А строка 480 **принимает `ядро` в кампанию наравне с сильными уровнями**.
Отсюда все 16 ошибок.

Усугубляет источник: **все 31 VK-привязки взяты из пабликов-лент и дайджестов** («Тамбов без
сахара», «Сальск», «Лента новостей Алчевска», «НАТЭК-Нефтехиммаш»), а **ни в одном посте нет ИНН
компании** — сильнейшего доказательства не было ни разу, привязка держалась только на имени.

## Что чинить в рассыльщике

1. **Не принимать уровень `ядро` в рассылку** — только `инн` и `полное_имя`. Уровень `ядро`
   отправлять на ручную проверку, а не в кампанию. Это убирает 9 тёзок из 16 одним правилом.
2. **Гейт по профилю (ОКВЭД).** Если событие про тепличный комплекс, а ОКВЭД компании —
   полеводство, привязку понижать. Ловит «Авангард-Агро», «АУРУС».
3. **Гейт по региону.** Если в тексте назван город/регион, отличный от региона компании, —
   понижать (ловит «Химпром»: Волгоград vs Чувашия).
4. **Метка «дайджест».** Пост >800 знаков с 4+ событиями — привязка только при ИНН или полном
   имени рядом с конкретным событием, не по всему тексту.
5. **6 привязок, ошибочно попавших под подозрение, — ВЕРНЫ**, их из кампании убирать НЕ надо
   (i=1,15,26,43,48,60). Список сохранён, чтобы не выкосить лишнее.
