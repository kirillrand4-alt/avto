# Два прогона через провайдера: марки и советские названия

29.07.2026. Владелец разрешил гнать в 15 потоков и потребовал перепроверять всех, включая
себя. Оба прогона шли локально, раннер не занимали. Тридцать одновременных запросов
(15 + 15) прошли с одним сбоем на 49 партий.

---

## 1. Тип и среда машины по марке

**Задача.** У 3 087 строк из 7 750 среда в тексте объекта не названа: стоит только
обозначение, «компрессор центробежный К-500-61-1 поз. 1/4». Из-за этого оценка «212
предприятий с воздушными машинами» была заведомо нижней.

**Разделение труда, важное для доверия.** Среда берётся из двух источников с разным весом:

| Источник | Обозначений | Как получено |
|---|---:|---|
| **данные** | 495 | те же обозначения в строках, где среда названа явно (≥3 наблюдений, ≥80 % согласия) |
| **модель** | 207 | вердикт провайдера, только «высокая» и «средняя» уверенность |

Итого среда известна у 702 обозначений из 1 660.

**Результат.** Проставлена среда **1 456 строкам**, которые раньше числились без неё:

| Среда | Строк |
|---|---:|
| **воздух** | **686** |
| природный газ | 446 |
| технологический газ | 299 |
| азот | 11 |
| кислород | 9 |
| прочее | 5 |

Из них 567 строк размечены по данным, 889 — моделью. **Обзвон идёт сначала по первым.**

**Воздушный сегмент вырос с 212 предприятий до 244** — 32 завода были невидимы, потому
что в тексте стояла только марка.

**Осторожность модели.** После того как из промпта убрали правило про серии (см.
`PROVERKA-klassifikatora.md`), модель отказывается отвечать в **958 случаях из 1 165,
это 82 %**. Из 1 165 обозначений 718 честно помечены «не машина» — номера цехов, позиций
и регистрации.

## 2. Советские названия → нынешние юрлица

**Задача.** В референс-листе Невского завода 475 заказчиков за 1947–2019, сопоставление по
строке даёт 9 совпадений с нашими 347. Причина не в отсутствии заводов, а в переименованиях.

**Решение по безопасности, принятое до запуска: ИНН у модели не спрашивается вообще.**
Идентификатор, который модель не может проверить, она выдумает, и выдумка будет выглядеть
правдоподобно — это ровно ловушка В11 (склеенный телефон). Модель отдаёт только современное
название и страну; ИНН подставляется поиском по названию **в наших собственных данных**,
поэтому несуществующий ИНН появиться не может физически.

Проверено на выходе: **строк с цифровым идентификатором в поле названия — ноль**.

| Страна | Заказчиков | | Состояние | Заказчиков |
|---|---:|---|---|---:|
| Россия | 227 | | работает | 204 |
| не знаю | 125 | | не знаю | 202 |
| Украина | 62 | | закрыто | 26 |
| другая | 26 | | ведомство упразднено | 22 |
| Казахстан | 19 | | вошло в состав другого | 21 |
| Узбекистан | 9 | | | |
| Белоруссия | 7 | | | |

**98 заказчиков из 475 остались за границей** — это ответ на вопрос, который висел в
разведке: «не измерена доля живых предприятий среди 243 советских заказчиков».

## 3. Слепая сверка — и в ней подвела сама сверка

Контрольный набор: 16 названий, размеченных вручную в `RAZVEDKA-novye-istochniki.md`.
Автоматическое сличение дало «10 совпало, 6 разошлось». Разбор глазами показал, что
**в трёх случаях из шести неправа была проверка, а не модель**:

| Название | Модель ответила | Почему автомат счёл ошибкой |
|---|---|---|
| Магнитогорский МК | Магнитогорский металлургический комбинат | эталон записан аббревиатурой «ММК» |
| Новолипецкий МК | Новолипецкий металлургический комбинат | эталон записан «НЛМК» |
| Нижнетагильский МК | Нижнетагильский металлургический комбинат | эталон записан брендом «ЕВРАЗ НТМК» |

Модель давала полное официальное название, эталон — аббревиатуру или бренд. Сличение по
вхождению подстроки этого не различает.

**Настоящий счёт: 13–14 верных из 16.** Одна реальная ошибка — «Навоиазот» сведён к
историческому «Навоийский азотно-туковый завод» вместо нынешнего АО «Навоиазот». Один
честный отказ — «Томский НХК», хотя правильный ответ (ООО «Томскнефтехим») известен.

**Вывод для метода: проверяющий требует проверки не меньше проверяемого.** Я собирался
отчитаться «модель ошибается в трети случаев» — и это было бы неправдой, порождённой
грубым сличением строк. Это третий случай за день, когда ошибка сидела не в данных и не в
модели, а в описании признака: кодировка (В10), словарь среды («газовый»), теперь сличение
названий.

## Чему верить нельзя

**Модельная половина разметки среды не проверена на этом объёме.** Слепой замер делался на
79 обозначениях и дал чистоту воздушного списка 90 % при нуле пропусков. Перенос этой цифры
на все 207 модельных вердиктов — предположение, а не измерение.

**Из 32 новых воздушных предприятий ни одно не проверено вручную.** Они пришли по цепочке
«марка → среда → предприятие», где каждое звено автоматическое.

**Ручной эталон в 16 названий сам собран мной** из выборки в 20 строк разведки, и он
опирался на те же источники. Совпадение модели с ним не означает совпадения с реальностью.

**Ни одного телефона по-прежнему нет.** Обогащение контактов на раннере в этот заход не
отработало: задание провисело 1 800 секунд без результата при живом `ping`.
