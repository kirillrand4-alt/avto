## Задача одной строкой

Книга продаж 2025: 2 045 операций, **491 ИНН, 2,69 млрд ₽** — это НАШИ ПОКУПАТЕЛИ. Нужно по
каждому достать ЛПР с рабочим контактом и влить в **отдельную базу пользователя user3**, не
смешивая с центробежной очередью.

Что уже есть по этим 491 в моей базе: 43 в центробежной очереди, 35 с людьми, 22 с
техническим человеком, **3 с техническим и личным мобильным**. 456 предприятий без единого
человека — и это 89 % всей суммы продаж.

## Решения владельца, которые НЕ обсуждаются (они уже приняты)

* приоритет предприятий — **строго по сумме покупок**, никаких весов по важности;
* **дилеров не отделяем**, звоним всем подряд;
* у user3 **отдельная база данных**;
* ЛПР: **сначала главный инженер / механик / энергетик, потом закупки**; мера прежняя —
  технические с личным мобильным;
* **источник в трёх местах = три кликабельных ссылки**, каждая проверена запросом;
* сбор **с нуля**, сверка с центробежной базой — последним шагом;
* свежесть данных о человеке — обязательна, «дата не определена» не считается свежим.
