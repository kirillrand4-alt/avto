## 2. Откуда брать доказательство: из ИСТОЧНИКА записи, а не из близости

Главное решение, и оно прямо из нашего общего правила «близость не доказывает
принадлежность»: силу доказательства даёт **способ добычи**, а не то, что имя
оказалось рядом с названием.

```
источник записи                          фраза в prinadlezhnost_chem              сила
ЕГРЮЛ / dadata                           выписка ЕГРЮЛ по этому ИНН              сильное
карточка закупки (ЕИС, площадки,         контактное лицо заказчика в карточке    сильное
   tender.pro, закупочная комиссия)
протокол РТН «проверка знаний»           организация названа, ИНН сверен          среднее
                                            ПО НАЗВАНИЮ
страница сайта (руководство,             только домен сайта                       слабое
   справочник, вакансии)
ссылки нет                               не доказано                              нет
```

Почему РТН — среднее, а не сильное: протокол называет организацию словами, а привязку
к ИНН мы делали сопоставлением названия. Название — не ИНН; это ровно тот штамп, про
который мы условились «ИНН подтверждён НЕ по названию». Три тысячи строк соблазнительно
записать в зелёные, но они не зелёные.

## 4. Проба на различение — обязательные отрицательные случаи

```
ДОЛЖНЫ стать сильными
   директор из выписки ЕГРЮЛ по этому же ИНН              → сильное ✓
   контактное лицо заказчика в карточке ЕИС               → сильное ✓
НЕ ДОЛЖНЫ стать сильными
   22 человека с segezha-group.com/providers/contacts     → слабое ✓ (источник «сайт:справочник»)
   «сайт:руководство» на подтверждённом домене            → слабое ✓ ← домен подтверждает САЙТ
   протокол РТН, ИНН сверен по названию                   → среднее ✓
   строка без source_url                                  → не доказано ✓
```

Четвёртый случай — тот самый, из-за которого заслон обязан быть строгим: подтверждённый
домен сегодня выглядит как доказательство и им не является.
