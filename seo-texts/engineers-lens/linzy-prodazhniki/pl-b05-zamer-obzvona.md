## Что добавить в сводку предприятий

**prioritet:** A | B | C  
Формула: A = (срок истёк ИЛИ планирует в ближайший квартал) И есть технический с телефоном. B = остальные с техническим. C = только снабжение или без людей.

Пример: inn=2124009521 (срок ИСТЁК, tehnicheskih_lyudey=35, s_telefonom=34) → A. inn=6626002291 (срок ИСТЁК, s_telefonom=0) → C.

**trigger_glavnyy:** (одно значение)  
Если несколько триггеров, выбрать главный: срок истёк > планирует > покупал > есть машина.

**marka_prioritetnaya:** (одна марка)  
Если марок много, выбрать ту, у которой срок истёк или по которой была закупка. Если данных нет — первую из списка. Чтобы продажник не терялся.

Пример: inn=0277077282 (5 марок, срок ИСТЁК у части) — записать марку с истёкшим сроком.

**poslednyaya_aktivnost_data:**  
Максимум из (data_zakluchenia, data_zakupki, kogda_planiruet). Для сортировки.
