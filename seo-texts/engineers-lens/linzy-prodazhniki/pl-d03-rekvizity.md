ЕГРЮЛ дозаполнит регион, директора, адрес, ОКВЭД и статус для 21 841 предприятия. Остальное (сайт, телефон, технический человек) он не даёт.

**Что даст ЕГРЮЛ:**
- Регион (извлечь из адреса) — сегментация по географии
- Директор — запасной контакт при отсутствии технического лица
- Адрес — проверка активности, логистика
- ОКВЭД — подтверждение профиля деятельности
- Статус — отсев ликвидированных

**Порядок дозаполнения:**

Запросить ЕГРЮЛ можно сразу для всех 21 841 ИНН (технически порядок не важен). Но обрабатывать результаты по приоритету бизнес-ценности:

1. **Группа А (3 577): есть экспертиза ПБ** — у них точно наше оборудование.
   - Срок истёк / истекает (из поля srok_sluzhby) — горячие лиды.
   - Марка оборудования известна (из поля marki) — конкретное предложение.

2. **Группа Б (≈1 000): покупает / планирует** — активная потребность.
   - data_zakupki или kogda_planiruet заполнены.

3. **Группа В (683): водоканал** — целевой сегмент, воздуходувка есть почти наверняка.

4. **Группа Г (примеры: ИНН 7704784450): вакансии** — растут, обновляют персонал.

5. **Группа Д: остальные** — на площадке, но предмет не наш или данных мало.

**Что НЕ решит ЕГРЮЛ:**

Главная беда остаётся: техническое лицо с телефоном есть только у 161 из 25 083 (0,6%). ЕГРЮЛ даст директора, но продажники просили главного инженера / механика / энергетика. Директор — вход через секретаря, менее прямой.

**Примеры из строк:**

ИНН 6319038803: сейчас chego_ne_hvataet=телефон предприятия, сайт, технический человек, реквизиты.  
ЕГРЮЛ даст: адрес, директора, ОКВЭД, статус.  
Останется нехватка: телефон, сайт, технический человек.

ИНН 5243009501: сейчас есть адрес, статус, выручка (из базы владельца), но chego_ne_hvataet=телефон предприятия, сайт, телефон технического человека.  
ЕГРЮЛ ничего нового не добавит — эти поля уже заполнены из базы владельца.

ИНН 0313003521: аналогично — уже есть из базы владельца.

**Вывод:**

ЕГРЮЛ дозаполнит структурные данные (регион, директор, адрес), что полезно для сегментации и маршрутизации звонков. Но проблему 103 технических людей против 25 083 предприятий он не решает. Для телефонов и технических лиц нужны другие источники: парсинг сайтов (если найдём через поиск), углубление парсинга Tender.pro (больше контактов из тендеров), парсинг отраслевых площадок.
