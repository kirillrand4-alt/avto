# Формула ранжирования для обзвона

## Базовый вес (0–100 баллов)

```
Вес = (состояние × 30) + (люди × 40) + (активность × 20) + (размер × 10)
```

## Компоненты и их веса

### 1. Состояние оборудования (30 баллов)

- **есть + срок ИСТЁК**: 30 баллов
  - Пример: ИНН 0277077282, `srok_sluzhby=срок ИСТЁК`
  - Машина выработала ресурс, нужна замена немедленно

- **есть + срок ИСТЕКАЕТ**: 25 баллов
  - Пример: ИНН 0277077282, `srok_sluzhby=срок ИСТЕКАЕТ в ближайший год`
  - Окно покупки открыто, решение принимается сейчас

- **есть + срок действует**: 15 баллов
  - Пример: ИНН 3808229774, `srok_sluzhby=срок действует`
  - Будущий клиент, но не срочно

- **планирует**: 20 баллов
  - Пример: ИНН 2725031842, `planiruet=1, kogda_planiruet=07.2026`
  - Закупка утверждена, бюджет есть

- **покупает**: 18 баллов
  - Пример: ИНН 7718560636, `data_zakupki=30.10.2020`
  - Покупали раньше, значит машина есть

- **водоканал**: 12 баллов
  - 683 организации из выгрузки
  - Воздуходувка есть наверняка, но срочности нет

- **только на площадке**: 5 баллов
  - Пример: ИНН 5243009501, `na_ploshchadke=1, sostoyaniy=0`
  - Слабый признак

### 2. Наличие людей (40 баллов)

- **технический человек + телефон**: 40 баллов
  - Пример: ИНН 6612005052, `tehnicheskih_lyudey=2, s_telefonom=2`
  - 161 предприятие из 25 083
  - Прямой контакт с ЛПР, звоним сразу

- **технический человек без телефона**: 25 баллов
  - Пример: ИНН 0277077282, `lyudej_tehnicheskih=1, lyudej_s_telefonom=0`
  - 103 предприятия, но телефон искать надо

- **любой человек с телефоном**: 15 баллов
  - Пример: ИНН 6451122250, `lyudej_s_telefonom=7, lyudej_tehnicheskih=0`
  - Не ЛПР, но войти можно

- **директор известен**: 8 баллов
  - 735 предприятий, поле `direktor`
  - Фамилия для секретаря

- **нет людей**: 0 баллов
  - Большинство базы

### 3. Активность (20 баллов)

- **свежая закупка (2025–2026)**: 20 баллов
  - Пример: ИНН 0277077282, `data_zakupki=10.07.2026`
  - Покупают прямо сейчас

- **закупка 2023–2024**: 12 баллов
  - Цикл 3–5 лет, скоро понадобится

- **вакансии**: 10 баллов
  - Пример: ИНН 7704784450, `vakansii=1`
  - Расширение, новые проекты

- **проверки надзора**: 8 баллов
  - Пример: ИНН 7701984274, `proverok_nadzora_2025_2026=172`
  - Высокий риск, следят за безопасностью

- **новость**: 6 баллов
  - 178 предприятий, поле `novost`
  - Компания на виду

- **старая закупка / нет активности**: 0 баллов

### 4. Размер (10 баллов)

- **выручка > 1 млрд**: 10 баллов
  - Пример: ИНН 2124009521, `vyruchka_rub=13500000000.0`
  - 3060 предприятий с выручкой
  - Есть деньги на машины

- **выручка 100 млн – 1 млрд**: 6 баллов
  - Средний бизнес

- **выручка < 100 млн**: 2 баллов
  - Малый бизнес

- **выручки нет**: 0 баллов
  - 22 023 предприятия, поле пустое

## Примеры расчёта

**ИНН 2124009521 (Химпром):**
- состояние: есть + истёк (30)
- люди: 36 технических + 85 с телефоном (40)
- активность: закупка 31.05.2024 (12)
- размер: 13,5 млрд (10)
- **Итого: 92 балла** — звонить первым

**ИНН 0277077282 (БГК):**
- состояние: есть + истёк + истекает (30)
- люди: 1 технический, телефона нет (25)
- активность: закупка 10.07.2026 (20)
- размер: выручки нет (0)
- **Итого: 75 баллов** — звонить, но телефон искать

**ИНН 5243009501:**
- состояние: только на площадке (5)
- люди: нет (0)
- активность: нет (0)
- размер: 56,2 млн (2)
- **Итого: 7 баллов** — не звонить

## Почему так

Вес отражает вероятность результата на звонок:
- **Люди (40%)** — главная беда базы. 103 технических человека на 25 083 предприятия. Если есть имя и телефон, это золото.
- **Состояние (30%)** — истёкший срок = срочная потребность. Планы закупок = утверждённый бюджет.
- **Активность (20%)** — свежая закупка означает, что с компанией можно работать прямо сейчас.
- **Размер (10%)** — выручка есть у 3060 из 25 083. Признак платёжеспособности, но не главный.
