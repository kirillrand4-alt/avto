## Степень доверия — как показать

Проблема видна в цифрах: 25 083 предприятия, технических людей 103, с телефонами 161. Продавец должен понимать, кому звонить в первую очередь.

### Что влияет на доверие (из ваших данных)

**Высокое доверие:**
- `rol=техническая` + `mobilnyy=1` + свежая дата + много упоминаний
- Пример: inn=2124009521, Сергеева — техник, 19 тендеров, май'24, мобильный+почта

**Среднее доверие:**
- Техник, но дата старая (inn=7417001747, Аминев — окт'16, 8 лет назад)
- Роль неясна, но свежий мобильный (inn=6670061296, Мерсикова — роль?, июн'24, 6 упоминаний)
- Снабжение вместо техники (inn=4205281286, Белова — снабжение, авг'23)

**Низкое доверие:**
- `rol=неясно` без мобильного (inn=4715030610, Алименко — роль?, только городской)
- В сводке: `tehnicheskih_lyudey=1` но `s_telefonom=0` — есть в документах, телефона нет

### Предложение: одна колонка `nadezhnost`

Формат: `категория | почему`

**Значения:**

```
НАДЕЖНЫЙ | техник 19т май'24 моб     ← звонить первым
СРЕДНИЙ | техник окт'16 моб устарел  ← проверить, может уволился  
СРЕДНИЙ | роль? 6т июн'24 моб        ← свежий, но не факт что техник
СЛАБЫЙ | роль? только гор            ← вход через секретаря
НЕТ ТЕЛ | техник упомянут            ← искать телефон отдельно
```

**Логика:**

1. Нет телефона → `НЕТ ТЕЛ`
2. `rol=неясно` + `mobilnyy≠1` → `СЛАБЫЙ`
3. Дата >3 лет → `СЛАБЫЙ`
4. `rol=техническая` + `mobilnyy=1` + дата <18мес + упоминаний >5 → `НАДЕЖНЫЙ`
5. Остальное → `СРЕДНИЙ`

### Что показывать в колонке

Короткий код из элементов:

**Роль:**
- `техник` = техническая
- `снаб` = снабжение  
- `роль?` = неясно

**Свежесть:**
- `май'24` — месяц+год последнего упоминания
- `окт'16 устарел` — если >2 лет

**Контакт:**
- `моб` = есть мобильный
- `только гор` = нет мобильного
- `+почта` = есть email

**Частота:**
- `19т` = 19 тендеров (если >5)

Пример заполнения для реальных строк:

```
inn=2124009521 Сергеева    | НАДЕЖНЫЙ | техник 19т май'24 моб+почта
inn=7417001747 Аминев      | СРЕДНИЙ | техник 2т окт'16 моб устарел
inn=6670061296 Мерсикова   | СРЕДНИЙ | роль? 6т июн'24 моб
inn=4715030610 Алименко    | СЛАБЫЙ | роль? 2т только гор
inn=0277077282 [нет людей] | НЕТ ТЕЛ | 1 техник без телефона
```

### Источники (уже есть, но раскидать по полям)

Не надо новую колонку — достаточно в `lyudi_podrobno` расширить:

```
Сергеева Оксана | ведущий инженер ТОиР | 8-960-314-72-92 | o.sergeeva@himprom.com | 
  ↳ 19 упоминаний, последнее 31.05.2024 в tender.pro/908999
  ↳ основание: "Консультации по телефону: Сергеева Оксана..."
```

Продавец видит: откуда взят контакт, сколько раз встречался, насколько свежий.

Числа: из 161 человека с телефоном примерно 50-60 будут НАДЕЖНЫЙ (техник+моб+свежий), 70-80 СРЕДНИЙ, 20-30 СЛАБЫЙ. Для 24 922 предприятий без людей — задача найти контакты.
