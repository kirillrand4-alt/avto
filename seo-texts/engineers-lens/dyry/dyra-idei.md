## КРИТИЧНЫЕ НАХОДКИ (собранные данные могут быть неверны)

### 1. КЭР: проверили закон, а не практику публикации

**Цитата:** "ПП РФ от 29.05.2025 № 777 размещает программу и обосновывающие материалы в ГИСП, слов «опубликовать»/«на официальном сайте»/«общедоступ» в нём нет"

**Класс ошибки:** Класс 1 (правильно проверенное утверждение о неправильном объекте). Проверили постановление о порядке размещения, но не проверили, публикуются ли КЭР с ППЭЭ другими путями: на сайтах предприятий (раздел экологии), в составе проектной документации на общественных обсуждениях (как декларация «Полюс Проекта» в п.52), в тарифных делах.

**Проверка:** взять 5 организаций из верхних строк реестра КЭР (4 505 записей), найти их корпсайты, поискать в разделах экология/раскрытие информации слова "комплексное экологическое разрешение" или номер из реестра. Если хотя бы один КЭР открывается и внутри есть программа с оборудованием и сроками — вывод "оборудования нет" неверен.

### 2. Экспертные заключения: вывод по форме, а не по документу

**Цитата:** "вывод «оборудования в ЭЗ нет» опирается на типовую форму ФАС 237/22, а не на живой документ"

**Класс ошибки:** Класс 1 (неправильный объект). Прямое признание: проверили бланк, а не заполненный документ.

**Проверка:** открыть 2-3 живых экспертных заключения региональных тарифных органов (адреса есть в п.61: СПб, Воронеж, Пермь, плюс Москва по Мосводоканалу). Ctrl+F "компрессор", "насос", "оборудование". Если хотя бы в одном есть перечень — форма и практика расходятся.

### 3. Процессные термины: инструмент отбраковки сломан

**Цитата:** "по признаку «машина не названа в тексте» из `epb-processy.csv` выброшены 43 живых записи Росэнергоатома с названными марками (305ВП-16/70, 7ВП-20/220...)"

**Класс ошибки:** Класс 3 (замер сломанным инструментом). Правило "нет марки = шум" применили ко всем 570 предприятиям, но на Росэнергоатоме оно дало 43 ложных отброса из 43 проверенных — 100% брак.

**Проверка:** прогнать `epb-processy.csv` (570 строк) через тот же скрипт поиска марок, что использовали для Росэнергоатома (п.63: запрос по обозначениям типа "305ВП"). Посчитать, у скольких из 570 в реестре есть заключения с названными машинами. Если >10% — правило убило реальные данные.

### 4. Водоканалы: крупнейший оператор не попал в выборку

**Цитата:** "АО «Мосводоканал» (ИНН 7701984274) отсутствует в списке 683 водоканалов... При этом Мосводоканал есть в `centro/epb-centro-vse.csv`. Сколько ещё крупных операторов пропущено — не измерено"

**Класс ошибки:** Класс 3 (сломанный инструмент). Если выборка по ОКВЭД 36.00/37.00 не поймала Мосводоканал (крупнейший по стране), значит механизм отбора даёт систематический пропуск.

**Проверка:** взять топ-20 городов РФ по населению. Для каждого найти водоканал вручную (поиск "водоканал [город]" → официальный сайт → ИНН). Сверить 20 ИНН со списком 683. Посчитать процент отсутствующих. Если ≥30% — база неполна на треть по крупным операторам, и все оценки по водоканалам занижены.

### 5. Порог длины марки: установлен наугад, даёт шум

**Цитата:** "«К-100-61-1» дал 369 заключений у 62 предприятий — короткая марка работает как широкий запрос, потому что поиск со стеммингом. Порог `--min-len 6` подобран на глаз"

**Класс ошибки:** Класс 6 (порог поставлен по краю, а не по данным). 369 заключений на одну марку — это явно не реальное распространение, а артефакт поиска. Но сколько марок попали под этот артефакт — не измерено, порог взят "на глаз".

**Проверка:** взять 10 коротких обозначений (длина 4-5 знаков) из каталога Невского завода. По каждому запустить поиск в реестре ЭПБ, посмотреть число заключений. Построить гистограмму: длина обозначения vs медианное число заключений. Найти длину, где число скачком падает с сотен до единиц — это настоящий порог. Если он не 6, значит текущий порог режет либо реальные данные, либо пропускает шум.
