## 1.4. Ближайшее к нашему профилю — тягодутьевое оборудование

Слова «воздуходувка» в 30 схемах нет ни разу. Зато есть **дымососы и дутьевые вентиляторы
с маркой, производительностью и мощностью в кВт**. Точный счёт: слово «дымосос» —
в **9 документах из 30** (Абан 46, Радужный 23, Кушва 18, Вязники-2020 15, Вязники-2023 14,
Наволоки 9, Палласовка 4, Кизилюрт 2, Свердловское 2); «дымосос» или «вентилятор» —
в **12 документах из 30** (добавляются Новокузнецк, Ачинск, Зеленоградск).
Дословно, схема г. Радужный, таблица 1.9
«Характеристики тягодутьевых устройств котельной КВГМ»:

1  Вентиляторы дутьевые            ВДН-17    3       75 000                    260             160            990

Это машины одного класса с нашими воздуходувками: центробежный нагнетатель воздуха на

`Электроподстанция ГПП 110/10 кВ`. То есть схема попутно отвечает на вопрос
«у кого на территории есть компрессорная станция».

# 2. ЕГРЗ — реестр заключений государственной экспертизы

**Это самая ценная находка сессии.** Реестр открыт целиком, без авторизации, машинным
интерфейсом.

## 2.1. Адрес и как открыть

* Портал: `https://egrz.ru/organisation/reestr/latest` — Angular-приложение, содержимого
  в HTML нет.
* **API: `https://open-api.egrz.ru/api/PublicRegistrationBook`** — OData v4,
  без ключа и без авторизации. Найден в `main.bundle.js` портала
  (`PublicPortal_API="https://open-api.egrz.ru/"`).
* Поддерживаются `$filter=contains(...)`, `$select`, `$top`, `$skip`, `$orderby`, `$count`.

**Упор, на котором потерял время и который надо помнить.** `egrz.ru` и `open-api.egrz.ru`
требуют **legacy TLS renegotiation**. Из-за этого:
* `fetch_url` через раннер падает: `SSL: UNSAFE_LEGACY_RENEGOTIATION_DISABLED`;
* `curl` в песочнице отдаёт код 000 и `error:0A000152 unsafe legacy renegotiation disabled`.

Лечится конфигом OpenSSL, а не отключением проверки сертификата:

```
# /tmp/ossl.cnf
openssl_conf = default_conf
[default_conf]
ssl_conf = ssl_sect
[ssl_sect]
system_default = system_default_sect
[system_default_sect]
Options = UnsafeLegacyRenegotiation
CipherString = DEFAULT:@SECLEVEL=0
```

и `OPENSSL_CONF=/tmp/ossl.cnf curl …`. После этого **ЕГРЗ открывается прямо из песочницы,
раннер не нужен вообще.** Это ещё один случай ловушки В8: «источник закрыт» относилось
к рукопожатию TLS, а не к источнику.

# 7. Чему верить нельзя

Раздел про собственную работу.

**Ни один вывод не проверен звонком.** Всё — то, что было на экране 30.07.2026.

**«Марок 46 в схеме Одинцова» — цифра моего регэкспа, а не документа.** Первая версия
парсера обрезала двухсловные марки: `Vitoplex 100 PV1` превращался в `PV1`,
`Vitoplex 200 SX2A` — в `SX2A`. Исправлено, но **в CSV осталась строка `100 M148`** —
это тоже обрезанная марка (вероятно `Vitoplex 100 M148`). Все строки из Одинцова в CSV
несут оговорку об этом. Полностью надёжны только те марки, которые приведены в отчёте
дословным блоком текста.

**216 строк из Одинцова — это один документ, а не 30.** Я распарсил таблицу только у него.

# 9. Инструменты этой сессии

Всё в `scratchpad/vp/`:

| Файл | Что делает |
|---|---|
| `egrz.py` | ЕГРЗ OData: `count <слово>` и `rows <слово> <N>`; сам ставит `OPENSSL_CONF` |
| `egrz_bulk.py` | постраничная выгрузка всех записей по списку слов в `egrz-rows.json` |
| `serp.py` | SERP через xmlriver: конфиг → `panel_file_put` → `panel_py serp_fetch.py` → разбор в песочнице; печатает `found`/`docs`/`err` по каждому запросу (правило В8) |
| `fu.py` | `fetch_url` через раннер + скачивание с дропа; **процентное кодирование кириллических URL и IDNA домена** |
| `get.py` | скачать документ: сначала локальный `curl` (дёшево), при неудаче — раннер |
| `doc.py` / `cache.py` | извлечение текста из PDF (pypdf + pdfminer), DOCX, XLSX, HTML; выбор кодировки по мета-тегу И по доле кириллицы |
| `scan.py` | по документу: извлекаемость (знаков на страницу → признак скана), счётчики марок, тягодутьевых, «год ввода», ФИО, телефонов |
| `ctx.py` | контекст ±N знаков вокруг слова в конкретном документе |

Ловушки, на которых потерял время:

* **ЕГРЗ требует legacy TLS renegotiation** — и раннер, и песочница падают до запроса.
  Лечится `OPENSSL_CONF`, а не отключением проверки сертификата.
* **Длинный запрос в DDG = ноль результатов.** Запросы из 14 слов давали 0 при
  `query_echoed=true`. Запросы в кавычках — тоже 0. xmlriver кавычки понимает.
* **Три муниципальных сайта из 33 не отдали PDF**: 403 и два невалидных сертификата.
  Через раннер тоже. Это 9 % потерь, и они не про источник, а про TLS у муниципалитетов.
* **`minenergo.gov.ru` отдаёт 403 из песочницы и 200 через раннер**, но содержимого нет
  в обоих случаях — это JS-приложение.
