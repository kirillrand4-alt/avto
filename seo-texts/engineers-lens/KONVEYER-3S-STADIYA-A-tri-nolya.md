## Диагноз по каждому — они РАЗНЫЕ, и это главное

**1. `zakupki` — конвейер спрашивает модель про номер аукциона.**

Живой код: `extract_event(title, source)` — классификатору уезжает **только `title`**.
А `title` у закупки выглядит так:

```
title      Электронный аукцион №0318300194226000355
link       https://zakupki.gov.ru/epz/order/notice/ea20/view/common-info.html?regNumber=…
query      компрессорная установка          <- ПРЕДМЕТ ЛЕЖИТ ЗДЕСЬ И НЕ ЕДЕТ ДАЛЬШЕ
collector  zakupki
```

В заголовке нет ни предмета, ни компании, ни суммы — по нему нельзя решить «капекс/не
капекс» в принципе. **zakupki обречён давать ноль всегда, сколько его ни собирай.** При
этом семантически это наш лучший источник: там не «завод модернизируется», там
«покупают компрессорную установку», то есть повод прямее некуда.

Починка дешёвая и без провайдера: склеивать текст для классификатора из `title + query`
(а лучше — дотянуть предмет закупки со страницы извещения, ссылка есть).
