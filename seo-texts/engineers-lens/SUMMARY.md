# Синтез 14 линз: как найти инженеров в промышленных компаниях

## Где линзы сошлись

**1. Реестр ОПО Ростехнадзора — единственный прямой источник списка предприятий с компрессорным хозяйством**

Линзы «Госреестры», «Приоритизация», «Company-first», «От списка компаних к людям» независимо назвали реестр опасных производственных объектов (pub.fsa.gov.ru) ключевым входом. Это ~400 тыс. объектов с ИНН владельца, фильтруемых по типу оборудования (компрессорные станции, сосуды под давлением). Публичный, обновляется ежеквартально, юридически чист. Даёт не людей, но даёт список предприятий, где компрессоры гарантированно есть.

**2. Закупки 44-ФЗ/223-ФЗ как источник двух сигналов: списка компаний и контактов в протоколах**

Четыре линзы («Госзакупки», «Приоритизация», «Company-first», «От списка компаний к людям») указали zakupki.gov.ru. Поиск по ключевым словам («компрессор», «винтовой», «осушитель») даёт ИНН заказчика (строим список компаний) + протоколы комиссий с ФИО и должностями членов (главные инженеры, техдиректора). Публичный источник, API существует (но НЕ ПРОВЕРЕНО: лимиты), парсинг возможен. Линза «Адверсариальная» не оспорила законность, только предупредила о протухании (6-12 месяцев).

**3. Официальный сайт компании (раздел «Руководство») + звонок на общий номер — связка с покрытием 70-80% для крупных предприятий**

Линзы «Цифровой след», «Company-first», «От списка компаний к людям» сошлись: сайт компании публикует структуру руководства с ФИО/должностями в 60-80% случаев для Tier 1 (крупные предприятия). Если сайта нет или контактов мало — звонок на общий номер с открытым запросом («готовим КП по компрессорам, с кем обсудить?») даёт контакт в 75% случаев. Бесплатно, легально, масштабируемо. Линза «Адверсариальная» не оспорила метод, только указала на риск раздражения при холодном письме после такого контакта.

**4. Вакансии на hh.ru через API — горячий сигнал смены человека в компании**

Три линзы («Рынок труда», «Приоритизация», «Company-first») назвали мониторинг вакансий «главный энергетик», «главный механик». Вакансия = компания ищет человека = предыдущий ушёл или компания растёт. API hh.ru открытый (api.hh.ru), 500-1000 активных вакансий по целевым должностям в любой момент. Даёт ИНН компании + иногда контакт HR/техдиректора в описании. Объём мал, но качество высокое. Юридически: публичные вакансии, серая зона по условиям API, но прямого запрета нет.

**5. Собственные данные (679 МБ обзвона + 1117 КП) ценнее внешних источников**

Линзы «Собственные данные», «Приоритизация», «Адверсариальная» сошлись: база обзвона и КП — это тёплые контакты с историей взаимодействия. Конверсия из тёплых в 10 раз выше, чем из холодных. КП содержат связку компания-модель-дата, что даёт расчёт «срока замены» оборудования — точку входа для персонализированного обращения. Нужна дедупликация по ИНН и обогащение актуальными должностями, но это дешевле сбора новой базы с нуля.

**6. ИНН как первичный ключ при работе от компании к людям**

Линзы «Инженерия данных», «Company-first», «От списка компаний к людям» сошлись: ИНН стабилен, уникален, связывает все реестры (ЕГРЮЛ, ОПО, закупки, СПАРК). Название компании нестабильно (ООО/АО, кавычки, реорганизации). Схема: список ИНН целевых компаний → обход источников для каждого ИНН → связка person_id — org_id — employment с датами и уровнем доказательства.

## Где линзы противоречат друг другу

**Противоречие 1: Масштабируемость vs актуальность**

Линзы «Патенты», «Госреестры», «Отраслевые события» предлагают парсинг массивов данных (ФИПС, СРО, программы конференций) — даёт тысячи записей разом. Линзы «Адверсариальная», «Доказательство и датировка» возражают: данные протухают быстрее, чем собираются. Патенты — связка на момент подачи заявки (отставание 1,5-3 года). Конференции — актуально 6-12 месяцев. Текучесть кадров 10-15%/год. Через год половина связок неверна.

**Какой аргумент сильнее:** Правы обе стороны в зависимости от цели. Если нужен холодный охват «в ширину» — массовые источники дают объём. Если цель — лиды с высокой конверсией — нужна верификация каждой записи перед использованием, что убивает масштаб. Компромисс: массовые источники для формирования списка компаний (ОПО, закупки), затем точечный обход каждой компании по свежим источникам (сайт, звонок). Не собирать «всех инженеров России», а собирать «инженера в конкретной компании прямо сейчас».

**Противоречие 2: Купить базу vs собрать самому**

Линза «Купить вместо собирать» предлагает Seldon.Basis (30 тыс. руб./1000 контактов), выставочные базы (100 тыс. руб./3000 контактов), платные справочники. Линзы «Адверсариальная», «Приоритизация», «Юридический контур» возражают: покупные базы протухают (продавец не обновляет), непроверенное качество (дубли, мусор), юридический риск (нет цепочки согласий на передачу ПДн третьим лицам). Стоимость очистки и верификации съедает экономию.

**Какой аргумент сильнее:** Правы противники покупки. НЕ ПРОВЕРЕНО: какой процент в Seldon.Basis именно целевая аудитория (главные инженеры, энергетики). Для узкой B2B-ниши (промышленные инженеры с компрессорным хозяйством) универсальные базы дают низкое покрытие. Разумное исключение: базы участников профильных выставок (Нефтегаз, Компрессоры и пневматика) — легально, актуально 3-6 месяцев, релевантно. Цена 30-50 руб./контакт. Проверить перед покупкой: тестовый доступ, оценить процент попадания в ЦА.

**Противоречие 3: Социальные сети как источник**

Линзы «Рынок труда», «Цифровой след», «Company-first» предлагают парсинг ВКонтакте, Одноклассников, Telegram-чатов — люди указывают место работы и должность. Линза «Юридический контур» и «Адверсариальная» возражают: массовый сбор из соцсетей нарушает пользовательские соглашения и может попасть под 152-ФЗ, если используется для рассылки без согласия. Один жалоба = проверка Роскомнадзора, штраф 30-150 тыс. руб.

**Какой аргумент сильнее:** Правы обе стороны. Соцсети годятся для ручного поиска конкретного человека (проверка, что Иванов И.И. из компании X действительно главный энергетик). Для массового сбора и холодной рассылки — токсично. Компромисс: использовать соцсети как этап верификации в company-first обходе (нашли ФИО на сайте компании → проверили в ВК, что место работы совпадает), но не как первичный источник.

**Противоречие 4: Полнота базы vs приоритизация**

Линзы «Госреестры», «Патенты», «Цифровой след» тяготеют к идее «собрать всех». Линзы «Приоритизация», «Адверсариальная», «Собственные данные» возражают: полнота — ловушка. Реальная вселенная задачи — 120-210 тыс. человек (40-70 тыс. предприятий × 3 роли на предприятие). База из 5-10 тыс. актуальных записей даёт работу на год. Первые 500 правильных записей (крупные предприятия, горячие сигналы) важнее 50 тыс. устаревших.

**Какой аргумент сильнее:** Правы сторонники приоритизации. Для команды «один человек + AI» тотальность недостижима и не нужна. Tier-система (Tier 1: уже покупали, выручка >500 млн, регион присутствия; Tier 2: закупали по 44/223-ФЗ, средний бизнес; Tier 3: просто подходят по ОКВЭД) фокусирует ресурсы. Дорогие шаги (платные базы, ручные звонки) — только для Tier 1.

## План на первые две недели

**День 1-2: Проверка гипотезы протухания базы обзвона**

- Взять 50 записей из 679 МБ базы (полугодовой давности).
- Позвонить в компании, спросить «ФИО работает у вас? Какая должность?».
- Посчитать долю несовпадений.
- **Успех:** <7% несовпадений → база актуальна, можно использовать. >15% → база мертва, приоритет на новый сбор.
- **Время:** 8-10 часов (50 звонков × 10 мин).

**День 3: Проверка качества связки ФИО-компания из публичных источников**

- Взять 30 записей, где источник не прямой контакт (парсинг сайтов, конференции).
- Позвонить, проверить должность и отчество.
- Посчитать долю ошибок.
- **Успех:** <5% ошибок → метод работает. >10% → нужна верификация каждой записи перед использованием.
- **Время:** 5-7 часов.

**День 4-5: Парсинг реестра ОПО Ростехнадзора**

- Выгрузить список предприятий с компрессорными станциями (pub.fsa.gov.ru).
- Извлечь ИНН, название, регион.
- Дедуплицировать по ИНН.
- **Успех:** 10-20 тыс. записей ИНН целевых предприятий.
- **Время:** 16-20 часов (написание парсера или ручная выгрузка по регионам).

**День 6-7: Парсинг закупок 44/223-ФЗ**

- Настроить поиск по ключевым словам («компрессор», «винтовой», «осушитель») через zakupki.gov.ru.
- Выгрузить ИНН заказчиков за последние 2 года.
- Скачать протоколы комиссий (PDF), извлечь ФИО и должности (вручную или через LLM).
- **Успех:** 1000-2000 ИНН компаний + 500-1000 записей ФИО из протоколов.
- **Время:** 16-20 часов.

**День 8-9: Тестовый обход 50 компаний по плейбуку**

- Взять 50 ИНН из реестра ОПО (Tier 1: крупные, регион присутствия).
- Пройти шаги: ЕГРЮЛ → сайт компании → закупки → звонок.
- Зафиксировать: сколько контактов нашли, сколько времени ушло, какие источники сработали.
- **Успех:** Найдено ≥1 релевантный контакт в 70% компаний. Среднее время <20 мин/компания.
- **Время:** 16-20 часов.

**День 10-11: Настройка мониторинга вакансий hh.ru**

- Зарегистрировать приложение в hh.ru API.
- Настроить ежедневный запрос вакансий по должностям («главный энергетик», «главный механик»).
- Извлекать ИНН компании, контакты из описания.
- **Успех:** Автоматический список 20-30 горячих компаний/неделю.
- **Время:** 8-12 часов.

**День 12-13: Дедупликация собственной базы по ИНН**

- Загрузить 679 МБ обзвона + 1117 КП в БД.
- Нормализовать ФИО, телефон, название компании.
- Найти ИНН через СПАРК/Контур.Фокус (если есть доступ) или через поиск по названию.
- Слить дубли по ИНН + ФИО.
- **Успех:** Единая база с полем ИНН для каждой компании.
- **Время:** 16-20 часов.

**День 14: Тестовая холодная рассылка 50 писем**

- Взять 50 записей с высоким confidence_score (корпоративный email + подтверждение должности).
- Написать персонализированное письмо с указанием источника контакта.
- Отправить, отследить открытия и ответы.
- **Успех:** Open rate >20%, ≥5 ответов, 0 жалоб на спам.
- **Время:** 8-10 часов (подготовка писем + анализ).

## Красные линии

**1. Не покупать серые базы с форумов/Telegram**  
Юридически токсично (нарушение 152-ФЗ), нет цепочки согласий, риск штрафа 30-150 тыс. руб. за одну жалобу.

**2. Не парсить соцсети массово для рассылки**  
Нарушает пользовательские соглашения ВК/ОК, попадает под 152-ФЗ при использовании без согласия. Допустимо только для ручной верификации конкретных людей.

**3. Не отправлять массовую рассылку с основного домена prokompressor.ru**  
Риск попадания в спам-листы убьёт деловую переписку с действующими клиентами. Использовать отдельный домен для холодных кампаний.

**4. Не игнорировать opt-out**  
Если человек ответил «отписаться» или пожаловался — удалить немедленно и навсегда. Повторный контакт = прямое нарушение ФЗ-38 и гарантия жалобы.

**5. Не отправлять письма на личные email (mail.ru, yandex.ru) инженеров**  
Воспринимается как вторжение, конверсия нулевая, риск жалобы высокий. Только корпоративные адреса.

**6. Не использовать данные старше 18 месяцев без переверификации**  
Связка человек-компания протухает. Письмо на устаревший контакт = минус к репутации.

**7. Не начинать холодную рассылку без прогрева домена**  
Сразу 500 писем = домен в бане за день. Прогрев: 10-20 писем/день × 2-4 недели, мониторинг bounce rate и spam rate.

## Что нужно проверить прежде, чем верить этому документу

**Про реестр ОПО:**
- НЕ ПРОВЕРЕНО: текущий объём записей (линза указывает ~80 тыс., но может измениться).
- НЕ ПРОВЕРЕНО: наличие фильтра именно по компрессорным станциям в веб-интерфейсе.
- НЕ ПРОВЕРЕНО: возможность массовой выгрузки без ручного парсинга по регионам.

**Про zakupki.gov.ru API:**
- НЕ ПРОВЕРЕНО: лимиты запросов к API.
- НЕ ПРОВЕРЕНО: доступность скачивания протоколов в машиночитаемом формате (может быть только PDF).

**Про hh.ru API:**
- НЕ ПРОВЕРЕНО: стабильность работы для коммерческого использования (условия могут запретить).
- НЕ ПРОВЕРЕНО: частота обновления вакансий (может быть задержка).

**Про покрытие источников:**
- Все проценты покрытия (70% для сайтов Tier 1, 75% для звонков) — оценки линз, не проверенные статистикой.
- Проверить на выборке 50-100 компаний перед масштабированием.

**Про текучесть кадров:**
- Линза «Адверсариальная» называет 10-15%/год, но это экстраполяция с общего рынка труда, не проверена для главных инженеров промышленных предприятий.
- Проверить на собственной базе обзвона (план, день 1-2).

**Про стоимость платных сервисов:**
- НЕ ПРОВЕРЕНО: точная цена доступа к базам выставок (линза указывает 100 тыс. руб., может отличаться).
- НЕ ПРОВЕРЕНО: процент целевой аудитории в Seldon.Basis.
- НЕ ПРОВЕРЕНО: цена Контур.Фокус API (линза указывает от 50 тыс. руб./год).

**Про юридические риски:**
- Линза «Юридический контур» даёт общие положения 152-ФЗ и ФЗ-38, но не консультацию юриста. Перед запуском холодной рассылки проконсультироваться с юристом по конкретной схеме сбора данных и формулировкам писем.

**Главный вывод:** Не верить объёмам и процентам до проверки на выборке. Начать с малого (50-100 компаний), измерить реальные цифры, скорректировать план.
