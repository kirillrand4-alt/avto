# Все источники под задачу «Алтайский край: кто закупал компрессорное, ТО, запчасти или проходил проверки»

Опись каналов: что даёт, чем берётся, открыт ли СЕЙЧАС, чем измерен. Отрицательные
результаты записаны наравне с положительными — они экономят заход.

---

## 0. Сначала о том, как режется регион. Одна ловушка уже поймана замером

**Код в номере заключения ЭПБ — это НЕ регион предприятия.** Проверено на своей базе:

```
22-ТУ-23990-2024   → ПАО «АКРОН», ИНН 5321029508  — Новгородская область
22-ТУ-613355-2025  → ООО «Рудник Весёлый», ИНН 0400005170 — Республика АЛТАЙ, не край
заключений с номером 22-… 251 у 20 предприятий, из них ИНН на 22 — только 4
```

Префикс номера — код территориального органа или экспертной организации, выдавшей документ.
Резать по нему значит собрать чужие регионы и потерять свои.

**Надёжный срез — ИНН и адрес ЕГРЮЛ:**

```
Алтайский край    ИНН начинается на 22
Республика Алтай  ИНН начинается на 04   ← разные субъекты, путать нельзя
```

**Что по краю уже готово в базе:**

```
фактов 304 у 54 предприятий; с маркой 146, со сроком 10, срок ИСТЁК у 9
ресивер 187 · компрессор 73 · воздуходувка 20 · ВРУ 14 · генератор кислорода 4 · ПКС 2
с контактом 41 предприятие из 54
примеры: АО «Барнаултрансмаш» · ФКП «БОЗ» · ООО «Бийскмясопродукт» · санаторий «Алтай»
```

## 2. Закупки: машина, ТО и запчасти

| источник | что даёт | доступ | замер и ловушки |
|---|---|---|---|
| **ЕИС zakupki.gov.ru** (44-ФЗ, 223-ФЗ) | предмет, заказчик, ИНН, сумма, дата, **контактное лицо с должностью** | из песочницы reset; через browser_probe ERR; **у соседей работает срезами** | без окна дат отдаёт голову общей ленты: срез по годам дал новых ИНН 57 → 353, доля подтверждений 21 % → 66 %; `recordsPerPage=50` — впятеро больше карточек |
| **карточка ЕИС, строка «Требования заказчика»** | НАСТОЯЩИЙ эксплуатант | там же | **объявитель ≠ заказчик у 44 % карточек**; по имени организации ловится 5 из 12 — «Администрация города» выглядит обычным заказчиком |
| **Сбербанк-АСТ, РТС-тендер, Росэлторг, ЭТП ГПБ, ТП** | номера процедур, дальше карточка ЕИС | скрипты `*_po_ocheredi.py` | 19 знаков = 44-ФЗ, 11 = 223-ФЗ; ФЗ-94 не спрашивать — 64 карточки из 64 пустые |
| **ТЭК-Торг** | то же | **сломан**: `buildId не найден в __NEXT_DATA__` | площадка сменила разметку, обход чинить |
| **tenderguru и прочие агрегаторы** | сводки | вторые руки | повод посмотреть, не доказательство |

**Слова по четырём видам, чтобы поймать всё:**

```
покупка машины  компрессор · компрессорная установка · воздуходувка · генератор азота/кислорода
ТО              техническое обслуживание компрессор · сервисное обслуживание компрессорного
                оборудования · ремонт компрессора · регламентные работы
запчасти        запасные части к компрессору · клапан всасывающий/нагнетательный ·
                фильтр воздушный · масло компрессорное · ремкомплект · сальник · поршневые кольца
проверка        экспертиза промышленной безопасности компрессор · техническое
                диагностирование · освидетельствование сосудов
```

**Закупка ТО и запчастей доказывает, что машина УЖЕ СТОИТ**; закупка машины — что появится.
Это разные классы, смешивать нельзя.

## 6. Порядок, в котором делать именно Алтайский край

1. Срез по ИНН на 22 из собранного — **54 предприятия готовы сегодня**, 41 с контактом.
2. Реестр ЭПБ идёт по словам, а не по регионам: гнать полный обход, регион резать после.
3. **ЕИС по краю — единственный канал, дающий ТО и запчасти**, реестр их не показывает.
   Заказчики с ИНН на 22, срезы по годам, слова из раздела 2.
4. checko и DaData по найденным ИНН: контакты, ОКВЭД, статус; ликвидированных отсеять.
5. Люди: страница поставщикам → линии служб → именные почты → карточка ЕИС.
