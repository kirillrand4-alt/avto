**Суть:** Ключ дедупликации строится из ИНН и ФИО/должности. Если ФИО и должность пусты (например, из файла `naznacheniya.csv` без телефона), ключ станет `(inn, '')`. Все такие строки с одним ИНН слипнутся в одну, хотя это разные люди.

### М16: Неполная цитата в проверке условия
**Где:** `svesti_obzvon.py`, строка 61

**Суть:** Проверка `'inn' in v` матчит не только слово «inn», но и любое вхождение: «winning», «beginning», «innov». Если в поле `note` написано «Winning bid for compressor» — это даст вес 2.0 («ИНН на странице»), хотя проверки не было.  
**Под угрозой:** Вес доказательства завышен, строка уйдёт выше в списке обзвона.

### М17: Разбор XML итератором без обработки namespaces
**Где:** `erknm_harvest.py`, строка 70  
```python
if el.tag.rsplit('}', 1)[-1] != 'INSPECTION':
    continue
```
**Суть:** Если XML изменит namespace (например, `ns2:INSPECTION` станет `ns3:INSPECTION`), условие `rsplit('}', 1)[-1]` всё равно вернёт `'INSPECTION'`. Но если namespace пропадёт совсем (`<INSPECTION>` без префикса), `.rsplit()` вернёт исходный тег целиком. Зависит от того, как `iterparse` обрабатывает дефолтный namespace.  
**Под угрозой:** Либо ничего (если `.rsplit()` правильно обрабатывает оба случая), либо все записи (если логика ломается).  
**Проверка:** Взять XML без namespace (`<INSPECTION>` вместо `<ns2:INSPECTION>`). Прогнать через `razobrat()`. Сравнить число найденных записей с исходным.

### М18: Дедупликация по нечувствительному ключу
**Где:** `mpb_harvest.py`, строка 114  
```python
seen, recs = set(), []
...
new = [r for r in got if r['nomer'] not in seen]
for r in new:
    seen.add(r['nomer'])
```
**Суть:** Номер заключения может содержать разделители (пробелы, дефисы, слеши), которые на сайте отображаются по-разному: «123/45-АБ» и «123/45 - АБ» — это один номер, но строки разные. Дедупликация по `.strip()` сработает, но если в HTML пробел закодирован как `&nbsp;` или `&#160;` — `html.unescape()` вернёт неразрывный пробел (Unicode `\xa0`), и `.strip()` его не уберёт.  
**Под угрозой:** Дубликаты в выходе. Счётчик `len(recs)` завышен.  
**Проверка:** Найти две страницы с одним заключением, где номер записан с разными пробелами. Прогнать обе через `rows()`. Если в множестве `seen` два разных ключа для одного номера — сработало. Заменить `.strip()` на `re.sub(r'\s+', '', ...)` (убрать все пробелы).
