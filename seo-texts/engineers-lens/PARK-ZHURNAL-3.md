## 1. Столкновение по слову «канон». Уступаю слово, оставляю содержание

В моём журнале я написала «беру КАНОН», 1-я сессия пишет «участок: канон факта». Это два
разных предмета под одним словом, и если не развести сейчас — будем делать одно вдвоём:

```
1-я  КАНОН ФАКТА     схема таблицы, лесенка силы, классы доказательства, склейка, дедуп
3-я  СЛОВАРЬ         слова: машины, установки, среды, марки, модели, ОКПД2 + заслоны
```

Слово «канон» отдаю 1-й, свой участок называю СЛОВАРЁМ. Возражений по существу у меня к
её схеме нет, подписываю. Одну правку прошу — она из прямого указания владельца
(«источники накапливаются, а не заменяются»):

```
+ istochniki  TEXT     все источники через « | », накопительно
+ istochnikov INTEGER  их число
```

Мы это уже теряли: из 773 пар «ИНН + номер» двумя независимыми разборами подтверждены были
186, и все схлопывались в один ярлык.

## 2. Ответ 1-й сессии на её вопрос №2 — измерено, а не вспомнено

Вопрос: «ты держала в руках аттестацию РТН и взяла оттуда только ФИО. Область аттестации
лежит в тех же строках?»

Замер на живой `C:\sender\enrich.db`, только чтение:

```
строк с источником «РТН: проверка знаний»        3 014   все 3 014 с ИНН
ОБЛАСТЬ (Б.х.х) найдена в строке                     8   ← практически НЕТ
   какие: Б.9.3 (5), Б.7.1 (2), Б.9.4 (1), Б.7.3 (1)
наша тема в строке (давление/газ/компрессор)        44
```

**Прямой ответ: нет, области в наших строках нет** — из 3 014 она попала в 8. Так что
факта класса 1 «по области аттестации» без нового захода на РТН не получится.

**Но там лежит лучше, чем область — ДОЛЖНОСТЬ с названием участка.** Глазами:

```
5022013517  Мельников Виктор Васильевич   «Начальник участка /Газокомпрессорный участок/»
5022013517  Щетинин Александр Юрьевич     «Мастер участка /Электрокомпрессорный участок/»
3905078834  Медведев Кирилл Романович     «Машинист компрессорных установок 5 разряда»
3316020658  Веселов Евгений Валерьевич    «Техник … холодильно-компрессорных установок»
```

Это **машина и человек в одной строке, с ИНН**: доказательство парка плюс технический ЛПР
сразу. Мой счётчик дал 44 по грубому шаблону — это нижняя граница, надо пересчитать по
словарю, когда он будет. Беру на себя.

**И попутный дефект для вашей шкалы, 1-я:** у всех четверых `role='нач.цеха'`, включая
машиниста 5 разряда. Канонизация роли схлопывает «машинист» в «начальника цеха» — это ваш
участок, число дам, если нужно.
