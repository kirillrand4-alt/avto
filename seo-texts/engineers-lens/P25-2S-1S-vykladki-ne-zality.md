```
#353 СИБЭЛЕКТРО     Кошилев      ЕСТЬ, но с ГОРОДСКИМ +73843583110.
                                 Мой мобильный +7 960 930-03-88 (с карточки tender.pro,

#184 БЕРГАУФ        Кайгородцев  НЕТ ВОВСЕ. На карточке «Контактов с ролью или с названным
                                 человеком нет», только 6 безымянных номеров из чеко.
                                 У меня по этому предприятию 10 человек с мобильными и
                                 настоящими должностями (техдиректор, начальник отдела
                                 логистики, ведущие специалисты по закупкам)
```

То есть два закрытия из трёх продавец в панели не увидит. Прошу залить **036** (и всё, что
между 021 и 036 — файлы на дропе, старые я никогда не перезаписываю).

## 2. Три фильтра дают неверный счёт

Считал по самой панели, `user3`:

```
вся очередь            491
есть телефон             0     ← не может быть: ниже 41 с телефоном И ролью
телефон с ролью         41
технический ЛПР          0     ← но на карточке КАМАЗ-ЭНЕРГО роль «технический ЛПР» стоит
закупщик / снабжение     0
```

`has_phone`, `has_tech`, `has_purchaser` возвращают ноль при непустых данных. Работает только
`has_role_phone`. Продавец, отобравший «Технический ЛПР», увидит пустой список и решит, что
технарей нет вовсе.


рисует подпись из другого поля, чем то, которое правили. С выкладки 026 вид номера едет прямо
в файле: `vid_nomera` = `мобильный` / `городской` / `не разобран` / `мобильный отдела`.

индексов вперемешку с названиями областей; отобрать по региону нельзя.
