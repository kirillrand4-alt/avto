### Конфликт формул

**Текущая:** дозвон (+40) + мобильный (+15) + техроль (+25) = **80 базовых** → удобство звонка определяет порядок.

**По вероятности покупки:** покупают (+50) + экспертиза (+40) = **90** → нужда определяет порядок.

**Пример конфликта:**
- Главный инженер на заводе, где **сейчас покупают** и экспертиза «не соответствует», но номера нет: 50+40+15+10+10 = **125 по нужде, 0 по текущей формуле**.
- Ведущий инженер на заводе, где машина просто стоит, но есть мобильник: 25+15+15+10 = **65 по нужде, 140+ по текущей формуле**.

Разница: **125 против 65 по сути, 0 против 140 по очереди**.

### Что не хватает для точной оценки

Из поданных колонок **не выводится:**
- размер компрессорного парка (одна машина или десять)
- кто принимает решение о закупке (главный инженер решает или только рекомендует)
- бюджет предприятия на ремонт/замену оборудования

Добывать это дорого (нужно звонить или искать в тендерах), но **из имеющихся данных** линза построена полностью.

### Рекомендация

Если цель — **продать машину**, а не **дозвониться**, базовую арифметику нужно перевернуть:

1. Сначала считать вероятность покупки (острота повода + стадия процесса)
2. Потом вычитать стоимость подхода (нет номера → минус 20, номер через секретаря → минус 10, прямой мобильный → 0)

Тогда НОВАТЭК с главным инженером без номера, где **сейчас покупают**, выйдет выше ХИМПРОМА с мобильниками, где покупали **в 2018 году**.
