ПАО "ХИМПРОМ", Иванов Александр: prioritet=141. Покупают воздушную центробежную, технический ЛПР с мобильным.

## Нормировка 0-100

**Максимум 100** = покупают + воздух центробежная доказанная + технический ЛПР с мобильным и должностью + крупное + свежее.

**0** = возможно нужна (вывод) + нет машины + нет контакта.

Структура: потребность (0-42) + машина (0-25) + контакт (0-28) + дополнительно (0-5).

## Что изменится

1. **Потребность доминирует.** "Покупают" без контакта (33) весит больше, чем "уже есть" с мобильным техническим ЛПР (13+28=41). Но если потребность острая (покупают), разница мала.

2. **"Покупали ранее" получают вес 18.** Было 0 без контакта. Теперь эти строки выше водоканалов с выводом.

3. **Главный инженер без номера = 76 из 100.** Было 88 из 141. Читается: "отличная цель, осталось добыть телефон".

4. **Доступность контакта снижена с ~50 до 28.** Мобильный техническому ЛПР важен, но не перекрывает потребность.

5. **Шкала читаема:** 90+ = горячие звонки, 60-80 = сильные цели без контакта или средние цели с контактом, 30-60 = слабые потребности либо нет доказательств, <30 = только выводы и догадки.

## Чего не хватает

Из колонок ничего критичного. Если добывать:
- **Количество машин на площадке** (парк компрессоров) — оценит размер сделки. Добыча: парсинг тендеров, запросы в открытые источники. Стоимость: высокая.
- **История взаимодействия** (были ли звонки, отказы) — избежит повторов по холодным. Добыча: CRM. Стоимость: низкая, если CRM есть.
