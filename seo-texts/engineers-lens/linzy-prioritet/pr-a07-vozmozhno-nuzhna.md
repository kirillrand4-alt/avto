## Разбор линзы: штраф −20 для «возможно нужна»

### Фактическая опора

**Доказательство из данных:**
АО "РАМЕНСКИЙ ВОДОКАНАЛ" (выручка 1 млрд руб) — `pometka=покупали ранее`, `sreda=воздух`, `tip_mashiny=центробежная`, `data_dokazatelstva=08.2024`, `prioritet=28`. 

Крупный водоканал покупал центробежник. Значит, вывод «у водоканала есть воздуходувка» не теоретический, а подтверждённый.

**Распределение водоканалов по выручке:**
- Крупные (>500 млн): ИНФРАСТРУКТУРНЫЕ Р (345,8 млн), Раменский (1 млрд)
- Мелкие (<100 млн): Водоканал-Тарнога (17,6 млн), Аквасервис (18,3 млн), Райводоканал (34,9 млн)

**Текущая формула:**
Все водоканалы с «возможно нужна» получают одинаковый штраф −20 независимо от размера. Результат: Инфраструктурные Решения (345 млн) = 0 баллов, мелкий Водоканал (17 млн) = 0 баллов.

### Штраф −20 не справедлив для крупных водоканалов

Технологическая реальность: станция аэрации >20 тыс. м³/сутки практически всегда использует центробежные машины. Выручка 1 млрд руб соответствует городу 100-200 тыс. жителей и станции такой мощности.

Вероятность наличия центробежника у крупного водоканала: 70-80%.
Вероятность у мелкого (<100 млн): 10-20% (используют винтовые).

Штраф −20 обнуляет воздух +20 и уравнивает крупный водоканал с предприятием без признаков машины. Это противоречит цели владельца: приоритет должен мерить вероятность сделки.

### Предложение: градированный штраф

Убрать фиксированный −20. Ввести штраф по выручке:

| Выручка | Штраф | Обоснование |
|---------|-------|-------------|
| >500 млн | −5 | Вероятность центробежника 70-80% |
| 100-500 млн | −10 | Вероятность 40-60% |
| <100 млн | −20 | Вероятность 10-20% |

**Результат:**
- Крупный водоканал (1 млрд): +20 (воздух) +6 (размер) −5 (штраф) = **21 балл**
- Средний водоканал (345 млн): +20 −10 = **10 баллов**
- Мелкий водоканал (17 млн): +20 −20 = **0 баллов**

**Проверка логики:**
- Раменский Водоканал с доказанной покупкой (28) > крупный водоканал с выводом (21). Верно: доказанный факт весит больше вывода.
- Крупный водоканал с выводом (21) > мелкий водоканал с выводом (0). Верно: вероятность машины выше.
- Крупный водоканал (21) < покупают с контактами (135). Верно: вывод без контактов слабее активной сделки.

Штраф −20 для всех водоканалов — это подмена «вероятности сделки» на «есть ли формальное доказательство». Градация по размеру исправляет это.
