Смотрю на живые строки по линзе.

## Что происходит сейчас

**Строки "покупали ранее" без человека:**
- "ЭНЕРГЕТИЧЕСКИЕ СИСТЕМЫ" покупали центробежник 09.2022, среда не названа, человека нет — приоритет 0
- ГКНПЦ им. Хруничева покупали центробежник 07.2022, нет человека — 0
- "ОДК ИНЖИНИРИНГ" покупали 01.2021, нет человека — 0
- АО "ПОЧТА РОССИИ" покупали (марка ТА12.60, 04.2021), нет человека — 0

**Строки "покупают" с человеком, но без номера:**
- "НОВАТЭК-ЮРХАРОВНЕФТЕГАЗ" покупают, воздух, центробежная, человек Голушко (первый зампред — главный инженер), номера нет — приоритет 88

**Проблема:**
Предприятия, которые УЖЕ покупали центробежник (доказанная потребность), получают 0, потому что формула считает только дозвон (+40) и техроль (+25). Контакт предприятия есть, человека нет — значит это очередь на ПОИСК ЛПР, а не мусор. Но формула их приравнивает к водоканалам "возможно нужна".

Сравнение:
- "ЭНЕРГЕТИЧЕСКИЕ СИСТЕМЫ" (покупали центробежник, факт) — 0
- "НОВАТЭК" (покупают, ЛПР известен, номера нет) — 88
- Водоканал "ПОДГОРНОЕ 1" (возможно нужна, вывод из аэротенков, чужой контакт) — -25

## Дефект формулы

Цель владельца: предприятие должно КУПИТЬ. Доступность контакта весит +40, больше любого признака потребности. Но "покупали ранее" доказывает потребность сильнее, чем "возможно нужна", а формула их не различает без человека.

"Покупали ранее" сейчас не весит ничего — этого слагаемого нет. Есть только "покупают" (+25) и "планируют покупать" (+30).

## Предложение

Добавить слагаемое **"покупали ранее" +25**. Это доказанная потребность, как "покупают" и "планируют", но в прошлом.

Добавить слагаемое **"человек известен, номера нет" +20**. Это промежуточное состояние: ЛПР найден, осталось добыть телефон. Сейчас такие строки получают техроль +25 и должность +10, но проигрывают +40 за дозвон. Разрыв 40 против 35 слишком велик: "НОВАТЭК" (покупают, главный инженер известен) должен быть выше случайного мобильного на заводе, где машина не нужна.

Тогда очередь:
1. Покупают, дозвон до человека есть (141) — звоним сейчас
2. Покупают, ЛПР известен, номера нет (113) — добываем телефон
3. Покупали ранее, человека нет (25) — ищем ЛПР внутри
4. Водоканалы "возможно нужна" (-25) — вывод, не факт

## Проверка на двойной счёт

Нет пересечений:
- "покупают" +25 (сейчас) vs "покупали ранее" +25 (прошлое) — разные события
- "дозвон до человека" +40 vs "человек известен, номера нет" +20 — разные состояния одной задачи

## Что стоит добавить (требует добычи данных)

**Марка машины +5** (если заполнена `marki`). Сейчас заполнена у 1244 из 7258 строк. Марка подтверждает конкретику: не "компрессор вообще", а "ЦК-135/8" или "К-345-92-1". Это острее абстрактной записи "есть центробежная".

Пример: АО "ПОЧТА РОССИИ" покупали ТА12.60 в 04.2021 — конкретная марка весомее записи "покупали центробежник" без подробностей.

## Итоговая правка формулы

Добавить:
- покупали ранее +25
- человек известен, номера нет +20
- марка названа +5 (если `marki` не пусто)

Строки "покупали ранее" без человека поднимутся с 0 до 25-30, встанут выше водоканалов, но ниже "покупают с ЛПР".
