Разбираю формулу на два разряда.

## Диагноз

Сейчас доступность контакта весит больше потребности в машине:
- «дозвон есть» +40 > «покупают» +25
- мобильный +15 сравним со «срок истёк» +15

**Пример из данных:**
НОВАТЭК-ЮРХАРОВНЕФТЕГАЗ (покупают воздушную центробежную, свежее доказательство) получает приоритет 88, потому что vid_nomera=номера нет.
ПАО «ХИМПРОМ» (тоже покупают) получает 141, потому что есть мобильный Иванова.

Разница +53 за наличие телефона при равной потребности.

Водоканалы с «возможно нужна» (вывод, не факт) получают -25 только за то, что контакт с чужого сайта, хотя там и потребность сомнительная (воздух +20, но «возможно» -20 = 0 по сути).

## Предложение

Считать два числа:

**1. Ценность (вероятность сделки)**
- покупают +40
- планируют покупать +30  
- срок службы истёк +25
- экспертиза «не соответствует» +20
- воздух +20
- газ/иная среда -15
- доказательство 2026 +15, 2025 +12, 2024 +10, 2023 +5
- марка указана +5 (конкретная машина, не общие слова)
- крупное предприятие (>1 млрд) +5
- «возможно нужна» (вывод без записи) -30

**2. Доступность (цена подхода)**
- мобильный человека +40
- городской с добавочным или прямой у имени +30
- имя и должность названы +15
- техническая роль +20
- контакт свежий (data_sobytiya_cheloveka >= 2024) +5
- общий телефон/почта предприятия +5
- контакт с чужого сайта -25

**Формула:** 
Приоритет = 2 × Ценность + 1 × Доступность

Коэффициент 2 даёт вес: острая потребность без номера важнее слабой потребности с номером.

## Что изменится на примерах

**ПАО «ХИМПРОМ», Иванов (покупают, мобильный)**
Было: 141
Ценность: покупают +40, воздух +20, марка ЦК-135/8 +5, крупное +5 = 70  
Доступность: мобильный +40, имя+должность +15, техническая +20 = 75
Станет: 140 + 75 = **215**

**НОВАТЭК-ЮРХАРОВНЕФТЕГАЗ, Голушко (покупают, нет номера)**
Было: 88
Ценность: покупают +40, воздух +20, 2026 +15 = 75  
Доступность: имя+должность +15, техническая +20, свежий контакт +5 = 40
Станет: 150 + 40 = **190**

**Водоканал «возможно нужна» (чужой сайт)**
Было: -25
Ценность: воздух +20, «возможно нужна» -30 = -10  
Доступность: общий телефон +5, чужой сайт -25 = -20
Станет: -20 + (-20) = **-40**

**Предприятие «покупали ранее», нет человека**
Было: 0  
Ценность: 0 (покупали ранее не даёт баллов)
Доступность: 0
Станет: **0**

## Порядок работы

При новых весах первые 100 подходов:
1. Покупают + есть контакт (215)
2. Покупают + нет номера, но роль известна (190) — **поднимается с 88**
3. Планируют + есть контакт (~170)
4. Срок истёк + экспертиза плохая + есть контакт (~160)
5. Есть машина + мобильный, но покупка не идёт (~90)
6. Покупали ранее, нет человека (0)
7. Водоканалы «возможно» (-40)

Главное: НОВАТЭК, где идёт закупка, но номера нет, обходит предприятия, где есть мобильный, но потребность слабая.

## Что не хватает для точности

Из того, что есть в колонках, но не используется полностью:
- `data_dokazatelstva` — сейчас бинарно (свежее 2024 да/нет), предложил градацию по годам
- `marki` — если заполнено, значит конкретная машина найдена (+5 к ценности)
- `data_sobytiya_cheloveka` — если свежее, контакт актуальнее (+5 к доступности)

Чего нет и добывать дорого:
- текущая авария/штраф/остановка (острая боль)
- размер компрессорного парка (10 машин → замена вероятнее)
- история обзвона (звонили, отказали, попросили через месяц)
