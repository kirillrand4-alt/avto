## Что записывать после звонка

**Минимум для пересчета:**

1. **Результат дозвона**
   - не взяли
   - взяли другого человека
   - взяли секретаря  
   - взяли нужного человека

2. **Состояние потребности** (если дозвонились)
   - активно ищут / тендер идет
   - планируют купить
   - есть машина, работает нормально
   - есть машина, нужна замена
   - не наша машина (не воздух / не центробежная)
   - не нужна

3. **Следующий шаг**
   - отправить коммерческое предложение
   - перезвонить через N дней
   - закрыть (отказ)
   - передать дальше по воронке

4. **Статус сделки** (обновлять по мере движения)
   - первый контакт
   - КП отправлено
   - обсуждение  
   - договор
   - сделка закрыта (выиграли / проиграли / отказались)

5. **Для сильных отклонений от прогноза** — комментарий: «номер оказался неверным», «человек уволился 2 года назад», «машина есть, но не центробежная».

---

## Как пересчитать веса по данным

После 50-100 звонков посчитать для каждого признака:

**Конверсия = (количество сделок с признаком) / (количество контактов с признаком)**

**Новый вес = (конверсия с признаком - базовая конверсия) × 100**

Базовая конверсия — это доля сделок от всех звонков.

Пример: из 100 звонков 10 закрылись сделкой → базовая 10%. Из 20 контактов с признаком «покупают» 12 закрылись → конверсия 60%. Вес = (0.6 - 0.1) × 100 = 50.

## Главные дефекты текущей формулы

### 1. Двойной счет доступности

**Строки ПАО ХИМПРОМ** (prioritet=141, prioritet_pochemu включает «дозвон до человека есть +40 | мобильный +15»):
- Сергеева Оксана, мобильный 8-960-314-72-92
- Иванов Александр, мобильный 8-937-390-40-13
- Кудряшова Лариса, мобильный 8-909-304-56-55

Если мобильный есть → «дозвон до человека есть» true автоматически. Итого +55 только за номер. Это больше, чем «покупают» (+25) + «воздух» (+20) + «крупное предприятие» (+6).

**Предложение:** считать доступность один раз.

Вариант разделения:
- Мобильный личный = 0 (базовый быстрый контакт)
- Городской прямой у имени = -5
- Городской с добавочным = -5  
- Только общий номер = -15
- Нет номера = -30

Техническая роль + должность названа = +35 (вместо +25 роль +10 должность).

---

### 2. Перевернутая воронка: «покупают» +25, «планируют» +30

Строки покупают: ПАО ХИМПРОМ (покупают ЦК-135/8), КАМАЗ (покупают К-345-92-1), филиалы заводов (покупают, data_dokazatelstva свежие).

По логике тендер (покупают) ближе к сделке, чем намерение (планируют). Но вес меньше.

**Предложение:**
- Покупают (процедура идет) = +40
- Планируют = +30
- Срок истек / экспертиза = +25  
- Уже есть = +10

---

### 3. Контакт с чужого сайта -25 слишком жесток

Водоканалы (prioritet=-25): «воздух +20 | только вывод, не факт -20 | контакт с чужого сайта -25» = -25.

Предприятия «покупали ранее» без контактов (prioritet=0): среда не названа, нет телефонов.

Контакт холдинга полезнее отсутствия контакта.

**Предложение:**
- Контакт с чужого сайта = -10 (показываем с пометкой)
- Нет контакта = -20

---

### 4. «Возможно нужна» -20 равен отсутствию доказательств

Водоканалы с аэротенками (prioritet=0 или -25): «воздух (аэротенки, вывод из процесса)» получают «только вывод, не факт -20».

Предприятия «покупали ранее» (prioritet=0): центробежная доказана, но контактов нет.

Вывод слабее факта, но не равен нулю. Если найти главного энергетика водоканала с аэротенками, это лучше предприятия с покупкой 5 лет назад и без контактов.

**Предложение:** разделить «нет доказательства» и «есть вывод».
- Доказанная машина = +20 (воздух) или -15 (газ)
- Вывод из процесса = +5 (слабое указание)
- Нет информации = 0

## Противоречия, которые надо устранить до пересчета

1. **Приоритет — это сделка или звонок?**  
   Сейчас доступность контакта (+55) больше признаков потребности. Строки ПАО ХИМПРОМ (все покупают, воздух, свежее доказательство) имеют prioritet=141, из них +55 за мобильный. Если убрать номера, приоритет упадет до 86.

   Водоканал ООО "ЕНИСЕЙВОДОКАНАЛ" (prioritet=0): выручка 83 млн, телефон есть, но «только вывод» -20. Это ниже предприятий без контактов.

   **Решение:** снизить вес доступности до 20-30% от суммы весов потребности.

2. **Техническая роль без имени что дает?**  
   Строки МУНИЦИПАЛЬНОЕ УЧРЕЖДЕНИЕ (prioritet=8): «покупали ранее» + «доказательство свежее 2024 года +8», но нет человека. Звонить на общий номер школы бесполезно.

   **Решение:** роль без имени = -10 (снизить приоритет).

3. **Срок связки «человек — роль»**  
   Строки ПАО ХИМПРОМ: data_sobytiya_cheloveka от 28.06.2018 до 31.05.2024. Записи до 2020 года устарели (6 лет), но выбросить нельзя.

   **Решение:** добавить штраф за возраст данных о человеке.
   - Свежее 2024 = 0
   - 2022-2023 = -5  
   - 2020-2021 = -10
   - Старше 2020 = -15

   Пересчитать после звонков: если 50% номеров старше 2020 не работают → штраф увеличить.

## Новые переменные из существующих колонок

**Не требуют добывания:**
- Возраст доказательства: (2026 - год из data_dokazatelstva) → если больше 3 лет, штраф -5
- Размер предприятия: vyruchka_rub разбить на <100 млн (0), 100 млн - 1 млрд (+5), >1 млрд (+10)
- Возраст данных о человеке: (2026 - год из data_sobytiya_cheloveka) → штраф по таблице выше

**Требуют добывания (оценить стоимость отдельно):**
- Количество машин на предприятии (размер парка): если 10+ машин → крупный заказчик, но это требует исследования каждого предприятия
- Конкуренты на предприятии: кто еще поставлял, кто обслуживает → требует звонков или баз данных
- История контактов: сколько раз звонили раньше, что отвечали → требует CRM с историей

## Итоговая схема проверки

1. Первые 10 звонков: записывать все подробно, смотреть, где прогноз ошибся сильно.

2. После 50 звонков: посчитать конверсию по каждому признаку, выявить самые сильные отклонения.

3. Пересчитать веса для признаков с отклонением >30%.

4. Проверить на противоречия: «покупают» > «планируют», сумма за доступность < суммы за потребность.

5. После 100 звонков: финальный пересчет всех весов, зафиксировать формулу на 3-6 месяцев.
