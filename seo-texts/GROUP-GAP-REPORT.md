# Сколько ещё групп можно сделать по разделу «Воздушные компрессоры»

Источник: `bitrix-export-full.tar.gz` с дропа (полная выгрузка Битрикса,
600 738 строк → 27 477 товаров). Раздел «Воздушные компрессоры»:
**20 046 активных публикуемых позиций**.

Порог: группа засчитана, только если в неё попадает **больше 10 товаров**.

Уже сделано: 567 посадочных в дереве `/catalog/vozdushnye-kompressory/` —
из них ~175 одиночных фасетов (бренд, страна, мощность, давление,
производительность, ресивер, тип, смазка, привод, комплектация, напряжение)
и ~390 комбинаций.

## Короткий ответ

| | групп |
|---|---|
| Одиночных фасетов, технически возможных (>10 товаров) | **655** |
| Из них осмысленных для SEO (шорт-лист) | **254** |
| Парных комбинаций по 14 связкам (>10 товаров), за вычетом сделанных | **≈1 900** |

Бренды и страны выбраны до дна: 58 брендов с >10 позиций и все 16 стран уже
имеют страницы. Рост — в **новых свойствах** и в **комбинациях**.

## Порядок запуска

1. **Тир 1 — 47 страниц, максимальный спрос при минимальной работе.**
   Поршневые и шестерёнчатые (3) · назначение: фотосепараторы / медицина / буровые /
   лазерная резка (4) · передвижные (1) · северное исполнение −40/−20 °C (2) ·
   напряжение 400 / 380-660 / 660-1140 / 6000 В (4) · мощность 1,5–5 кВт (5) ·
   ресивер 270 / 300 / 150 / 100 / 50 / 90 / 24 / 36 / 120 / 140 / 160 / 180 /
   230 / 240 / 350 / 540 / 750 л (17) · давление 7,5 и 8,5 бар (2) ·
   водяное охлаждение (1) · IP65/IP66 (2) · малошумные (1) ·
   генераторы азота + центробежные (2) · дизель Cummins/Yuchai/Isuzu (3).
2. **Тир 2 — 79 страниц серий.** Делать вложенно в бренд: `/enger/eagle/`,
   `/atlas-copco/ga/`. Требует сверки названий серий с сайтом производителя.
3. **Тир 3 — 128 страниц.** Винтовой блок (31), круглая производительность (38),
   остальные давление (17) и мощность (14), остальная товарная группа 1С (12),
   остальные ДВС (9), гарантия (2), точка росы (2), IP56, воздушное охлаждение,
   дизельный тип двигателя.
4. **Тир 4 — ~1 900 комбинаций.** Начинать с «Бренд × Мощность» (529):
   у нас уже есть и бренды, и мощности по отдельности — пересечение даёт
   самые длинные коммерческие ключи.

## Что учесть перед генерацией

- Значения свойств в Битриксе грязные: `IP 54` / `IP54`, `Да` / `да`,
  `7-May` вместо `7-5` в давлении, `Сummins` с русской «С». Нормализация —
  в `group_gap.py`, но перед публикацией фильтра базу надо чистить.
- «Товарная группа 1С» — внутренние названия склада, в заголовки не годятся.
- Производительность: 2 250 уникальных значений на 20 046 товаров. Точечные
  страницы делать нельзя, только круглые значения или диапазоны.

```
python3 group_gap_report.py    # разбор A / B / C

```
