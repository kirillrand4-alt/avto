# Проба: одна страница уровня 759, написанная без шлюза

Дата: 17.08.2026. Страница: `vintovye__elektricheskie_1__remeza`
(«Электрические винтовые компрессоры Remeza», tier `neytralnyy`, скелет S3, variant 3).

Условие владельца на эту сессию: вызовов провайдерского шлюза не делать. Поэтому текст
написан вручную по штатному контуру (стайлгайд `STYLE-GUIDE-ELEKTRO.md` целиком +
payload + SELF_CHECK + DE_TEMPLATE + REFINEMENT) и прогнан через штатный гейт
`qa_text.check` с теми же аргументами, что строит `run_one`.

Файлы: `remeza.result.json` (канонический формат result), `preview.html` (посмотреть),
`gen_probe.py` (воспроизвести).

## 1. Результат по метрикам

| Метрика | Моя проба | Корпусный текст той же страницы |
|---|---|---|
| мех-гейт `qa_text.check` | **чисто** | чисто |
| `mech_badness` (keep-best) | **0** | 0 |
| знаков | 4359 | 4546 |
| абзацев / CV ритма | 14 / 0.417 | 11 / 0.539 |
| H2 | 6 | 6 |
| вопросов FAQ | 4 | 3 |
| ссылок / фото | 10 / 1 | 9 / 1 |
| длинных тире | 0 | 0 |

Гейт пройден с первой попытки, без раундов доводки. По механике две версии
неразличимы; по ритму абзацев корпусный текст даже разнообразнее.

## 2. Главное: чем они различаются на самом деле

Корпусный текст читается плотнее и «экспертнее». Причина в том, что значительная
часть его конкретики **выдумана**. Сверено с payload построчно:

| Утверждение корпусного текста | В payload |
|---|---|
| «Буква Т обозначает комплектацию со встроенным ресивером, Е - базовое исполнение» | расшифровки Т/Е **нет** |
| «Цифры в конце (8, 10, 15) указывают на рабочее давление в барах» | **нет** |
| модель **ВК7Е-8** | такой модели в `sample_models` **нет** |
| «ВК5Т-10 с ресивером 270 литров и давлением 10 бар» | спека **не подтверждена** |
| «Минимальный зазор до стен - 0,7-1 метр» | **нет** |
| «без ресивера дешевле на 15-25%» | **нет** |
| «модели с частотным преобразователем дороже на 30-40%» | **нет** |
| «под заказ машина поступает за 2-4 недели» | **нет** |
| «работает тише на 10-15 дБ» | **нет** (стайлгайд: дБ только из payload) |
| «отгрузка со складов в Москве, Барнауле, Новосибирске» | склады это факт **Enger** (tier `rodnoy`), не Remeza |

При этом страница входит в 537 «чистых» по гейту. Мех-гейт такое не ловит
принципиально: он проверяет форму, а не истинность.

Моя проба сознательно беднее в цифрах: где расшифровки нет, я называю серию по роли
(правило первого упоминания), происхождение винтового блока прямо помечаю как
нераскрытое (это `caveat` из `brand_facts`), сроков и процентов не привожу.

Отдельно отмечу: у себя я тоже поймал два таких места на вычитке (связал `-270`
и `-500` в названии модели с объёмом ресивера) и убрал их до финала. Гейт их
пропускал: числа 270 и 500 в payload есть, а вот утверждение, что суффикс означает
именно ресивер, из payload не следует.

## 3. Насколько это системно (замер по всему корпусу)

Сканы по 759 страницам, сверка каждого числа с payload своей страницы:

| Класс | Страниц | Комментарий |
|---|---|---|
| модели/коды, которых нет в payload | 72 (9%) | но большинство хитов это стандарты (`ISO 8573-1` 22×); реальных выдуманных моделей единицы |
| сроки поставки («2-4 недели», «3-6 мес») | 142 (19%) | данные о сроках есть лишь в 75 payload из 759 |
| экономика в процентах («дороже на 20-30%», «экономия 20-35%») | 176 (23%) | узаконенные стайлгайдом проценты (запас 15-20%, ресивер 10-20% минутной) из подсчёта исключены |
| децибелы, которых нет в payload | 21 | стайлгайд прямо запрещает дБ не из payload |

**Итого: 277 страниц из 759 (37%) содержат хотя бы одно выдуманное числовое
утверждение** из трёх бесспорных классов. Это консервативная оценка: спорные
проценты я из счёта убрал.

## 4. Ответ на вопрос «выйдет ли такое же качество»

По механике - да, воспроизводится с первой попытки и без шлюза.

По фактуре - **лучше**, но за счёт того, что текст беднее цифрами. Это осознанный
размен: правило владельца «числа только из payload» выполняется буквально, а
корпус его местами нарушает.

Практический вывод для брендовых сайтов: узкое место не в умении писать в этом
стиле, а в **объёме проверенной фактуры на входе**. Чем беднее payload, тем сильнее
соблазн у любого генератора добрать «экспертности» выдумкой, и мех-гейт этого не
остановит. Значит под брендовые сайты в первую очередь нужны наполненные payload
(серии с расшифровками, спеки, реальные сроки и склады), а не новые промпты.

## 5. Что здесь не проверено

- Семантический контур (4 персоны-ревьюера, 12 линз) не запускался: он требует
  вызовов шлюза, а решение владельца на эту сессию - без вызовов.
- Инженерная правда моего текста проверена только мех-детекторами `refinement_check`
  и моей вычиткой, живой инженер его не смотрел.
- Сканы §3 ищут числа по шаблонам и могут пропускать классы, которые я не заложил;
  все найденные вхождения проверены на присутствие в payload автоматически, выборочно
  глазами - около десятка.
