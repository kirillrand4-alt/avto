# Ревью коммерческой ценности данных v2 → рост ВП

Дата: 2026-07-17. 5 линз на откалиброванном датапаке (мастер-таблица страниц + квал-лиды Roistat
+ каналы + device + спрос), со всеми поправками владельца (SEO≈Директ по квал, Директ=2 режима,
топливный шок занижает конверсию окна, малые числа=шум, лиды в штуках).

## Вердикт

SEO — не 'вторичный' канал, а со-равный Директу движок квал-лидов (≈125 vs ≈126/мес) при ~3% визитов, и он недомонетизирован: конвертящие категории застряли на 2-й странице с тысячами показов и почти нулём кликов. Рост ВП идёт не из выбора 'SEO против платного', а из двух параллельных ходов — оптимизации Директа по стоимости квал-лида (быстрые деньги + экономия) и вывода доказавших конверсию SEO-страниц в топ-5 (крупнейший структурный ВП). Все цифры — диапазоны на 1 мес данных; закрывать сделку решением можно только после подстановки реальных close-rate/чека/маржи из CRM.

## Топ-ходы (2 параллельных рычага)

1. **Чистка/фикс слитых платных посадочных по CPL + минусация автотаргета (remeza modulnye отказ90%/8с/0квал, mrqz-квиз 6271в**
   - ВП: 0.9-2.25 млн ₽/мес квал + прямая экономия рекламного бюджета _[низкий-средний (правки лендингов + перебаланс]_
2. **Вывод конвертящих категорий со стр.2 в топ-5 при большом спросе (prokompressor vintovye: 15022 показа/поз17.7/43 клика/6**
   - ВП: 1.8-3.6 млн ₽/мес через 3-6 мес (со-равный движок: SEO≈125 ≈ Директ≈126 квал/мес) _[средний (контент/перелинковка/ссылки, лаг 2-4]_
3. **Починка связки 'органика есть — квал нет': страницы с большим органик-трафиком и вовлечением, но 0 квал (berg pryamym-pr**
   - ВП: 0.36-0.9 млн ₽/мес _[низкий (правка CTA/формы на готовом трафике)]_
4. **Модельные лендинги из КП-базы (99 брендов/1588 моделей с ценами) под подтверждённый спрос и gap-модели: винтовые (ядро),**
   - ВП: 0.5-2.0 млн ₽/мес через 6-12 мес (питает A и B) _[высокий (контент+индексация+ассортимент, нако]_
5. **Устранение индексационных пробелов и возврат потерянного трафика: 301 с битых URL на живые категории; техаудит простаива**
   - ВП: 0.2-0.5 млн ₽/мес (трафик уже оплачен, восстановление веса) _[низкий-средний, обратимо]_

## Быстрые победы

- Отключить/переклеить остро сливающие автотаргет-посадочные: remeza modulnye (отказ90%), mrqz-квиз ironmac (0квал), remeza spiralnyy KC10 (5.
- Добавить CTA/форму/оффер на berg pryamym-privodom (4823 органик-клика, 302с, но 0 квал) — самый готовый трафик
- 301-редиректы с битых URL на живые конвертящие категории
- Минус-слова + порог интента на berg-kompressor.ru и enger-air.ru (42k и 28k платных визитов → по 2 квал)

## Самая яркая конкретика

- **berg pryamym-privodom: 4823 органик-клика, 302 сек на сайте, но 0 квал-лидов** — трафик
  максимально готовый (вовлечён), а конвертить нечем. Добавить CTA/форму/оффер = чистый ВП.
- Конвертящие категории застряли на стр.2 с тысячами показов и ~0 кликов → в топ-5.
- remeza modulnye: отказ 90% на платном → сливает бюджет (ребаланс по CPL).

## Досбор данных (без него ВП-цифры — диапазоны)

- Реальные close-rate / средний чек / ВП-маржа из CRM — заменить самое уязвимое допущение GP 50-180к ₽ на факт
- Учёт офлайн-конверсий (звонки: dali 7.3k виз/0квал/9 звонков) перед выводом о сливе бюджета
- Разделение Директа на 2 режима (ручной/автотаргет) с CPL по каждому — без этого нельзя ранжировать по стоимости квал-лид
- CPL до/после по каждой посадочной — мерить эффект ребаланса, а не долю визитов
- Полный спрос_топ_запросы (в выборке усечён) ↔ сверка с наличием/ценами КП-базы для приоритета gap-моделей
- Полный битые_url_все (в пакете усечён) для оценки потерянного трафика
