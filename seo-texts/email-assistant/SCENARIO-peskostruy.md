# Сценарий холодной рассылки: сегмент «Пескоструйные работы»

Пилот на вычитку. Сгенерирован через провайдера (claude-fable-5), прогнан через
6 линз ревью: **0 CRITICAL, 4 WARN** (правки внесены; правки линз с длинным тире
не применены — у нас правило «без длинных тире», вместо тире перефразировано).

Каденция: 3 письма (день 0 / +3 / +7). Атрибуцию (ИНН) и ссылку отписки движок
добавляет сам при отправке. Переменные `{{город}}` / `{{число_в_регионе}}` /
`{{крупный_клиент}}` подставляются из `region-index.json` по региону получателя.

Число пруфа: **более 45** проектов по пескострую (опубликованный floor из 47),
**5580+** проектов всего по компании. Про бренды — «ведущих производителей»
(реально дилеры 65 брендов + свой Enger; конкретное число подставим по решению).

## Что осталось решить владельцу (вычитка)

1. **Регион-переменные.** `{{число_в_регионе}}` = проверяемый floor из
   опубликованных (напр. Москва 94, Алтай 86). Реальные числа выше (публикуем не
   всё), но floor защищаем факт-чекером. Оставляем floor или ставим оценку ×5.5?
2. **Число брендов.** Сейчас «ведущих производителей» без цифры. Ставим «более 60
   брендов» (реально 65), «13» (как в черновике) или оставляем без числа?
3. **Крупный клиент региона.** Подставляется автоматически из топ-выручки региона;
   проверить, что для name-drop нет чувствительных (можно ли называть клиента).
4. **Тон под размер.** Этот вариант — нейтральный (средний бизнес). Для крупных
   усилить сервис/референсы, для малых — цену/лизинг (см. SEGMENTATION.md, ось 3).
