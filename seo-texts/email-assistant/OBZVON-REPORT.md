для холодной рассылки. Дублей ИНН между базами НЕТ (проверено). Слабое место - хвост
микрокомпаний и нулёвок: скоринг по ОКВЭД не видит размера. Фильтр это решает:

## 4. Главные правки для v2

1. Ценность ДО телефона: в письмо - вилку цен/окупаемость или мини-расчёт, телефон
   просить как «удобнее посчитать точно» после пользы, не вместо неё.
2. Персонализация из базы: регион + отрасль + повод («для предприятий вашего ОКВЭД
   ставили...») - поля в базе уже есть.
3. Не вопросы, а готовые гипотезы решения («судя по профилю, вам подходит X за Y»).
4. Починить обрыв письма 9; сроки поставки и условия в каждом письме.
5. Проверяемые кейсы: ссылка на страницу проекта вместо голого названия клиента.
