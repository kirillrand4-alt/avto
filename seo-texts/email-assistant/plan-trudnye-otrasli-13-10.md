# План: письма для «сопротивляющихся» отраслей (13.10)

Цель: довести пластик, вторсырьё, химию, стекло, лес, металл и зерно до ≤ $0.40 за годное письмо.

## Шаги
1. **Предклассификатор — правила владельца явно** (пластик — только переработчики; вторсырьё — только переработка смешанного потока; стеклобой да, мастерские нет; нерудные карьеры да; жидкая химия нет; соль/удобрения/гранулы — да). Включить для химии и зерна. Сейчас он снимает точно (14/15), но пропускает 8/15 лишних — их потом бракует генератор по $0.15.
2. **Эталонное письмо на каждую отрасль** (лес — щепа/опил, вторсырьё — флекс/смешанный поток, стеклобой, нерудные, удобрения/соль). Черновики пишу я, утверждает владелец/редактор. Без эталона модель тянет непищевую компанию в пищевой рентген.
3. **Готовая строка представления для непищевых**: «Работаю с переработчиками вторсырья по вопросам сортировки потока» вместо пищевой.
4. **Боль по отрасли раньше боли по коду ОКВЭД** для непищевых (Тайга-продукт получил «слипшиеся конфеты» из кода 10.89).
5. **Линза покупателя — те же правила, что у предклассификатора**, чтобы они не спорили друг с другом.
6. **Химия: разобрать 6 штампов редактора** и разрешить отраслевую лексику, где штамп ложный.
7. **Зерно: компрессорная лексика** — найти, откуда в письме Meyer слова КЦ (карточка/паспорт элеватора).
8. **Проверка**: по 15 образцов на отрасль после правок; цель ≤ $0.40, иначе отрасль остаётся на паузе.
