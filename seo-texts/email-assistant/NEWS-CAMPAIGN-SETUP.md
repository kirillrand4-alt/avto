# Кампания «новостные» — пакет на дропе + команды создания

Дата: 2026-07-24. По команде владельца: «влей в кампанию "новостные" (её создай),
чтобы была готова к отправке». Файл владельца сверен с master-выгрузкой — правок
нет (0 расхождений), берём как утверждённый состав.

> ⛔ Холд: живая отправка только руками владельца через панель (live_send).
> Создание кампании и очередь подтверждений — разрешённая подготовка.

## Что на дропе

**`news-campaign-recipients.csv`** — 66 получателей в формате importer'а сендера
(алиасы колонок совпадают с COLUMN_ALIASES): email; инн; название; оквэд; сегмент
(`новостные`); источник; регион; итоговый балл приоритета; макс. балл по связке;
приоритет × выручка / 10000.

Состав: 28 «в базе» (направление точное) + 38 вне базы (направление по checko-ОКВЭД,
разметка владельца в работе), конкуренты исключены, у всех есть email.

## Команды (на боевом сервере, каталог сендера)

```bash
# 1) скачать CSV с дропа (или вручную положить рядом)
# 2) импорт получателей (колонки автодетектятся по русским алиасам):
python3 -m sender.cli import news-campaign-recipients.csv

# 3) создать кампанию:
python3 -m sender.cli campaign-create --name "новостные" \
    --segment "новостные" --send-order priority_desc

# 4) шаг-письмо (шаблон — актуальный новостной из наработок, с {news_object}/{city}/{equipment}):
python3 -m sender.cli campaign-add-step --campaign <ID> --index 0 --delay 0 \
    --subject "<тема>" --body "<шаблон>"

# 5) активировать (письма лягут в очередь ПОДТВЕРЖДЕНИЙ, не в отправку — live_send off):
python3 -m sender.cli campaign-activate --campaign <ID>
```

## Что проверить после

- Панель: кампания «новостные», 66 получателей, письма в `pending_review` со
  всеми блоками (новостной повод берётся из enrich.db signals по ИНН — панель
  сама подтянет, потому что signals уже в БД).
- Гейт направлений: 28 «в базе» пройдут; **38 вне базы будут заблокированы
  («направление не определено») до импорта разметки владельца** — это правильно.
  Импорт разметки — по ТЗ division_overrides (см. переписку/ENGINEER-TASKS).
- {news_object}/{city} пустые → лид упадёт в очередь «дозаполнить данные», не
  потеряется.

## Примечание для инженера

Шаблон письма (шаг 4) — на твоей стороне: актуальная версия новостного письма
с подстановками и подписью менеджера (канон 23.07). Тексты под калибровку —
поэтому первый прогон только в очередь подтверждений.
