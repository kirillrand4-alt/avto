# Аудит внутреннего поиска prokompressor.ru — v4 (второй контрольный прогон)

Метод: точное воспроизведение v2/v3. Те же 1000 фраз через `/catalog/?q=` (176 из живого
внутреннего поиска + 824 из вебмастера), тот же прогон, та же оценка ИИ-аудитором,
независимая рецензия и построчная классификация. Дата прогона: 03.08.2026
(v3 — 26.07.2026, v2 — 15.07.2026). Отклонение от методики: независимая рецензия
этого отчёта через провайдерский API не выполнена — шлюз в день прогона стабильно
возвращал пустые ответы на большие рецензионные промпты (малые запросы работали);
все цифры отчёта вместо этого перепроверены прямыми расчётами по сырым данным
(diff-v3-v4.json, serp-diff-v34.json). Относительно v3 выдача изменилась у 757 фраз
из 1000: разработчик продолжает крутить поиск, это новая итерация, а не откат
(с v2 совпадают только 22 выдачи).

## Итог одной строкой

Главное из v3 сделали, но сломали другое: модельные запросы с числами (приоритет №1)
починены — model_not_found упал с 23 до 4, IC 10 и GA 55 наконец находят свои модели;
зато выпали генераторы газов (кислород подменяется азотом, азотные синонимы дают ноль),
аксессуары утонули под компрессорами, и сообщение «ничего не найдено» снова пропало.
Общий балл просел (точных 77% → 61%), но существенная часть просадки - хвост топа
и строгость оценщика, а не топ-3 (подробнее в оговорке).

## Что починили (приоритеты №1-2 из v3 — внедрены)

1. **Токенизация номеров моделей работает** (приоритет №1 v3): «Ironmac IC 10» и
   «IC 10/10» теперь показывают IC 10/10 первыми (раньше топ был из IC 100);
   «Atlas Copco GA 55» отдаёт настоящие GA55 (было GA 110/132/200 по суффиксу
   давления «/5,5»); «GA 7» — модели GA7; «BERG ВК-18» — ВК-18,5 вместо ВК-11.
   model_not_found: 23 → 4. Из 23 модельных провалов v3 девять вышли на «точно»,
   ещё часть на «частично». Динамика болей v2 (v2 → v3 → v4): IC 10/10: 2→0→2,
   IC 20: 2→0→2, GA 55: 1→0→2, GA 7: 1→0→2, ВК-18: 1→0→1.
2. **Бренд-запросы отчасти выправлены** (приоритет №2 v3): «dalgakiran» — компрессоры
   вместо клапанов (0→2). Машины теперь выше запчастей. Но у этой медали есть
   обратная сторона — см. пункт 2 ниже.

## Что сломали (новые кластеры v4)

1. **Генераторы газов — крупнейший провал прогона (~30 фраз)**. Кислородные запросы
   («генератор кислорода», «кислородная установка» и ещё ~11 вариантов) показывают
   АЗОТНЫЕ генераторы, хотя кислородные ENGER GO есть в каталоге и в v3 находились
   (2→0 по всем). Азотные синонимы («азотная станция», «азотная установка»,
   «азотный генератор», «азотные станции» — ~15 фраз) дают НОЛЬ результатов,
   в v3 все находили генераторы ENGER GN (2→0). Это профильный товар магазина,
   уходящий в ноль на коммерческих запросах с «купить/цена».
2. **Аксессуарные категории утонули под машинами — перекос весов в другую сторону**.
   «Адсорбционный осушитель» (и ~10 вариантов) — первым идёт винтовой компрессор;
   «осушитель сжатого воздуха» — компрессоры ЗИФ вместо осушителей; «Фильтр
   магистральный» — топ из компрессоров Cross Air; «воздушный ресивер» — компрессоры
   на ресивере вместо самих ресиверов. Правило «машины выше запчастей» применилось
   и там, где покупатель ищет именно аксессуар.
3. **Хвост топа разбавлен соседями серии — числовой подстрочный матчинг остался
   в ранжировании**. Топ-1 теперь чаще верный (токенизация), но позиции 4-8 забиты
   другими номерами: «GX 4» → GX2/GX7, «ВК-7,5» вперемешку с ВК-75, «5.5 квт» →
   модели 55 кВт, «CAAD-1.2» → CAAD-120, «15 бар» → модели 15 кВт (бар/кВт
   по-прежнему путаются). Оценщик за это снижал балл с 2 до 1 массово (wrong_top
   195 → 340).
4. **«Ничего не найдено» откатилось** (в v3 работало): из 34 пустых выдач сообщение
   не показано ни на одной — снова пустая страница без объяснения.
5. **Мелочь, но заметная**: мономарочные топы на широких запросах («винтовой
   компрессор воздушный купить» — только ABAC, «дизельный воздушный компрессор» —
   только Sullair); латиница не матчится с кириллицей («компрессор berg bk» → 0,
   хотя ВК в каталоге); дубли карточек с разным регистром (FIAC/Fiac) в одном топе.

## Общая статистика (1000 фраз, v2 → v3 → v4)

- Точных ответов: 73% → 77% → 61%; частичных: 16% → 16% → 25%;
  плохих/пустых: 11% → 7% → 14%.
- Средняя релевантность: живые внутренние 1,80 → 1,73 → 1,66;
  вебмастерские 1,58 → 1,70 → 1,42.
- Пустых выдач: 32 → 1 → 34 (из них 31 — азотно-кислородный кластер и пескоструй).
- Переходы v3 → v4: лучше 64 фразы, хуже 213 (на изменившихся выдачах);
  живые фразы: лучше 18, хуже 32.
- Проблемных строк: 274 → 230 → 393. Ядро: 185 → 195 → 295 (из них 99 с нулевой
  релевантностью). Вставки из поисковика: 89 → 35 → 98.
- Провалы по типам: wrong_top 340 (в основном разбавленный хвост топа),
  empty_but_should 31, model_not_found 4 (было 23).

### Оговорка о строгости оценщика
На 243 выдачах, идентичных v3, оценщик в этом прогоне поставил ниже 29 фразам
и выше 7 (нетто минус 9%) — этот прогон судил строже, чаще наказывая за
разбавленные позиции 4-8 при верном топ-1. Часть падения общего балла — эффект
оценщика, а не поиска. Но выводы отчёта на это не опираются: 213 реальных
ухудшений против 64 улучшений на изменившихся выдачах, пустые выдачи (34) и
подмена кислорода азотом — объективные факты, видимые в самих выдачах.
За 8 дней между прогонами мог измениться и каталог (замечены новые карточки
Ironmac «DF 500L») — тест меряет систему «поиск + каталог» целиком.

## Приоритеты для разработчика Битрикса (v4)

1. **Вернуть генераторы газов**: кислородные запросы — к генераторам кислорода GO
   (они в каталоге), азотные синонимы («станция», «установка») — к генераторам
   азота GN. Похоже, при перенастройке индекса категория выпала/подменилась.
2. **Скорректировать перекос «машины выше всего»**: если в запросе назван аксессуар
   (осушитель, фильтр, ресивер, сепаратор) — приоритет соответствующей категории,
   а не компрессорам. Правило из v3 верное, но должно работать в обе стороны.
3. **Распространить токенизацию чисел на ранжирование хвоста**: топ-1 верный,
   но позиции 4-8 не должны заполняться соседними номерами серии (GX4 ≠ GX2,
   5,5 кВт ≠ 55 кВт, 7,5 бар ≠ 7,5 кВт, 1.2 ≠ 120).
4. **Вернуть «ничего не найдено»** — работало в v3, пропало в v4.
5. Мелкие: нормализация кириллица/латиница (ВК = BK, uppercase = lowercase),
   дедупликация карточек, разнообразие брендов на широких категорийных запросах.
