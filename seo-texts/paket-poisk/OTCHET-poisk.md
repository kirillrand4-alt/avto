# Аудит внутреннего поиска prokompressor.ru — 1000 реальных фраз

Метод: прогнали через `/catalog/?q=` 1000 фраз (176 из внутреннего поиска сайта + 824
из вебмастера, очищенные до товарного интента), выдачу каждой оценил ИИ-аудитор
против интента покупателя. Данные — в `search-problems.csv` (все проблемные с топ-выдачей).

## Общая картина
- **728 из 1000 (73%)** — поиск отвечает точно (релевантность 2/2).
- **165 (16%)** — частично (топ размыт, но нужное есть).
- **107 (11%)** — плохо/пусто.
- Средняя релевантность: внутренние фразы **1,8/2**, вебмастерские **1,58/2**
  (люди на сайте ищут «чище», их обслуживают лучше — но 33 их запроса всё равно провалены).

## 4 корневые проблемы (по убыванию важности)

### 1. Размытый топ: числа в моделях matching-ем как подстроки (крупнейший кластер, 210 запросов)
Поиск не считает число частью точного токена:
- «Ironmac IC 10» → топ забит моделями **IC 100** (100 содержит «10»)
- «Atlas Copco GA 55» → в топе **GA 110 / 132 / 200**, точной GA 55 в первой четвёрке нет
- «Cross Air CA 22» → на 1 месте **осушитель** CAAD-22, а не компрессор CA22
- «DALGAKIRAN DKK 40» → сверху **клапан/запчасть**, а не сам компрессор
Причина: (а) числа не токенизируются как точные; (б) нет весов полей — запчасти, осушители
и компрессоры ранжируются наравне.
Фикс в Битриксе: поднять вес свойства «модель/артикул» и названия; понизить вес разделов
запчастей/аксессуаров в поиске; включить точное совпадение по числовым токенам.

### 2. Пустая выдача на «тонких» категориях при многословном запросе (33 запроса, чистые баги)
«поршневой компрессор» → 20 результатов, НО «купить поршневой компрессор» → **0**
(при этом «купить винтовой компрессор» → 20). На категориях с малым числом товаров лишнее
слово роняет релевантность ниже порога и выдача обнуляется — причём БЕЗ сообщения
«ничего не найдено», просто пустая страница «Поиск».
Провалены ходовые коммерческие запросы:
- поршневые: «купить поршневой компрессор», «компрессор поршневой воздушный купить»
- безмасляные: «безмасляный компрессор купить», «винтовые безмасляные компрессоры»
- «модульные компрессорные станции», «промышленный компрессор купить»
- «дизельный передвижной компрессор цена»
- «азотное оборудование», «оборудование для производства кислорода» (генераторы газов есть в каталоге!)
Фикс: включить морфологию и разбор запроса по OR с ранжированием (а не жёсткий AND);
индексировать в поиске РАЗДЕЛЫ каталога, а не только товары (тогда «поршневые компрессоры»
найдёт категорию); добавить синонимы (безмасляный=масло-free, азот=азотный генератор).

### 3. Точные модели: вариации не схлопываются (10 запросов)
«BERG ВК-18» → показан ВК-18.5 (близко, но не то); «Enger LC-11DFR-500 16» → LC-11DFRE
(другая модификация); «Atlas Copco GA 75» → выдало «давление 7.5 бар» вместо модели.
Фикс: нормализация модельных обозначений (точки, дефисы, регистр), словарь синонимов моделей.

### 4. Слишком мало результатов по существующим моделям (20 запросов)
Поиск модели даёт 1-2 позиции там, где есть исполнения (давление/комплектация).
Фикс: тот же вес модели + не отсекать варианты исполнений.

## Что это даёт бизнесу
Внутренний поиск — инструмент для уже пришедшего, «тёплого» покупателя. Каждая пустая
выдача по «купить поршневой компрессор» = ушедший клиент, который был готов покупать.
27% запросов работают хуже идеала; приоритет — кластеры 1 и 2 (они бьют по деньгам сильнее всего).

## Приоритет внедрения для админа/разработчика Битрикса
1. Индексация разделов каталога в поиске + морфология (закроет кластер 2 — чистые нули).
2. Веса полей: модель/название вверх, запчасти/осушители вниз (закроет половину кластера 1).
3. Точная токенизация чисел в моделях (вторая половина кластера 1).
4. Словарь синонимов и нормализация моделей (кластеры 3-4).
Полный список фраз с диагнозом и реальной выдачей — в search-problems.csv.
