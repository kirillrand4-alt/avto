# Аудит внутреннего поиска prokompressor.ru — v2 (только реальные проблемы)

Метод: 1000 фраз через `/catalog/?q=` (176 из живого внутреннего поиска + 824 из вебмастера),
оценка выдачи ИИ-аудитором, затем независимая рецензия выводов + построчная классификация
всех проблемных фраз на «внутрипоисковые паттерны» и «вставки из поисковика».
v2 отличается от v1: масштаб пересчитан, вебмастерские «купить»-фразы вынесены в приложение
(владелец верно заметил: внутри сайта так не ищут — среди 176 живых фраз НОЛЬ содержат «купить»).

## Реальное ядро проблем: 185 строк с внутрипоисковыми паттернами
(из них ~95 — несомненные по строгой оценке рецензента; полный список: search-problems-core.csv)

### 1. Модельные запросы с числами — подстрочный matching (подтверждено на живых фразах)
«Ironmac IC 10» тонет в IC 100; «Atlas Copco GA 55» — в топе GA 110/132/200;
«Cross Air CA 22» — первым идёт осушитель CAAD-22, а не компрессор;
«DALGAKIRAN DKK 40» — сверху клапан-запчасть. Все примеры — фразы реальных посетителей.
Это главная боль: люди внутри сайта ищут именно модели.

### 2. Вариации моделей не схлопываются (полностью подтверждён рецензией, все примеры живые)
«BERG ВК-18» → показан только ВК-18.5; «Enger LC-11DFR-500 16» → найден LC-11DFRE;
«Atlas Copco GA 75» → выдало «7.5 бар» вместо модели; «atlas cd 250», «et ofs 5» → не найдены.
Человек, вбивший точную модель, — самый горячий покупатель из всех возможных.

### 3. Жёсткий AND-порог обнуляет выдачу на «тонких» категориях (механика подтверждена)
«поршневой компрессор» → 20 результатов, «купить поршневой компрессор» → 0 без сообщения
«ничего не найдено». Конкретные «купить»-фразы — из поисковиков (приложение), но механика
задевает и реалистичные запросы: «модульные компрессорные станции», «азотное оборудование» → 0
при наличии товара. И пустая страница без пояснения — плохой UX при любом источнике фразы.

## Приоритет фиксов для разработчика Битрикса (пересчитан по рецензии)
1. **Веса полей поиска**: название/модель/артикул вверх, запчасти и аксессуары вниз
   (лечит: осушитель выше компрессора, клапан выше машины).
2. **Точная токенизация чисел в моделях** (лечит IC 10 vs IC 100, GA 55 vs GA 110) +
   нормализация модельных обозначений: точки/запятые/дефисы/регистр (лечит ВК-18 vs ВК-18.5,
   LC-11DFR vs LC-11DFRE).
3. **Морфология + OR-ранжирование вместо жёсткого AND** и **индексация разделов каталога**
   (лечит нули на категориях; бонусом бесплатно чинится весь коммерческий лонг-тейл
   из приложения — корневая причина общая).
4. Сообщение «ничего не найдено» с подсказками должно показываться ВСЕГДА при пустой выдаче
   (сейчас пустая страница «Поиск» без объяснения).

## Приложение: 89 фраз-«вставок из поисковика» (search-problems-serp-paste.csv)
«Купить поршневой компрессор» и подобные. Внутри сайта так почти не ищут, НО: (а) часть людей
вставляет запрос из Яндекса в строку сайта целиком; (б) корневые причины провалов у этих фраз
те же, что у ядра — отдельных работ не требуется, починятся заодно. Приоритет — низкий,
выбрасывать из вида — не стоит.

## Общая статистика теста (для справки)
1000 фраз: 73% точных ответов, 16% частичных, 11% плохих/пустых. Внутренние фразы
обслуживаются лучше вебмастерских (1,8 против 1,58 из 2) — но и на них ядро проблем
(модели, вариации) бьёт напрямую.
