# Центробежные компрессоры: карта отраслей-потребителей и признаки для сегментации базы

*Исследование для формирования и скоринга базы потенциальных клиентов*

---

## Краткое резюме

Центробежные (динамические) компрессоры — оборудование для перекачки и сжатия больших объёмов газа при непрерывном цикле производства. Их отличает высокая производительность, поэтому они концентрируются в крупной непрерывной промышленности: транспорт газа, нефтегаз, нефтехимия, химия, металлургия, промышленные газы, водоканалы.

Ключевой вывод для сегментации: **ОКВЭД сам по себе — слабый фильтр.** Он даёт «широкую воронку», но внутри неё много компаний без центробежных машин (поршневые/винтовые или вообще без компрессоров). Рабочая модель — **скоринг**: ОКВЭД задаёт список кандидатов, а подтверждают наличие оборудования дополнительные признаки (реестр ОПО Ростехнадзора, закупки, вакансии, принадлежность к холдингу, порог по выручке).

## 1. Отрасли, где применяются центробежные компрессоры

### Ядро спроса (машины есть почти гарантированно)

| Отрасль | Где стоит компрессор | Комментарий |
|---|---|---|
| **Транспорт и хранение газа** | Компрессорные станции магистральных газопроводов (ГПА с ЦБ-нагнетателями), дожимные станции, ПХГ | Крупнейший парк в стране. Газпром и независимые операторы |
| **Добыча нефти и газа** | Компримирование ПНГ (утилизация), газлифт, закачка газа в пласт, дожимные станции промыслов | Требование по утилизации ПНГ создаёт постоянный спрос |
| **Газопереработка и СПГ** | ГПЗ, гелиевые производства, заводы СПГ (компрессоры хладагента) | Компрессоры СПГ — самые крупные машины в отрасли |
| **Нефтепереработка (НПЗ)** | Каткрекинг, компрессоры водородсодержащего газа на риформинге и гидроочистке | Несколько крупных машин на каждом заводе |
| **Нефтехимия** | Пиролиз этилена (компрессор пирогаза — «сердце» ЭП-установки), полиэтилен, полипропилен, каучуки | |
| **Химия и удобрения** | Аммиак (синтез-газ, воздух, CO₂), метанол, карбамид (CO₂ на 150+ атм), азотная кислота (нитрозный компрессор) | Один агрегат аммиака = 3–4 центробежные машины |
| **Промышленные газы** | Воздухоразделительные установки: воздушные, кислородные, азотные компрессоры | Спецкомпании + кислородные цеха внутри металлургии |
| **Чёрная металлургия** | Доменное дутьё (воздуходувки), кислородные станции конвертеров, коксовый газ | |

### Второй контур (машины часто, но не всегда)

| Отрасль | Где стоит компрессор |
|---|---|
| **Горнодобыча / ГОКи** | Компрессорные станции сжатого воздуха шахт, воздуходувки флотации на обогатительных фабриках |
| **Цветная металлургия** | Кислородное дутьё, технологические газы (алюминий, медь, никель, свинец-цинк) |
| **Энергетика** | Дожимные компрессоры топливного газа перед ГТУ/ПГУ |
| **Водоканалы / очистные** | Турбовоздуходувки аэрации. Массовый недооценённый сегмент — идёт волна замены старых ТВ-воздуходувок |
| **ЦБК, сахар, цемент** | Сатурационный/технологический газ, дутьё, крупные центробежные чиллеры |

Поэтому выгружать нужно по основному **И** дополнительным кодам, а холдинговые структуры добирать вручную по принадлежности к группе.

## 3. Портрет целевой компании (характеристики для квалификации)

| Параметр | Значение / диапазон |
|---|---|
| **Сегмент** | Один из отраслей раздела 1 |
| **Выручка** | Новые машины и капремонт — реально от ~1–2 млрд ₽. Исключение — водоканалы (решает не выручка, а инвестпрограмма/концессия) |
| **Тип производства** | Непрерывный цикл |
| **Принадлежность к холдингу** | Газпром, Роснефть, СИБУР, Новатэк, Лукойл, Татнефть, ФосАгро, ЕвроХим, Акрон, Уралхим, НЛМК, ММК, Северсталь, Евраз, Металлоинвест, Русал, Норникель, УГМК, Илим — централизованные закупки, меняет тактику захода |
| **Тип потребности** | Новая машина / модернизация / сервис и капремонт / ЗИП |
| **Установленный парк** | Советские К-250, ЦК, 32ВЦ, машины Невского завода и Казанькомпрессормаша — либо импорт Siemens / Dresser-Rand, Baker Hughes (Nuovo Pignone), MAN, Elliott, Mitsubishi, Atlas Copco |

> **Горячий сегмент 2024–2026:** импортные машины ушедших вендоров, оставшиеся без фирменного сервиса. Спрос на локализованный сервис, ЗИП и замену — один из самых активных.

## 4. Опознавательные признаки помимо ОКВЭД (для скоринга)

### Регуляторные маркеры (самые сильные)

- **Реестр ОПО Ростехнадзора** — зарегистрированные опасные производственные объекты типа «площадка компрессорной станции / цеха», «станция воздухоразделительная», объекты I–II класса опасности.
- **Лицензия Ростехнадзора** на эксплуатацию взрывопожароопасных и химически опасных ОПО (видна в выписке ЕГРЮЛ и в сервисах проверки контрагентов в блоке лицензий).
- **Реестр объектов НВОС I категории** — все крупные промплощадки там.

### Поведенческие маркеры

- **Закупки** (ЕИС, ЭТП) по ключевым словам: «центробежный компрессор», «нагнетатель», «воздуходувка», «ГПА», «ЗИП компрессорного оборудования», плюс по конкретным маркам. Даёт компанию + подразделение + контакт.
- **Вакансии** (hh.ru и др.): «машинист компрессорных установок», «машинист технологических компрессоров», «механик компрессорного цеха», «инженер по эксплуатации ГПА».
- **Годовые отчёты и декларации промбезопасности**, где перечислены установки (ЭП-300, каткрекинг, агрегат аммиака и т.п.).

### Ловушка при фильтрации

ОКВЭД **не гарантирует** наличие центробежных машин: под 20.13 или 37.00 сидят тысячи мелких компаний с поршневыми/винтовыми компрессорами либо вообще без них.

**Рабочая связка скоринга:**

> ОКВЭД из списка **+** порог по выручке **+** подтверждение через ОПО / закупки / вакансии (как скоринговый балл)

## 5. Рекомендованный алгоритм формирования базы

1. **Широкая воронка** — выгрузка по ОКВЭД (ядро + второй контур), по основному и дополнительным кодам.
2. **Фильтр по выручке** — отсечь мелочь (кроме водоканалов, где фильтр другой).
3. **Обогащение** — сверка с реестром ОПО, лицензиями РТН, НВОС.
4. **Скоринг** — начисление баллов за поведенческие маркеры (закупки, вакансии, отчёты).
5. **Ручная добивка холдингов** — дочерние структуры групп по принадлежности, а не по ОКВЭД.
6. **Приоритизация** — вверх списка компании с импортным парком без сервиса + активными закупками.
