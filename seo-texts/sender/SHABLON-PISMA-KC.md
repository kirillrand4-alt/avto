# Шаблон письма КЦ — собран из 118 отправленных

Не сочинён. Каждая формулировка взята из писем кампании «Металлообработка 25.x»,
которые реально ушли 06–11.08 и на которые отвечали живые люди. Числа в скобках —
в скольких из 118 писем встретился этот вариант.

Письмо состоит из шести слотов. Четыре из них шаблонные (вариативность там была
чисто косметическая — модель перефразировала одно и то же), два собираются под
компанию.

---

```
Вопрос по компрессорному парку в «{Компания}»                    (26)
Вопрос по системе сжатого воздуха в «{Компания}»                 (7)
Вопрос по сжатому воздуху в «{Компания}»                         (6)
Вопрос по компрессорному парку и азоту в «{Компания}»            (5)
Вопрос по подготовке воздуха в «{Компания}»                      (3)
Вопрос по передвижным компрессорам в «{Компания}»                (3)
```

Для роли снабжения к теме добавлялся префикс `Для снабжения: ` (11 писем).

## Слот 2 — хук по профилю  ← собирается под компанию

Формула: **зачин + описание с сайта + куда у них идёт воздух.**

Зачины:
```
Смотрел профиль «{Компания}»: {описание}.
Изучил профиль {Компания}: {описание}.
Профиль вашей компании «{Компания}»: {описание}.
{Описание} - это в первую очередь {потребители}.
```

Связки «куда идёт воздух» (выбираются по описанию):
```
Значит, воздух идёт и на пневмоинструмент при зачистке швов, и на распыление
при окраске.

Воздух нужен сразу в нескольких точках - плазменная резка, пневмоинструмент
на сборке и зачистке швов, окраска распылением.

На таком производстве сжатый воздух расходится по многим точкам сразу:
пневмозажимы на станках, обдув зоны резания, продувка каналов после мойки.

Значит, станки с пневмозажимами и обдув после резки. Воздух нужен ровно
всю смену.

На таком переделе давление в магистрали - часть основного процесса,
а не вспомогательная система.
```

## Слот 3 — обострение  ← собирается под компанию

Одиннадцать тем. Ниже по одной формулировке на тему, все из отправленных.

```
давление/конкуренция участков
  Когда резка и окраска идут в одну смену, воздух делится между ними.
  Стоит добавить один пост, и запаса уже нет.

неизвестный расход
  Когда точек потребления много, реальный расход обычно никто не считает,
  и подобрать компрессор "по факту" становится сложно.

влага перед покрытием
  В этой связке влажность воздуха обычно самое чувствительное место: капли
  из магистрали попадают на поверхность до полимеризации.

точка росы
  Тут всё решает точка росы на выходе: рефрижераторный осушитель даёт около
  +3С, адсорбционный уходит в минус.

разные требования на одной магистрали
  У каждого из них свои требования по давлению и по чистоте воздуха, и когда
  всю систему держат на одном режиме под самого требовательного, платит
  за это весь цех.

просадка от соседнего участка
  Предположу, что оба участка сидят на одной магистрали, и пока идёт
  пескоструйка, на сборке давление подсаживается.

азот на лазерной резке
  На нержавейке кромка чувствительна к чистоте азота: влага и остаточный
  кислород в газе дают потемнение реза.

уход брендов
  Если оборудование работает на пределе или часть парка осталась
  без поддержки после ухода зарубежных брендов - помогу найти рабочий аналог.
```

## Слот 4 — представление и вопрос

```
Я веду компрессорное направление в Компрессор Центре.
Я подбираю компрессоры и осушители в Компрессор Центре.
Я занимаюсь компрессорным оборудованием и генерацией азота в Компрессор Центре.
Я подбираю и считаю конфигурации компрессорного оборудования в Компрессор Центре.
```
+ вопрос:
```
Подскажите, актуален ли сейчас вопрос по компрессорному парку?
Подскажите, актуален ли сейчас вопрос по системе сжатого воздуха у вас
на площадке?
Подскажите, актуален ли для вас сейчас вопрос обновления или расширения
системы сжатого воздуха?
```
+ необязательный хвост:
```
Если да - помогу с пневмоаудитом и расчётом конфигурации по вашему потреблению.
Если да - помогу найти рабочий аналог под ваши задачи.
```

## Что надо решить владельцу

**1. Заход «Смотрел профиль».** Он в письмах основной, но вчера по твоей же
команде я поставил на него заслон как на штамп — тогда 186 писем начинались
одинаково. Развилка: либо снимаем заслон и признаём его штатным зачином
(тогда нужны 4–5 равноправных вариантов зачина, чтобы не выглядело копиркой),
либо оставляем заслон и заходим иначе.

**2. Обращение по имени.** Сейчас 85 писем из 118 ушли без имени, просто
«Добрый день!». Ставить имя всегда, когда оно есть в базе?

**3. Подпись.** Во всех 118 стоит «Менеджер по продажам,» — без указания
направления человека. Оставляем как есть?

**4. Длина.** Отправленные: от 547 до 1409 знаков, медиана 773. Держим около
медианы или даём длиннее там, где профиль богатый?
