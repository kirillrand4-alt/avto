# Таксономия ответов для автоответчика — по РЕАЛЬНОЙ кампании Meyer

Источник: coldy-кампания «Intekprom консервы» (июль-2025, 52 лида, направление
Meyer). Сырьё: `drop:coldy-meyer-replies-2026-07-20.tar.gz` (7 из 8 ответивших
тредов + полные переписки). Разобрано 2026-07-20.

**Бенчмарк кампании:** 52 отправлено → 34 open (65%), 8 ответов (15.4%),
3 bounce (5.8%), 1 горячий (1.9%). Планка для нашего пилота.

## 7 классов ответов (все встретились на 7 живых ответах!)

| Класс | Пример из кампании | Действие автоответчика |
|---|---|---|
| `hot` 🔥 | «Пришлите прайс-лист» (СиаСтар) | Мгновенно: КП + вопрос про телефон → тёплый лид в Bitrix, уведомление продажнику |
| `deferred` ⏰ | «Строим производство, вернёмся позже» (Фуд Тим) | Вежливое спасибо + **запланированный follow-up через N мес** (снуз, НЕ закрытие) |
| `redirect` ↪ | «Ухожу в декрет, пишите на общую почту для Володина Д.В.» (БАСТИОН) | Поблагодарить + переслать на указанный адрес с пометкой + новый контакт в базу |
| `objection_tech` | «Ваш рентген не видит нитки/волосы/окурки — не подходит» (РКЗ) | Честное закрытие; лог возражения как продуктовый фидбек |
| `objection_status_quo` | «Металлодетектор нас устраивает» (Богдановичский МК) | Нуртуринг-ответ: 1 факт «что металлодетектор не ловит», без дожима |
| `wrong_contact` | «Марии Сергеевны у нас нет» (ЛукоморьеБел) | Пометить контакт битым + вежливо спросить верного адресата |
| `competitor_in_place` | «Работают Bizerba и Mettler Toledo» (Фабрика Качества) | Учёт: конкурентный аккаунт, низкий приоритет, длинный цикл |

Плюс служебные (уже в reply_classify): `auto_reply` (OOO), `dsn/bounce`,
`complaint`, `unsubscribe`.

## Уроки классификации (coldy ошибся в 2 из 7!)

- coldy пометил **редирект** как `auto`, **отложенный интерес** как
  `not_interested` → обе потерянные сделки при наивной автоматике.
  Наш классификатор ОБЯЗАН отличать deferred/redirect от отказа.
- `interested` у coldy = только явное «пришлите прайс». Реальные деньги
  прячутся в deferred (стройка завода!) и redirect (передача ЛПР).

## Прочие наблюдения из тредов

- Первые письма шли **без темы**; follow-up обыгрывает это: «письмо могло
  затеряться, оно ушло без темы — бывает :)». Open 65% — возможно, вклад
  этой странности. Для нас: тема обязательна (ФЗ-38 атрибуция), но
  follow-up-приём «коротко напомню суть» — рабочий.
- 3 персоны отправителей на ящиках meyercorp.ru (Кочергина, Лиман,
  Погорелый) — ротация имён внутри одного домена.
- `isStopSendingOnReply: true` — ответ останавливает цепочку (у нас так же).
- Возражение РКЗ пришло от человека, слышавшего доклад Meyer на форуме
  INTEKPROM — холод пересекается с офлайн-активностью; учитывать историю
  касаний.

## Что это меняет в коде (для сессии-инженера)

1. `reply_classify`: суб-классы выше = целевой набор меток AI-разбора
   (7 бизнес + 4 служебных). Эти 7 реальных писем — first-class
   few-shot примеры для промпта (лежат в архиве на drop).
2. `leaddesk/store`: статусы `deferred(until)` и `redirect(new_contact)` —
   не «closed», а активные состояния с планировщиком.
3. Автоответ на `hot` — шаблон «КП + запрос телефона»; на `redirect` —
   пересылка с пометкой; на остальное — черновик оператору (не авто-слать,
   пока не отладим на пилоте).
4. AI-разбор на деплой-хосте ходит в провайдерский API → на сервере нужен
   `PROVIDER_API_KEY` в env (добавить в README деплоя, когда включим).
