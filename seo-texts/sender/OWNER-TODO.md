# Чеклист владельцу (вернуться и сделать за один проход)

Дата: 2026-07-18. Код под все пункты уже готов/готовится в ветке
`claude/persona-prompt-seo-sender-vi4tcq` — от вас только доступы/клики.
Секреты класть НЕ в чат: файлом на drop (`drop_client.sh up <file>`) или в
env-переменные окружения сессии.

## 1. Bitrix24 — вебхук (10 мин)

Битрикс24 → «Разработчикам» → «Другое» → «Входящий вебхук» → права: CRM →
скопировать URL вида `https://ваш.bitrix24.ru/rest/<ID>/<токен>/`.

Передать:
- `BITRIX_WEBHOOK_URL=<этот URL>`
- (опц.) ID сотрудника-ответственного по умолчанию → конфиг `bitrix.default_responsible`
- (опц.) адрес портала для ссылок на карточки → конфиг `bitrix.portal_url`
- решение «лид или сделка» — сейчас коннектор создаёт ЛИДЫ (`crm.lead.add`);
  если нужны сделки, скажите — добавим `bitrix.entity: deal`.

## 2. Telegram-уведомления (5 мин)

1. В Telegram: @BotFather → `/newbot` → получить токен.
2. Создать ops-чат (или личку), добавить туда бота, написать любое сообщение.
3. Узнать chat_id: открыть `https://api.telegram.org/bot<токен>/getUpdates` —
   в ответе `chat.id` (для группы отрицательный).

Передать: `TELEGRAM_BOT_TOKEN=...`, chat_id ops-чата (конфиг `notify.ops_chat_id`),
опц. личка on-call (`notify.oncall_chat_id`).

## 3. Постофис Mail.ru + Яндекс.Постмастер (15 мин)

1. postmaster.mail.ru → войти под аккаунтом Mail.ru → добавить домен(ы) рассылки →
   подтвердить (DNS TXT или мета-тег) → в настройках получить API-токен.
2. Яндекс: postmaster.yandex.ru (вход под Яндекс ID) → добавить те же домены →
   подтвердить. ⚠️ У Яндекс.Постмастера нет публичного API — панель смотрится
   руками; автоматизация только по Mail.ru.

Передать: `POSTOFFICE_TOKEN=...` (+ каким аккаунтам подтверждены домены).
