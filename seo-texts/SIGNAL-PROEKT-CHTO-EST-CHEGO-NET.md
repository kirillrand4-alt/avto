## 1. ЕГРЗ (egrz.ru) — РАЗВЕДАН, РАБОТАЕТ, НО В КОНВЕЙЕР НЕ ВСТАВЛЕН

Это главный вывод разбора. Канал найден прошлой сессией, описан с рецептом — и **в
серверных модулях не упоминается ни разу**.

```
API            https://open-api.egrz.ru/api/PublicRegistrationBook   OData v4, без ключа
живая проверка сегодня: HTTP 200, @odata.count = 596 891 запись
                        (в записи разведки было 587 750 — реестр вырос на 9 141)
поля           ExpertiseNumber, ExpertiseConclusionDate, ExpertiseResultType,
               ExpertiseType, ExpertiseDocumentType, SubjectRf (!) — регион прямо в записи
фильтры        $filter=contains(...), $select, $top, $skip, $orderby, $count
```

**Ловушка, из-за которой канал выглядел закрытым:** egrz.ru требует legacy TLS
renegotiation, `curl` отдаёт код 000. Лечится конфигом OpenSSL, а не отключением проверки
сертификата:

```
# ossl.cnf
openssl_conf = default_conf
[default_conf]
ssl_conf = ssl_sect
[ssl_sect]
system_default = system_default_sect
[system_default_sect]
Options = UnsafeLegacyRenegotiation
CipherString = DEFAULT:@SECLEVEL=0
```
`OPENSSL_CONF=ossl.cnf curl …` — и реестр открывается **прямо из песочницы**, раннер не нужен.

Границы канала, измеренные на выгрузке 420 записей: ИНН застройщика есть у **397**,
марка машины — **редко (4–6 из 420)**, ФИО — **0**. То есть ЕГРЗ даёт «кто и когда получил
заключение по проекту», а не «какая машина». Для сигнала «проект существует до закупки» это
именно то, что нужно.
