# Рекомендованный топ доноров (статьи пишем сами)

Условие владельца 05.08: «сделай топ из своих рекомендаций под меня, желательно
если стоимость размещения будет не по 7000 каждый, мы же все таки генерируем статьи».

Раз статьи генерируем сами, платим только за размещение — колонка «Написание ₽» из
июньского медиаплана из расчёта убрана.

**Как считалась корзина и почему не «эффект на рубль».** Первый вариант ранжировал
по «качество / цена» — и собрал дно биржи: самогоноварение, рыбалка, диваны, квартиры
по 401-801 ₽. Формально множитель релевантности у них приличный, фактически ссылка
оттуда стоит примерно нисколько: промышленного покупателя там нет. Поэтому цена
входит как ПОТОЛОК, а внутри потолка выбор идёт по качеству и по отраслевому слою.

**Известная слабость автоматики.** AUDIENCE-шкала считает улики по словарю и на DIY-
сайтах ошибается: divankomod.ru (мебель, раздел «мастер-классы») получил 92 балла за
слова «производство, завод, монтаж, стройка» в статьях про сборку своими руками.
Отделить снабженца от домашнего мастера одним словарём нельзя, поэтому отраслевые
площадки размечены руками по названию и структуре разделов — колонка «слой».

## Как это считалось

1. Корзина A свежего скоринга (SCORE ≥ 72) — 191 донор.
2. По каждому измерена релевантность краулом живых разделов (`donor_relevance.py`):
   AUDIENCE-шкала «где живёт наш покупатель», гейт по токсичности (порог 1%),
   штраф доскам объявлений. Множитель 0 = отказ, такие сюда не попадают.
3. Качество = SCORE × множитель. Эффект = качество / цена × 1000.
4. Из корзины исключены доноры с отдельными основаниями против.

Чего в расчёте НЕТ и что стоит добавить перед закупкой: доля проиндексированных
размещений и доля dofollow по конкретному донору. Это меряется `audit_donor_pages.py`
и выгрузкой Ahrefs (UR по страницам-источникам) — именно этот шаг снял в своё время
dvobozrenie.ru, который по цифрам выглядел отлично.
