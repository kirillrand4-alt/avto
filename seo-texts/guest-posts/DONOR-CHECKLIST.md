# Чек-лист отбора площадок-доноров для гост-постов (максимальный)
Формат: критерий -> порог/правило -> как проверить (Б = бесплатно, П = платно).

## 1. Тематическая релевантность
1.1. Тематика сайта: промышленность/оборудование/производство/строительство/авто - или
     общий портал с ЖИВЫМ разделом такой тематики. -> глазами (Б)
1.2. На сайте уже есть статьи про пневматику/компрессоры/сжатый воздух - плюс;
     ищем `site:домен компрессор` (Б). Если есть - смотрим их качество.
1.3. Аудитория B2B/инженерная (не «женский журнал со статьёй про всё»). -> глазами (Б)
1.4. Семантическое пересечение: у донора есть трафик по запросам, смежным с нашими
     кластерами. -> Keys.so/Мегаиндекс по домену (П/Б-лимиты)

## 2. Трафик
2.1. Посещаемость от 5-10 тыс/мес (для узкоотраслевых порталов допустимо от 2-3 тыс,
     если тематика 1-в-1). -> Similarweb (Б, грубо), Keys.so (П), у биржи в карточке
2.2. Доля ПОИСКОВОГО трафика >= 50% (портал живёт SEO, а не закупкой). -> Similarweb (Б)
2.3. Гео: РФ >= 70%. -> Similarweb (Б)
2.4. Динамика за 6-12 мес: рост или плато. Обвал -2х+ = сайт под фильтром. -> Similarweb (Б)
2.5. СТАТЬИ (не главная) собирают поисковый трафик: проверяем 2-3 чужих гост-поста
     на площадке через Keys.so/букварикс по URL. -> (П/Б)

## 3. Авторитетность / траст
3.1. ИКС Яндекса >= 500 для порталов, >= 150 для узких отраслевых. -> webmaster.yandex (Б)
3.2. Возраст домена >= 3 лет; домен НЕ дроп (история в web.archive без «казино-периодов»). -> (Б)
3.3. Ahrefs DR >= 20-30; ссылающихся доменов больше, чем исходящих продаж. -> Ahrefs (П)
3.4. CheckTrust: Траст >= 30, Спам <= 7. -> CheckTrust (П)
3.5. Бренд-запросы у площадки есть (её ищут по имени). -> Wordstat (Б)

## 4. Заспамленность исходящими
4.1. Исходящих ссылок на статью: <= 2-3 коммерческих. Если в каждой статье по 5+ ссылок
     на магазины - линкоферма. -> глазами 3-5 статей (Б)
4.2. Доля гост-постов в ленте <= 30-40%: живая редакция должна писать своё. -> глазами (Б)
4.3. Нет «токсичного соседства»: казино, беттинг, эссе-райтинг, крипта-казино, фарма,
     микрозаймы в соседних статьях = уходим. -> site:домен казино|ставки|займ (Б)
4.4. Анкор-лист исходящих не переспамлен «купить X» - смотрим выборочно. -> (Б)

## 5. Индексация и техника
5.1. Гост-посты площадки В ИНДЕКСЕ Яндекса и Google (проверить 3 конкретных URL через
     site:/url:). Не в индексе = деньги в мусор. -> (Б)
5.2. Ссылки dofollow (не nofollow/sponsored/ugc) - смотрим код чужого гост-поста.
     nofollow-площадка годится только для трафика/бренда, не для веса. -> (Б)
5.3. Статья доступна без JS, без canonical на чужой URL, не закрыта в robots/noindex. -> (Б)
5.4. Скорость индексации новых статей: свежие материалы в индексе за <= 2 недели. -> (Б)
5.5. Статья остаётся на сайте НАВСЕГДА (permanent), а не «на год». -> условия площадки
5.6. Внутренняя перелинковка: статья доступна из раздела/ленты, а не сирота. -> (Б)

## 6. Редакционная политика и юридика
6.1. Маркировка рекламы (ЕРИР/erid): если размещение платное - как площадка оформляет?
     Немаркированная реклама = риск штрафа; «редакционный» материал без оплаты - ок.
     Решение: либо площадка сама маркирует, либо материал идёт как редакционный. -> спросить
6.2. Право правок: можем ли обновить статью/ссылку позже. -> спросить
6.3. Пометка «партнёрский материал» - минус к CTR, но не смертельно; уточнить где стоит.
6.4. Договор/акт для платных размещений (если юрлицо требует). -> спросить

## 7. Красные флаги (мгновенный отказ)
- домен-дроп с чужой историей; обвал трафика 2х+ за полгода
- статьи не индексируются / раздел статей закрыт от индексации
- казино/займы/эссе в соседях; исходящих ссылок больше, чем страниц
- «оптовые» прайсы на ссылки на самой площадке в открытую (сигнал линкофермы и для ПС)
- сплошной nofollow при продаже «сео-размещений» (обман)
- требование ставить обратную ссылку на площадку с нашего сайта (ссылочный обмен - след)

## 8. Экономика и приоритизация
8.1. Ориентир цены: 3-15 тыс. руб. за вечное размещение на отраслевом портале; дороже -
     только при ИКС 1000+ и живом трафике.
8.2. Метрика сравнения: цена / (ИКС * доля поискового трафика). Собираем в таблицу,
     сортируем, режем нижний квартиль.
8.3. Пакетные скидки и «2-я статья дешевле» - спрашивать всегда.
8.4. 20% бюджета - эксперименты (Дзен, vc.ru, отраслевые Telegram-дайджесты со ссылкой).

## 9. Скоринг (быстрая модель)
Тематика 25 + Трафик 20 + Траст 20 + Чистота исходящих 15 + Индексация/dofollow 15 +
Экономика 5 = 100. Порог покупки: >= 65 и ноль красных флагов.
Минимальный набор проверок, если времени нет (15 минут на площадку):
site:домен компрессор (Б) -> Similarweb гео/динамика (Б) -> 3 чужих гост-поста: индексация,
dofollow, соседство (Б) -> ИКС (Б). Четыре «да» = можно брать.
