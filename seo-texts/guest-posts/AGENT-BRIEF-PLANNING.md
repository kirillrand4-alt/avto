# ТЗ агенту-планировщику: пара «донор → акцептор → угол → анкоры»

Задание для агента, который готовит ОДНУ джобу под генератор статей. Статью агент
не пишет — он решает, **о чём** она, **на какой сайт** ведёт, **какими анкорами**
и **в каком жанре**. Выход — заполненная джоба для `gen_wave.py`.

Одна задача = один донор. Не планировать несколько доноров в одном прогоне: раскладка
по неделям и квоты считаются снаружи, агенту приходит уже назначенный донор.

---

## 1. Что на входе

| Файл | Что берём |
|---|---|
| `BUY-LIST.md` | какой донор к какому блоку относится (A тематический / B, C весовые) |
| `ml-cards.json` | **лимиты площадки**: сколько ссылок и доменов пускают, берут ли нетематические |
| `acceptors-v15.json` | акцепторы: страница, позиция Google, деньги, надёжность, **6 готовых анкоров** |
| `weight-verdicts.json` | по каким запросам площадка живёт НА САМОМ ДЕЛЕ (для весовых — обязательно) |
| `THEMATIC-FINAL.json` | угол по тематическим донорам (поле `angle`) |
| `PLACEMENTS-LOG.md` | что этот акцептор уже получал и когда |
| `STYLE-GUIDE-GUEST.md` | тон-канон, целиком уходит в промпт генератора |

Данные Semrush и семантики: `weight-semrush.json`, `WEIGHT-DONORS.md`.

## 2. Жёсткие правила (нарушение = джоба не принимается)

1. **Один донор — один наш сайт.** Ссылки только на один домен нашей сети. Пара
   «производитель + каталог» (enger + prokompressor в одной статье) ЗАПРЕЩЕНА:
   в 18 карточках из 27 стоит «максимум доменов = 1», а там, где лимит позволяет,
   мы всё равно не смешиваем — это единственная конфигурация, которая читается
   как реклама сети. Донор закрепляется за сайтом навсегда, а не на одну статью.
2. **Лимит ссылок берётся из `ml-cards.json`, а не из головы.** `berkat.ru`,
   `tvcenter.ru`, `kakoj-segodnja-prazdnik.com` дают ровно ОДНУ ссылку — значит
   один URL акцептора и всё. Где лимит 2–3, можно категория + подкатегория ОДНОГО
   сайта.
3. **Нетематические ссылки.** Если в карточке «нет» — донор годится только под
   тематически близкий акцептор. Такие в списке: `factories.kz`, `fgisrf.ru`,
   `perekos.net`, `truckmix.ru` (все блока A, там это не мешает).
4. **Темп.** Не больше 2 новых доменов на один наш сайт в неделю; повторная ссылка
   на тот же URL акцептора — не раньше чем через две недели. Проверяется по
   `PLACEMENTS-LOG.md`.
5. **Тему не натягивать.** Если пересечение предмета акцептора с аудиторией донора
   пустое — вернуть отказ с объяснением, а не выдумывать мост.

## 3. Раскладка по нашим сайтам (решение владельца 19.08)

Приоритет — основной сайт и сателлиты; `enger-air.ru` в этой волне не первый.

| Сайт | Доноров | Что качаем |
|---|---|---|
| **prokompressor.ru** | 12 | `/po-tipu/vintovye` (72 152 ₽/мес, позиция падает — ей лучшие доноры), затем дизельные винтовые, `/airman`, `/kompressory-50/-80/-25`, `/kompressory-10` |
| **berg-compressor.com** | 3 | `/vintovye-kompressory` (позиция 5,0), `/kompressory-s-resiverom-i-osushitelem` (8,0) |
| **dali-kompressor.ru** | 2 | `/catalog/ca` (7,4) |
| **abac-kompressor.ru** | 2 | `/vintovye-kompressory` (5,3) |
| **ac-kompressor.ru** | 2 | `/catalog/xas` (ставка на Яндекс, чек дизельных 3,7 млн), `/vintovye-kompressory` |
| **enger-air.ru** | 3 | остаток весовых доноров |

Сателлитам тематические доноры полезнее, чем prokompressor: у них 36–52 dofollow-домена
на весь сайт, а у страниц ac-kompressor.ru вообще **UR 0 и ноль внешних ссылок** —
там сдвинет и одна живая ссылка.

**Яндексовые страницы — отдельно.** `ac-kompressor.ru/catalog/xas` качается под Яндекс
(457 показов на позиции 9,1). Для неё выбирать донора по ИКС, а не по органике Semrush:
`metallicheckiy-portal.ru` 1590, `flotenk.ru` 410, `perekos.net` 360, `galan.ru` 270.

## 4. Как рождается угол: предмет × призма × слова

1. **Предмет** — что качаем: тема страницы-акцептора.
2. **Призма** — кто читает. Для блока A берётся из `THEMATIC-FINAL.json` (`angle`).
   Для блоков B и C — из `weight-verdicts.json`, поле `why`: там записано, по каким
   запросам площадка живёт на самом деле. Это факт, а не заявленная биржей тематика.
3. **Слова** — живые запросы акцептора (`../frog/acceptor-top100.xlsx`, колонка
   «Топ-запросы») плюс анкоры из `acceptors-v15.json`.

Один акцептор на разных донорах = разные углы. Азотная страница: для агро —
«азот при хранении зерна», для промгорода — «азот в цеху».

### Блоки B и C: статья пишется В ЖАНРЕ ПЛОЩАДКИ

Семантика проверена по 2000 запросов на домен: наша доля аудитории там 0–1%. Отраслевой
текст на такой площадке — инородное тело и для редактора, и для читателя. Жанр берётся
из таблицы:

| Донор | Жанр, в котором писать |
|---|---|
| citaty.info | цитаты из фильмов и аниме, мотивация |
| berkat.ru | доска объявлений Ингушетии: работа, аренда |
| get-color.ru | цвет и палитры, инструменты дизайнера |
| kakoj-segodnja-prazdnik.com | календарь праздников и памятных дат |
| 4tololo.ru | развлекательный контент, аномалии |
| tvcenter.ru | шоу-бизнес и знаменитости |
| twizz.ru | мемы и интернет-фольклор |
| afk-arena.com | компьютерные игры, гайды |
| nashaplaneta.net | туризм: курорты, пляжи, погода |
| moluch.ru | научно-образовательный, студенческий |
| gorod24.online | новости Крыма |
| satom.ru | дача и частное хозяйство |

Мост к нашей теме должен быть честным, а не натянутым. Рабочий пример из журнала:
`operativa.ru` — площадка про ремонт ПК; сервисный угол там провалился (место 2/10),
а зашла электроника как единственное производство, понятное её читателю, — и там
воздух обязан быть безмасляным. Место 9/10, релевантность 9/10.

## 5. Анкоры

Берутся ГОТОВЫМИ из `acceptors-v15.json`, поле `anchors` — шесть слотов на каждый URL:
`commercial` («купить винтовой компрессор», без бренда), `exact` («винтовые компрессоры
ENGER», множественное число, можно с брендом), два `diluted`, `brand`, `naked` (домен).

**Анкорной переоптимизации не опасаемся** (решение владельца 19.08, подтверждено
цифрами: у prokompressor.ru 3891 dofollow-ссылка, 16 новых анкоров — 0,4% профиля).
Поэтому:

- **блок A (тематические)** — слоты `commercial` и `exact`: они там естественны и
  передают максимум смысла;
- **блоки B и C (весовые)** — слоты `brand` и `naked`. Причина не алгоритм, а
  модерация: редактор площадки про мемы завернёт статью с «купить компрессор».

Имя бренда допустимо ТОЛЬКО внутри текста-якоря. Вне якорей брендов и наших компаний
в тексте нет — это ловит линза `neutral`.

## 6. Что агент возвращает

Заполненная джоба в формате `gen_wave.JOBS` — словарь с полями:

```python
dict(slug='latinica-s-defisami',
     donor='domain.ru',
     links=[('точный URL акцептора', 'тип якоря + сам текст якоря из v15')],
     angle='тема с конкретикой; без обещаний фактов, которых нет в kb/',
     case='обезличенный кейс: БЕЗ юрлиц клиентов, брендов и артикулов',
     skeleton='постановка задачи -> разбор -> подбор -> практическое резюме',
     donor_note='профиль аудитории площадки + «без выдуманных местных фактов»',
     seo='главный ключ + 3-5 живых запросов + LSI-термины предметки')
```

Плюс отдельно — обоснование на 3–5 строк: почему этот акцептор (деньги и позиция из
v15), почему такой угол (какое пересечение предмета и аудитории), какие лимиты
площадки учтены.

## 7. Самопроверка перед сдачей

1. ☐ Ссылки ведут на ОДИН наш сайт, число ссылок не больше лимита из `ml-cards.json`
2. ☐ URL акцептора точный, без редиректа (`/catalog/mks` отдаёт 301 — брать конечный
   `/catalog/kompressornye-stantsii-szhatogo-vozdukha/mks`)
3. ☐ Анкоры взяты из `acceptors-v15.json`, тип слота соответствует блоку донора
4. ☐ Для блоков B и C жанр статьи = жанр площадки, а не отраслевой разбор
5. ☐ Темп не нарушен: по `PLACEMENTS-LOG.md` этот URL не получал ссылку менее двух
   недель назад, и на этот наш сайт на этой неделе не больше двух новых доменов
6. ☐ Кейс обезличен, скелет деловой, сцен-репортажей и «звонков читателей» нет
7. ☐ В `angle` нет чисел и фактов, которых нет в `kb/brand-facts-clean.json`

## 8. Куда джоба идёт дальше

`gen_wave.py <slug>` — черновик и мех-QA (объём 5200–14000, стоп-слова, белый список
ссылок, целостность тегов). Затем `finalize_gp.py <slug>` — 12 линз: link (ставит
баллы МЕСТО и РЕЛЕВАНТНОСТЬ, ниже 7 = FAIL), platform, engineer, neutral, logic, seo,
seo_yandex, seo_google, antiai, language плюс две инженерные (`teh_technolog`,
`teh_skeptik`). Выход — `ready/gp-<slug>.final.html`.

Запись в `PLACEMENTS-LOG.md` делается ДО закупки. Отправка на площадку — действие
вовне, только по явному ОК владельца.
