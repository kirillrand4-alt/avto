**B. Трафик — 0-22**
`B = 22 * clamp( log10(max(T,1)/300) / log10(100), 0, 1 )`
Контрольные точки: 300→0 | 1 000→5,7 | 3 000→11,0 | 10 000→16,7 | ≥30 000→22
Множители:
- `Ta ≥ 0.1*T` → ×1,0 | `0 < Ta < 0.1*T` → ×0,75 | `Ta` пусто → ×0,85

- `d ≥ 45 и T < 300` → d-часть = 0 (PBN)
- `ИКС ≥ 300 и T < 500` → ИКС-часть = 3 (унаследованный ИКС дропа)

**D. Индексация — 0-16**

**E. Чистота исходящих — 0-14**

`S/(max(T,1)/1000) > 50` → `E −= 4`

## 5. ДОП. ДАННЫЕ — топ-3

**1. Keys.so / Serpstat: число фраз в топ-10 и топ-50 Яндекса + оценочный Яндекс-трафик.**
Замена блока B целиком: `B = 22 * clamp(log10(max(Ya_traffic,1)/300)/log10(100),0,1)` без множителей когерентности. Новый hard-фильтр: `фраз в топ-50 < 100` → отказ независимо от заявленного трафика. Отсекает дзен-новостники, которые иначе берут 17-22 из 22. Ожидаемый отвал: 30-40% формально «трафиковых» доноров.

**2. Ahrefs: linked domains, доля dofollow, прирост исходящих за 12 мес.**
Замена блока E: `LD ≤ 50→14 | 51-120→11 | 121-250→7 | 251-400→3`. Hard-фильтры: `LD > 400` или `прирост > 20 домена/мес`. Плюс диагностика: `LD / Статей > 3` → донор торгует на 3+ биржах, максимум корзина «ручная проверка».

**3. Whois + Wayback (5-6 срезов за 5 лет): возраст и непрерывность контента.**
Даёт множитель на C: смена тематики или контентный разрыв → `C = 0`, потому что ИКС и DR унаследованы и Яндексом уже переоценены. Домен младше 12 мес → потолок «тестовая корзина» вне зависимости от SCORE. Закрывает самую дорогую ошибку — «сильные метрики, нулевая реальная ценность».

### 3. ФИНАЛЬНАЯ ФОРМУЛА СКОРИНГА (0-100 баллов)

Формула использует только заданные колонки, исключает ручные оценки и легко переносится в Python/Excel. 

**Блок A. Тематика (Макс: 25)**
*   Вхождения: *Промышленность, Оборудование, Строительство, Сельское хозяйство, Транспорт, Авто, B2B* -> **25**
*   Вхождения: *Бизнес, Экономика, Технологии* -> **15**
*   Вхождения: *СМИ/Газеты + Регион Россия* -> **10**
*   Остальное -> **0**

**Блок B. Трафик (Макс: 25)**
Используем логарифм, чтобы сгладить выбросы (доноры с 1 млн трафика не должны ломать шкалу).
*   Формула: `B = 25 * (log10(Трафик) - 2) / 2.47` (где `log10(100)`=2, а `log10(30000)`≈4.47).
*   Ограничители: Если `Трафик < 100`, B = 0. Если результат > 25, B = 25.
*   *Ориентиры: 300 чел = 3 балла, 1000 чел = 10 баллов, 5000 чел = 17 баллов.*

**Блок C. Траст: ИКС и DR/DA (Макс: 20)**
*   **ИКС (Макс 12):** `<100` -> 0 | `100-299` -> 4 | `300-999` -> 8 | `>=1000` -> 12
*   **DR или DA (Макс 8):** *Сначала смотрим Ahrefs DR, если пусто — смотрим Moz DA.*
    *   `<10` или оба пусто -> 0 | `10-19` -> 2 | `20-39` -> 5 | `>=40` -> 8
*   *Штраф за спам-профиль:* Если `CF` и `TF` заполнены, и `CF / TF > 2.5` -> вычитаем **15 баллов** из общего итога.

**Блок D. Индексация (Макс: 15)**
*   `% индекс Я >= 95` -> 15
*   `85 - 94.9` -> 10
*   `75 - 84.9` -> 5
*   `<75` -> 0

**Блок E. Заспамленность биржей (Колонка «Статей») (Макс: 15)**
*   `<= 100` -> 15 *(чистые доноры)*
*   `101 - 250` -> 10
*   `251 - 500` -> 5
*   `> 500` -> 0

**ИТОГ И ПОРОГИ (Сумма A+B+C+D+E - Штрафы):**
*   **>= 65 баллов** — **Green-лист (Покупаем)**. Отличные площадки.
*   **50 - 64 балла** — **Yellow-лист (На ручную проверку)**. Годятся, если тематика 100% целевая.
*   **< 50 баллов** — **Отказ**. Мусор, PBN или мертвые сайты.

```python
# Псевдокод для вычисления (вычислимо автоматически)
import math
def calc_score(row):
    score = 0
    # A. Тематика
    if any(t in row['Тематика'] for t in ['промышленность', 'строительство', 'сельское', 'авто', 'транспорт']): score += 25
    elif any(t in row['Тематика'] for t in ['бизнес', 'экономика', 'технологии']): score += 15
    elif 'СМИ' in row['Тематика'] and row['Регион'] == 'Россия': score += 10
    
    # B. Трафик
    t = row['Трафик'] if row['Трафик'] else 0
    if t >= 100:
        b_score = 25 * ((math.log10(t) - 2) / 2.47)
        score += max(0, min(25, b_score))
        
    # C. Траст
    iks = row['ИКС'] if row['ИКС'] else 0
    if iks >= 1000: score += 12
    elif iks >= 300: score += 8
    elif iks >= 100: score += 4
    
    dr_da = row['Ahrefs DR'] if row['Ahrefs DR'] else row['Moz DA']
    dr_da = dr_da if dr_da else 0
    if dr_da >= 40: score += 8
    elif dr_da >= 20: score += 5
    elif dr_da >= 10: score += 2
    
    if row['CF'] and row['TF'] and row['TF'] > 0 and (row['CF'] / row['TF'] > 2.5):
        score -= 15
        
    # D. Индекс
    idx = row['% индекс Я'] if row['% индекс Я'] else 0
    if idx >= 95: score += 15
    elif idx >= 85: score += 10
    elif idx >= 75: score += 5
    
    # E. Статей
    arts = row['Статей'] if row['Статей'] else 0
    if arts <= 100: score += 15
    elif arts <= 250: score += 10
    elif arts <= 500: score += 5
    
    return score
```

### 4. ОТСЕЧКИ (Hard-фильтры ДО скоринга)

Обязательно отфильтруйте датасет по этим правилам до запуска формулы, иначе купите накрученный мусор:

1.  `Язык != Русский` ИЛИ `Регион не в [Россия, Беларусь, Казахстан]` ➔ **Причина:** Нецелевая аудитория, Яндекс пессимизирует такие ссылки для коммерции РФ.
2.  `% индекс Я < 75` ➔ **Причина:** Сайт под скрытым фильтром или технически сломан. Ваша статья в поиск не попадет.
3.  `Трафик < 100` ➔ **Причина:** Мертвый сайт. Яндекс обнулил вес ссылок с ресурсов без живой аудитории.
4.  `Статей > 800` ➔ **Причина:** Конвейерная линкопомойка. Алгоритм SpamBrain обнуляет весь исходящий ссылочный вес таких доменов.
5.  `Цена ₽ < 500` ➔ **Причина:** Ниже себестоимости модерации. Хост принимает абсолютно любой спам (включая казино и фарму), что заражает соседей по исходящим.

### 5. ДОП. ДАННЫЕ (Топ-3 внешние метрики, которые нужно достать)

Данные Miralinks сильно искажены. Если владелец сети может спарсить доп. параметры, вот 3 самых критичных, которые радикально улучшат закупку:

1. **Органический поисковый трафик из Яндекса (Keys.so, Букварикс или Be1)**
   *   *Как меняет формулу:* Полностью заменяет колонку `Трафик` (блок B). Сейчас в выгрузке лежат цифры с ботами и соцсетями (Дзен-трафик). Если поисковый трафик Яндекса `< 150 в месяц` — донор идет в отбраковку, даже если общий счетчик показывает 10 000.
2. **Исходящие домены (Ahrefs Linked Domains или CheckTrust "Спам")**
   *   *Как меняет формулу:* Заменяет колонку `Статей` (блок E). Биржа показывает только проданное *через нее*. Сайт мог продать 50 статей в Miralinks и 3000 в GoGetLinks. Если метрика Спама по CheckTrust > 12 (или исходящих доменов > 1000 при слабом трафике) — это жесткий хард-фильтр (отсечка), минуя скоринг.
3. **История и возраст (WebArchive / Whois)**
   *   *Как меняет формулу:* Защита от дроп-доменов (брошенных сайтов, которые перекупили ради пузомерок). Если сайт сменил тематику за последний год или домену меньше 1 года — принудительно обнуляем Блок C (Траст), так как ИКС и DR на таком сайте не передадут вес, пока Яндекс/Google не пересчитают их для нового владельца.

| Тематическая близость: промышленность, строительство, агро, авто, транспорт, B2B | 4/4 | Ядро отбора |
| Живой органический/поисковый трафик | 4/4 | Важнее общего заявленного трафика |
| Индексация в Яндексе | 4/4 | Критично для Яндекс-приоритета |
| Низкое число продажных статей и исходящих ссылок | 4/4 | Главный антиспам-признак |
| Согласованность ИКС, DR/DA, трафика и индекса | 4/4 | Нужно ловить дропы и накрутки |
| Русский язык и Россия/СНГ | 4/4 | РФ основной приоритет, Беларусь/Казахстан допустимы при наличии продаж |
| Авторитет домена: ИКС, DR/DA, TF/CF | 4/4 | Использовать совместно, не доверять одной метрике |
| Проверка реального размещения и индексации статьи | 3/4 | Обязательна перед дорогой покупкой |
| Внешнее обогащение данных | 4/4 | Одной выгрузки Miralinks недостаточно |

Не использовать: `Спам Я`, почти одинаковый у всех `Рейтинг Miralinks`. `Эксклюзив` и `Траст` оставить только как слабые признаки.

## 2. Спорное

### Трафик

- fable: отсечка ниже 100, рабочий уровень 500-2 000;
- Gemini: общий трафик от 300 и Ahrefs-трафик от 50;
- Terra: допустимы 30-99 для узких отраслевых сайтов;
- Grok: ориентир 500-2 000, но предлагает сомнительную линейную нормировку.

Практичнее не ставить безусловный порог 300 или 500: у узкого промышленного сайта может быть 100-300 качественных посещений. При этом высокий общий трафик нельзя считать органическим. Решение: жестко отбраковывать только комбинацию `Трафик <100 И ИКС <30`, а остальное учитывать логарифмически и подтверждать внешним Яндекс-трафиком.

### Число статей

- Gemini предлагает до 50 как лучший уровень;
- fable допускает до 250, выше 700 считает почти отказом;
- Terra допускает до 300 и только после 1 000 обнуляет баллы;
- Grok ошибочно начисляет больше баллов за большее число статей.

Практичнее вариант fable/Terra: небольшое число статей предпочтительно, но узкий отраслевой сайт с 100-250 публикациями не нужно автоматически исключать. `>800` делаем hard-фильтром, а плотность статей относительно индекса учитываем отдельно.

### ИКС и DR

- Grok требует ИКС 200+ и DR 35+;
- Terra использует более мягкие границы;
- fable справедливо снижает вес метрик при низком трафике;
- Gemini считает ИКС/DR почти бинарными.

Практичнее мягкая шкала Terra плюс штраф за несогласованность. Высокий DR или ИКС без трафика не должен сам по себе давать высокий результат.

### TF/CF

Grok предлагает абсолютные TF/CF, Terra использует соотношение TF/CF, fable только штрафует `CF/TF > 2,2`. Практичнее использовать TF/CF как детектор качества ссылочного профиля, а не как основной показатель авторитета: метрики Majestic слабо сопоставимы с Яндексом.

## 3. Финальная формула 0-100

Перед расчетом пустые числовые значения трактуются как `0`, кроме `Ahrefs трафик`, где пустое значение означает «нет данных». Все диапазоны включают нижнюю границу.

### A. Тематика: 0-22

- Промышленность, оборудование, производство, энергетика, строительство, агро, транспорт, авто: `22`
- Бизнес, экономика, наука и технологии, IT: `14`
- Газеты/СМИ с регионом Россия: `10`
- Газеты/СМИ без региональной привязки: `6`
- Остальное: `0`

Если указано 5 и более тематик, блок ограничить: `min(A, 8)`.

### B. Трафик и органика: 0-18

```text
B1 = 12 * clamp(log10(max(Трафик, 100) / 100) / log10(300), 0, 1)
```

Ориентиры: 100 = 0; 1 000 примерно = 4,7; 3 000 примерно = 6,6; 30 000 = 12.

`B2` по `Ahrefs трафик`:

- пусто: `3` нейтральных балла;
- 0-9: `0`;
- 10-49: `2`;
- 50-199: `4`;
- 200-999: `5`;
- 1 000+: `6`.

```text
B = B1 + B2
```

Штрафы:

- `Трафик / Стр. в индексе Я >50` при `Стр. в индексе Я <200`: `B -= 3`;
- если `Ahrefs трафик` заполнен и составляет менее 3% от `Трафик` при `Трафик >1000`: `B -= 2`.

### C. Авторитет: 0-16

`C1`, ИКС, максимум 7:

- `<20`: 0
- `20-49`: 2
- `50-99`: 4
- `100-299`: 5
- `300-999`: 6
- `1000+`: 7

`C2`, DR, либо DA при пустом DR, максимум 5:

- `<10`: 0
- `10-19`: 1
- `20-34`: 3
- `35-49`: 4
- `50+`: 5

`C3`, TF/CF, максимум 4:

- `TF >=15` и `TF/CF >=0,5`: 4
- `TF >=10` и `TF/CF >=0,3`: 2
- `TF >=5`: 1
- иначе: 0

Штрафы:

- `DR >=45` и `Трафик <300`: `C2 = 0`;
- `ИКС >=300` и `Трафик <500`: `C1 = min(C1, 2)`;
- `CF/TF >2,2`: `C -= 2`.

### D. Индексация и доля статей: 0-18

Процент индекса, максимум 10:

- `>=95`: 10
- `90-94`: 8
- `80-89`: 5
- `70-79`: 2

Страницы в индексе, максимум 5:

- `>=300`: 5
- `100-299`: 4
- `30-99`: 2
- `25-29`: 1

Доля статей `r = Статей / Стр. в индексе Я`, максимум 3:

- `r <=0,05`: 3
- `0,05<r<=0,15`: 2
- `0,15<r<=0,30`: 1
- `0,30<r<=0,35`: 0

### E. Чистота: 0-16

По `Статей`:

- `0-30`: 12
- `31-100`: 10
- `101-250`: 7
- `251-500`: 3
- `501-800`: 1

Дополнительно:

- `Траст = да`: `+2`;
- `Эксклюзив = да`: `+2`.

### F. Цена и регион: 0-10

Цена:

- `400-1199`: 2
- `1200-2999`: 3
- `3000-7000`: 5
- `7001-15000`: 2

Регион:

- Россия: `3`
- Беларусь/Казахстан: `2`
- остальные допустимые значения: `0`

```text
SCORE = clamp(A+B+C+D+E+F, 0, 100)
```

**Порог покупки:**

- `>=70`: покупать после проверки конкретной страницы;
- `60-69`: только ручная проверка и тестовая закупка;
- `<60`: отказ.

## 4. Hard-фильтры до скоринга

| Условие | Причина |
|---|---|
| `Язык != Русский` | Не соответствует аудитории и Яндексу РФ |
| `Регион` не Россия, Беларусь или Казахстан | Нет целевой географии |
| `Трафик <100` и `ИКС <30` | Вероятно мертвый хост |
| `% индекс Я <70` | Высокий риск выпадения статьи |
| `Стр. в индексе Я <25` | Слишком маленький или пустой сайт |
| `Статей >800` | Вероятная линкопомойка |
| `Статей / Стр. в индексе Я >0,35` | Слишком высокая доля продажных материалов |
| `Цена <400 ₽` или `>15000 ₽` | Мусорный демпинг либо вне бюджета |
| `DR >=45` и `Трафик <300` | Вероятный PBN/накрученный DR |
| `ИКС >=500` и `Трафик <500` | Вероятный дроп с унаследованным ИКС |
| В `Тематика` есть казино, МФО, adult, ставки, эзотерика, накрутка | Токсичное соседство |
| `Домен` уже используется сетью | Риск аффилиатной склейки |

## 5. Три наиболее полезных дополнительных данных

1. **Яндекс-видимость за 12 месяцев:** число фраз в ТОП-10/50, органический трафик РФ, динамика.  
   Заменяет `Трафик` в блоке B. При `<100` фраз в ТОП-50 или падении более 30-40% домен отбраковывается.

2. **Реальные исходящие ссылки:** referring domains, dofollow-доля, коммерческие анкоры, прирост за год.  
   Заменяет `Статей` в блоке E и расчет `r`. `>300` referring domains или прирост `>20/мес` делает домен отказным; расхождение с Miralinks более чем втрое снижает его максимум до тестовой корзины.

3. **Возраст и история домена через Whois/Wayback.**  
   Добавляет штраф или hard-фильтр: возраст `<12 месяцев` только тест; смена тематики, дроп или длительный разрыв контента обнуляет блок C и требует отказа при наличии альтернатив.

Дополнительно перед каждой покупкой нужно проверить 3-5 последних гостевых статей: индекс Яндекса, `nofollow/sponsored`, наличие внутренних ссылок и число внешних ссылок.
