# Критерии идеального донора и скоринг (канон 05.08.2026)

Собрано методом «идеи от 4 ИИ → судья от каждого»: fable-5, gemini-3.1-pro,
gpt-5.6-terra, grok-4.5 дали критерии и формулы (`DONOR-CRITERIA-IDEAS.md`),
три судьи-синтезатора свели их в консенсус (`DONOR-CRITERIA-JUDGES.md`).
Реализация: `score_donors.py`. Прогон базы Miralinks 05.08.2026 (14338 доноров):
`donors-scored.xlsx`.

## 1. Что делает донора идеальным (консенсус 4/4)

1. **Тематическая близость на уровне рубрики**, а не галочки биржи: промышленность,
   производство, стройка, агро, транспорт, авто/СТО. Ссылка из профильной рубрики
   весит кратно больше той же ссылки из «разного» - и приводит живого снабженца.
2. **Живой поисковый трафик** (не «трафик вообще»). Медиана базы 91 = большинство
   доноров мертво. Порог отсечения 300, рабочий уровень 2000-10000+.
3. **Индексация страницы размещения.** Неиндексируемая статья = ссылки не существует;
   по оценкам линз 20-30% дешёвых размещений в индекс не попадают.
4. **Низкая плотность продажности**: мало уже размещённых статей относительно объёма
   сайта. Больше трети индекса - гостевые → хост переклассифицируется в «сайт для ссылок».
5. **Согласованность метрик между собой.** DR 55 при трафике 150 - PBN; ИКС 800 при
   трафике 300 - дроп с унаследованным ИКС. Расхождение важнее абсолютных значений.
6. **Русский язык, РФ/СНГ-регион.** Проект под Яндекс, покупатель - российский снабженец.
7. **Цена как обратный индикатор**: за 300 ₽ никто не проводит редактуру и не ограничивает
   поток. Наш бюджет 3-15 тыс - цена в этой базе вообще не ограничение.
8. **Уникальность донора внутри нашей сети**: один донор - один наш сайт (иначе
   склейка prokompressor + enger + дилеров в один кластер, риск аффилиат-фильтра).

## 2. Скоринг 0-100 (реализован в `score_donors.py`)

| Блок | Вес | Суть |
|---|---|---|
| A. Тематика | 0-24 | промышленная рубрика 24 / бизнес 15 / СМИ+РФ 10 / СМИ 6; ≥5 тематик → срез до 9 |
| B. Трафик | 0-22 | логшкала 300→0, 30000→22; ×0.75 если органики <10% трафика; ×0.5 при Дзен-профиле (трафик/страницы >50 при индексе <200) |
| C. Авторитет | 0-16 | ИКС 0-10 + DR/DA 0-6; обнуления: DR≥45 при трафике <300 (PBN), ИКС≥300 при трафике <500 (дроп) |
| D. Индексация | 0-16 | % индекса + страниц в индексе + доля гостевых (r>0.30 → −5) |
| E. Чистота исходящих | 0-14 | по числу размещений: ≤30 → 14, >700 → −10; штраф за плотность продаж на трафик |
| F. Majestic | 0-2 | CF/TF как детектор ссылочной схемы; >2.5 → 0 и C ×0.75 |
| G. Экономика | 0-2 | цена ≥2500 → 1; эксклюзив +0.5; российский регион +0.5 |
| H. Спам Яндекса | 0-6 | ≤2% → 6, ≤5% → 5, ≤10% → 3.5, ≤15% → 2, ≤18% → 0.5, выше → 0 |

**Пороги:** ≥72 - корзина A (покупаем после ручной проверки образца); 62-71 - корзина B
(после доп. проверок); 52-61 - экспериментальная; <52 - отказ.

## 3. Hard-фильтры (до скоринга)

язык ≠ ru · регион вне РФ/СНГ · токсичные тематики (гэмблинг/займы/эзотерика/adult) ·
трафик <100 И ИКС <30 · индексация <70% · >700 размещений · гостевые >35% индекса ·
цена <400 ₽ · сайт <25 страниц · DR≥45 при трафике <300 · ИКС≥500 при трафике <500 ·
≥7 тематик (нет ядра) · **спам Яндекса ≥18%**.

## 5. Ловушки этой базы (важно)

- **«Спам Я» - РАБОЧАЯ метрика** (поправка владельца 05.08). Значения - доли: 0.16 = 16%.
  Ненулевых 9182 из 14338, медиана 2%, p90 17%, максимум 20%. В первом прогоне я ошибочно
  счёл колонку нулевой из-за собственного округления при печати - формула это учитывала
  неверно. Сейчас: блок H (0-6 баллов) + hard-отсечка при ≥18%.
- **«Рейтинг Miralinks» = 5 почти у всех** - административная метрика, не сигнал.
- **«Траст» есть у 66%** - признак, выполняющийся у двух третей, не разделяет выборку.
- **«Статей» считает только размещения через Miralinks.** Донор параллельно торгует на
  GGL/Collaborator/Sape - реальное число исходящих бывает в 3-5 раз выше.
- **«Трафик» - число без источника** (SimilarWeb/LI/декларация), включает Дзен и ботов.
- **ИКС - лаговая и наследуемая** метрика; ИКС 160 (p90 базы) - всё ещё слабый сайт.
- **«% индекс Я» гримируется** через robots.txt; читать только вместе со «Стр. в индексе».
- **Тематика проставлена вебмастером** и биржей не верифицируется: из 907 «сельское
  хозяйство и производство» реально отраслевых будет 100-150.
- **Потолок цены базы 7000 ₽.** Ориентир «3-15 тыс ₽ за размещение» я взял из
  `DONOR-CHECKLIST.md:64` (старый чек-лист проекта), а НЕ от владельца - бюджет с ним
  не согласовывался и подлежит уточнению. Независимо от цифры вывод сохраняется:
  флагманских отраслевых медиа на Miralinks нет, они не продают через биржу.
  Miralinks - средний объёмный слой профиля; 3-5 флагманских ссылок в год добираются
  напрямую, под них нужен отдельный бюджет.

## 6. Что достать дополнительно (приоритет)

1. **Яндекс-видимость** (Keys.so / Serpstat / Букварикс): число фраз в топ-10/50 Яндекса
   и оценка поискового трафика. Полностью заменяет колонку «Трафик» в блоке B.
   Правило: <100 фраз в топ-50 → отбраковка независимо от заявленного трафика.
   Отсечёт дзен-новостники, которые сейчас получают максимум по блоку B.
2. **Реальные исходящие** (Ahrefs/Megaindex): linked domains, доля dofollow, прирост за
   12 мес. Заменяет «Статей» на достоверную. >300 доменов или прирост >20/мес → отказ;
   расхождение с «Статей» >3× = донор торгует на 3+ биржах → максимум корзина B.
3. **Аудит размещений донора** - реализован: `audit_donor_pages.py` + `DONOR-PAGE-AUDIT.md`
   (краул статей с внешними ссылками + домерж Ahrefs UR → доля живых размещений).
4. **Ручная проверка 3-5 последних гостевых статей** (самая дешёвая и решающая):
   в индексе ли Яндекса, есть ли внутренние ссылки на статью, dofollow ли внешние,
   есть ли пометка «реклама/партнёрский материал», сколько всего внешних ссылок.
   <60% в индексе, или sponsored/nofollow, или 5+ внешних ссылок → жёсткий отказ.
5. Возраст и история домена (Whois + Wayback): моложе 12 мес → только эксперимент;
   смена тематики/дроп → блок C обнуляется.
6. Пересечение с ссылочными профилями 5-8 конкурентов: подтверждает живость, но
   4+ прямых конкурента у одного донора → вес размыт, приоритет вниз.

## 7. Как пользоваться

```bash
cd seo-texts/guest-posts
python3 score_donors.py <выгрузка-биржи.xlsx> -o donors-scored.xlsx
```
Выход: листы «Скоринг» (все прошедшие, зелёная заливка ≥72, жёлтая 62-71),
«Корзины», «Отбраковка» (с причинами), «Сводка». Дальше: отобранных из корзины A
прогнать через проверку п.6.3 руками, релевантных занести в матрицу донор-фита
`FINAL-ACCEPTORS.md` и планировать статьи по `PLAYBOOK-GENERATION.md`.
