# Идеи критериев идеального донора (3 ИИ, 05.08.2026)


# fable-5

# 1. Критерии идеального донора (и почему)

1. Тематическая близость на уровне рубрики, а не галочки биржи. Нужны разделы «оборудование / производство / промышленность / стройка / агро / транспорт / автосервис». Яндекс с 2019-2021 сильно завязал вес ссылки на тематическое соответствие хоста и страницы; ссылка из рубрики «Промышленность» весит кратно больше той же ссылки из «Разное». Плюс это единственный способ получить хоть какой-то referral от снабженцев.

2. Живой поисковый трафик из Яндекса (не «трафик вообще»). Медиана 91 в базе означает, что большинство доноров — мёртвые сайты. Яндекс не передаёт вес со страниц, которые сам считает нерелевантными и непосещаемыми. Порог отсечения — 500/мес, рабочий уровень — 2000-7000+.

3. Гарантированная индексация страницы размещения. Неиндексируемая статья = ссылка не существует. Отсюда: `% индекс Я ≥ 90`, наличие статьи в разделе с внутренними ссылками (не в «архиве блога» без входящих). Это самый недооценённый критерий: 20-30% дешёвых размещений просто никогда не попадают в индекс Яндекса.

4. Низкая плотность продажности. Показатель — `Статей` относительно объёма сайта. Когда 30%+ контента — гостевые посты с внешними ссылками, Яндекс переклассифицирует хост в «сайт для ссылок» и обнуляет вес всего исходящего. `Статей > 500` (это ~p85-p90 базы) — практически всегда линкопомойка.

5. Согласованность метрик между собой. ИКС, DR, трафик и объём индекса должны быть в одном порядке. DR 55 при трафике 150 = PBN с накрученным ссылочным. ИКС 800 при трафике 300 = дроп с унаследованным ИКС или сайт на дзен-трафике. Расхождение — сильнейший маркер накрутки, важнее абсолютных значений.

6. Русский язык + российский регион + русская хост-зона. Проект под Яндекс, покупатель — российский снабженец. Украина/Индонезия/Индия в базе (1300+ доноров) для нас нулевые.

7. Цена как обратный индикатор. Медиана базы 321 ₽ при нашем бюджете 3-15 тыс. Значит цена нам вообще не ограничение, и её надо читать наоборот: за 300 ₽ никто не проводит редактуру и не ограничивает поток размещений. Реальный отраслевой сайт с трафиком не продаёт статью дешевле 2-3 тыс. Максимум базы 7000 ₽ — берём верхний дециль без колебаний.

8. Уникальность донора внутри нашей сети. Один донор — один наш сайт. Prokompressor, enger-air и дилерские сайты не должны линковаться с одних и тех же хостов: это склеивает их в один кластер и повышает риск аффилиат-фильтра Яндекса в коммерческой выдаче.

# 2. Скоринг-формула (100 баллов, только имеющиеся колонки)

## A. Тематика — 0-22

| Условие | Баллы |
|---|---|
| Есть «Сельское хозяйство и производство» ИЛИ «Транспортные услуги» ИЛИ «Авто и Мото» ИЛИ «Строительство» ИЛИ промышленность/оборудование/энергетика | 22 |
| Только «Бизнес» / «Экономика» / «Наука и технологии» / «IT» | 14 |
| «Газеты/СМИ» + Регион = Россия (региональное деловое СМИ) | 10 |
| «Газеты/СМИ» без региональной привязки | 6 |
| Прочее нерелевантное | 0 |
| Штраф: указано ≥5 тематик (сайт «обо всём») | итог блока = min(итог, 8) |

## B. Трафик — 0-24 (логарифмическая нормировка, иначе p90=7242 съедает шкалу)

`B = 24 * clamp( log10(Трафик/100) / log10(300), 0, 1 )`

Пороговые точки: 100 → 0 | 300 → 4,5 | 1 000 → 9,4 | 3 000 → 13,8 | 10 000 → 18,7 | 30 000 → 24.

Штраф на несогласованность: если `Трафик / Стр. в индексе Я > 50` при `Стр. в индексе Я < 200` → `B = B * 0.5` (трафик не поисковый).

## C. Авторитет — 0-20 (ИКС 0-12 + DR 0-8, с обработкой пропусков)

ИКС: `<20 → 0` | `20-49 → 3` | `50-99 → 6` | `100-299 → 9` | `300-999 → 11` | `≥1000 → 12`

DR: `отсутствует → 3` (нейтрально-низко, не 0 и не полный балл) | `<10 → 0` | `10-19 → 2` | `20-34 → 5` | `35-49 → 7` | `≥50 → 8`

Обнуления внутри блока:
- `DR ≥ 45 и Трафик < 300` → DR-часть = 0 (PBN)
- `ИКС ≥ 300 и Трафик < 500` → ИКС-часть = 3 (унаследованный ИКС дропа)
- `CF / TF > 2.2` (если оба есть) → `C = C * 0.6` (ссылочная схема)

## D. Индексация — 0-16

| % индекс Я | Баллы |
|---|---|
| ≥95 | 8 |
| 85-94 | 6 |
| 75-84 | 3 |
| <75 | 0 |

| Стр. в индексе Я | Баллы |
|---|---|
| ≥300 | 5 |
| 100-299 | 4 |
| 30-99 | 2 |
| <30 | 0 |

Доля гостевых в индексе `r = Статей / Стр. в индексе Я`: `r ≤ 0.05 → +3` | `0.05-0.15 → +2` | `0.15-0.30 → 0` | `>0.30 → −5`

## E. Чистота исходящих — 0-14

| Статей | Баллы |
|---|---|
| ≤30 | 14 |
| 31-100 | 11 |
| 101-250 | 7 |
| 251-500 | 3 |
| 501-700 | 0 |
| >700 | −10 (фактически отсечка) |

Штраф по плотности: `Статей / (Трафик/1000) > 50` → `−5` (много продаж на мало трафика).

## F. Экономика и прочее — 0-4

Цена: `2500-7000 → 2` | `1200-2499 → 2` | `500-1199 → 1` | `<500 → 0`
`Эксклюзив = да → +1`
`Регион = Россия → +1`

## Итог и порог

`SCORE = A + B + C + D + E + F` (максимум 100, возможны отрицательные слагаемые)

| Диапазон | Действие |
|---|---|
| ≥72 | Корзина A — покупаем, только ручная проверка страницы-образца |
| 62-71 | Корзина B — покупаем после проверок из блока 5 (пп. 1, 2, 4) |
| 52-61 | Только в экспериментальную корзину и только при цене <1500 ₽ |
| <52 | Отказ |

Ожидаемый выход по такой базе: 100-250 доменов ≥62 из 14338. При темпе ≤2 новых домена/нед на сайт этого хватает на 12-18 месяцев работы всей сети — то есть надо не расширять сито, а ужесточать.

```python
def score(row):
    A = topic_points(row["Тематика"], row["Регион"])
    t = row["Трафик"] or 0
    B = 24 * clamp(log10(max(t,1)/100) / log10(300), 0, 1)
    if row["Стр. в индексе Я"] and row["Стр. в индексе Я"] < 200 \
       and t / max(row["Стр. в индексе Я"],1) > 50:
        B *= 0.5
    C = iks_points(row["ИКС"], t) + dr_points(row["Ahrefs DR"], t)
    if row["CF"] and row["TF"] and row["CF"]/max(row["TF"],1) > 2.2:
        C *= 0.6
    D = index_pct_points(row["% индекс Я"]) + pages_points(row["Стр. в индексе Я"]) \
        + guest_ratio_points(row["Статей"], row["Стр. в индексе Я"])
    E = articles_points(row["Статей"])
    if t and row["Статей"]/(t/1000) > 50: E -= 5
    F = price_points(row["Цена ₽"]) + (1 if row["Эксклюзив"] else 0) \
        + (1 if row["Регион"] == "Россия" else 0)
    return A + B + C + D + E + F
```

# 3. Красные флаги — отбраковка до скоринга

1. Язык ≠ русский. Регион вне {Россия, Беларусь, Казахстан}. Украина — в отказ (аудитория + риски). Индонезия/Индия/прочее (~1500 доноров) — минус сразу.
2. `Трафик < 100` И `ИКС < 30` одновременно. Мёртвый хост, ссылка не имеет веса ни в Яндексе, ни в Google. Это срезает около половины базы.
3. `% индекс Я < 70`. Частичный вылет из индекса — почти всегда следствие фильтра или технического мусора. Ваша статья тоже не проиндексируется.
4. `Статей > 700`. Независимо от ИКС и трафика. Ориентир: p90 = 640, то есть это верхние ~7% продавцов-конвейеров.
5. `Статей / Стр. в индексе Я > 0.35`. Больше трети сайта — гостевые посты.
6. `Цена < 400 ₽`. Ниже себестоимости редактуры. Такой донор физически не может отказать никому.
7. Тематические кластеры-токсины в списке: гэмблинг/ставки, займы/МФО, эзотерика, знакомства, «заработок в интернете», рефералки, adult, накрутка/SMM. Даже одна такая рубрика — отказ: соседство по исходящим переносится на нас.
8. `DR ≥ 45 при Трафике < 300` — PBN. `ИКС ≥ 500 при Трафике < 500` — дроп с унаследованным ИКС.
9. `Стр. в индексе Я < 25` — сайт из 15 страниц, где ваша статья висит в пустоте.
10. Домен уже присутствует в ссылочном профиле любого сайта нашей сети.
11. Указано «все тематики» или ≥7 тематик — площадка не имеет тематического ядра.

# 4. Ловушки этой конкретной базы

Колонка «Спам Я» полностью нулевая. Это не «все чистые», это «данные не собирались». Любой скрипт, который читает её как признак, систематически завышает оценки. Исключить из формулы полностью.

Колонка «Трафик» — не источник, а число. Провенанс неизвестен (SimilarWeb / LiveInternet / декларация вебмастера), включает прямые заходы, соцсети и ботов. Для нас критичен только Яндекс-поисковый трафик. Отдельная беда: значительная часть доноров с «трафиком» 20-100к — это новостные агрегаторы, живущие на Дзене и Турбо-страницах. Такой трафик даёт ноль поисковой видимости и обнуляется при первом же изменении алгоритмов рекомендаций. Отсюда штраф `Трафик/Стр. в индексе` в блоке B — но по-настоящему решается только проверкой из блока 5.

«Рейтинг Miralinks» = 5 почти у всех. Административная метрика, информационная ценность нулевая.

«Траст» (бинарный) есть у 9461 из 14338, то есть у 66%. Признак, который выполняется у двух третей выборки, не разделяет её. Максимум ±1 балл, лучше игнорировать.

«Статей» считает только размещения через Miralinks. Донор параллельно торгует на GoGetLinks, Collaborator, PR-CY, Sape и напрямую. Реальное число проданных ссылок бывает в 3-5 раз выше. Значение 53 (медиана) может означать 250 фактических исходящих.

ИКС — лаговая и наследуемая метрика. Обновляется раз в месяц, реагирует на любой трафик (включая соцсети), полностью переходит к покупателю дропа. ИКС 160 (p90 базы) — это всё ещё слабый сайт; в промышленных тематиках нормальный отраслевой ресурс имеет 500-3000. То есть база в целом состоит из площадок ниже нашего целевого уровня.

«% индекс Я» = в индексе / известно роботу. Легко гримируется: закройте мусор в robots.txt — получите 100%. Сайт на 40 страниц с 100% хуже сайта на 5000 страниц с 88%. Всегда читать вместе с `Стр. в индексе Я`.

DA / CF / TF — Moz и Majestic, по рунету обновляются плохо и коррелируют с Яндексом слабо. Единственное рабочее применение — отношение CF/TF как детектор ссылочной схемы. Абсолютные значения в формулу не берём.

«Эксклюзив» (7757 шт) — заявление вебмастера, что площадка представлена только здесь. Непроверяемо и часто ложно. Отсюда вес всего 1 балл.

Тематика проставлена вебмастером и биржей не верифицируется. Из 907 доноров с «Сельским хозяйством и производством» реально отраслевых, по опыту, окажется 100-150 — остальные это универсальные новостники, поставившие галочку ради спроса. Колонка годится для первичной фильтрации, не для финального решения.

Ценовой потолок 7000 ₽ при нашем бюджете 15 000 ₽ — главный стратегический вывод по базе. Площадок, которые для нас были бы флагманскими (отраслевые медиа, «Промышленные страницы», региональные деловые издания с реальной редакцией), на этой бирже нет: они не продают статьи за 7 тысяч через Miralinks. Miralinks — это средний объёмный слой профиля. Флагманские 3-5 ссылок в год добираются напрямую или через отраслевые ассоциации, и на них надо резервировать отдельные деньги, а не искать их в этой выгрузке.

«Вечное размещение» — договорное обещание, не техническая гарантия. По практике 15-25% размещений теряются за 2 года (редизайн, смена CMS, смерть сайта, чистка вебмастером). Планируйте, что часть бюджета амортизируется, и раз в квартал прогоняйте закупленные URL на код 200 + наличие ссылки + наличие в индексе.

# 5. Что достать дополнительно (5 позиций)

1. Яндекс-видимость донора: Keys.so / Serpstat / Букварикс — число фраз в топ-10 и топ-50 Яндекса, оценочный поисковый трафик из Яндекса, тематическое распределение запросов.
Как меняет решение: полностью заменяет колонку «Трафик» в блоке B. Правило: <100 фраз в топ-50 Яндекса → отбраковка, каким бы ни был заявленный трафик. Это отсекает дзен-новостники, которые иначе получают 22-24 балла из 24. Ожидаю, что через это сито не пройдёт 30-40% формально «трафиковых» доноров.

2. Реальные исходящие: Ahrefs (или Megaindex) — количество внешних linked domains, доля dofollow, динамика прироста за 12 месяцев, доля коммерческих анкоров.
Как меняет решение: заменяет колонку «Статей» на достоверную. Правила: linked domains >300 или прирост >20/мес → отбраковка независимо от скора. Расхождение с колонкой «Статей» больше чем в 3 раза = донор торгует на 3+ биржах, площадка перегружена → корзина B максимум.

3. Возраст и история домена: Whois + Wayback Machine, 5-6 срезов за 5 лет.
Как меняет решение: домен младше 12 месяцев → только экспериментальная корзина. Обнаруженная смена тематики или разрыв в контенте (дроп) → блок C обнуляется, потому что ИКС и DR унаследованные и Яндекс это уже переоценил. Отсекает самую опасную категорию: «сильные метрики, нулевая реальная ценность».

4. Ручная проверка 3-5 последних гостевых статей на домене — самая дешёвая и самая решающая проверка. Смотреть: в индексе ли Яндекса (`yandex.ru/search/?text=<url>`), есть ли на статью внутренние ссылки из рубрик и листингов, dofollow ли внешние ссылки, стоит ли пометка «реклама / партнёрский материал / на правах рекламы», сколько всего внешних ссылок в статье.
Как меняет решение: если <60% свежих гостевых в индексе Яндекса, или ссылки закрыты `rel=sponsored/nofollow`, или в статье 5+ внешних ссылок — жёсткая отбраковка, минуя скоринг. Это единственная проверка, которая напрямую отвечает на вопрос «получим ли мы вообще ссылку».

5. Реальный регион донора в выдаче Яндекса (по гео-зависимым запросам или через Яндекс.Вебмастер, если дают доступ) + пересечение с ссылочными профилями 5-8 наших конкурентов.
Как меняет решение: при равном скоре приоритет донорам с привязкой к промышленным регионам, где работают дилеры — это усиливает гео-запросы дилерских сайтов и поднимает донора из корзины B в A. Пересечение с конкурентами используется как подтверждение живости площадки, но если донор линкует 4+ прямых конкурента — понижаем приоритет: ссылочный вес там уже размыт, а тематический кластер выглядит скупленным.

# 6. Сегментация выборки

Топ по формуле нельзя брать целиком: получится однородная группа «трафиковых новостников», а это неестественный профиль и высокая корреляция рисков. Распределение по корзинам от бюджета на ссылки:

Корзина 1 — Отраслевое ядро, 40% бюджета. Тематика A=22, `Трафик ≥ 1000`, `Статей ≤ 250`. Здесь мы сознательно снижаем требование к трафику: тематический сайт с 1500 посетителей полезнее универсального с 40 000. Целевые доноры — производственные, строительные, агро- и транспортные ресурсы. 8-15 доменов на сеть в год.

Корзина 2 — Региональные деловые СМИ России, 25%. «Газеты/СМИ» + Регион = Россия, `Трафик ≥ 5000`, `ИКС ≥ 100`, `% индекс ≥ 90`. Дают хостовый траст и региональную привязку. Основной адресат — дилерские сайты с гео-запросами.

Корзина 3 — Трафиковые тяжеловесы, 15%. `Трафик ≥ 30 000`, `ИКС ≥ 300`, тематика нейтральная (Бизнес, Технологии, Экономика). 2-4 домена, каждый обязательно через проверки 1, 2 и 4 из блока 5 — именно здесь концентрируются накрутки. Задача: подтянуть общий уровень авторитета профиля.

Корзина 4 — Смежные потребители, 10%. «Авто и Мото» (автосервисы, шиномонтаж, СТО), агро-порталы, площадки для монтажников. Требования к ИКС ослабляем, требование к тематическому трафику ужесточаем: эти доноры дают не только ссылку, но и реальные заявки. Оценивать по конверсии, а не по скору.

Корзина 5 — Экспериментальная, 10%. Скор 52-61, цена <1500 ₽, до 5-8 доменов. Назначение — калибровка модели: проверяем, индексируется ли статья и появляется ли динамика. Через 60 дней смотрим индексацию и позиции; всё, что не проиндексировалось, помечаем и выводим соответствующий паттерн (обычно это конкретное сочетание `% индекс` и `Статей`) в красные флаги.

Корзина 6 — СНГ, не более 5% и только Беларусь/Казахстан, только если там есть продажи.

Ограничения поверх корзин:
