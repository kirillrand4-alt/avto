### Три вещи, которые это меняет

**1. Четыре весовые площадки не примут нашу ссылку — 23 005 ₽ из 61 710 ₽.**
`spark.ru`, `bookmix.ru`, `ecoportal.info`, `kvartblog.ru` стоят с пометкой
«размещение нетематических ссылок — нет». Весь смысл весового блока в том, чтобы
поставить ссылку на нерелевантной площадке ради веса, — площадка с таким запретом
для этой задачи бесполезна по определению, и статью снимут на модерации. Из блока C
остаются четыре: `nashaplaneta.net`, `moluch.ru`, `gorod24.online`, `satom.ru`.

Это ошибка отбора, а не биржи: фильтр по нетематическим надо было ставить в самом
начале весового отбора, рядом с ценой и трафиком. В выгрузке поля нет, поэтому
следующий отбор требует либо добавления его в парсер панели статистики, либо обхода
карточек — по 2.5 секунды на площадку.

**2. «Максимум доменов = 1» у 18 площадок из 27.** Пара «производитель + каталог»
(enger-air.ru вместе с prokompressor.ru в одной статье) там невозможна — только
два URL одного сайта. Правило из `PLAYBOOK-GENERATION.md` §1.4 на этих площадках
не применяется; связку планировать только там, где стоит 2 или 3.

**3. `berkat.ru` и `tvcenter.ru` берут ровно одну ссылку.** Один акцептор, без
подкатегории. Для tvcenter.ru это особенно обидно — он лучший по цене российского
трафика (59 ₽ за тысячу).

Мелочью: `moluch.ru` кладёт статьи на глубину 3 клика от главной, `flotenk.ru` и
`tvcenter.ru` вложенность не указывают вовсе. У `metallicheckiy-portal.ru` статейность
18% в Яндексе и 29% в Google — почти треть индекса гостевые, это верхняя граница
приемлемого.

**Не снято:** `kakoj-segodnja-prazdnik.com` — единственная площадка без скриншота
в выгрузке (заглушка `catNoScreen.png`), поэтому ID неизвестен. Нужен URL её карточки
из браузера.

## Как это покупать

**Очередь.** Сначала блок A целиком (18 220 ₽) — он окупается не только ссылкой.
Затем блок B по возрастанию цены веса: citaty.info, berkat.ru, kakoj-segodnja-prazdnik.com,
get-color.ru, tvcenter.ru, afk-arena.com, twizz.ru, 4tololo.ru. Блок C — остаток бюджета.

**Темп.** Лимит из `FINAL-ACCEPTORS.md` действует: не больше 2 доменов на enger-air.ru
в неделю, повторная ссылка на один акцептор — не раньше чем через две недели.

**Что проверять при оплате.** Гарантия размещения на весь срок (особенно spark.ru —
там nofollow), индексация статьи через 2-3 недели, отсутствие пометки «реклама» или
«партнёрский материал», не больше 5 внешних ссылок на странице.

**Чего не ждать.** Заявок с блоков B и C не будет — там наша доля аудитории 0–1%.
Их метрика — рост ссылочного профиля и позиций акцепторов, мерить через 8-12 недель.
