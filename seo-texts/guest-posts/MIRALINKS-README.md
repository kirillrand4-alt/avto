# Выгрузка статей на Miralinks

Собирается скриптом `make_miralinks_zip.py`. Формат биржи прислал владелец 06.08
(`miralinks_article_sample.zip`) и воспроизводится побайтно: плоский архив из `art_N.txt`,
внутри блоки `[__ключ__]` со значением на следующих строках, UTF-8 без BOM, переводы
строк CRLF, пустая строка между блоками.

```bash
cd seo-texts/guest-posts
JOBS_MODULE=wave-jobs python3 make_miralinks_zip.py --ready-only --wave-only \
    -o ARTICLES-MIRALINKS-wave2.zip
```

- `--ready-only` — только статьи, прошедшие приёмку;
- `--wave-only` — только текущая волна, без статей прошлых волн.

Соответствие `art_N.txt` ↔ статья пишется в `MIRALINKS-INDEX.md` рядом с архивом,
а НЕ внутрь: шаблон биржи содержит только `art_N.txt`, лишний файл в загрузке может
сломать разбор на их стороне.

## Что чинилось 20.08

**Готовность статьи определяется по ПОСЛЕДНЕМУ итогу в логе, а не по первому.**
Раньше бралось первое вхождение `Файл: ready/...`, и 13 статей волны 2, принятых
руками, выглядели незавершёнными: файл переименован в `.final.html`, а шапка лога
описывает прошлый автоматический прогон. Теперь лог дописывается (ручная приёмка,
дозапуск отдельных линз), и читать надо конец.

**Список линз берётся из `finalize_gp`, а не копией в этом файле.** Копия отстала:
к 20.08 в приёмке 17 линз, а список знал 12. Пока набор только рос, это было безобидно,
но при переименовании линзы копия начала бы молча пропускать статьи.

**Поле `slug` проверяется на латиницу.** У одной статьи волны 2 в мете остался слуг
с кириллическими буквами внутри латинского имени — а он уходит на биржу как
рекомендация для URL страницы.
