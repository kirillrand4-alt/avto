- Цепочки моделей зашиты и оптимизированы под поведение шлюза, менять без замеров нельзя:
  `DRAFT_MODELS = [openai:gemini-3.6-flash, claude-haiku-4-5, openai:gemini-3.1-pro-preview]`,

  `JUDGES = [claude-fable-5, claude-opus-4-8, openai:gemini-3.6-flash]` (`finalize_gp.py:49`).

  и два первых судьи из трёх становятся одной моделью. Команда из плейбука
  (`PROVIDER_DEAD_MODELS='' python3 finalize_gp.py <slug>`) - не украшение.
- Живость моделей мерили 27.07 и 03.08. **Сегодня не перемеряно.** Перед большим
  прогоном - смоук, это меняет и цену, и качество.

### 5.1. Фактура брендов: покрытие по сайтам (проверено на `kb/brand-facts-clean.json`)

Готовы (есть серии, safe_facts, caveats): **enger, dali, remeza, abac,
atlas_copco (ac-), fini, kraftmann, ironmac** - 8 сайтов.

Нет в чистой базе: **berg (2 сайта), comaro, cross_air, ekomak** - и это не приговор
фактам, а потеря на шаге синтеза. Все четыре ЕСТЬ в `kb/brands-assembled.json`
(60 слагов) и отсутствуют в `kb/brands-synthesized.json` (41 слаг). Причина видна
в коде: `synth_brands.py:41-44` делает `re.search(r'\{.*\}', t, re.S)` и
`json.loads(...)` без локального `try/except`; падение ловится общим
`except Exception` (`:52`) и бренд просто выпадает из `results`. Потеряно ровно
60 - 41 = 19 брендов, по браку парсинга, а не по качеству фактуры.
Путь спасения: перезапустить синтез точечно по нужным слагам с устойчивым парсером,
затем `audit_kb.py`.

**zif** нет ни в одном слое - по нему фактуры нет вообще, нужен сбор с нуля.

## 6. Порядок работы над статьёй для бренд-сайта (предлагаемый)

1. Определить тип страницы: информационная статья или коммерческая категория
   (от этого зависит, брать шаблон `guest-posts` или `site-pages`).
2. Проверить фактуру бренда по §5.1; при отсутствии - сначала спасение KB.
3. Живые запросы страницы - из выгрузки Вебмастера, а не из головы
   (`frog/acceptor-top100.xlsx`, приём из `PLAYBOOK-GENERATION.md` §2).
4. Генерация → мех-QA → 12 линз → `ready/*.final.html`.
5. Публикация на сайт = действие вовне, только по явному ОК владельца.
