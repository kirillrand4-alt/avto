# Что значит каждая колонка в `PARK-SPISOK-DLYA-ZVONKA-1S.csv`

Одна строка — один звонок. В каждой строке ДВЕ ссылки: на человека и на машину.
Строка без обеих в список не попадает: продавцу нечем ответить на «откуда у вас мои
данные».

| колонка | что значит | чему верить |
|---|---|---|
| `inn` | ИНН предприятия | ключ, по нему всё сходится |
| `predpriyatie` | имя: сначала из справочника обзвона, потом из ЕИС, потом самое частое в фактах | имя может отличаться от вывески |
| `chelovek` | ФИО как записано в источнике | обращения из шаблонов («Уважаемый Иван Петрович») вычищены |
| `dolzhnost` / `rol` | должность как в источнике / сведённая роль | роль — наша нормализация, должность — цитата |
| `krug` | 1 гл. инженер/механик/энергетик · 2 нач. цеха/производства · 3 снабжение · 4 руководство · 5 прочее | 1–2 это техконтакт, ради которого список и делался |
| `nomer` | телефон как в источнике | |
| `vid_nomera` | мобильный / городской — по формату номера | это ФОРМАТ, а не доказательство личного владения |
| `lichnyy_nomer_cheloveka` | 1 = номер доказанно привязан к этому человеку (имя стоит рядом с номером в первоисточнике) | вот это и есть «личный», а не формат номера |
| `nomer_u_neskolkih_predpriyatiy` | у скольких ИНН встречается этот же номер (0 = только у одного) | признак 3-й сессии: >1 почти всегда приёмная или подрядчик |
| `prinadlezhnost` | словами: как именно проверялась привязка номера к человеку | «не проверена» — честно, а не «плохо» |
| `mashina` | тип машины из 13 канонических | |
| `model` | марка машины | позиции цеха («К-3», «ТВ-2») из этого поля вычищены — это не модель |
| `rang_mashiny` | 1–10, выше = дороже машина | правило владельца: выше в списке тот, у кого машина дороже |
| `chem_rang` | ЧЕМ доказан ранг: A сумма из документа · B кВт/м³ по марке · C класс по серии · D+ срок ЭПБ истёк · D класс опасности · E известен только тип | если стоит E — машина известна только типом |
| `sila_fakta` | 1 сильнее, дальше слабее | |
| `os` | «парк машин» (машина есть) или «расход газа» (покупает баллоны/жидкий — цель для генератора) | это два разных разговора |
| `ssylok_na_kontakt` | сколько источников подтверждают контакт | |
| `ssylka_chelovek` | страница, где виден номер этого человека | открывается |
| `ssylka_mashina` | страница, где видна машина этого предприятия | открывается |

## Как сортирован список

Правило владельца дословно: «выше будут те, у кого машина дороже, и контакт с лучшей
тех ролью». Ключ: `rang_mashiny` вниз → `krug` вверх → доказанный личный номер вперёд.

## Чего в списке НЕТ и почему

* Строк без ссылки на человека или без ссылки на машину — отсеяно 82 контакта, у которых
  предприятие в парке, но конкретный факт машины ссылкой не открывается.
* Телефонов без единого источника (`ssylok=0`).
* Обращений из шаблонов писем в поле «человек».
