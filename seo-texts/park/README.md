# Парк компрессорного оборудования — инструменты 1-й сессии

Задача владельца: собрать наиболее полную базу предприятий, у которых есть компрессорная
машина, генератор азота/кислорода или МКС; выше в выдаче — те, у кого машина дороже и есть
контакт с лучшей технической ролью. **Каждый контакт и факт доказывается ссылкой**;
ссылок может быть несколько.

База (`park.db`) живёт в песочнице сессии и выкладывается снимком на дроп
(`park_snapshot.db`). Здесь — только инструменты, чтобы они пережили пересоздание
контейнера.

## Порядок работы

```
сбор           park_gaz_eis.py · park_brendy_eis.py · park_obshchie_eis.py   (ЕИС, браузер на сервере)
               park_kartochki.py · park_gaz_kartochki.py                     (ИНН и контакты с карточек)
               park_perechen2.py                                             (заключения ЭПБ по перечню)
вливание       park_vlit_*.py                                                (в park.db, с журналом)
проверка       park_tipy_polnyy.py -> park_tipy_primenit.py                  (тип машины провайдером)
               park_proverka_net.py -> park_net_primenit.py                  (встречная проверка исключений)
               park_serii_fix.py -> park_serii_primenit.py                   (марка или позиция в цехе)
               park_tipy_kanon.py                                            (свод типов к 13 каноническим)
ранг и выдача  park_rang.py -> park_vydacha.py -> park_spisok.py
обогащение     park_obogatit.py                                             (штатный конвейер enrich_contacts)
               park_dadata_vlit.py                                          (имя, руководитель, статус ЕГРЮЛ)
```

## Правила, выведенные замерами (не менять без нового замера)

* **Удаление одним голосом недопустимо.** Разметку типа один проход правит следующий,
  а удалённого факта в выдаче просто нет. Встречная проверка другой моделью показала
  17% ошибочных исключений.
* **Счётчик новизны стоит ПОСЛЕ заслона** (правило 3-й сессии), отбракованное пишется
  в файл-отвал с причиной — иначе «принято 0» неотличимо от «ничего не нашлось».
* **ЕИС рвёт слова пробелами** для подсветки («жидк ого азот а») — заслон сравнивает
  строки без пробелов вовсе.
* **Потолок выдачи ЕИС — 1 000 записей на запрос** (20 страниц по 50). Общие запросы
  нарезаются по окну публикации: год, а где больше 900 — месяцы.
* **Адрес карточки закупки зависит от длины реестрового номера**: 11 знаков — 223-ФЗ,
  19 знаков — 44-ФЗ. Форма `/epz/order/notice/notice-info/` отдаёт 404.
* **Заводской номер сверять только внутри «зав. № X»**, а не по всей строке: цифры
  совпадают с номером заключения и факт получает чужой документ.
* Результат серверной работы пишется в серверное хранилище с fsync; песочница при
  рестарте откатывается.
