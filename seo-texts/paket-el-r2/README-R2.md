# Раунд 2 калибровки: Fable 5 vs Sonnet 5, новые типы страниц

Страницы: Hansmann (дружественный бренд), Россия (страна), ременной привод,
10 бар (давление), 1000 л/мин (производительность).
Конвейер: все 21 замечание вычитки вшиты (без тире, без жаргона, без title/description,
блок «от задачи», «поставка» вместо «доставки», наличие на складах и т.д.).

## Итоги
- QA-гейт: 10/10 чистых, все с первого прохода (после механической правки id у одного текста Sonnet)
- «Россия» перегенерирована после уточнения по ZEGA (страна производства Китай)
- SEO-ревью через API-Fable: средний вердикт 6.6/10 у обеих моделей (детали в svodka-r2.csv)

## Мой разбор вердиктов ревьюера (что валидно, что нет)
ВАЛИДНО (пойдёт в следующую итерацию конвейера):
1. Проскакивают цифры не из данных: «28 исполнений с частотником», «ресивер 34-1000 л»
   (категорийный диапазон, который payload прямо запрещал), «более 900 позиций» на России
   (реально ~696 без ZEGA). Лечится: жёстче правило чисел + пересчитанные поля в payload.
2. Остаточный ИИ-стиль: ровный ритм предложений, штампы «закрывают задачу», «инженер фиксирует
   стоимость», дубли фраз текст/FAQ. Лечится: анти-ритмический пункт самопроверки + запрет
   конкретных штампов.
3. H2 почти дублирует H1 (Россия/Fable) - усилить правило 10.
4. Мост-блок Enger отдельным H2 на фасетных страницах ревьюер дважды пометил как
   «SEO-накрутку, размывающую фокус» - ВОПРОС НИЖЕ.

НЕВАЛИДНО (ревьюер не знал наших правил, в следующей версии ревью-промпта учтено):
- «нет цен в тексте» - наше сознательное правило (цены плавают за курсом)
- «нет титула/дескрипшена» - отменены владельцем

## Вопрос владельцу
Сжать мост-блок Enger на ФАСЕТНЫХ страницах (мощность/давление/страна/привод) до 1-2 предложений
без отдельного H2? На брендовых страницах конкурентов H2-мост остаётся как есть.
Аргумент за: два независимых ревью пометили жирный мост как размытие фокуса страницы.
Аргумент против: мост - главный инструмент перелива трафика на Enger.

## Стоимость раунда (по данным API, с учётом кэша)
Fable 5: ~$0.31/текст. Sonnet 5: ~$0.16/текст. Ревью: ~$0.09/текст.
