# Как собрать карточки по словарю моделей и обогатить контакты

Короткая шпаргалка: какой скрипт что делает и в каком порядке запускать.
Состояние на 2026-07-28.

**Важно, где что лежит.** Тендерные скрипты и словарь живут НЕ в основной
ветке, а в `origin/claude/read-intro-section-hrstzj` и
`origin/claude/procurement-file-delivery-guxgbq` (каталог
`seo-texts/engineers-lens/`). Обогащение контактов боевого конвейера — в
основной ветке (`seo-texts/server/enrich_contacts.py`). Перед работой:
`git checkout origin/claude/read-intro-section-hrstzj -- seo-texts/<файл>`.

**Общее ограничение** (из указателя модулей): 86 модулей из 127 нельзя
запустить по одному ИНН — путь ко входному файлу зашит, фильтра нет. Они
гоняют всю базу целиком.

## А. Карточки по словарю моделей

### 1. Словарь

`engineers-lens/centro/SLOVA-DLYA-OBHODA-PLOSHCHADOK.txt` — 778 строк: формы
названий моделей (`32ВЦ 100`, `32ВЦ-100`, `32ВЦ100`, `К 100 90 7`…). Три
написания на модель, потому что площадки пишут по-разному.

### 2. Разведка: где вообще есть что качать

```
python3 tender_centro_scan.py
python3 tender_centro_scan.py --only gpb,tektorg --terms "нагнетатель,ЦНД"
```

Выход: `scan-ploshchadki.csv` — счётчики найденных процедур и первые
организации по каждой паре «площадка × термин». Карточки НЕ выгружает, только
показывает объёмы. Прогон по шести площадкам (ЭТП ГПБ, ТЭК-Торг 223-ФЗ,
ТЭК-Торг Роснефть, Фабрикант, Росэлторг, ЕИС планы) — 42 строки.

Что знать про выдачу: у Росэлторга нет счётчика «найдено N», вместо числа —
разбивка («активные торги: 8; архив: 181»), суммировать вручную. Секция
Роснефти по пяти терминам из семи отвечает «ничего не найдено» — это честный
ответ площадки, а не сбой.

### 3. Прицельная выгрузка карточек

| Площадка | Скрипт | Что даёт |
|---|---|---|
| Tender.pro | `tenderpro_harvest.py [--zamer] [--spisok] [--kartochki] [--inn] [--threads N] [--stranic N]` | список → карточки → ИНН → контакты из комментариев |
| ЭТП ГПБ | `gpb_po_slovam.py`, `gpb_kartochka_kontakt.py` | карточки по словам словаря + контакт из карточки |
| ЕИС (223-ФЗ) | `eis_probe.py`, `vlozheniya.py` | карточки закупок и текст вложений (ТЗ, извещения) |
| Защищённые площадки | `browser_probe.py` | обход через браузер, когда обычный запрос не проходит |

### 3а. Два пласта готовых выгрузок — не путать

Прошлые прогоны оставили ДВА разных набора файлов, и они отвечают на разные
вопросы. Перед тем как брать файл, посмотрите, каким способом он собран.

**Словарные (по словам центробежки):** `portal-postavshchikov-centro.csv` 5 681,
`fabrikant-centro.csv` 2 821, `roseltorg-centro.csv` 1 834,
`rts-tender-centro.csv` 448, `etpgpb-po-slovam.csv`. Список слов: воздуходувка,
турбокомпрессор, турбоагрегат, нагнетатель, «центробежный компрессор»,
воздуходувная, турбовоздуходувка, ЦК-135. **Другого оборудования там нет по
построению** — винтовые, поршневые, чужие бренды (Atlas Copco и т.п.) в эти
файлы попасть не могли. Плюс в них намеренно замешаны контрольные строки на
слово «кастрюля» (25 из 448 у РТС, 354 у Фабриканта) — это заслон против
«площадка молча отдаёт что попало», а не данные. Колонка
`centrobezhnyy_predmet` — механический отсев по корням, не приговор:
«воздуходувка» помечается «да» и в садовом контексте.

**По компаниям (все закупки предприятия подряд, без фильтра предмета):**
603 тысячи карточек по шести площадкам — ЭТП ГПБ 210 151, Tender.pro 131 039,
Портал Москвы 108 271, Росэлторг 44 673, остальное ТЭК-Торг/РТС/Сбербанк-АСТ.
Брались не ради предмета, а ради ЛЮДЕЙ в карточках (отсюда `tp-lica.csv`,
3 184 человека). **Только по этому пласту имеет смысл искать чужой бренд или
непрофильное оборудование** — предмет в нём не отсеивался вообще.

Измеренная разница способов (`PLAN-RABOT.md`, пункт B1в): на одной выборке
словарный обход дал 6 876 закупок, обход по компаниям — 131 039. Но новых
предприятий словарь при этом дал 0.

### 4. Сборка

`svod_tri_sostoyaniya.py` → `SVOD-tri-sostoyaniya.csv` (свод по трём

## Б. Обогащение контактов

### Основной канал — боевой, самый актуальный

`seo-texts/server/enrich_contacts.py`, запускается раннером:

```
python3 run_on_server.py enrich_contacts '{"companies":[{"inn":"7736050003","name":"Газпром"}]}'
```

Цепочка внутри: ИНН/название → поиск сайта (кэш → xmlriver → list-org/DDG →
браузер → антидетект) → страница «Контакты» → адреса с ролями и ФИО →
MX-проверка → выбор лучшего адреса по порядку ролей (закупки → главный
инженер → директор → продажи → общий). Подробности — раздел 7а доки 15.

Это тот код, что крутится в проде и правился 28.07 (в нём же чинили резолв
ИНН через dadata, который молча возвращал пустоту из-за мёртвого прокси).

### Дополнительные каналы (engineers-lens)

| Скрипт | Откуда берёт людей |
|---|---|
| `vlozheniya.py` | вложения закупок ЕИС: ТЗ, извещения, протоколы |
| `tenderpro_lica.py`, `tp_lica_bez_tel.py` | комментарии к карточкам Tender.pro |
| `lica_so_stranic.py`, `lica_stranic.py` | страницы «Контакты» и «Руководство» сайтов |
| `kontakty_strukturnyh_podrazdeleniy.py` | разделы структурных подразделений |
| `sajty_po_ocheredi.py` | поиск сайта по ИНН с проверкой принадлежности |

### Свод и проверка

* `accumulate_contacts.py` → `contacts-accumulator.csv` — все найденные
  контакты в одну таблицу по ИНН с приоритетом обзвона (роль + канал +
  свежесть + оборудование по ЭПБ);
* `svesti_obzvon.py` — ранжированный список для обзвона;
* `email_probe.py` — SMTP-пробы существования адресов, без отправки писем.

## Порядок для типовой задачи

1. Разведка объёмов: `tender_centro_scan.py` → смотрим `scan-ploshchadki.csv`,
   решаем, какие площадки вообще качать.
2. Выгрузка карточек по словарю: скрипты площадок из таблицы выше.
3. Свод фактов и классификация: `svod_tri_sostoyaniya.py` → `tip_mashiny.py`.
4. Контакты: сперва боевой `enrich_contacts` по списку ИНН, затем добор
   специальными каналами (вложения ЕИС, лица из тендеров, страницы сайтов).
5. Сведение: `accumulate_contacts.py` → `svesti_obzvon.py`; адреса прогнать
   через `email_probe.py`.

Полное описание каждого модуля (вход, выход, аргументы, вызывает ли
провайдера) — 127 карточек в `engineers-lens/MODULI/`, указатель:
`engineers-lens/MODULI/UKAZATEL.md`.
