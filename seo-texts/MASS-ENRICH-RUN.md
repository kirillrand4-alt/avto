# Массовый прогон обогащения (xmlriver → сайт → контакты)

**Запущено:** 2026-07-21, автономно. Финальная задача владельца: «ставь xmlriver на поиск
сайтов + выгрузку контактов по всей базе без сайта + новостным компаниям».

## Что делает
Для каждой компании БЕЗ сайта (126 642 из 161 761): xmlriver находит официальный сайт
(knowledge-graph карточка Яндекса → органика, фильтр агрегаторов) → краул главной + страниц
контактов → извлечение email с ролями (mailto/JSON-LD/деобфускация + провайдер на текст) →
MX-проверка. **По убыванию выручки** (лучшие лиды первыми). Резюмируемо.

## Как устроено (устойчивость к рестартам)
- **Драйвер:** `seo-texts/server/mass_enrich_loop.py` (сторона песочницы) — пачками `cap`
  submit'ит `enrich_contacts` mass_base-задания раннеру.
- **Резюмируемость:** каждое задание строит done-set из `enrich_stream_mass.jsonl` на сервере
  и пропускает сделанные ИНН. Прогресс живёт НА СЕРВЕРЕ (jsonl + enrich.db), не в песочнице.
- **Рестарт песочницы/сервера НЕ теряет данные** — максимум теряется одна пачка «в полёте»,
  её ИНН просто переобработаются. Драйвер орфан-толерантен (короткий per-batch-timeout).

## Параметры текущего запуска
`python3 mass_enrich_loop.py 80 0 12 12 1200`
= cap=80/пачку, batches=0 (до опустошения пула), workers=12, channels=12, batch_timeout=1200с.
channels=12 проверено безопасным (0 ошибок «нет свободных каналов»).

## Как ПРОДОЛЖИТЬ после рестарта контейнера (важно!)
Песочница НЕ переживает рестарт → драйвер (pid) умирает, но данные целы. Перезапуск с того
же места:
```bash
cd /home/user/avto/seo-texts/server
nohup python3 mass_enrich_loop.py 80 0 12 12 1200 > mass_loop.out 2>&1 &
```
done-set сам пропустит уже сделанное. Никакого дублирования.

## Скорость / масштаб / стоимость (честно)
- Пропускная способность ~0.10 компании/сек (xmlriver делает реальный Яндекс-SERP, ~медленно).
- Вся база без сайта (126.6k) ≈ **~14 дней** непрерывного прогона. НО лучшие (высоковыручные)
  лиды готовы в первые 1-2 дня — дальше «хвост» мелких компаний с падающим выходом (много
  «сайт не найден», т.к. у микрокомпаний нет сайта).
- **xmlriver платный** (запрос ≈ копейки, но 126k запросов — заметная сумма; хвост часто = 0
  сайта = потраченный запрос). **Решение владельца:** гнать весь хвост или остановить на
  топ-N по выручке — можно прервать в любой момент (данные сохранены).

## Мониторинг
- `tail seo-texts/server/mass_loop.out` — прогресс пачек (обработано/сайтов/email).
- Итоги на сервере: `enrich_stream_mass.jsonl` + `enrich.db` (op `rebuild` восстанавливает БД).
- Забрать выгрузку: задание `enrich_db` (экспорт) или скачать jsonl (нужен пуш на дроп).

## Новостные компании (вторая часть задачи)
После/параллельно: события из `news_scan` (ФРП/zakupki/медиа) → те же mass-обогащение по
названию→ИНН(dadata)→сайт→контакты. Запускается тем же `enrich_contacts` по списку компаний
из событий (передать `enrich:true`+`dadata_token` в news_scan, либо отдельным прогоном).
