# Данные генератора писем (факты и глоссарии)

Эти файлы читает `sender/ai_letter.py` и ждёт их **рядом с пакетом**, а не внутри
него: путь задаётся `SENDER_DIR` (на сервере `C:\sender`), переопределяется
переменными `KC_FACTS` / `MEYER_FACTS` / `KC_GLOSSARY` / `MEYER_GLOSSARY`.

Почему лежат здесь. Их не было в репозитории вообще — только копии части из них
в `sender-patches/meyer-gen/`. Файлы существовали единственным экземпляром на
сервере, и потеря диска означала бы потерю фактической базы генерации. Забраны с
боевого сервера 26.07.2026 и положены под версионный контроль.

Почему это важно для писем. Если файла нет, `load_facts` молча берёт пустой
запасной набор (`_FACTS_FALLBACK`) — генератор не падает, но письмо остаётся без
отраслей, болей и разрешённых чисел, а гейт срезает даже законные цифры, потому
что проверяет их по этому же списку. Внешне выглядит как «модель стала хуже
писать».

| Файл | Что внутри |
|---|---|
| `kc-facts.json` | Компрессор Центр: 5580 внедрений, 1018 проектов на сайте, счётчики по 55 регионам, 25 подтверждённых клиентов |
| `meyer-facts.json` | Meyer: 200 предприятий, 5 доказательств, 14 типовых отраслей, 11 типовых болей, 11 клиентов на подтверждении владельца |
| `product_glossary.json` | Названия компрессорного оборудования (9 разделов) — чтобы генератор не путал типы |
| `meyer_glossary.json` | Названия рентген-инспекции и фотосепараторов (12 разделов) |

Обновление на сервере — как и остальные файлы панели: через дроп в `C:\sender`
(см. `server/PANEL-DEPLOY.md`).
