# База под Мейер: шесть сегментов из нашей базы, с источником у каждой строки

Заказ: база под Мейер из уже собранного, обязательно со ссылками на источники; шесть
сегментов по ОКВЭД; контакты — не секретари, а ЛПР по закупке, эксплуатации и качеству.

Файлы на дропе: **`MEYER-BAZA.xlsx`** (4 листа), `MEYER-BAZA-KOMPANII.csv` (52 МБ),
`MEYER-BAZA-KONTAKTY.csv` (50 МБ, 212 958 строк контактов).

## Где на самом деле лежит база, и почему это пришлось выяснять

Первый заход я сделала по справочнику реквизитов `obzvon-index.db` и получила **одного
названного человека на 43 559 компаний**. Это был приговор не данным, а моему запросу.

Настоящая база — `enrich.db`:

| таблица | строк | что в ней |
|---|---|---|
| `companies` | 169 790 | название, регион, сайт, вид деятельности, почта, метка `division` (`kc` 130 439 / **`meyer` 34 956**) |
| `phone_contacts` | **777 736** | телефон, `person`, `role`, `source`, **`source_url` у 98 %** |
| `people` | ~2,6 тыс. ИНН | названные люди с должностями |

Справочник `obzvon-index.db` (161 799 карточек) оставлен только для того, чего в базе
нет: ОКВЭД дополнительные, выручка, год отчётности, численность, директор по ЕГРЮЛ.

**Все 43 559 нашлись в нашей базе `companies`**, то есть сегменты собраны по нашей базе.

## Главное число — не 43 559, а вид контакта

```
директор по ЕГРЮЛ (имя есть, прямого номера нет) .... 20 924
номер без роли ...................................... 17 373
контакта нет ........................................  4 465
приёмная или общий номер ............................    447
личный контакт с именем .............................    191
роль ЛПР без имени ..................................    105
первое лицо .........................................     54
```

Вы просили не секретарей. Честно: прямых контактов ЛПР в собранном мало — **191 личный
контакт с именем на 43 559 компаний**. Это не свойство агро-сегмента, а состояние базы:
во всей таблице `phone_contacts` имя человека заполнено у **3 068 строк из 777 736**,
то есть у **546 ИНН**. Телефоны есть у 130 837 ИНН, имён — у 546.

Вот почему параллельные сессии постоянно уходят в «странные выборки»: слоя с именами
в базе почти нет, и каждая пытается добыть его заново.

## Чего в файле нет, сказано прямо

* **Беларуси нет.** По слову «Беларус» — 3 строки, «Минск» — 84, и это российские
  компании с минским адресом в тексте. Белорусов по ягодам надо добывать отдельно.
* **Экспортёры — кандидаты.** ОКВЭД экспорта не существует, признака ВЭД или таможенных
  операций в базе нет ни одного. Сегмент собран по оптовой торговле зерном и продуктами
  переработки. Это гипотеза по отрасли, и так подписано в колонке сегмента.
* Выручка есть у 31 889 компаний и **не использовалась как фильтр** — мелких не
  выбрасывали. Колонка «Выручка, руб» числовая, по ней можно сортировать.
* Сайт у 19 689, почта у 28 001, рабочий телефон у 36 531.

## Контроли

* выдуманный ИНН 9999999999 в выборке — 0 строк;
* строк контактов со ссылкой на источник — 207 159 из 212 958 (97 %);
* все 43 559 компаний присутствуют в нашей базе, а не только в справочнике.

## Что делать дальше

База предприятий собрана, узкое место — люди. Следующий шаг не «искать ещё компании»,
а добывать ФИО и прямые номера по 20 924 компаниям, где известен только директор по
ЕГРЮЛ: сайт (у 19 689 он есть), карточки закупок, подписи со страниц.

# Отбор по приоритету должностей: только ЛПР

Заказ: оставить только тех, кто влияет на закупку, эксплуатацию и требования к качеству,
по отдельному списку ролей для каждого сегмента. Файл на дропе: **`MEYER-BAZA-LPR.xlsx`**.

Списки разные, поэтому и фильтр разный: агроном проходит у семеноводов и элеваторов, но
не у пищевых; технолог и качество проходят у пищевых, но не у семеноводов. Компании,
попавшей в несколько сегментов, разрешены роли всех её сегментов. Запасной ход через
бухгалтерию и приёмную сделан **только для элеваторов** — дословно как вы разрешили.

## Числа

```
контактов подошло по роли ................ 1 038
  из них с телефоном ..................... 728
  из них с НАСТОЯЩИМ именем ..............  89
  подтверждено двумя и более источниками .. (колонка «Источников»)
запасной ход для элеваторов ..............   188
директор по ЕГРЮЛ (имя, прямого номера нет) 20 924
компаний, где есть хоть кто-то из списка .. 21 306 из 43 559
  из них с ПРЯМЫМ ЛПР ....................   553
```

## Две правки, которые пришлось внести по ходу

**Дубли.** Один человек с одним номером приходит из нескольких карточек закупок, и
ООО «ЧМНГ» занимало восемь строк подряд. Схлопнуто 1 080 → 1 038, при этом источники
не потеряны, а накоплены: число источников стоит отдельной колонкой.

**В поле имени стояла должность.** «закупки», «Главный инженер», «Опросы Статистика
Карта» — всё это лежало в `person`. Проверено правилом «Фамилия И.О.» и перенесено в
колонку роли. Из 498 строк с непустым полем имени настоящими именами оказались **89**.
Это и есть честное число названных людей по шести сегментам.

## Что отсеяно, но не удалено

17 373 номера без роли, 4 465 компаний без контакта вовсе, приёмные и продажи у всех
сегментов кроме элеваторов. Полные выгрузки лежат на дропе: `MEYER-BAZA-KOMPANII.csv`,
`MEYER-BAZA-KONTAKTY.csv`.

# Только дозваниваемые: мобильные и городские с добавочным

Заказ: «оставь только мобильные либо рабочие с добавочным, которые ведут к нужному
человеку». Городской без добавочного — коммутатор, к человеку он не ведёт.
Файл на дропе: **`MEYER-LPR-MOBILNYE-I-DOBAVOCHNYE.xlsx`**.

```
строк в файле ......................... 282
  прямые ЛПР .......................... 235
  запасной ход по элеваторам ..........  47
из них мобильных ...................... 270
из них городских с добавочным .........  12
из них с НАСТОЯЩИМ именем человека ....  24
разных компаний ....................... 184
```

Путь числа, чтобы видно было, где что терялось:
**43 559 компаний → 212 958 контактов → 1 038 по роли ЛПР → 282 дозваниваемых.**

## Дефект, который замер поймал на мне

Первое правило считало мобильным только запись через `+7`: «+7 (933) 335-49-00».
А `89878645759` — тот же мобильный с ведущей восьмёркой — уезжал в городские и
выбрасывался. Теперь ведущая 8 приводится к 7 **до** проверки кода, и все номера
приведены к единому виду `+7 (9XX) XXX-XX-XX`. Без этой правки часть мобильных
исчезла бы молча, и файл выглядел бы беднее, чем есть.

## Чего здесь нет

* 547 городских без добавочного и 310 строк без номера — остались в `MEYER-BAZA-LPR.xlsx`;
* 20 924 директора по ЕГРЮЛ — у них имя есть, а прямого номера нет, только общий телефон;
* имя человека есть не у всех: у части известна только роль («закупки», «гл.инженер»).
  Такой номер всё равно ведёт в нужный отдел, поэтому оставлен, а колонка
  «Это настоящее имя» показывает, где имя есть.
