Редакция 4, 09.10.2026. Экономный режим. План для новой сессии: она выполняет его без доработки скриптов.

**Задание владельца.** Собрать максимально полную базу предприятий для Meyer — направления ООО «Руспром»:
фотосепараторы (оптическая сортировка), рентген-инспекция и рентгеновская сортировка.

**Результат.** Excel на дропе с подписью «откуда и что внутри». По каждой компании:
- название, ИНН (или УНП), регион, сайт;
- основной и дополнительные ОКВЭД, сегмент и как он определён;
- описание и паспорт с сайта, выручка — колонкой, а не фильтром;
- номера и почты с ФИО, должностью, ролью, отметкой «ЛПР по оборудованию» и ссылкой на страницу-источник.

**Экономный режим** (владелец 09.10):
- модель — GPT-6 Luna везде, где качество почти не теряется;
- запросы урезаны по отдаче, измеренной пилотом.

**Что готово.** 08–09.10 весь конвейер прогнан пилотом на трёх регионах: Краснодарский край, Свердловская и Минская

|---|---|

| «да» в своих сегментах | Агрономия и Хранение — у семеноводов, элеваторов, ягод и орехов; Обогащение — у руд, угля и нерудных |
| «возможно» | Коммерция, Прочее |
| «нет» | Продажи, Финансы, Кадры, Общий номер |

Порядок строк в Excel:
1. ЛПР «да» с ФИО.
2. ЛПР «да» без ФИО.
3. «Возможно».
4. Прочие.
5. Общие.

Внутри группы мобильный и добавочный идут выше городского.

**Почты — как номера**
- Источники — `mailto:` и текст; защита от сборщиков (`[at]`, «собака») снимается (`kc_pochty.py`).
- Своя почта — на домене сайта. Публичная (mail.ru и т. п.) берётся только со своей страницы.
- Чужой домен, веб-студия, noreply, заглушки — в «Снято».

**Правила качества (нарушать нельзя)**
1. **Источник номера или почты** — только живая страница:
   - сайт самой компании;
   - сайт холдинга, с пометкой;
   - карточка закупки, где компания — заказчик.

   checko, rusprofile, СМИ и каталоги годятся только для поиска компаний и ОКВЭД.
2. **Вывод модели или агента** скрипт проверяет по заново скачанной странице.
3. **В «Снято» с причиной:** чужие контакты, горячие линии, дилеры, ведомства, другие заводы группы.
4. **Сайт подтверждён**, если на нём есть ИНН, или модель ответила «та же / группа», или агент привёл цитату. Вдобавок
   опровергатель не должен найти ловушку. Отклонённый сайт в колонку «Сайт» не ставится; «сомневаюсь» — лист
   «Спорные».
5. **В выдаче 0 сделок и 0 запретов панели.** Повторы с файлами Meyer 1–6 (на дропе) отмечаются колонкой.

# Часть Б. Шаги по порядку

Набор в примерах — `meyer7`. Каждый шаг заканчивается проверкой; не прошла — дальше не идти.

### Б1. Окружение и балансы
1. Подтянуть ветку:
   `git fetch origin claude/detailed-study-7j12hg && git checkout claude/detailed-study-7j12hg`.

   - `bash drop_client.sh list` — список файлов;

**Проверка:** на xmlriver ≥ 7 тыс. ₽, у провайдера не меньше суммы из части В.

**Проверка через 15 минут:** строки в `meyer7-serp.jsonl` растут, ошибок меньше 2%.

# Часть Г. Что может пойти не так

| Признак | Что делать |
|---|---|
| xmlriver: «Закончились средства» | Поиск встаёт сам по резерву. Остальные шаги — остановить (`_ostanov_pilot_vse.py`), сообщить владельцу сумму, после пополнения продолжить с того же шага |
| Провайдер: `credit wallet quota insufficient` | Стоп конвейера. Записи без ролей и описаний удалить (`_pilot_pustye.py` → `_pilot_chistka_pustyh.py`), после пополнения продолжить с шага |
| Обрывы связи сервер → шлюз (WinError 10054) | Шаги повторяют вызов сами. Если сбоев больше 5%, гнать вызовы модели из сессии (образец `pilot_bench_lokalno.py`) |
| DaData выбран (10 тыс. в сутки) | Не ждать: `POISK_NE_ZHDAT=1`, компании копятся на «Ждут ОКВЭД», добор — Б9 |
| Агенты идут медленно (6–8 мин на компанию) | 30 потоков (`KC_AGENT_POTOKOV`). Больше 40 не ставить: xmlriver и сайты начинают отказывать |
| Перерасход больше 30% | Сообщить владельцу. Хвост агентов можно отключить: `AGENT_HVOST_MODEL=нет` |
| Контейнер сессии перезапустился | Всё работает на сервере. Состояние брать из `meyer7-konveyer.json` и логов, не из песочницы. Фоновые наблюдатели в сессии перезапустить |
| Чужие сайты в списке (СКРИН, газеты, министерства) | Ловят шаги 7–9. Обход по ним тратит немного времени Luna: это дешевле, чем отдельная проверка до обхода |
| Раннер: предел 30 минут | Всё долгое — только через лаунчеры `_pusk_*` |
