# Ночной автономный прогон — статус (2026-07-23)

Задача владельца (10 пунктов): доделать ВСЁ обогащение, протестировать каждый источник,
обогатить 400 центробежных максимально полно, потом новостные лиды, максимум параллелизма,
интерфейс продажникам, закрыть дельфин-профили, кнопка перегенерации письма, дельфин-прокси.

## 1. Тест каждого источника отдельно (source_selftest) — оп готов и прогнан
Единый оп `enrich_contacts {op:source_selftest}` гоняет 8 источников на реальных компаниях
и отдаёт per-source «даёт ли данные» + hit-rate на панели компаний:

| # | Источник | Итог |
|---|----------|------|
| 1 | xmlriver сайт+карточка | OK (находит сайт) |
| 2 | staff-поиск (ФИО/должности) | OK — 3/4 металлургов дали страницу руководства |
| 3 | ЕГРЮЛ-email (dadata findById) | 0/27 — код исправен (возвращает [] без ошибок), но у **крупного пром-ядра email в ЕГРЮЛ практически не заполнен**; источник полезнее для мелкого хвоста/новостных лидов |
| 4 | ЕИС-закупки (44/223-ФЗ) | OK — контакт закупщика (ФИО+email+тел) |
| 5 | справочники (list-org/2ГИС/zoon) | OK — verified по ИНН, ФИО-emails |
| 6 | SMTP-проба ящиков | OK — smtp_ok / catch-all / smtp_reject различаются |
| 7 | ОПО-сигнал | OK (после фикса, см. ниже) |
| 8 | dadata-резолв (название→ИНН) | OK — Северсталь high-confidence |

Вывод: 7/8 дают реальные данные; ЕГРЮЛ-email честно почти-нулевой на ядре (данных нет, не баг).

## 2. Исправления качества (владелец: «не смотри крутится=работает, приходит пустой/мусор»)
- **ОПО-детектор ложняк**: ловил определение термина «площадка компрессорной станции» из
  ЮР-СПРАВКИ (закон/приказ, sudact.ru/law) и вешал на компанию. Пофикшено: разбор по
  отдельным результатам SERP (границы `<url>`), отсев юр-справочных доменов, приоритет
  авторитетных источников (e-ecolog/gosnadzor/rusprofile) — тип объекта только из
  компанийного результата, не из свода законов.
- **Добор контакта для компаний С САЙТОМ но без email на нём**: раньше доноры ЕГРЮЛ/справочник
  работали ТОЛЬКО в ветке «сайт не найден»; компании с сайтом но пустым краулом бросались
  с «email не найдены». Теперь тот же добор (ЕГРЮЛ→справочник) в основной ветке → полнее.

## 3. Обогащение 400 центробежных (ядро) — прогон
Список: `centrifugal-core-inns.txt` (396 ИНН, отфильтровано по ОКВЭД+выручке). Все источники
включены: xmlriver-сайт → краул → staff → ЕГРЮЛ → ЕИС-закупки → справочник → SMTP → ОПО.

воркерах; справочник покрывает лучше). Резюмируемо (stream `enrich_core2.jsonl`).

- Было (enrich.db baseline): сайт 144, email 113, best 109, verified 86, тел 183.
