# Панель обзвона «Центробежные» — правки владельца

Копии файлов, которые ставятся в боевое приложение `C:\seostat\app`
(оно живёт вне этого репозитория, служба `obzvon`, порт 8012).

| файл здесь | куда ставится |
|---|---|
| `centro.html` | `app/templates/centro.html` |
| `centro_medium.py` | `app/services/centro_medium.py` |
| `centro_catalog.py` | `app/services/centro_catalog.py` |

Ставить: `python pl_run.py postavit_shablon.py <файл-на-дропе> <путь/внутри/app>`
— он делает бэкап, перезапускает службу, ждёт её подъёма и откатывается,
если панель не отвечает.

Проверять: `python pl_run.py proverit_panel.py <пароль> [признак]` — логинится
как продавец и ищет признак в той странице, которую тот реально получит.
Проверка без логина ловит страницу входа и врёт: неверный шаблон за логином
отдаёт такой же 200.
