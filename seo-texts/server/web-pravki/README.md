# Наложения фронта панели (то, что кладёт `sobrat_front.py`)

Живые исходники панели восстановлены из sourcemap в `C:\sender\_tmp\web-src-iz-mapy`;
наши правки лежат поверх в `C:\sender\_tmp\web-pravki`, и сборка накладывает
вторые на первые. Здесь — копия наложений, чтобы они пережили потерю сервера
или откат песочницы: на сервере они лежат в единственном экземпляре.

Порядок работы:
1. правку вносить в `C:\sender\_tmp\web-pravki\...` на сервере;
2. собирать `python C:\sender\server\sobrat_front.py --vylozhit`
   (vite без tsc; кладёт в `C:\sender\web\dist` с бэкапом);
3. свежую копию наложений класть сюда (`_vygruzka_pravok_fronta.py` → дроп).

Файл `Leads.tsx` в корне — устаревший дубль `screens/Leads.tsx`, сборка берёт
тот, что в `screens/`.
