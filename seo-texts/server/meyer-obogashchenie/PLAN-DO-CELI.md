# План до цели: паспорт, контакт с того же сайта и роль — у всех мейеровских

Цель владельца 30.08: «все компании мейера с паспортами и контактами, желательно
с этого же сайта что и паспорт, плюс роль».

## Точка отсчёта — 9,4%

Замер на боевой базе 30.08, а не оценка:

| | компаний | доля |
|---|---|---|
| всего в направлении | 32 646 | 100% |
| есть паспорт сайта | 16 517 | 50,6% |
| есть контакт, снятый с того же домена | 7 081 | 21,7% |
| паспорт **и** контакт с того же домена | 7 055 | 21,6% |
| **паспорт, контакт с того же домена и роль** | **3 079** | **9,4%** |

Девять процентов — это и есть сегодняшнее состояние цели. Дальше считаем эту
метрику после каждого шага: она одна, и она честная.

## Что мешает — по слоям

Разложение важно: слои разной цены, и два самых больших не требуют ни сети, ни
денег.

| слой | компаний | чем закрывается |
|---|---|---|
| A. сайта нет вообще | 13 549 | только платный поиск |
| B. сайт есть, страниц нет | ~4 400 | обход Зенкой |
| C. страницы есть, паспорта нет | ~500 | цикл фактов |
| **D. паспорт есть, контакта с того же домена нет** | **9 462** | **разбор и слив — уже идут** |
| **E. контакт есть, роли нет** | **3 976** | **провайдер по сохранённому контексту** |

Слои D и E вместе — 13 438 компаний, и обе задачи решаются на уже скачанных
страницах. Это и есть ближайшая работа.

## Шаги

### Шаг 1. Дочистить слой D — идёт сейчас, без сети и без денег

* разбор кэша конвейера: осталось 50 903 компании по всей базе, десять
  процессов, примерно пять часов;
* слив находок: 146 894 адреса ждут записи, порциями по восемь тысяч;
* по мейеру ожидается +2 248 компаний с первой почтой с собственного сайта.

Условие: Зенка закрыта, процессор свободен — разбор поднят на максимум.

### Шаг 2. Добор страницы «Контакты» — нужна Зенка

У каждой пятой компании без находок на скачанных страницах есть ссылка на раздел
контактов, который Зенка не взяла: примерно 1 220 компаний, оценка +210 адресов.
Дешевле полного обхода: одна страница на компанию.

### Шаг 3. Слой E — роли и ФИО через провайдера

По мейеру 9 002 адреса без детерминированной роли, и у каждого сохранён контекст
в ±80 символов. Ручной разбор сорока случайных: признак роли или ФИО есть у 35%.

Прогноз: **+1 400–1 800 ролей и +2 000–2 400 ФИО примерно за 350 запросов**.
Сегодня именной контакт есть у 692 мейеровских компаний — это утроение.

Две поправки, без которых прогон испортит данные: пачковать по компании (а не по
адресу) и запретить перенос ФИО соседнего адреса на общий ящик.

### Шаг 4. Телефоны с ролью — сначала правка кода

Сейчас у телефонов роль есть у 3,9% компаний, ФИО — у 0,13%, и причина в коде:
экстрактор отдаёт телефоны голым множеством, без контекста. Нужно, чтобы телефон
нёс ctx так же, как адрес. Тогда тот же провайдерский проход из шага 3 даст роли
и телефонам — по прикидке 9,3 тысячи ролей и 4,6 тысячи ФИО.

### Шаг 5. Паспорта там, где страницы уже есть

Примерно 500 компаний со скачанными страницами без паспорта. Поднять цикл фактов
адресно по ним, а не ждать общей очереди.

### Шаг 6. Обход — когда Зенка снова работает

В очереди 5 874 строки: 4 355 живых целей впереди и 1 519 известно-плохих в
хвосте. Плюс 977 нетронутых кандидатов. Это слой B.

### Шаг 7. Слой A — 13 549 без сайта, ваше решение по деньгам

Все бесплатные каналы проверены и дали ноль: домен из почты — 0 попаданий из 96
проверенных, выгрузка обзвона — 0 доменов, справочники — чужие страницы.

Работает один канал: **второй круг XMLRiver**. Первый дал 38% попаданий. По цене
25 ₽ за тысячу запросов полный круг по 13 549 компаниям стоит около **340 ₽**.

Параллельно — три готовых источника, которые по мейеру не гоняли ни разу:
`checko-реквизиты` (на компрессорном направлении дал 411 компаний с нулевым
пересечением), `сайт:руководство` (КЦ 159, мейер 6), `сайт:обход` (КЦ 134,
мейер 0).

## Куда это приводит

Прогноз честный, с пометкой, что это прогноз:

| после шага | метрика цели | доля |
|---|---|---|
| сегодня | 3 079 | 9,4% |
| шаг 1 (разбор и слив) | ~4 200 | 13% |
| шаг 3 (роли и ФИО) | ~7 000 | 21% |
| шаги 5–6 (паспорта и обход) | ~8 500 | 26% |
| шаг 7 (платный поиск сайтов) | ~11 000–12 500 | 34–38% |

Выше сорока процентов подняться нечем: 13 549 компаний без сайта, из них платный
поиск вернёт хорошо если половину, а часть найденных сайтов окажется мёртвыми,
одностраничными или без единого контакта. Обещать «все 32 646» было бы враньём —
у трети направления в интернете просто нет собственного представительства.

## Порядок и зависимости

1. Шаги 1 и 3 не зависят ни от чего и идут первыми (шаг 1 уже идёт).
2. Шаг 4 — правка кода, потом входит в тот же провайдерский прогон.
3. Шаги 2, 5, 6 ждут запущенной Зенки.
4. Шаг 7 ждёт вашего слова про деньги.
