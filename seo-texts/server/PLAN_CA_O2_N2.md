## 0. Суть на одном экране

- **Кислород Enger** (PSA, 93 ± 3 %, GO1-GO100): растворение O2 в воде и пульпе, горение, питание озонатора.
  Для резки стали и заправки баллонов 93 % не годится (ГОСТ 5583 требует от 99,5 %).

## 2. Конвейер по шагам

**Общие правила.** Каждый долгий шаг - отдельный процесс на сервере (лаунчер по образцу `_pusk_meyer7_zakupki.py`)
с файлом прогресса и флагом остановки. Результат: `C:\sender\server\ca\ca-<шаг>.jsonl` с fsync + enrich.db
(`stage_log`, стадии `ca_*`); резюм только по серверным данным. В enrich.db пишет один процесс. Нагрузка ≤ 90 %.
LLM только через провайдерский API на сервере (`gen_provider`, `pilot_konveyer.МОДЕЛЬ_ШАГА`). Словарь кодов, слов,
порогов и лесенки по сегментам - новый `ca_cel.py` по образцу `kc_cel.py` (вопрос 9).

### Шаг 0. Замер на сервере (только чтение)

- **Скрипт:** новый `ca_zamer.py` (sqlite `mode=ro`, потоковый разбор zip). **Вход:** `revexp.zip`
  (`C:\sender\_ops\ak\fns\`), свежий реестр МСП ФНС, `obzvon-index.db`, enrich.db, checko-файлы.
- **Считает:** ИНН в revexp; в МСП (юрлица отдельно от ИП); не-МСП = revexp минус МСП, выше порогов
  30/50/100/150/300 млн; у скольких не-МСП ОКВЭД уже есть в своих базах; сколько МСП попадает в коды ЦА по основному
  и по дополнительному ОКВЭД.
- **Пробы:** 20-30 запросов к ГИР БО bo.nalog.ru (есть ли ОКВЭД в карточке, только основной или все, пакетность,
  лимит), несколько к статрегистру Росстата, остаток лимита DaData.
- **Выход:** `ca-zamer.json` на дроп = размер дыры по ОКВЭД. **1 день, 0 ₽.**

### Шаг 1. Реестр от налоговой

В МСП нет крупных (выручка > 2 млрд, штат > 250) и нет ЛЮБЫХ дочек с долей холдинга > 49 %: фабрики золотых
холдингов, рыбхозы «Русского моря» и «Инарктики», заводы фармгрупп. Поэтому универсум ИНН = revexp, а МСП - источник
ОКВЭД для своей части.
1. `ca_fns_reestr.py`: разбор МСП (ИНН, регион, ОКВЭД основной и все дополнительные, ССЧ), отбор по `ca_cel`.
2. Не-МСП выше порога: `ca_okved_dobor.py`, цепочка до первого полного ответа с журналом «уже спрашивали»:
   свои базы (`okved_iz_obzvona.py`, enrich.db, checko-файлы) → ГИР БО → статрегистр Росстата → DaData
   (`dadata_client.py`, ~10 тыс./сутки, бесплатно только основной код) → checko (`kc_okved_fns.py`, `cc_checko.py`,
   прокси). Запасной платный путь - «ЕГРЮЛ по подписке» ФНС, первоисточник checko (вопрос 6).
3. Размер: доход revexp, ССЧ `sshr.zip`, налоги `paytax.zip`; ниже порога не удаляем, а помечаем. Ликвидированных
   и гос помечаем по DaData/checko.
- **Выход:** `ca-reestr.jsonl`, `ca-okved.jsonl`, сводка-счётчик по категориям на дроп. **Срок:** код 2 дня, добор
  ОКВЭД 3-5 суток в фоне (при 30-50 тыс. ИНН без кода). **0 ₽.**

### Шаг 2. Сигналы газа (параллельно, только ранжирование)

- **Сразу, 0 ₽:** греп скачанного `fsa-meyer-decl.jsonl` (877 МБ) по МГС; `site_facts.газы` (5 529 паспортов),
  «модифицированная атмосфера» (335), `nash_priznak='кц-газы'` (381).
- **ФСА:** докачка по словарю «МГС / азот / защитная атмосфера» и продуктам категорий: `fsa_meyer_vykachka.py`
  (`FSA_LEGKO=1`, 2 потока). Продавцов газа (E941) метим как поставщиков.
- **Закупки газа** - новый `ca_gaz_zakupki.py`: ЕИС HTML-поиск, все статусы + реестр контрактов за 2-3 года, ОКПД2

- **Реестры** - новый `ca_reestry.py`: Роснедра (рудное/россыпное), ГРЛС + лицензии Минпромторга + GMP, РАР,

### Шаг 3. Сайт каждой компании

1. Свои данные: `enrich.companies.site`, `obzvon.sites`, домен корпоративной почты (обзвон, ФСА).

### Шаг 4. Глубокие контакты (главное отличие от прошлых обходов)

Сейчас `kc_kontakty.обход` берёт 15 страниц и до 40 людей, PDF пропускает. Нужна обёртка `ca_kontakty_glub.py`:
до ~60 страниц и ~200 карточек сотрудников с пагинацией на сайт, потолок времени `KC_LIMIT_MIN`, тот же журнал.

**Страницы сайта:** контакты; руководство, структура, отделы и службы (ОГМ, ОГЭ, производство, снабжение); филиалы и
площадки (у рыбхозов и ЗИФ телефоны часто только там); вакансии («по вопросам - главный инженер», и сам состав
должностей); новости за 2-3 года (ФИО с должностью, запуски линий); закупки на сайте (контактные лица по лотам).

**PDF и документы:** годовые отчёты и раскрытие АО (e-disclosure.ru, органы управления), прайсы и бланки с
добавочными, политика ПДн (ответственный), карточка предприятия, ТЗ с подписью инженера.

**Внешние каналы:**
- ЕИС по ИНН: контактное лицо закупки (`kc_zakupki_dobor.py`, RSS `find_zakupki_contacts`; `find_zakupki_org`
  сломан); порог выручки снизить до порога категории;
- **ТЗ из базы тендерного сервиса** (`C:\tendery\data\tendery.db`, `tender_doc_text`, только чтение): «ответственный /
  по техническим вопросам / главный энергетик» рядом с ФИО и телефоном, по ИНН заказчика;
- филиалы: КПП обособленных подразделений (checko/ЕГРЮЛ) → адреса площадок → их телефоны;

**Как приписываются роли:**

## 3. Ранжирование: формула приоритета

**Балл = Категория + Сигналы (не больше 10) + Размер + ЛПР + База**; при равенстве выше выручка.

| Слагаемое | Значения |
|---|---|
| Категория | ядро +3 (рыбоводство, золото коридор, нарезка, снеки/орехи/кофе, сухое молоко, РГС, лазер с нержавейкой); вторая линия +2 (вино, масло, сыр, готовая еда, фарма, электроника, озон, узел ИЦ); резерв 0 |
| Сигналы газа | закупка газа или аренды баллонов за 2 года +5; стройка/расширение +4; ФСА МГС, паспорт «газы», лицензия «рудное» / GMP / РАР / РМС +3; вакансия +2; Цербер +2; код ЦА только дополнительный -1; минус-слово категории (россыпь, пруд, POX) -4 |
| Размер | в коридоре +2; выше коридора 0 (золото → лист «Узел ИЦ»); ниже порога -2 |
| ЛПР | лучший найденный: ступень 1-2 +4; 3-4 +3; 5 +2; 6 +1; только общий номер 0; нет телефона -2 |
| База | давняя сделка КЦ без покупки +1; сделка только Meyer 0 с пометкой; активная сделка или купивший → «Снято» |

Веса стартовые: после первых 200 прозвонов подстраиваем по ответам.

- **ГИСП (лицензии на ЛС) только браузером**; формат ГРЛС и РАР проверить с сервера.
- **FTP ЕИС закрыт с 2025 г.**: только HTML-поиск, не чаще 1 запроса в 1,5 с.

  кодов крупных останется дырой (checko или подписка ЕГРЮЛ).
- **Продукт:** O2 не заменяет аварийный резерв клиента; азот 8 бар без бустера не подходит лазеру; фарма без
