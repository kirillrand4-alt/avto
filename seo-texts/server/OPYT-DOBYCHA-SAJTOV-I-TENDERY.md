# Два опыта: добыча сайта и контакты с тендерных площадок

Замер 12.08.2026. В код ничего не встроено, в базу ничего не записано — только сбор
доказательств и разбор. Выборки случайные, проверка: жёсткая улика на странице
(ИНН/ОГРН) → мои глаза → провайдер-судья по собранным данным.

---

## Опыт 1. Сайт для 50 компаний, у которых он неизвестен

Взяты компании без `site` и без `cand_site`. Пять независимых каналов на каждую:

1. **Яндекс, топ-10** — xmlriver, запрос «имя регион официальный сайт»
2. **Google, топ-10** — тот же xmlriver, другой движок
3. **Поиск по ИНН** — запрос «ИНН 1234567890 имя»
4. **Домен корпоративной почты из выгрузки базы обзвона** — новый канал, в конвейере его нет
5. **Догадка по транслитерации имени** — `имя.ru` и `имя.рф`

Каждый найденный домен открывался, и на странице искались ИНН, ОГРН и имя компании.

### Что вышло

| исход | компаний |
|---|---|
| жёсткая улика (ИНН или ОГРН на странице) | **3** |
| имя компании на странице, улики нет | 23 |
| кандидаты открылись, ничего не подтверждают | 24 |
| ничего не нашли | 0 |

**Жёсткая улика — редкость: 6%.** Малые ООО не публикуют реквизиты на сайте, и
требовать ИНН как условие означает отбросить почти всё.

Провайдер-судья по собранным данным (заголовок, кусок страницы, регион) назвал сайт
у **27 из 50**: высокая уверенность у 17, средняя у 9, низкая у 1. Каким каналом
найден тот домен, который судья выбрал:

| канал | побед |
|---|---|
| Яндекс топ-10 | 16 |
| Google топ-10 | 6 |
| **домен почты из выгрузки** | **4** |
| догадка по имени | 1 |

### Что я вижу глазами

Убедительные: `fakel02.ru` для ООО предприятие «Факел» (02 — код Башкирии),
`вистек.рус` для ПК-Вистек (плюс ИНН на странице), `ctm-medicina.ru`,
`itle-kitchen.ru`, `teploiglino.ru`, `crbpechora.gosuslugi.ru` для Печорской ЦРБ,
`rosoil.ru` для АО «ХТЦ УАИ» — последний найден **доменом почты**, и страница прямо
называет технопарк «ХТЦ УАИ-РОСОЙЛ».

Сомнительные, которые судья отдал с высокой уверенностью: `domino-gurman.ru` для
ООО «ДОМИНО» — это кафе, а чем занимается наше ООО, из данных не видно; `okvk-rb.ru`
для ООО «ВОДОКАНАЛ» — название слишком частое; `dveribunker.ru` для ООО «БУНКЕР».

Отдельный дефект: в кандидаты пролез `innproverka.ru` — сервис проверки контрагентов.
Значит `_is_own_site` не отсекает часть справочников.

### Главная находка опыта

**Домен корпоративной почты из выгрузки — канал, которого у нас нет, и он почти
бесплатный.** Ни одного запроса к поиску, ни одной страницы качать не надо: домен
уже лежит в поле `emails_base`/`emails_site` базы обзвона.

По всей базе: из 161 799 строк корпоративный домен почты (не mail.ru/yandex.ru) есть
у **30 649**. Только бесплатная почта — у 77 070. Из наших 6734 компаний без сайта
домен почты есть у **1530** — это 23% дыры, закрываемые одним SQL-запросом без
единого обращения к сети.

## Опыт 2. Контакты с тендерных площадок для 50 компаний без почт

Каналы: карточка организации в ЕИС (`find_zakupki_org`) и поиск карточек поставщика
на восьми площадках (zakupki.gov.ru, rts-tender, b2b-center, roseltorg, etpgpb,
tender.pro, sberbank-ast, fabrikant) через выдачу.

### Результат — ноль из пятидесяти

Ни одной пригодной почты. Это не «плохо искали», а две конкретные поломки.

**Поломка 1. `find_zakupki_org` не находит карточку вообще ни у кого.** Проверил на
заведомых заказчиках 44-ФЗ — ГБУЗ РК «Печорская ЦРБ», ГУП «Водоканал СПб», КАО «Азот»,
ООО «Водоканал»: у всех четырёх пустой результат и пустая ошибка. Страница поиска ЕИС
при этом отдаётся целиком, 168 КБ, но ссылки `/epz/organization/view/info` в ней нет.
То есть разметка реестра изменилась или выдача подгружается скриптом — регулярка,
которой мы её вытаскивали, больше не совпадает. Функция молча возвращает пусто, и все
прогоны, которые на неё опирались, давно берут ноль, не сообщая об этом.

**Поломка 2. Поиск по площадкам не даёт карточек поставщика.** Запрос вида
«имя ИНН поставщик контакты» на 50 компаний вернул **одну** страницу площадки. Разбор
выдачи объясняет почему: по ИНН поисковик отдаёт исключительно справочники —
rusprofile, checko, focus.kontur, list-org, audit-it, companium, sravni. Карточек
площадок в органике нет.

Зато нашёлся рабочий приём: **`site:b2b-center.ru <ИНН>` возвращает карточку сразу**
(`b2b-center.ru/firms/ooo-sk-geografiia/765520/`). То есть искать надо не общим
запросом, а по каждой площадке отдельно с ограничением по домену — ровно так же, как
мы уже делаем `site:домен` при добыче реквизитов.

---

## Что из этого стоит делать (не сделано, решение за владельцем)

1. **Домен почты из выгрузки как первый канал добычи сайта.** Бесплатно, закрывает
   1530 компаний без сайта. Проверять по-прежнему обязательно: домен почты бывает у
   хостинга или у головной конторы.
2. **Чинить `find_zakupki_org`** — сейчас он тихо возвращает ноль для всех, включая
   тех, кто в реестре точно есть.
3. **Поиск по площадкам вести запросами `site:<площадка> <ИНН>`**, а не общим
   запросом: на пробе это единственный способ, который карточку находит.
4. **Дополнить отсев справочников** — `innproverka.ru` прошёл как кандидат в сайты.
5. **Не требовать ИНН на странице как условие принятия сайта**: жёсткая улика есть
   лишь у 6%, порог отбросил бы почти всё найденное.
