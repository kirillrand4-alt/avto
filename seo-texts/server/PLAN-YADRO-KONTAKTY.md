## 3. Главный вопрос — какие сайты обходить (ИНН → сайт)

Источник истины нет; правило подтверждения одно: на страницах сайта есть ИНН/ОГРН компании или совпали название + регион + телефон.
По стоимости:
1. домен корпоративной почты из наших баз (ivanov@zavod.ru → zavod.ru) — бесплатно;
2. сайты из баз и журналов (обзвон, enrich, подтверждённые обходом) — бесплатно;
3. checko / справочники / Я.Карты / 2ГИС — поле «сайт», проверять;
4. **обратный индекс по доменной зоне**: список доменов .ru/.рф/.su (~6 млн, живых 2–3 млн; список покупается — решение владельца),
   главная + «контакты»/«реквизиты» → ИНН/ОГРН на странице своего домена → индекс ИНН → сайт (+ телефоны и почты сразу);
   ~8–10 млн простых запросов без браузера и модели — несколько дней на 1–2 российских VPS;
5. xmlriver по названию + региону — только для ядра без сайта (~0,025 ₽ за запрос), с проверкой ИНН/названия на странице.
Опыт ca: сайт нашёлся у ~70 % (6,8 из 9,9 тыс.), у мелких — меньше.

## 4. VPS

Весь интернет — не нужно. Под уровни 0–1 и обратный индекс зоны — 1–2 российских VPS (4–8 ядер, 1,5–3 тыс. ₽/мес каждый):
сервер уже на 80–100 % при 3 процессах обхода (предел 90 %), панель рассыльщика не должна страдать; VPS только качают и снимают
номера/почты/ИНН, модель, агенты и журнал — на основном сервере (durability как сейчас). Риск: IP датацентров режут часть сайтов.
Для уровней 2–4 VPS не нужен (упор в модели и поиск).

## 5. Порядок

1. Покрытие по уровням из того, что уже есть (ЛПР по базам — ~51 тыс. компаний; сколько обойдено в каждом уровне).
2. Бесплатные источники сайтов (почты, базы).
3. Уровни 4 → 3 → 2 на текущем сервере.
4. Решение по VPS и обратному индексу зоны — перед уровнями 1–0.
