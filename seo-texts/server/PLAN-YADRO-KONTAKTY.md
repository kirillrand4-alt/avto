## 3. Главный вопрос — какие сайты обходить (ИНН → сайт)

Источник истины нет; правило подтверждения одно: на страницах сайта есть ИНН/ОГРН компании или совпали название + регион + телефон.
По стоимости:
1. домен корпоративной почты из наших баз (ivanov@zavod.ru → zavod.ru) — бесплатно;
2. сайты из журналов обхода (подтверждённые) — бесплатно; базы обзвона/enrich — только для поиска сайта, сами компании
   и контакты оттуда — исключение (уже отработаны);
3. checko / справочники / Я.Карты / 2ГИС — поле «сайт», проверять;
4. **обратный индекс по доменной зоне**: список доменов .ru/.рф/.su (~6 млн, живых 2–3 млн; список покупается — решение владельца),
   главная + «контакты»/«реквизиты» → ИНН/ОГРН на странице своего домена → индекс ИНН → сайт (+ телефоны и почты сразу);
   ~8–10 млн простых запросов без браузера и модели — несколько дней на 1–2 российских VPS;
5. xmlriver по названию + региону — только для ядра без сайта (~0,025 ₽ за запрос), с проверкой ИНН/названия на странице.
Опыт ca: сайт нашёлся у ~70 % (6,8 из 9,9 тыс.), у мелких — меньше.

## 4. VPS

Весь интернет — не нужно. Под уровни 0–1 и обратный индекс зоны — 1–2 российских VPS (4–8 ядер, 1,5–3 тыс. ₽/мес каждый):
сервер уже на 80–100 % при 3 процессах обхода (предел 90 %), панель рассыльщика не должна страдать; VPS только качают и снимают
номера/почты/ИНН, модель, агенты и журнал — на основном сервере (durability как сейчас). Риск: IP датацентров режут часть сайтов.
Для уровней 2–4 VPS не нужен (упор в модели и поиск).

## 7. Контакты для всех, включая хвост (уровень 0, ИП, компании без сайта)

Хвост — сотни тысяч компаний, у большинства сайта нет. Поэтому здесь только массовые и дешёвые источники, без агентов и почти
без модели; цель — хоть один рабочий контакт компании (общий телефон/почта), ЛПР — где повезёт.

**Источники, по порядку (дешевле → дороже):**
1. **Наши базы — только как исключение, не как источник** (владелец 16.11: «их уже отработали — прозвонили или написали письма»):
   база обзвона, enrich.db/панель, MEYER-PISALI и т. п. — компании/контакты оттуда помечаются «уже отработаны» и в новый
   поиск/выдачу как новые не идут. Сайты, найденные раньше обходом (журналы наборов), — можно использовать для поиска сайта.
2. Почта из ЕГРЮЛ (юрзначимая, через dadata — уже в enrich_contacts, источник egrul:dadata); с 2025 поле обязательное,
   покрытие высокое. Это общий ящик, не ЛПР, но рабочий.
3. Обратный индекс зоны (раздел 3): кто имеет сайт — получает и сайт, и телефоны/почты со страниц «контакты/реквизиты».
4. Карточки организаций: Яндекс.Карты / 2ГИС — телефон и сайт (через поиск xmlriver или карты; проверка по адресу/названию).
5. Закупки: ЕИС и коммерческие площадки — контактное лицо заказчика/поставщика с телефоном и почтой (часто снабжение = ЛПР).
   Площадки ведёт другая сессия — согласовать.
6. Для ИП и мелкой пищевки без сайта: декларации и сертификаты ФСА (заявитель — почта/телефон; владелец ранее этот источник
   для сборщика не выбрал — только по отдельному «да»), группы ВК/Telegram (токены ВК есть), справочники — как улика.
7. Вакансии — НЕ используем (решение владельца 11.11).

**Проверка, чтобы хвост не засорил базу:**
* дубли — по ИНН + 10 цифр номера + доб. + почта; источники склеиваются;
* номер/почта «подтверждён», если найден на сайте компании или в карточке с её ИНН; остальное — с пометкой источника и надёжности
  (как с базой обзвона: домен почты = сайт → хорошо; бесплатный ящик → средне; чужой корп. домен → низко);
* проба почт (без отправки) — только по «да» владельца (холд рассылок, CLAUDE.md);
* в «заливку» — только надёжные; остальное — в полной базе с пометкой.

**Сколько стоит и сколько ждать:** источники 1–2 — бесплатно, часы; 3 — VPS и список доменов, несколько дней на всю зону;
4–5 — копейки за запрос, но медленно (каналы xmlriver), разумно только для уровней 1–2 и пищевки Meyer; 6 — по решению.
Ожидание по хвосту: общий контакт у большинства (ЕГРЮЛ-почта почти у всех ЮЛ), ЛПР — у малой доли.
