# Фильтры поиска тендеров: что добавить к текущему списку

Текущий список закрывает слово «компрессор» во всех написаниях, азот, осушители,
ресиверы, фотосепараторы и оптическую сортировку. Ниже — то, чего в нём нет.
Лексика взята не из головы: посчитана по полям `оборудование_линии`, `газы` и
`энергохозяйство` в наших паспортах сайтов и по текстам новостных закупок.

## 1. Бренды — самая большая дыра

В списке есть только `ATLAS`. А дорогая закупка почти всегда названа брендом и
моделью: «Поставка ЗИП БКК компрессора Atlas Copco G45, воздушной осушки
Atlas Copco BD100» — это реальный предмет закупки из нашей базы.

Встречаются в наших же паспортах (число — сколько раз):

```
Kaeser*          Ingersoll*        Ceccato*        ABAC*
Boge* (4)        Sullair* (3)      Dalgakiran* (2) Gardner Denver* (1)
Howden* (1)      Mycom* (1)        Bitzer* (11)
Berg* (32)       Enger* (5)        Comaro*         Almig*
Fini*            Chicago Pneumatic*                Remeza* / Ремеза*
ЧКЗ              Чебоксарск* компрессорн*
```

По мейеровскому направлению: `Bühler*` / `Buhler*` (15), `Satake*` (1),
`Tomra*` (2), `Sortex*` (2), `Ishida*` (2), `Mettler*` (3), `Sesotec*`,
`Anzai*`, `Newtec*`.

## 2. Синонимы, в которых слова «компрессор» нет вовсе

Владелец 15.09: **воздуходувки не нужны**, поэтому семейство воздуходувок и
нагнетателей ушло в раздел «Кроме», а не в поиск. Остаётся то, что относится к
компрессорам и газовым станциям:

```
дожимн*            (20)      ДКС                ВКС
бустер*            (3)       безмасл*    (6)    винтов* блок*
станц* сжат* воздух*         систем* сжат* воздух*
```

Газовые станции стоят дороже самих компрессоров:

```
азотн* станц*      азотн* установк*     генератор* азота (есть)
кислородн* станц*  (188!)               кислородн* установк*
ПСА                мембранн* установк*
адсорбцион* осушител* (23)              рефрижератор* осушител* (60)
```

## 3. Услуги и ремонт — там повторяющиеся деньги

В списке только `монтаж компрес*`. Добавить:

```
техническ* обслуживан* компрессор*     сервисн* обслуживан* компрессор*
капитальн* ремонт компрессор*          ремонт винтов* блок*
ревизи* компрессор*                    диагностик* компрессорн*
пусконаладк* компрессор*               шеф-монтаж компрессор*
реконструкц* компрессорн*              модернизац* компрессорн*
```

Плюс промбезопасность — сосуды под давлением и есть компрессорное хозяйство:

```
экспертиз* промышленн* безопасност* сосуд*
освидетельствован* сосуд* давлен*
ЭПБ компрессор*
```

## 5. Признаки того, что закупка ДОРОГАЯ

Если нужен отбор именно крупных, эти слова в предмете почти всегда означают
проект, а не расходник:

```
под ключ            поставк* и монтаж        комплекс* поставк*
реконструкц*        техническ* перевооружен*  строительств* компрессорн*
модернизац*         проектирован* и поставк*
```

## 6. ОКПД2 — то, что ловит закупки БЕЗ ключевых слов

Самое надёжное, если площадка умеет фильтровать по коду. Слова в названии
бывают какими угодно, код — нет:

```
28.13.2   — насосы и компрессоры прочие
28.13.28  — компрессоры воздушные передвижные
28.13.31  — части компрессоров (то есть ЗИП)
28.25.13  — оборудование холодильное и вентиляционное
33.12.19  — ремонт и ТО прочего оборудования общего назначения
33.12.29  — ремонт и ТО прочих машин специального назначения
```

## 7. Раздел «Кроме» — что отсечь, чтобы не тонуть в мусоре

```
компрессор автомобильн*      компрессор кондиционер*
компрессор холодильник*      компрессор для шин
компрессор ингалятор*        компрессор стоматологическ*
компрессорн* чулк*           компрессионн* (бельё, трикотаж)
воздуходув*                  газодув*
нагнетател*                  турбовоздуходув*
Aerzen*
```

Ловушка с трикотажем не выдумана: маска `компресс*` из текущего списка прекрасно
совпадает с «компрессионным трикотажем» и «компрессионными чулками», а их в
закупках больниц много. Воздуходувки и нагнетатели здесь по решению владельца
15.09 — не наш профиль; `Aerzen*` тоже, это производитель именно воздуходувок.

## Что это даст

Оценка, а не замер: бренды и синонимы без слова «компрессор» — это тот пласт,
который текущая маска не видит в принципе, а услуги и ЗИП дают повторяющиеся
закупки у тех же предприятий, то есть готовый список действующего парка.
