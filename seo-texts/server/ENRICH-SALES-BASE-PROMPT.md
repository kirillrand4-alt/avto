## ГЛАВНОЕ: штатный конвейер, как его правильно вызвать

Файл `enrich_contacts.py`, функция `main()`. **Аргументы читаются из STDIN**
(`json.load(sys.stdin)`), НЕ из argv — на этом легко споткнуться. Поэтому
скрипт-обёртка на сервере должен подменять stdin:

```python
import io, json, sys
sys.path.insert(0, r'C:\sender\server')
import enrich_contacts as EC
args = {...}
sys.stdin = io.StringIO(json.dumps(args, ensure_ascii=False))
EC.main()
```

Ключевые аргументы (все проверены по коду `main()`, строки ~6476-6700):

| Аргумент | Значение |
|---|---|
| `companies` | список `{inn, name, city, site}` — **без `name` компания молча пропускается** |
| `workers` | параллелизм между компаниями (кап 80) |
| `browser_workers` | сколько одновременных браузерных сессий (кап 30) — см. предупреждение о Дельфине |
| `zakupki_check: true` | включает контакт закупщика из ЕИС внутри конвейера |
| `hh_check: true` | ищет компрессорные вакансии компании (сигнал «оборудование есть») |
| `opo_check: true` | эвристика ОПО Ростехнадзора |
| `extract_model` | модель для `extract_roles`; для массового вала `claude-haiku-4-5` |
| `resume: true` | пропускать уже сделанные ИНН из `stream_file` |
| `stream_file` | путь потока для резюмируемости |
| `write_db: true` | писать в `enrich.db` сразу по готовности компании |
| `pace_min` / `pace_max`, `fetch_timeout` | темп и таймаут запросов |

Что конвейер делает сам (не нужно писать заново):
- `crawl_contacts()` — обход сайта: **staff-страницы приоритетом**
  (`сотрудники / команда / руководство / персонал / staff / kollektiv`), затем
  закупки/снабжение/поставщикам, затем остальное; знает кириллические слаги и
  типовые Bitrix-пути `/company/staff/`; при необходимости JS-рендер.
  **Возвращает КОРТЕЖ** `(текст, страницы, None, источники)`, где
  `источники['emails'][адрес]['url']` — страница, на которой email найден
  впервые (это и есть провенанс для кликабельной ссылки).
- `extract_roles(text, company)` — **провайдер** извлекает email с ролями
  (директор / снабжение-закупки / гл.инженер / продажи / бухгалтерия /
  приёмная / общий), ФИО, телефоны с метками отделов и добавочными,
  `activity` (чем занимается), `is_compressor_maker` (наш конкурент?) и
  `owner_match` (сайт вообще этой компании?). Фолбэк — regex.
  **owner_match=false → контакты брать НЕЛЬЗЯ**, это чужая фирма.
- `find_zakupki_contacts(inn)` — ЕИС: RSS-поиск извещений по ИНН заказчика →
  карточка закупки → блок «Контактная информация» (ФИО + телефон + email
  снабженца) + URL карточки.

## Осторожно: реальные грабли этой задачи

1. **Дельфин.** Владелец поймал, что один и тот же профиль запускался много
   раз. Перед прогоном ограничивать `browser_workers` (2-4), проверять
   `dolphin_proxy_check`, по окончании — `dolphin_stop_all`. VK-профиль
   `829115401` закреплён по IP, его не трогать.
2. **Таймаут 560 с на процесс.** Гнать порциями (`resume: true` +
   `stream_file`), а не одним куском.
3. **Дубликаты телефонов и мусор.** Регулярка на «телефон» цепляет ОГРН, счета
   и заглушки (`+7 (000) 000-00-00`). Валидатор: нормализовать к 10 цифрам
   (снять ведущую 7/8), отбросить `код 000`, `все цифры одинаковые`, и
   выводить единым форматом `+7 (XXX) XXX-XX-XX`. Дедуп — по 10 цифрам.
4. **checko.ru**: прямой `https://checko.ru/company/<ИНН>` даёт 404 (там слаг
   `имя-огрн`); рабочий путь — `https://checko.ru/search?query=<ИНН>` (сам
   редиректит на карточку) и затем `<карточка>/contacts` — там блок
   «Контактная информация» со всеми телефонами и почтами.
5. **Площадки закупок.** Проверено 27.07: ЕИС (zakupki.gov.ru) работает и даёт
   именные контакты; **tektorg** отдаёт процедуры только после JS-рендера, на
   карточке процедуры есть почта закупщика (телефоны там — служебные номера
   площадки, шум); **etpgpb.ru** через прокси-пул не открывается вовсе
   (ConnectionError — режет IP); **tender.pro** за стеной логина.
6. Провайдерский шлюз: модели `claude-fable-5` и `claude-opus-5` периодически
   принимают запрос, но отдают только ping-кадры. В `gen_provider.py` уже
   стоят часы на стрим и автоподмена через `PROVIDER_DEAD_MODELS` /
   `PROVIDER_MODEL` (сейчас список пуст). Если генерации виснут — проверить
   это первым делом.
