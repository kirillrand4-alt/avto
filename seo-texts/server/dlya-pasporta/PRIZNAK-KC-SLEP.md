# Признак КЦ в паспорте сайта промахивается на четырёх компаниях из пяти

Справка для сессии, которая строит паспорта сайтов (`enrich.db/site_facts`).
Написана 19.08.2026 сессией рассыльщика. Всё ниже — замеры по боевой базе, не
предположения; команды для перепроверки приложены.

---

## 1. Что не так

В паспорте есть блок `разбор_КЦ`:

```json
"разбор_КЦ": {
  "воздух_точно": [],
  "газы_технические": [],
  "энергообъекты_без_воздуха": [],
  "признак_КЦ": false
}
```

Замер по всей базе:

| | компаний | доля |
|---|---|---|
| паспортов с блоком `разбор_КЦ` | 12 519 | — |
| `признак_КЦ = true` | **2 651** | **21.2%** |
| `признак_КЦ = false` | 9 868 | 78.8% |
| есть хоть одна улика `воздух_точно` | 2 384 | 19.0% |
| есть `газы_технические` | 635 | 5.1% |

Проверить: `ops/naskolko_slep_priznak_kc.py`.

Признак стоит у каждой пятой компании. Это не значит, что покупателей мало.
Компрессор для завода — **инструмент, а не товар**, и на сайте про него не
пишут: там пишут, что компания делает и продаёт. Детектор ищет следы воздуха,
а следов нет не потому, что воздуха нет.

---

## 2. Живой пример промаха

**ООО СК «Дорожник-2»**, ИНН 2263030778, сайт dorogi22.ru. Паспорт снят
корректно и подробно:

```json
"продукция": ["асфальтобетон"],
"цитата": "Собственное производство асфальтобетона.",
"оборудование_линии": ["Собственный парк спецтехники", "Собственная автотехника"],
"контроль_качества": ["международного ISO 9001"],
"год_основания": "2002",
"уверенность": "высокая",
"разбор_КЦ": {"воздух_точно": [], "газы_технические": [], "признак_КЦ": false}
```

А в тексте их сайта (6 056 знаков, снят и лежит в базе) прямым текстом:

> «Ямочный ремонт асфальта. Устранение ям, сколов, трещин…
> обрабатываем основание и края карт **битумной эмульсией**; укладываем
> асфальтобетонную смесь; выполняем уплотнение»

> «Собственный **парк спецтехники**»

Почему это КЦ, без всяких «может быть»:

1. **Ямочный ремонт.** Карту перед битумной эмульсией **продувают сжатым
   воздухом** — иначе эмульсия не сцепится с основанием. Это обязательная
   операция дорожной технологии, а не опция. Компрессор там нужен физически.
2. **Асфальтобетонный завод.** Пневматика на дозаторах, обдув рукавных
   фильтров, продувка битумопроводов.
3. **Собственный парк спецтехники** — значит своя ремонтная база:
   пневмоинструмент, подкачка колёс, продувка узлов, покрасочный пост.

Ни одно из этих слов на сайте не написано, и `признак_КЦ` встал в `false`.

Проверить: `ops/sayt_dorozhnika.py 2263030778`.

## 3. Детектор не тупой — у него неполный список выводов

Он умеет выводить воздух из операций, а не только ловить слово «компрессор».
Пример сработавшего вывода из той же базы:

```json
"воздух_точно": ["Покраска мебели", "Покраска пвх окон, дверей, конструкций"],
"признак_КЦ": true
```

Покраска → краскопульт → компрессор. Вывод правильный. Значит чинить надо не
подход, а **список операций, из которых следует воздух**.

---

## 4. Что предлагаем добавить в список выводов

Каждая строка ниже — операция, которая физически не идёт без сжатого воздуха
или технических газов. Слева то, что реально встречается в текстах сайтов.

**Дорожные и строительные работы**

| что написано на сайте | почему воздух |
|---|---|
| ямочный ремонт, карты, ремонт дорожного покрытия | продувка карты перед битумом |
| асфальтобетон, АБЗ, битумная эмульсия | пневматика дозаторов, обдув фильтров |
| дорожная разметка | нанесение краски безвоздушкой/краскопультом |
| бурение, сваи, шпунт | пневмомолот, продувка скважины |
| снос, демонтаж | отбойный молоток |
| торкретирование, набрызг-бетон | подача смеси воздухом |

**Металл и машиностроение**

| что написано | почему воздух |
|---|---|
| плазменная резка, лазерная резка | плазмообразующий газ, поддув, обдув реза |
| дробеструйная, пескоструйная обработка | это чистый пневмопроцесс |
| порошковая окраска, окрасочная камера | распыление и сушка |
| сборка на пневмоинструменте, гайковёрты | прямо |
| термообработка, азотирование | азот |
| гальваника, анодирование | перемешивание барботажем |

**Пищевое и упаковка** (эти важны и для второго направления)

| что написано | почему воздух |
|---|---|
| фасовка, упаковка, розлив | пневмоприводы автоматов |
| пневмотранспорт муки, зерна, гранулы | прямо |
| выдув ПЭТ | бустер высокого давления |
| газовая среда, МГС, вакуумная упаковка | азот, углекислота |

**Прочее**

| что написано | почему воздух |
|---|---|
| очистные сооружения, аэрация | воздуходувки |
| водоканал, КНС | аэрация, продувка |
| автосервис, шиномонтаж, покрасочный пост | пневмоинструмент, краскопульт |
| деревообработка, покраска мебели | уже ловится, оставить |
| парк спецтехники, своя ремонтная база | пневмоинструмент на обслуживании |

**Отрицательный список тоже нужен.** «Энергообъекты без воздуха» в блоке уже
есть — стоит дополнить: чистый офис, консалтинг, IT, финансы, страхование,
аренда помещений, торговля со склада без своих операций, медицина.

## 5. Как этим пользоваться, пока не починено

Важный вывод для всех, кто читает `признак_КЦ`:

* **как «ДА» — годится.** Те 2 651, у кого он стоит, почти гарантированные
  покупатели: улики нашлись на их же сайте. Их стоит поднимать в приоритет
  отбора;
* **как «НЕТ» — не годится.** Отсев по `признак_КЦ = false` выбросил бы
  четыре пятых законных адресатов, включая всю дорожную технику и весь
  металлопередел, который не хвалится оборудованием.

Мы у себя на него не опираемся: классификатор направления (см. ниже) читает
`цитата`, `продукция`, `оборудование_линии`, `сырьё` — то есть чем компания
занимается, — и делает вывод сам.

---

## 6. Что просим

1. Расширить список операций, из которых выводится воздух (раздел 4).
2. Пересчитать `разбор_КЦ` на существующих 12 519 паспортах — текст сайта уже
   снят и лежит, заново ходить в интернет не нужно.
3. Держать `признак_КЦ` честным: если улик нет, но операции указывают на
   воздух — это должно быть видно отдельным полем (например
   `воздух_вероятно`), чтобы «нет улик» не путалось с «воздуха нет».

Замеры и разборы, на которые ссылается справка:
`ops/naskolko_slep_priznak_kc.py`, `ops/sayt_dorozhnika.py`,
`ops/kto_stroit_pasport.py`, `ops/chto_v_pasporte.py`.
