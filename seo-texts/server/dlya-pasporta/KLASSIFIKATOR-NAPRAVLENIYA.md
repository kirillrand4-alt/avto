# Дешёвый классификатор направления по паспорту сайта

Справка 19.08.2026, сессия рассыльщика. Мысль владельца: «может сначала
дешёвым прогоном на самой дешёвой моделькой паспорт сайта прогнать на
направление кц/мейер?». Проверили — работает, и разница в цене не в
проценты, а в порядки.

---

## 1. Зачем он понадобился

Разбор 20 последних мейеровских отказов (`ops/razobrat_otkazy_meyera.py`):

```
 11  инженерная линза: не наш профиль
  9  прочее
```

Все 11 отказов **верные**: металлоконструкции, кабельная продукция, лифты,
дороги, вывоз отходов, сэндвич-панели, изготовление оснастки. Ни одному из
них не нужен ни фотосепаратор, ни рентген-инспекция.

Беда в том, ГДЕ мы это узнали. Цепочка была такая:

```
кандидат -> [дорогая линза покупателя, opus] -> письмо (opus, best-of-2)
         -> судья -> верификатор -> линза профиля -> ОТКАЗ
```

То есть за компанию, которая не пищевая по своей природе, мы платили полный
круг генерации. На мейеровской партии из 23 попыток это съело **$20.57, из
них примерно половина — на заведомо чужих компаниях**.

---

## 2. Что сделали

Поставили перед дорогим гейтом дешёвый отсев по паспорту сайта:

```
кандидат -> [ПРЕДКЛАССИФИКАТОР, gpt-5.6-luna, пачками по 25]
         -> [дорогая линза] -> письмо -> проверки
```

Классификатор получает не сырой сайт, а выжимку паспорта — те поля, что
говорят о деле:

```
цитата, продукция, оборудование_линии, сырьё, масштаб, мощности
```

и отвечает одним словом на компанию: `кц` | `мейер` | `оба` | `никуда`.

Код: `ops/partiya_gen.py`, функции `_паспорт_кратко()` и `_predklass()`;
отдельный проверочный прогон — `ops/deshyovyy_klassifikator_napravleniya.py`.

## 3. Цена

| | модель | цена вызова | на компанию |
|---|---|---|---|
| дорогая линза покупателя | `claude-opus-4-8` | ~$0.03 | ~$0.03 |
| **предклассификатор** | **`gpt-5.6-luna`** | **$0.00148 за 18 компаний** | **$0.00008** |
| несостоявшееся письмо | opus, полный круг | — | **$0.90** |

Отсев одной компании дешевле несостоявшегося письма **более чем в десять
тысяч раз**. Даже против одной только линзы — в 375 раз.

Работает пачками: 18 компаний ушли **одним вызовом** (вход 7 452 токена,
выход 987, 21 секунда). В генераторе шаг пачки 25.

Ставка `gpt-5.6-luna` на шлюзе: $0.11 за миллион входа, $0.67 за выход —
это самая дешёвая модель из 25 доступных. Для сравнения, opus стоит $5/$25,
то есть в 45 раз дороже по входу и в 37 по выходу.

## 4. Точность

Проверяли на 18 компаниях с **известным дорогим исходом** — 10 снятых
инженерной линзой и 8 с вышедшим письмом:

```
сошлось   15 из 18
разошлось  3
```

Главное число: **все 8 компаний, которые потом сняла дорогая линза, дешёвая
модель отсеяла заранее.** Ни одной не пропустила.

Три расхождения — случаи, где классификатор скорее прав, а письмо не стоило
писать:

| компания | дешёвый вердикт | что было | кто прав |
|---|---|---|---|
| СК «Дорожник-2» | `кц` | ушло мейеровское письмо | классификатор: асфальтобетон не пищевка |
| «Кристально-чистая вода» | `никуда` | ушло мейеровское | классификатор: напитки владелец из мейера исключил |
| «ИЛАЛ» | `никуда` | ушло мейеровское | классификатор: «реализация мяса без своего производства» — торговля |

## 5. Граница по мясу — на ней classifier чуть не потерял целый сегмент

Первая версия промпта перечисляла мейеровское как «пищевой поток: зерно,
крупы, мука, орехи, ягоды…» — и мяса с рыбой там не было. Мясопереработка
уехала бы в отсев целиком.

Владелец поправил: «рентген точно можно, сортировки нет». Это ровно то, что
записано и в каноне писем: филе, фарш и котлеты оптикой не сортируют, а
рентген готовой упаковки им нужен.

Теперь промпт знает про ДВА станка:

* **фотосепаратор** — только сыпучий поток: зерно, крупы, мука, семена,
  орехи, сухофрукты, ягоды, бобовые, овощи на переработку, комбикорм,
  замороженные ягоды и овощи;
* **рентген-инспекция** готовой упаковки — шире, и сюда входят **мясо и
  рыба**: колбасы, полуфабрикаты, фарш, филе, пресервы; плюс кондитерка,
  снеки, молочка, готовая еда.

Компания идёт в мейер, если подходит **хоть один** станок.

Проверка границы (`ops/proba_myaso_v_klassifikatore.py`), 5 из 5:

```
Мясокомбинат              -> оба     (ждали мейер)   ок
Рыбозавод                 -> оба     (ждали мейер)   ок
Мясная лавка со склада    -> никуда  (ждали не мейер) ок
Мельница                  -> оба     (ждали мейер)   ок
Завод металлоконструкций  -> кц      (ждали не мейер) ок
```

## 6. Осторожности, которые стоит перенять

1. **Нет паспорта — не режем.** Компания без выжимки в классификатор не
   уходит и остаётся кандидатом: судить не по чему.
2. **Сбой классификатора не режет пачку.** Упал вызов или не разобрался
   JSON — пачка идёт дальше как есть. Дешёвый отсев не имеет права стоить
   партии.
3. **Считаем отсев в журнале прогона** отдельной строкой
   («предклассификатор: другое направление»), чтобы молчаливое сокращение
   партии не выглядело как «кандидаты кончились».
4. **`признак_КЦ` из паспорта не используем** — он стоит лишь у 21%
   компаний и как «нет» негоден (см. `PRIZNAK-KC-SLEP.md`). Классификатор
   судит по описанию деятельности, а не по этому флагу.
