## 1. **Tender.pro: должности в свободном тексте**

**Где:** документ «для владельца», «передача сессии», «инвентарь данных»

**Что не так:** В параллельной сессии стоит «должность на тендерных площадках — шесть из шести не печатают». В нашей сессии достали два примера должностей из свободного текста комментария Tender.pro: «начальник ОМТС» и «заместитель главного механика». Сведённое утверждение дало ложный запрет.

**Как надо:** Уточнить в параллельной сессии: речь про структурное поле (там пусто) или про свободный текст (там есть). Если не разведено — исправить формулировку. Проверить, отражено ли это в таблице источников (73 человека из Tender.pro — это только снабженцы из поля, или включены технари из комментариев).

```python
    summary['warnings'].append(f"⚠ {collector_name} отключён (дроп недоступен)")
```

## 5. Невозможно проверить критическое утверждение (блокирует доверие к данным)

### 5.1. «Должность на тендерных площадках — 6 из 6 не печатают»

**Где:** Вводная к проверке (пример дыры)  
**Что не так:** Утверждение противоречит собственному примеру: «Корвяков Константин Евгеньевич, начальник ОМТС» и «Лосев, заместитель главного механика» — обе должности из Tender.pro.

**Что на самом деле:**  
- Структурное поле «должность» в API — действительно пустое (проверено)
- Должность в свободном тексте комментария — есть (2 примера подтверждены)

**Как надо переформулировать в исходном документе:**  
```
Tender.pro:
- Структурное поле «должность» API — пустое у всех 6 проверенных карточек
- Должность в свободном тексте комментария — присутствует (проверено на Корвякове и Лосеве)
- ВЫВОД: парсить комментарий, не полагаться на API-поле
```

### 5.2. «73 человека в 30 компаниях» — неясно, откуда

**Где:** Передача сессии §2.5, передача 29.07 раздел 3  
**Что не так:** Число названо без указания, из какого прогона (структурное поле или старый код, разбиравший текст), проверены ли контакты, какой процент verified.

**Как надо:**  
```
Tender.pro: 73 человека в 30 компаниях.
Источник: [дата прогона], код версии [commit hash].
Проверка: X из 73 имеют verified=true, Y — из структурного поля API,
Z — из свободного текста (требуют ручной проверки перед звонком).
```

## Что НЕ вошло (отброшенные находки)

Выброшены как несущественные или решённые:
- DOLPHIN_TOKEN: противоречие «ФИКС» vs «✅ УСТРАНЁН» — устранён, блокера нет

- Множественные находки вида «требует замера» без конкретного риска — оставлены только те, где отсутствие замера блокирует решение
