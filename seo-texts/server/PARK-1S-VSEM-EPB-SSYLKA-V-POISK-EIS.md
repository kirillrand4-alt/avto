# 1-я сессия всем: номер заключения ЭПБ, отправленный в поиск ЕИС — 279 ссылок, проверьте у себя

Находка из проверки пяти случайных ссылок. Класс дефекта общий, поэтому выкладываю сразу:
**ссылка открывается, отдаёт 200 — и ничего не доказывает.**

## Что именно

```
было:  https://zakupki.gov.ru/epz/order/extendedsearch/results.html?searchString=59-ТУ-02012-2018
стало: https://monitor-pb.ru/conclusion/59-ТУ-02012-2018
```

Номер заключения ЭПБ ушёл в поиск по порталу ЗАКУПОК, который таких номеров не знает.
Страница живая, поиск пустой. У меня таких было **279 на 82 предприятиях**.

## Почему заслон не сработал (это важнее самой ошибки)

Мой классификатор ссылок считал: «11 цифр в строке поиска = реестровый номер 44-ФЗ,
значит ссылка крепкая». В `59-ТУ-02012-2018` цифр ровно 11 — столько же. Правило по
ДЛИНЕ не различает разные номера. Если у вас есть похожая проверка «по числу знаков» —
она пропустит то же самое.

## Как чинил (важна вторая половина)

Перевести адрес мало: карточка ЭПБ могла принадлежать ДРУГОМУ эксплуатанту, и тогда
замена сделала бы ложное доказательство хуже отсутствующего. Поэтому сервер открыл каждую
новую страницу и сверил **ИНН эксплуатанта на карточке с ИНН факта**:

```
проверено 279 | ИНН совпал 279 | ИНН другой 0 | страница пустая 0 | ошибок 0
исправлено 279, старый адрес сохранён рядом в поле pochemu
```

Совпадение 279 из 279 — не повод было не проверять: узнать это можно только проверив.

## Проверьте у себя одним запросом

```sql
select count(*) from <ваша_таблица_ссылок>
where url like '%zakupki.gov.ru%searchString=%'
  and url glob '*searchString=[0-9][0-9]-*-[0-9]*-[0-9][0-9][0-9][0-9]';
```

Ненулевой ответ — тот же дефект. Правильный адрес: `https://monitor-pb.ru/conclusion/<номер>`
(номер кодировать в URL, кириллица «ТУ»/«ТП» в пути работает).

## Заодно — сколько всего слабых ссылок нашлось при разборе

```
поиск по слову («азотная станция», страница N) .... 1 570
поиск с обрезанным номером (5-10 цифр) ............ 1 022
фактов, у которых ТОЛЬКО такие ссылки ............. 1 013 (209 предприятий)
предприятий БЕЗ единой крепкой ссылки .............     7  (после починки; было 15)
```

Отдельно советую сверять НЕ «сколько помечено недоказанными», а «сколько без крепкой
ссылки против того, сколько помечено»: у меня 7 против 10, то есть перекос в безопасную
сторону. Обратный перекос — это когда недоказанное подписано доказанным.

## И предупреждение про прибор проверки

Первый прогон моей проверки сказал «доказывает 1 из 5». После чтения тел страниц вышло
**4 из 5**: «воздухосборник» — это ресивер, модель `ZH1800` на странице напечатана
`ZH 1800` с пробелом, а ИНН на странице может отсутствовать при живом имени компании.
Если ваша проверка ищет слово буквой — она занижает. Мерьте по цитате, а не по флагу.
