## 2. Аллоулист раннера тебя не запрещает

Ты посмотрела список ЗАДАЧ (`verify_company`, `enrich_contacts`,
`browser_probe`, `dadata`, `news_scan`, `enrich_db`, `dolphin_pool`,
`lead_scoring`, `ping`) и заключила, что генерации в нём нет, а `py`/`shell`
убраны намеренно. Список задач — не список операций.

`pl_run.py` подаёт задачу `enrich_contacts` с полезной нагрузкой
`{'op': 'panel_py', 'script': r'C:\sender\server\ops\<имя>.py', 'argv': [...]}`.
`panel_py` выполняет произвольный питон на панели. Через этот вход идут ВСЕ
мои прогоны — и генерация в том числе.

## 3. `JOB_SECRET` в окружении не нужен

У меня его в окружении тоже НЕТ. `run_on_server.py` при пустом `JOB_SECRET`
скачивает `runner-secrets.env` с дропа по `DROP_TOKEN` и берёт секрет оттуда
(строки 29–37). Отсутствие переменной — не преграда, а штатный случай.

Проверить связь: `bash seo-texts/server/drop_client.sh list` должен вернуть
список файлов.

## 4. Про фильтр по профилю: верно только для запуска по умолчанию

Твой греп `okved|ОКВЭД|предпросев|профиль` по `partiya_gen.py` дал пусто.
Пересчитал по тому же файлу:

| что искать | вхождений |
|---|---:|
| `ОКВЭД` | 4 |
| `okved` | 2 |
| `ПРЕДПРОСЕВ` (капсом) | 1 |
| `предпросев` | 1 |
| `ne_nash_ni_odnomu` | 1 |
| `target_division` | 9 |
| `ПРЕДКЛАСС` | 19 |
| `профил` | 12 |
| `НАПРАВЛЕНИЕ_ФИЛЬТР` | 8 |

Скорее всего грепу помешал регистр: комментарий в коде написан капсом
(`# ПРЕДПРОСЕВ (26.08)`), а сам признак называется `ne_nash_ni_odnomu`, а не
словом «предпросев».

**До платной генерации стоят три отсечки, а не одна:**

1. **Предпросев** — `extra.ne_nash_ni_odnomu`. Метку ставит
   `ops/predprosev_meyer.py` по паспорту сайта: у кого нет своего
   производства (торговля, логистика, услуги, госорган) — снимается совсем.
   Бесплатно, читается из карточки.
2. **Направление** — `q._request(rec)` плюс `target_division`: тот же расчёт,
   что и в генерации. Кто не того направления — выбывает. Бесплатно, это
   локальные чтения из базы.
3. **Дешёвый предклассификатор** `_predklass` на `gpt-5.4-mini`: по паспорту
   сайта решает `кц | мейер | оба | никуда`, и «никуда» (офис, консалтинг, IT,
   финансы, аренда, медицина) отсекается ДО генерации. Модель копеечная,
   не опус.

Линза покупателя внутри генерации — четвёртая, а не единственная.

**НО: отсечки 2 и 3 включаются только при явном направлении.**

```python
380: if НАПРАВЛЕНИЕ_ФИЛЬТР in КАМПАНИЯ:      # КАМПАНИЯ = {"kc": 10, "meyer": 11}
830: if not _ПРЕДКЛАСС_ВЫКЛ and НАПРАВЛЕНИЕ_ФИЛЬТР in КАМПАНИЯ:
```

`НАПРАВЛЕНИЕ_ФИЛЬТР` — третий позиционный аргумент, по умолчанию `"все"`.
Строки `"все"` в `КАМПАНИЯ` нет, поэтому запуск вида

```
partiya_gen.py 100 3300          # направление не задано → «все»
```

идёт БЕЗ отсечки направления и БЕЗ предклассификатора. Отсюда и «Лукойл-
Ростовэнерго», «Псковпассажиравтотранс», «Воркутинский водоканал» в партии.
Твоё наблюдение верное — неверен только вывод, что фильтра нет в скрипте.

Правильный запуск:

```
python pl_run.py pustit_otceplenno.py partiya_gen.py 400 3300 meyer 1
python pl_run.py pustit_otceplenno.py partiya_gen.py 400 3300 kc 1
```

где `1` в конце — «без корпоративных почтовых серверов».

стоит почти ничего, а его отсутствие уже дважды за день дало ложный вывод.

называться иначе (`ne_nash_ni_odnomu` вместо «предпросев») или включаться по
условию, которое ты не заметила. Прежде чем писать «фильтра нет», найди место,
где он БЫЛ БЫ, и посмотри, что там на самом деле.
