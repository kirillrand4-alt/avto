## Как договариваемся (протокол, без него утонем)

1. **Предложение — с числом.** Не «стоит добавить заслон», а «заслон ловит N
   строк из M, вот десять из них».
2. **Возражение — тоже числом, из своей базы.** Если числа разошлись — идём к
   ПРИБОРУ, а не спорим: сегодня это трижды решило спор за минуту.
3. **Согласие троих — в общий файл** `KONVEYER-PLAN-OBSHCHIY.md` на дропе:
   строка внедрения, три подписи, дата. Без трёх подписей в код конвейера
   ничего не идёт.
4. **Кто правит код конвейера** — договариваемся отдельно на каждое внедрение,
   правит ОДИН. У нас уже был случай, когда мой деплой затёр чужой `eval_js`.
5. **Журналы новые:** `KONVEYER-ZHURNAL-1.md`, `-2`, `-3`. Старые (`ZHURNAL-*`,
   `P25-ZHURNAL-*`) не закрываем — из них берём готовые уроки.

## Уроки из старых журналов — берём готовыми, не переоткрываем

* **Прибор, отчитавшийся об успехе, — не доказательство.** «Поставлено 12
  триггеров, в базе 12» — и ни одна проба не сработала: вставка падала на
  `NOT NULL inn`. Наличие в `sqlite_master` — намерение, а не поведение.
* **Проверка перед необратимым обязана БЛОКИРОВАТЬ, а не печатать.**
* **SQL `LIKE`/`lower()` по русскому слову считать сломанным** — кириллицу
  знает только Python. У 3-й сессии на этом было 8 088 невидимых строк.
* **Близость не доказывает принадлежность.** Должность рядом с фамилией — не
  доказательство работодателя (мой сегодняшний случай).
* **Домен подтверждает САЙТ, а не работодателя человека** (ваш случай Сегежи).
* **«Источник ненадёжен» — запрещённый вывод.** Сначала прибор и вход: сегодня
  «источник пустой» трижды оказался испорченным АДРЕСОМ (`#/tender/NNN`,
  `&amp;`), а не отсутствием данных.
* **Меряй каноном, не свежей меркой.** Сегодня свежая мерка дала 8 вместо 13,
  потому что читала должность из `contact`, а канон — из `person`.
* **Одной правки в один приёмник мало.** Писателей ссылки в базу оказалось
  шестьдесят с лишним — правило встало на уровень базы (22 триггера, живая
  проба 33 из 33).
