# Панель: окно авто-отправки настраиваемо + сессия не разлогинивает + понятные причины (2026-07-24)

По запросу владельца. Поверх ветки движка + patches (AI-генерация).

## 1. Окно авто-отправки — настраивается из панели (не правя yaml)

Владелец: «отправлять с 9 до 11 утра пн-чт + настраивать можно (не все в Москве)».
Только для **АВТО-отправки**; ручное подтверждение из очереди окно НЕ ограничивает
(`pick_mailbox(manual=True)`).

- **store.py**: таблица `panel_settings(key,value,updated_at)` + `get_setting/set_setting`
  (JSON-значения). Живая настройка без рестарта/правки конфига.
- **sender.py** `_within_window`: сперва `store.get_setting("sending_window")`
  (override), иначе `config.sending_window()`. Override:
  `{days:[1,2,3,4], start:"09:00", end:"11:00", tz:"Europe/Moscow"}`.
- **api/app.py**: `GET/POST /sending-window` (POST — только owner; валидация
  дней 1-7, HH:MM, start<end; аудит `sending_window.set`). `WindowBody`-модель.
- **фронт** (`views.tsx` → экран «Ящики» карточка «Окно авто-отправки»):
  чекбоксы дней (Пн-Вс), `time`-инпуты, выпадашка **часового пояса РФ**
  (Калининград … Владивосток), кнопка «Сохранить» (owner). Показывает
  источник (из конфига / задано из панели).
- Дефолт при первом заходе — пн-чт 09:00-11:00 Europe/Moscow (`_WINDOW_DEFAULT`
  в app.py и одноразовая инициализация `panel_settings` при деплое).

## 2. Сессия перестаёт разлогинивать

Владелец: «надоело постоянно авторизовываться». Токен и так в `localStorage`
(`context/auth.tsx`) — перезагрузка браузера при живой сессии НЕ разлогинивала.
Причина частого релогина — TTL сессии 12 ч. **auth.py**: `_SESSION_TTL_HOURS`
12 → **720 (30 дней)**.

## 3. Понятные причины «ящик не готов»

Владелец: «что значит `outside_window`, подпиши в панели». **components/ui.tsx**
`ReadyBadge`: словарь `READY_REASON_LABELS` — `outside_window`→«вне окна
авто-отправки», `paused`→«на паузе», `gate_tripped`→«сработал гейт репутации»,
`quota_exhausted`→«исчерпан дневной лимит». Плюс подсказка в title, что ручная
отправка из очереди уходит всегда.
