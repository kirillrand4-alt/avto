# AI-генерация писем первого касания в панель (2026-07-24)

Вшивание конвейера генерации/проверки холодных писем в ядро панели по спеке
инженера `PANEL-INTEGRATION-SPEC.md` (ветка `rusprom-b2b-email-templates-8rrstf`).
Порт эталона `email-templates/pipeline/regen_kc.py` в **панельный режим**:
генерация по данным ПОЛУЧАТЕЛЯ (не переписывание вариаций).

## Файлы (поверх ветки движка `claude/persona-prompt-seo-sender-vi4tcq`)

- **`ai_letter.py`** (новый модуль) — ядро конвейера:
  - `RULES` — 13 правил ДОСЛОВНО из эталона (юр-рамка 38-ФЗ, отказ один раз,
    голос «подбираю», без тире, канон чисел, оборудование-не-сервис, человечность,
    не-реклама, маршрутизация NEWS/GENERIC);
  - `NEWS_MECHANICS` — 10 механик заходов из `NEWS-ZAHODY.md` (ротация);
  - `gate()` — механический гейт §3: все регексы (тема, стоп-слова, детектор
    отказа `OPTOUT`/`OPTOUT_RE`, числа-допуск, псевдо-новость только в GENERIC,
    объём 45-140, финал «С уважением,», витрина) **+ падежный гейт города**
    (урок 2026-07-24: «в Санкт-Петербург» из шаблонной подстановки → брак;
    несклоняемые «в Иваново» пропускаются);
  - `AiLetterGen.generate()` — цикл: генерация батчами → гейт → верификатор
    (линзы юрист/тон/спам/инженер/факты/структура/человечность одним JSON-вызовом)
    → до 3 раундов доработки + принудительный → не прошло → `rejected` (письма нет);
  - `stamp_overflow()` — анти-штамп §6 (счётчики оборотов по партии, масштаб от 49);
  - `log_results()` — брак-лог `ai_letter_log` (текст, раунды, статус) — сырьё
    для калибровки правил.
  - Движок stdlib: боевой `caller` = `review_lenses.default_caller` (провайдер,
    стриминг, ретраи, фолбэк модели), в тестах — фейковый caller.
- **`personalize.py`** — крюк: если у кампании `config.letter_mode=="ai"`,
  `render()` идёт в `_render_ai()` → `AiLetterGen` по данным получателя (режим из
  `config.ai_mode`: news/generic/auto) → готовое письмо в очередь; брак после всех
  раундов → `PersonalizationGateError` → письмо в `needs_data` (не теряется, не
  уходит вслепую).
- **`kc-facts.json`** — факты (числа/клиенты) для промптов, пересобраны из
  `projects-index.json` (индекс опубликованных проектов сайта): 55 регионов с ≥3
  кейсами, 25 клиентов (по одному на город — упоминается только в письме региона).
- **`test_ai_letter.py`** — 14 тестов: гейт (чистое проходит; ловит стоп-слова/тире/
  числа/тему/псевдо-новость/**склонение города**), анти-штамп, цикл (fix чинит
  брак; безнадёжное → rejected; вердикт верификатора → fix; auto-маршрутизация).

Полный сьют панели: **969 passed** (955 прежних + 14 новых).

## Как включить кампанию в AI-режим

`campaign.config_json`: `{"segment": "...", "letter_mode": "ai",
"ai_mode": "auto"}` (auto: есть `extra.news_object`+`city` → NEWS, иначе GENERIC).
Данные получателя из `extra_json`: `news_object`, `city`, `news_month`, `equipment`.

## Пейсинг и первый прогон (спека §7)

Генерация — фоновой фазой батчами 3-5 (LLM-цикл 30-90 с на письмо, в tick не
гонять). Все письма — в очередь подтверждений (`confirm`), НЕ в отправку.
Первый прогон = только очередь: оператор вычитывает, правки → золотые пары
(`confirm_golden`) → доводка промптов. Пейсинг боя — раз в 10-15 мин буднями.
