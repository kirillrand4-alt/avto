# ЕГРЗ по нашей теме: шире словом, чище разбором

Заказ владельца дословно: «да, там есть полезное, расширяй, только и почисть от мусора
тоже». К словам был приложен снимок первой эксельки с обведённой строкой
«Реконструкция участков водопроводной сети … **до ул. Компрессорная, 1**» — то есть слово
поймало улицу, а не машину.

Файл на дропе: **`EGRZ-NASHA-TEMA.xlsx`** (9 листов), сырьё — **`EGRZ-NASHA-TEMA-2.jsonl`**.

## Ловушка, которая стоила первому заходу 203 записи

Искать надо **подстроку**, а не основу через пробел. `кислородн станц` даёт 0, потому что
в тексте стоит «кислородн**ая** станц**ия**». Из-за этого первый заход потерял 157 записей
по кислороду и 46 по азоту. Обе группы теперь в файле.

## Что нашли глаза, чего не нашло правило

Разбор проверялся дважды: на 30 случайных строках «нашей темы» и на **всех** строках
первого файла, ушедших в отсев. Так нашлись четыре подделки и четыре потери:

**Подделки** (лежали в «нашей теме», не должны были):
* «нагнетательная **скважина**» — нефтяная скважина закачки, а не нагнетатель ГПА;
* «Реконструкция здания компрессорной **под** зал бокса» — машину убирают, а не ставят;
* «комплекс по выпуску деталей турбокомпрессоров» — конкурент;
* «Транспортно-пересадочный узел Компрессорный» — топоним, как обведённая строка.

**Потери** (лежали в «сомнительном», должны были быть в теме):
* «ПАО НЛМК. **Кислородный цех**. Строительство нового КРП-1.1»;
* «азотно**кислородное производство**», «азотно-воздушная станция»;
* «Северсталь. ТЭЦ-ЭВС-2. Здание ЭВД-4 с **установкой компрессора**» — основа «компрессор**а**»,
  а правило искало «компрессор**ная**»;
* «аммиач**но**-холодильная установка» — дефис вместо пробела.

Одна правка правила оказалась слишком широкой и была сужена по ходу: требование
«производств… рядом с компрессором» отсеяло настоящее «здание **производственного -
компрессорной**». Теперь нужен предлог и родительный падеж: «**по производству**
компрессор**ов**».

## Чего в файле нет

* Людей в ЕГРЗ нет вовсе — ни ФИО, ни телефонов. Контакты подтянуты из нашей базы.
* Марки машины практически нет: какой именно компрессор стоит — не отсюда.
* У 126 записей из 1 419 застройщик не назван вовсе (в «нашей теме» у 13) — так в реестре.
* У одной иностранной проектной организации в поле ИНН стоит заглушка `0000000000`;
  она обнулена, иначе пошла бы в счёт «разных предприятий» как отдельное лицо.
* Это **заключения экспертизы**: стройка могла не начаться, а могла и закончиться.

## Как повторить

```
OPENSSL_CONF=<ossl.cnf>  python3 seo-texts/egrz_nasha_tema_vygruzka.py   # выгрузка 15 слов
                         python3 seo-texts/egrz_nasha_tema_razbor.py     # классы и причины
python3 seo-texts/zapusk_na_servere.py seo-texts/egrz_nt_kontakty_server.py  # контакты из базы
                         python3 seo-texts/egrz_nasha_tema_excel.py      # сборка эксельки
```

`ossl.cnf` нужен из-за legacy TLS renegotiation на egrz.ru: без него curl отдаёт код 000 и
источник выглядит закрытым.

```
openssl_conf = default_conf
[default_conf]
ssl_conf = ssl_sect
[ssl_sect]
system_default = system_default_sect
[system_default_sect]
Options = UnsafeLegacyRenegotiation
CipherString = DEFAULT:@SECLEVEL=0
```

Запросы идут **через curl**, а не urllib: мой urllib получал HTTP 500 на каждом запросе там,
где curl минутой раньше отвечал 200. Это дефект моего клиента, а не реестра.
