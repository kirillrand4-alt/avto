| Параметр | Значение | Комментарий |

| Позиций в каталоге | 35 | Округлять до 30, дописать «с учётом исполнений» |
| Мощность | 1.5-22.0 кВт | Диапазон всей линейки |
| Давление | 8-10 бар | Только два стандартных значения |
| Производительность | 130-2440 л/мин | Диапазон от младшей до старшей модели |
| Ресивер | нет данных | Не упоминать встроенные ресиверы |
| Безмасляные | 0 | Все маслозаполненные |
| Частотник | 0 | Нет VFD в этой категории |
| Исполнение с ресивером | 0 | Все компрессоры поставляются без ресивера |
| Исполнение с осушителем | 0 | Без встроенных осушителей |

| Ременный привод | 21 | Позиций с ременным приводом |

**Что можно выводить из этих данных:**
- «около 30 позиций с учётом исполнений»
- конкретные границы диапазонов мощности, давления, производительности
- соотношение прямого и ременного привода (40% / 60%)
- отсутствие частотника, встроенных ресиверов и осушителей как характеристику линейки

**Что НЕЛЬЗЯ:**
- средние цены (они в карточках)
- «типовая комплектация для 70% заказов» (нет данных)
- срок службы
