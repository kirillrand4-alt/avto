# План работ: производство страниц брендовой сетки

Решение владельца 20.08: **«делаем всё, публиковать буду по очереди»**.
Значит производим полный объём, отдаём партиями, публикация на стороне владельца.

Этот документ — про производство. Правила и решения — в `SVOD.html`,
экономика и приоритеты — ниже.

---

## 1. На чём стоит приоритет

Не на количестве кликов, а на ожидаемых деньгах со страницы. Это поправка
владельца, и она перевернула мой прежний порядок.

| | Кликов/мес | Лидов при 1/60 | Чек |
|---|---|---|---|
| винтовые, вся сетка | 2 296 | ~38 | ~350 тыс. |
| газ и МКС, 9 страниц на prokompressor | ~43 | ~0,7 | **2-10+ млн** |

Один модуль равен шести-тридцати компрессорам в выручке. При замеренных
**4,8 клика со страницы в месяц** шестьдесят газовых и модульных страниц дают
порядка 290 кликов и около пяти лидов в месяц — в деньгах это больше, чем вся
винтовая категория, при восьмикратно меньшем трафике.

Отдельно: газовых обращений было мало **потому что страницу завели недавно**,
а не потому что рынок мал.

### Чем ограничен перенос этой цифры

4,8 клика со страницы — цифра prokompressor, домена с 29 тысячами URL
и накопленным весом. Домены не линкуем, значит новую страницу на слабом сайте
подпереть нечем. Поэтому очередь доменов строится не по спросу, а
**по способности домена ранжироваться**:

1. **prokompressor.ru** — 4,8 клика со страницы подтверждены;
2. **enger-air.ru** — 861 клик в месяц, из них чистых 856; свой газовый товар;
3. **berg-kompressor.ru, zif-kompressor.ru, remeza-kompressor.ru** — есть свой
   товар или уже есть показы по теме;
4. **остальные** — по одной пробной странице, расширяем по факту отдачи.

`berg-compressor.com` в замеры не берём: 93% его кликов аномальные, эффект
текста там не измерить.

## 2. Очередь производства

### Волна 0. Данные и починки (без генерации)

| Задача | Выход | Блокирует |
|---|---|---|
| Инвентаризация каталога по всем доменам | `katalog-inventory.json` | всё |
| Загрузка карточек: центробежные всех брендов, газовое ЗИФ и Atlas Copco | карточки в Битриксе | волны 1 и 2 |
| Дубль МКС на enger-air: 301 на `/catalog/mks/` | — | волну 1 |
| Тайтл Ekomak про Pneumatech | — | — |
| Карта сайта dali: ни одной карточки товара | — | тексты для dali |
| Фасетные посадочные: единый ЧПУ, canonical, закрытие сырых фильтров | миграция | волну 3 |
| Проверка остальных 17 сайтов на ту же фасетную поломку | список | волну 3 |
| Свежая выгрузка запросов и спек-матча | файлы | замеры |

**Правило-гейт:** меньше **восьми** карточек в разделе — страница
не генерируется. Порог поднят с трёх: текст на категорию с тремя-семью
карточками не даёт ни поиска (мало товара), ни конверсии (выбирать не из чего).

**Ещё два блокера, добавленных проверкой:**

- **Сверить `brands-allow.json` с реестром дилерских договоров.** Белый список
  собран из выгрузки, то есть отражает наличие товара, а не право им торговать.
  Если в нём есть бренд без договора, текст выйдет со словами «официальный
  дилер» и это претензия от производителя. Час работы, но без него каждая
  генерация — рулетка.
- **Payload обязан хранить связь числа с источником.** Сейчас число «3800 л/мин»
  в payload есть, а из какой карточки и для какого исполнения — нет. QA
  проверяет «число есть», но не «число про то». Это ровно та ошибка, которую
  я сам сделал с ВК-22, приняв пять исполнений за характеристику одной машины.

### Волна 1-пилот. Десять страниц вместо шестидесяти

**Правка по итогам второй проверки.** Множитель 4,8 клика со страницы снят
с prokompressor — домена в 29 тысяч URL. Переносить его на dali с восемнадцатью
URL в карте методологически неверно: там та же страница даст скорее 0,8-1,2
клика за первые три месяца. Значит прогноз не 290 кликов, а 50-80, и если газ
даст один лид вместо пяти против тридцати восьми у винтовых — приоритет
переворачивается.

Поэтому: **сначала десять страниц** (шесть на prokompressor, четыре
на enger-air), публикация сразу, замер через месяц, пересчёт прогноза.

- отдача 3+ клика со страницы — расширяем на остальные четыре домена;
- 1-2 клика — останавливаем газ и переходим к категорийным.

Пилот стоит порядка пятнадцати часов и страхует от месяцев работы не в ту
сторону.

### Волна 1-полная. Газ и модули на сильных доменах

Самый высокий чек, домены способны ранжироваться.

| Сайт | Страницы |
|---|---|
| prokompressor | центробежные (категории нет, 22 карточки Enger лежат плоско) |
| enger-air | МКС переписать, модульные кислородные завести, модульные азотные усилить |
| zif | центробежные СЦЭ, азотные, кислородные, безмасляные СВЭБ, спиральные |
| berg-kompressor | МКС переписать |
| remeza | МКС МКР, генераторы азота RNS |
| ac-kompressor | центробежные ZH/ZR, азотные NGP+, кислородные OGP |

### Волна 2. Центробежные и модули на остальных

Dali DLTA, пробные страницы модулей на comaro, crossair, abac, kraftmann,
fini, ironmac, ekomak, cmprg, oil-free, dizel-compressor — **по одной,
с замером через месяц**, расширение только по факту.

### Волна 3. Фасетные посадочные

Только после технической раскладки. Правило отсечения: одна фасета —
индексируем при достаточном числе товаров; две — из утверждённого списка пар;
три и больше — canonical.

**Важное из данных:** по запросу «компрессоры 37 квт» уже показываются семь
наших доменов. Фасеты разводим брендом в запросе — «компрессор Berg 37 кВт»,
а не «компрессоры 37 квт» на семи сайтах.

### Волна 4. Категорийные описания

188 категорий на 16 сайтах плюс 21 на enger-air. Основной объём, самый низкий
приоритет по чеку.

### Волна 5. Кейсы и сравнения

Кейсы: 5580 реализованных проектов, опубликовано 1018. На сателлитах —
обезличенно, фото из банка на 351 кадр. Сравнения — только относительные цены.

## 3. Конвейер одной страницы

```
инвентаризация карточек домена
   -> payload (числа, серии, диапазоны, проекты, фото)
   -> ТЗ по шаблону 13 разделов        [gen_tz.py]
   -> генерация текста                  [gen_provider.py]
   -> механический QA                   [qa_text.py]
   -> линзы + сквозная проверка чисел
   -> пересечение скелетов, порог 40%
   -> series_check.py между сайтами
   -> сборка HTML + CSV для вставки
   -> проверка размещения после публикации
```

Гейты, на которых страница не проходит дальше:

- карточек в разделе меньше восьми;
- число в тексте, которого нет в payload;
- **число из payload использовано без своего контекста** в радиусе двухсот
  знаков (для какого исполнения, из какой карточки);
- марка, которой нет в `brands-allow.json`;
- ссылка за пределы своего домена;
- пересечение скелета с соседней страницей выше 40%;
- байлайн на брендовом сайте;
- абсолютная цена в теле текста.

## 4. Чем меряем результат

Не кликами. **Лидами по типу оборудования** — иначе пять процентов роста
трафика скроют внутри себя два модульных запроса, которые перекрыли всё
остальное.

| Метрика | Как считаем | Зачем |
|---|---|---|
| лиды по типу оборудования | CRM | единственная метрика, отражающая деньги |
| клики по темам | выгрузка запросов, без аномальных строк | отдача страницы |
| клики со страницы в месяц | то же | множитель для планирования, сейчас 4,8 |
| пересечение доменов по запросам | скрипт по выгрузке | ранний сигнал аффилиата: сейчас 10,1% Яндекс, 30,5% Google |
| размещение | `check_placement.py` | генерация не равна публикации |
| **звонки, а не только формы** | коллтрекинг | в B2B заметная часть лидов идёт по телефону из шапки. Метрика «лиды из CRM» их не увидит, и рост будет выглядеть нулевым |
| **поведение до ранжирования** | глубина просмотра, возвраты на выдачу, CTR сниппета | при восемнадцати доменах на одну тему это то, по чему Яндекс выбирает выжившего. Формируется раньше позиций |
| **консистентность между доменами** | сверка тиров и формулировок | на одном сайте Berg в начальном сегменте, на другом премиум — пользователь видит оба в одной выдаче |

Из всех замеров исключаем аномальные строки: 65% кликов сетки не от людей,
93% из них на одном домене.
