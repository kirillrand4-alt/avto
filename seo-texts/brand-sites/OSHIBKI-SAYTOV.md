# Реестр поломок на сайтах сетки

Найдено при разведке 20.08.2026 (карты сайта, метатеги, меню каталогов 18 доменов).
Каждая запись: полные ссылки, что именно не так, чем подтверждено, что делать.

Статусы: `открыто` / `в работе` / `закрыто <дата>`.

## 1. Enger: два раздела МКС с дословно одинаковым H1 — открыто

**Полные ссылки:**

```
https://enger-air.ru/catalog/mks/
https://enger-air.ru/catalog/tsentrobezhnye-kompressor1y/
```

Третья страница, с которой это соседствует и которую нельзя задеть при исправлении:

```
https://enger-air.ru/catalog/tsentrobezhnye-kompressory/
```

**Что не так.** Проверено 20.08.2026, обе отдают HTTP 200:

| | `/catalog/mks/` | `/catalog/tsentrobezhnye-kompressor1y/` |
|---|---|---|
| TITLE | Модульные компрессорные станции Enger - заказать на официальном сайте завода | Модульные компрессорные станции Enger |
| DESCRIPTION | Модульная компрессорная станция - это готовое автономное решение для обеспечения производства сжатым воздухом. Пришлите нам техническое задание info@enger-air.ru… | Модульные компрессорные станции Enger |
| H1 | Модульная компрессорная станция – компрессоры Enger в контейнере | Модульная компрессорная станция – компрессоры Enger в контейнере |
| текста | 7643 симв | 3073 симв |
| robots | index, follow | index, follow |
| canonical | нет | нет |
| в карте сайта | да | да |

Четыре факта вместе и дают кривой снипет:

1. **H1 совпадает дословно**, тайтлы отличаются только хвостом.
2. У дубля **дескрипшен — точная копия тайтла**. Поисковику нечего показать
   в сниппете, и он собирает его из тела страницы.
3. **Canonical не проставлен ни на одной**, обе `index, follow` — то есть обе
   допущены в индекс и конкурируют.
4. Дубль сидит на URL про центробежные компрессоры, с опечаткой:
   `tsentrobezhnye-kompressor` **1** `y`. Похоже на заготовку под второй раздел
   центробежных, в которую залили контент МКС.

**Важная деталь для исправления:** дубль **не слинкован с главной** (проверено:
ноль упоминаний в HTML главной страницы). Он живёт только за счёт карты сайта,
то есть страница-сирота. Значит 301 на `/catalog/mks/` ничего не сломает
в навигации — терять нечего.

**Что делать:**

1. `301` с `/catalog/tsentrobezhnye-kompressor1y/` на `/catalog/mks/`.
2. Убрать дубль из карты сайта.
3. Проставить `canonical` на `/catalog/mks/` на саму себя.
4. Переписать дескрипшен `/catalog/mks/` по формуле «состав раздела с числами +
   что получает покупатель» (см. `PLAN.md`, раздел 4).
5. Если раздел под центробежные всё-таки нужен вторым — не воскрешать этот URL,
   а разводить с живым `/catalog/tsentrobezhnye-kompressory/` (12 754 симв),
   иначе получим второго каннибала на том же месте.

**Как перепроверить:**

```bash
for u in https://enger-air.ru/catalog/mks/ \
         https://enger-air.ru/catalog/tsentrobezhnye-kompressor1y/; do
  echo "$u"; curl -sL -A "Mozilla/5.0" "$u" \
    | grep -oiE '<title>[^<]*|<h1[^>]*>[^<]*|name="description" content="[^"]*'
done
```

## 2. Enger: разделы МКС и центробежных без карточек товара — открыто

```
https://enger-air.ru/catalog/mks/
https://enger-air.ru/catalog/tsentrobezhnye-kompressory/
```

В карте сайта enger-air.ru (1198 URL) под этими двумя разделами **ноль карточек**.
Раздел без товара — это страница, из которой сниппету нечего взять, кроме общего
текста. Связано с пунктом 1: даже после склейки дублей снипет останется слабым,
пока в разделе нет моделей.

Для сравнения: под `/catalog/azotnye-ustanovki/` карточки и подразделы есть
(колонного типа, модульного типа, мембранные).

## 3. Ekomak: тайтл раздела рекламирует чужой бренд, дескрипшена нет — открыто

```
https://ekomak-kompressor.com/catalog/generatory-azota-ppng/
```

- TITLE: **«Генераторы азота Pneumatech»**
- DESCRIPTION: **отсутствует полностью**
- H1: «Генераторы азота Pneumatech»
- В тексте страницы Ekomak упомянут 3 раза.

PPNG — серия **Pneumatech**, не Ekomak. Оба входят в группу Atlas Copco, но
покупатель, пришедший на брендовый сайт Ekomak, этого не знает. Плюс отсутствие
дескрипшена означает, что сниппет собирается автоматически из первого попавшегося
куска текста.

**Что делать:** решить, чей это раздел. Если возим Pneumatech PPNG под маркой
Ekomak — тайтл должен объяснять связь, а не подменять бренд. Если это ошибка
переноса — переписать под Ekomak. Дескрипшен добавить в любом случае.

## 4. oil-free.ru: H1 не совпадает с содержимым страницы — открыто

```
https://oil-free.ru/catalog/modulnye-kompressornye-stantsii/
```

- TITLE: «Модульные компрессорные станции - заказать в Центре безмасляного воздуха»
- H1: «Безмасляные компрессоры в модульном исполнении»
- В тексте: **20 упоминаний Enger**

Страница фактически про МКС Enger, а тайтл и H1 — про абстрактную безмасляность.
Ни один из трёх сигналов не совпадает с двумя другими, поэтому сниппет не попадёт
ни в запрос «мкс enger», ни в «модульная компрессорная станция безмасляная».

## Как обновлять реестр

Новая поломка — новый пункт с полными ссылками и способом перепроверки.
Закрытая — статус меняется на `закрыто <дата>` с одной строкой о том, что сделали;
пункт не удаляется, чтобы через полгода было видно, что уже чинили.
