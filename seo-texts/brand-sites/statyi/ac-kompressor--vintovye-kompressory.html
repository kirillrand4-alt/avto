Класс чистоты воздуха ISO 8573-1: сертификация для пищевых и фармацевтических производств

Стандарт ISO 8573-1 определяет содержание твёрдых частиц, воды и масла в сжатом воздухе по классам. Безмасляные компрессоры Atlas Copco серий ZR, Z обеспечивают класс 0 по маслу - технически безмасляные, подтверждается сертификатами производителя.

Для пищевых производств это требование ХАССП и технических регламентов Таможенного союза. Для фармацевтики - GMP. Сертификация документально: сертификаты соответствия, протоколы испытаний, декларации.

Класс чистоты воздуха по ISO 8573-1 для конкретной модели компрессора в наших данных не указан системно; точный класс уточняется по паспорту выбранной модели и подтверждается документами производителя.

Масляные компрессоры требуют дополнительной фильтрации для достижения высоких классов чистоты. Безмасляные дают класс 0 по маслу конструктивно - воздух не контактирует с маслом в процессе сжатия.
