# Шаблоны холодных писем КЦ (компрессоры + генераторы), редакция v3

Основа: документ владельца «Отредактированные шаблоны холодных писем Компрессор
Центра» (вторая волна редактуры) + разбор пилота 20-21.07.2026 (61 письмо s1->s2,
см. PILOT-2026-07-20-RAZBOR.md). Юр-рамка 38-ФЗ соблюдена в каждом шаблоне:
без «предлагаем/скидка/акция/купите», без цен, с вежливой опцией отказа.

## Что изменилось против v2 (док владельца)

1. Убраны длинные тире «—» (правило анти-ИИ): только дефис или перестройка фразы.
2. Из тела убрана подпись с компанией и контактами. Пилот показал дубль подписи
   в 59 письмах из 61: тело заканчивалось «ООО «Руспром» · prokompressor.ru», и
   движок дописывал юр-футер с тем же текстом. Тело теперь кончается на
   «С уважением,» - имя менеджера и юр-футер подставляет движок при отправке.
   Формат футера (решение владельца 23.07): «ООО «Руспром», ИНН 2221239841» -
   БЕЗ домена (он виден в адресе отправителя) и БЕЗ строки «отписаться»
   (отказ обрабатывается по тексту письма, повторных писем без согласия нет).
3. Каждый шаблон закрывается опцией отказа (в пилоте её не было ни в одном письме).
4. Голос менеджера честными глаголами (уточнение владельца 23.07): поставляет
   КОМПАНИЯ, менеджер лично подбирает/считает/ведёт направление. «Я поставляю»
   запрещено наравне с «мы поставляем».
5. Добавлены два генераторных шаблона (азот, кислород) - сегмент КЦ включает
   генераторы, в пилоте эти темы дали самые живые формулировки.

## Merge-поля и контракт

Поля движка (Personalizer._base_fields): {greeting} {first_name} {company_name}
{okved} {segment} {contact_name} и др. Незаполненное поле роняет отправку, поэтому:

- Шаблоны 1-2 (именные) используют {greeting}/{first_name} - слать ТОЛЬКО по
  контактам с заполненным именем.
- Шаблоны 3-6 (общий адрес) именных полей не трогают.
- {news_event} и {news_object} - поля extra для батчей news-лидов. Контракт
  импортёра: news-батч обязан заполнять оба, иначе использовать шаблоны без
  инфоповода.
- {manager_name} и {manager_role} - имя и должность отправителя. В core-полях
  движка их пока нет: задавать через extra при импорте или добавить
  campaign-уровнем на ветке движка (пометка для ветки
  persona-prompt-seo-sender-vi4tcq, здесь не правим).
- Канон чисел (уточнение владельца 23.07): на сайте 1079 ОПУБЛИКОВАННЫХ
  проектов, всего в CRM больше 5580. Региональные числа (44 СПб, 51 Новосибирская
  и т.д.) - это счётчики по опубликованным кейсам, в письме их подавать как
  «N опубликованных кейсов по региону» (проверяемый факт, не обещание), а общий
  объём - «больше 5580 внедрений по стране». Не смешивать: «5580 опубликованных» -
  неправда, «в регионе всего N внедрений» - занижение. Ссылки в первое письмо не
  вставлять; подборку кейсов региона предлагать прислать в ответ.
- {equipment_pitch} - AI-поле по ОКВЭД. Контракт стиля: 1-2 предложения,
  конкретная боль отрасли применительно к сжатому воздуху, без цен, без
  «предлагаем», без обещаний экономии в процентах, если числа не из payload.

## Шаблон 1: именной адрес + инфоповод

Тема: `{first_name}, вопрос по компрессорам для {news_object}`

```
{greeting}

Меня зовут {manager_name}, я {manager_role} в Компрессор Центре.
Подбираю компрессорное оборудование для промышленных предприятий.

Увидел новость: {company_name} {news_event}. На этом этапе обычно
уже считают энергозатраты и выбирают компрессор. Если отложить,
потом это оборачивается переделкой трубной разводки и потерянными
неделями на переоборудование.

Скажите, этот вопрос у вас уже закрыт или пока в работе?

Если решение принято - извините за письмо, вопросов больше не
будет. Если тема открыта, покажу 2-3 модели, которые обычно
ставят на подобных объектах.

С уважением,
```

## Пул тем (юр-чистые, без цен и продающих слов)

- `{first_name}, вопрос по компрессорам для {news_object}`
- `Вопрос по компрессорам - {company_name}`
- `Один вопрос про ваш компрессор`
- `один вопрос про осушитель воздуха`
- `как вы сейчас получаете азот`
- `Компрессоры под новый цех` (только для news-батчей с инфоповодом)

НЕ использовать в темах: «цена», «цены», «лизинг», «ROI», «скидка», «акция»,
«только сегодня», «в наличии», «снизим/сэкономим» (продающее обещание) - по
судебной практике ст. 14.3 КоАП штрафуют за явные рекламные формулировки.
В теле также запрещены: любые суммы в рублях, «пришлю цены» (заменять на
«пришлю варианты и сроки»), «гарантия», «купить», проценты экономии без
источника из payload, канцелярит «реализовали». Числа в темах («53 проекта в Петербурге») - только из
реальных данных projects-index под конкретный батч.

## Чек-лист перед постановкой шаблона в движок

1. Нет «—» (только дефис или перестройка).
2. Нет подписи компании/контактов в теле: последняя строка «С уважением,».
3. Есть вежливая опция отказа.
4. Нет «предлагаем / скидка / акция / купите», нет цен и экономии в процентах
   без числа из payload.
5. Один конкретный следующий шаг (вопрос).
6. Все {поля} шаблона гарантированно заполнены для целевого батча.
7. Объём - один экран, ритм рваный: короткая фраза чередуется с длинной.
8. Голос менеджера честными глаголами (подбираю / веду / помогаю выбрать);
   поставляет - компания. «Я поставляю» и «мы поставляем» запрещены.
