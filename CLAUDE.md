# Контекст репозитория

В репо ДВА независимых проекта:

1. **Корень** (`src/`, `web/`, `RUNBOOK.md`) — антидетект-браузер / GSC-автоматизация.
   У него свои понятия «provider» (движки dolphin/adspower) — НЕ путать с пунктом ниже.
2. **`seo-texts/`** — SEO-тексты для 759 страниц каталога prokompressor.ru
   (генерация через провайдерский API, QA, регенерация, ревьюеры, отчёты).

## Инфраструктура (переменные окружения)

- `DROP_URL` + `DROP_TOKEN` — файловый обменник на сервере владельца
  (`https://parsercompressor.online/drop`). Клиент: `seo-texts/server/drop_client.sh`
  (`list | up <file> | down <name> | del <name>`). Токен передаётся заголовком
  `X-Drop-Token`. Там лежат тяжёлые исходники: выгрузка Битрикса
  (`bitrix-export-full.tar.gz`), каталоги производителей, дампы краулинга,
  финальные CSV. Скачивай оттуда, а не проси у владельца заново.
- `PROVIDER_API_KEY` (+ `PROVIDER_BASE_URL`, по умолчанию `https://router.cheap`) —
  Anthropic-совместимый API для тяжёлой генерации (модель `claude-fable-5`).
  Рабочий клиент с ретраями/WAF-обходом: `seo-texts/gen_provider.py` (`make_client`,
  `call`). Стриминг обязателен; правило владельца: «всю тяжёлую работу — через
  этот API», квоту сессии беречь.

Фраза владельца «проверь drop и провайдера» означает:
1) `bash seo-texts/server/drop_client.sh list` → должен вернуть список файлов;
2) короткий тестовый вызов провайдерского API через `gen_provider.call()`.

## seo-texts: карта проекта

- `gen/payload-*.json` + `gen/result-*.json` — данные и финальные тексты 759 страниц;
  `gen-orig/` — бэкап до правок. `publish/` — plain/schema варианты, `make_csv*.py` — CSV.
- `qa_text.py` — механический QA-гейт (вызывается на каждой генерации).
- `regen_driver.py` — регенерация с keep-best и инженер-проверкой каждой 6-й страницы.
- Отчёты: `seo-effect-report.md`, `review-*.md`, sweep-и. Очереди/состояние: `regen-*.json`.
- Стайлгайды: `gen/STYLE-GUIDE*.md`. Факты брендов (гейт по достоверности): `kb/`,
  `brand_facts_lib.py`.

Правила текстов: без длинных тире, без `<ul>` (CSS сайта рисует тире-маркеры),
байлайн «ООО «Руспром»», числа только из payload, фото-блок — кликабельная
карточка-ссылка. Полные правила — в стайлгайдах и промптах `gen_provider.py`.
