# XMLRiver-путь: что он даёт (кратко для другой сессии)

Ветка `claude/great-ride-fx2pi9`. Полный отчёт — `baza-kontaktov/PILOT-XMLRIVER-OTCHET.md`, код — `baza-kontaktov/pilot/`.

## Суть

Отраслевые запросы с регионом (Яндекс и Google через XMLRiver) → домены → главная страница → балл профиля и ИНН/УНП
→ сверка с тем, что уже есть на сервере. Без LLM.

## Пилот 05.10

| | |
|---|---|
| Запросы | 802: 401 P1-фраза × 2 поисковика, только топ-10 |
| Регионы | 2 региона на сегмент + РБ |
| Стоимость | 20 ₽ |
| Время | ≈ 1 ч сбор + 6 мин проверка |

- Найдено **2 031 домен**, из них **609 профильных**. Профильный = живой сайт, не площадка, оборудование, розница или СМИ, балл ≥ 4.
- **76 % профильных — новые**: их домена и ИНН нет ни в `enrich.db`, ни в `obzvon-index.db`, ни в базах «Мейер».
  - старые по домену — 23 %;
  - старые по ИНН — 1 %.
- Где ИНН на сайте найден, с базой совпали только 5 из 97. Значит, старые базы эти сегменты почти не покрывали.
- **Исключение — элеваторы:** 54 % уже в базе.
- **Самые «новые» сегменты:** ягоды (91 % новых), орехи, экспортёры, семеноводы.
- **Ручная проверка:** профильных компаний среди новых ≈ 60–65 %. Остальное — дилеры, дистрибьюторы, госучреждения.
  - Без фильтра типа сайта точность была 30 %.
  - Фильтр `tip_sayta` уже в коде.
- **Итог: ≈ 290 реально новых профильных компаний за 20 ₽.**
  - 92 из них — с ИНН/УНП на сайте: `pilot/inn_novye.csv` с ручной оценкой, 56 «профильная».
  - Остальным нужен обход сайта.
- **Яндекс** даёт 84 % профильных доменов. **Google** добавляет +16 % уникальных.

## Что знать, чтобы повторить

- **Цена и выдача XMLRiver:** 0,025 ₽ за запрос, 10 результатов на запрос. `groupby` больше 10 игнорируется, так что топ-50 = 5 запросов.
- **Ошибки:** «Выполните перезапрос» не списывается — ретраить.
- **Гео:** серверные скрипты его не передают. Работает так (проверено пробой):
  - Яндекс: `lr=<код региона>` + `domain=ru|by`;
  - Google: `country=2643` (РФ) или `2112` (РБ).
- **Запуск** — на сервере, ключ остаётся там:

  ```
  python3 baza-kontaktov/pilot/na_server.py pusk.py serp 1
  ```

  Затем `analiz etalon | proverka | otchet` и `pusk.py status`. Сбор идёт 3 потоками, ≈ 25 запросов/мин, с продолжением с места остановки.
- **Баланс XMLRiver:** ≈ 60 ₽, общий с другими сессиями. Проверка: `na_server.py balans.py`.

## Масштаб

- P1–P2 по всем подходящим регионам — ≈ 14 900 фраз на поисковик.
- Топ-10 Я+G стоит ≈ 750 ₽, только Яндекс — ≈ 370 ₽.
- Ожидание — порядка **3–5 тыс. новых профильных компаний** (грубо).

## Слабые места / что доделать

1. Доучить фильтр профиля:
   - отсекать дилеров, дистрибьюторов, ФГБУ/МКУ;
   - для семян, ягод и орехов требовать признаков собственного производства;
   - откалибровать порог.
2. ИНН на главной и контактах — только у 19 % профильных сайтов. Нужен обход: реквизиты, политика ПДн, PDF.
3. Словарь запросов:
   - удалить 7 нулевых запросов;
   - «экспортёр X {регион}» и «элеватор {город}» тонут в агрегаторах — заменить продуктовыми формулировками;
   - лучшие шаблоны: «… элита РС1 от производителя», «гибриды … производитель семян», «замороженная … оптом производитель», «питомник …», английские «grain trading company Russia».

## Тест 60 идей запросов от моделей (06.10, ≈ 3 ₽)

Идеи — от 6 моделей через провайдерский API (`pilot/idei/svod.csv`, 238 штук); прогнаны лучшие 60.
Регионы — те же, что в пилоте. Итог — `IDEI-TEST.csv` и `IDEI-DOMENY.csv` на drop.

| | Пилот | Идеи |
|---|---|---|
| Запросов (фраз) | 401 | 60 |
| Профильных доменов | 609 | 203 |
| Из них нет в базе | 463 | 150 |
| Нет в базе, на фразу | 1,15 | **2,5** |

- **Нет ни в базе, ни в выдаче пилота:** 69 доменов.
- **Ручная разметка этих 69:** ≈ 30 реальных компаний (≈ 45 %).
  - Примеры: КХП (Раменский, Урбахский, Щигровский, Речицкий, Борисовский), крахмальные заводы,
    молочные комбинаты (сухое молоко), сахарный комбинат, питомники фундука, кедровые заготовители,
    арахис, сублимация ягод, асептическое пюре, белорусские КФХ.
  - Мусор: английские экспортные запросы тянут биржевые и аналитические сайты (commodity3, grainsprices);
    «асептик/ГОСТ» — сайты-справочники ГОСТ и поставщиков ингредиентов; «питомник …» — садовые центры.
- **Лучшие формулировки** (новых на фразу):
  - «питомник привитого фундука …»;
  - «сухое молоко … завод»;
  - «агрофирма выращивание ремонтантной малины …»;
  - «асептический сок концентрат производитель»;
  - «АО КХП приёмка зерна нового урожая»;
  - «давальческая переработка зерна в муку …»;
  - «завод нативного крахмала …»;
  - «rapeseed meal supplier Russia bulk vessel».
- **Пустые:** «КХП услуги хранения зерна {регион}», «ореховодческое хозяйство … {регион}».
- **Вывод:** идеи дают примерно вдвое больше новых на фразу, чем исходный словарь. Их стоит добавить в `zaprosy.csv`,
  особенно для пищевых (новые продукты: сухое молоко, крахмал, сахар, пюре) и элеваторов (форма «АО КХП»).
  Английские экспортные запросы — только вместе с фильтром против бирж и аналитики.

## Словарь обновлён (06.10)

- **+207 идей моделей** с подсегментом `идеи моделей`:
  - 28 в P1 — проверенные, дали ≥ 3 новых для базы;
  - 179 в P2 — проверенные слабее и непроверенные.
- **Не взяты:** идеи про документы и реестры (СДИЗ, апробация, госреестр, ФГИС, расписки), ГОСТ с номерами, лаборатории
  элеваторов — они тянут госсайты и справочники.

  - «экспортёр X {регион}» → P2;
  - «элеватор {город}», «клубника плантация {регион}», «ягодное хозяйство клюква {регион}», «грецкий орех очистка
    цех {регион}» → P3;
  - «экспорт {культура} из России», «заготовка дикоросов {регион}» → P2.
- **Оговорка:** английские экспортные идеи в P1 отчасти держатся на биржевых и аналитических сайтах, которые фильтр
  профиля пока считает профильными. Их стоит гнать только вместе с фильтром против бирж и аналитики.
