# Источники доменов компаний (каталоги, выставки, союзы, реестры)

Проверено 05.10.2026 запросами curl/WebFetch из зарубежной сети (не с сервера в РФ).
Часть российских и белорусских сайтов сбрасывает соединение для зарубежных IP. Такие
сайты помечены «не открылся» и требуют повторной проверки с сервера.

Принцип (PLAN.md, п. 2.1): из каталогов берём **только домены** (и названия для запросов
«"название" город»). Данные о компании и ЛПР берём с её собственного сайта. Домены самих
каталогов внесены в `stop_domeny.txt` с типом `katalog_istochnik`.

Обозначения в таблицах:
- **Сайт в карточке**: да / нет / частично, то есть указано, есть ли у участника ссылка на собственный сайт.
- **Объём**: оценка по странице на момент проверки.

## 1. Экспортёры

**Агроэкспорт (ФЦРЭ АПК Минсельхоза): «Экспортный каталог АПК региона»**
- Список: `https://aemcx.ru/region_reviews/eksportnyj-katalog-apk-regiona-{регион}/`. Поиск по сайту
  `https://aemcx.ru/?s=экспортный+каталог` даёт все каталоги. На странице есть кнопка «Скачать региональный обзор»
  с PDF вида `https://aemcx.ru/wp-content/uploads/2026/07/katalog_altajskij-kraj.pdf`.
- Найдены каталоги: Алтайский край (есть версии на англ. и кит.), Башкортостан, Иркутская, Калининградская,
  Липецкая, Новосибирская, Омская, Орловская, Татарстан, Удмуртия, Хабаровский край (есть версия на кит.),
  Челябинская.
- Сайт в карточке: **да**. В PDF Алтайского края 87 страниц и 74 уникальных домена (минус вузы и ведомства),
  домены извлекаются через `pdftotext` + regex.
- Ценность: компании сами заявили экспорт, поэтому каталог даёт балл к `is_exporter`. Засчитывать ли его
  как «реестр Агроэкспорта = 3», нужно согласовать: это каталог, а не реестр.

**Российский зерновой союз (grun.ru)**
- Члены: `https://grun.ru/membership/spisok_chlenov_rzs.php` ссылается на PDF «Члены РЗС на 20.02.2026»
  (4 стр.; колонки: название, ОПФ, регион, деятельность, сайт). Около 70 членов, около 40 доменов. Среди них
  есть СМИ, банки и производители удобрений, поэтому нужен фильтр по деятельности.
- Сертифицированные ХПП: `https://grun.ru/objectsapk/voluntary_certification/hpp/list_certification/`,
  HTML-таблица по регионам, около 94 элеваторов/КХП с адресами и мощностями. **Сайтов нет**, только название и
  адрес, поэтому их используем как запросы «"название" город» для сегмента «элеваторы».

**Реестры для балла `is_exporter` (по PLAN.md): не проверены в этой итерации**
- Россельхознадзор: `https://fsvps.gov.ru/reestry-2/` (открылся, но со сбросами соединения). Реестры
  предприятий-экспортёров (Цербер, `cerberus.vetrf.ru`) и реестр GACC (китайская таможня, единое окно
  `singlewindow.cn`) не проверялись.
- РЭЦ, `exportcenter.ru`: сбрасывает соединение из зарубежной сети.
- Масложировой союз России, `https://mzhsr.ru/o-soyuze/chlenyi-soyuza`: страница открывается, но списка
  членов в HTML нет (42 предприятия по данным союза; вероятно, логотипы или JS). Проверить вручную.

## Порядок использования

1. Сначала берём источники с прямыми ссылками на сайты: Агроэкспорт PDF, productcenter, Экспоцентр,
   ITE, Руспродсоюз, БелТПП, produkt.by. Получаем домены, прогоняем через `stop_domeny.txt` и фильтр «живой
   собственный сайт».
2. Источники только с названиями (РЗС-ХПП, реестр оригинаторов, zol.ru) превращаем в запросы
   «"название" {город}».
3. Основной объём даёт поиск: `zaprosy.csv` × `regiony.csv`. Перебор начинаем с `agro_priority=1` и
   `segments_likely`, содержащих нужный сегмент. Минус-слова берём из `minus_slova.txt`.
