# Минус-слова для поиска сайтов профильных компаний (к zaprosy.csv)

# Формат: одно слово/фраза на строку; строки с # - комментарии.
#
# ДВА уровня, и это важно:
#   [query:*] - минус-операторы внутри запроса (-слово, -"фраза").
#               Яндекс отсекает ДОКУМЕНТ, в тексте которого слово встретилось хоть раз.
#               Поэтому сюда идут только слова, которых почти не бывает на сайте
#               производителя. «Вакансии», «отзывы», «фото», «магазин», «Wildberries»,
#               «оборудование» есть в меню и текстах многих заводов, в запрос их не ставим.
#   [post:*]  - фильтр ПОСЛЕ выдачи по title + URL (+ сниппет, где указано).
#               Срабатывание = понижение балла / ручная проверка, а не автоматический отсев.
#
# Сегменты: exporters, seeds, food, elevators, nuts, berries (как в zaprosy.csv).
# «купить» и «цена» не используем как минус: «цены приёмки», «закупочные цены» -
# маркер элеватора и трейдера, а «купить оптом» встречается на сайтах производителей.
# Минус-слово в Яндексе отсекает все словоформы («-реферат» = реферата, рефераты...).
# Домены агрегаторов, маркетплейсов, СМИ - в stop_domeny.txt, не здесь.
