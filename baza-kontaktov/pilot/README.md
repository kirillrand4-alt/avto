# Пилот XMLRiver: подготовка (к ТЗ-PILOT-XMLRIVER.md)

| файл | что делает | где запускать |
|---|---|---|
| `vyborka.py` → `pilot_zaprosy.csv` | P1-шаблоны × регионы пилота + минус-слова: 401 запрос на поисковик | песочница |
| `obrabotka.py` | домен eTLD+1/punycode, стоп-лист по суффиксу, пост-фильтр, порталы (≥5 сегментов), балл профиля, парковки, ИНН/УНП с контрольной суммой, статусы | библиотека; `--test` |
| `sbor_serp.py` | выдача XMLRiver (Яндекс + Google), строго 1 поток, jsonl с fsync и продолжением; `--proba` | сервер (ключ только там) |
| `analiz.py etalon / proverka / otchet` | эталон известных доменов/ИНН (базы read-only) → проверка главных → `BAZA-PILOT-DOMENY.csv` + сводка на drop | сервер |

Регионы пилота: элеваторы — Алтайский край, Ростовская обл.; семеноводы — Краснодарский край,
Воронежская обл.; экспортёры — Ростовская обл., Краснодарский край; орехи — Краснодарский и
Ставропольский края; ягоды — Липецкая, Новосибирская обл. + РБ: Брестская, Гомельская обл.;
пищевые — Белгородская обл., Алтайский край + РБ: Брестская, Гомельская обл.

Пилот прогнан 05.10.2026 (топ-10, 802 запроса, 20 ₽): итоги — `../PILOT-XMLRIVER-OTCHET.md`.
Коды `lr` и `country=2643/2112` проверены пробой (`proba.py`). XMLRiver: 0,025 ₽/запрос, 10 результатов
на запрос (groupby больше 10 игнорируется), ошибки не списываются.

Служебное: `na_server.py <скрипт> [аргументы]` кладёт файлы пилота в `C:\sender\_ops\baza_pilot\` и
запускает скрипт; `pusk.py serp N | analiz <этап> | status | stop` — долгие этапы отдельным процессом;
`balans.py` — баланс XMLRiver.
